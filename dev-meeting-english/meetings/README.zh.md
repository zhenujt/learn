# 会议场景：把语法用在站会和周会里

> [English version](README.md) · [返回课程首页](../README.zh.md) · [语法目录](../grammar/README.zh.md) · [学习计划](../00-study-plan.zh.md)

语法课教你**看懂句子**；这一部分教你**在什么时候说什么**。每课都有：这个时刻会发生什么 → 固定的说话公式 → 按功能分组的句子 → 一段完整对话（改写自真实会议，已匿名） → 听到哪些信号说明轮到你 → 可以填空的个人模板 → 练习与答案。

## 7 个场景

| 课 | 什么时候用 | 你最先要会的一句 |
| --- | --- | --- |
| [M01 站会](01-stand-up-updates.zh.md) | 每天的站会，轮到你说昨天、今天、阻塞 | `Nothing from my side.` / `I'm working on …` |
| [M02 周会与 Sprint 同步](02-weekly-sprint-sync.zh.md) | 主持人逐个模块过 Jira 看板，问每个 Story 的状态 | `For the web part, most stories are completed.` |
| [M03 主持会议与共享屏幕](03-hosting-and-screen-sharing.zh.md) | 开场、共享屏幕、看不到屏幕、切换话题 | `Can you see my screen?` / `Let's move to …` |
| [M04 提问与澄清](04-questions-and-clarifying.zh.md) | 没听懂、要确认理解、要追问细节 | `Just to clarify, do you mean …?` |
| [M05 看法与建议](05-opinions-and-suggestions.zh.md) | 表态、同意、委婉反对、提方案 | `I think that works.` / `How about …?` |
| [M06 阻塞、风险与求助](06-blockers-risks-and-help.zh.md) | 卡住了、可能延期、需要别人帮忙 | `I'm blocked by …` / `Could you help me with …?` |
| [M07 收尾与行动项](07-wrap-up-and-action-items.zh.md) | 会议结束、确认谁做什么、会后跟进 | `That's all for today.` / `I'll follow up on …` |

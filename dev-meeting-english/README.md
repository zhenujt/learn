# English for Software Meetings: From Reading Subtitles to Giving Updates

> [中文版](README.zh.md) · [Study Plan](00-study-plan.md) · [How to Read Meeting Subtitles](01-how-to-read-subtitles.md) · [Grammar Index](grammar/README.md) · [Meeting Situations](meetings/README.md)

This is now the **single main course** in this repository. It merges grammar and workplace expressions that used to be spread across several courses, organized by topic and with duplicates removed. Older materials remain as an archive; see the table at the end.

## Who This Course Is For

- Software engineers in China with a weak or rusty English foundation.
- People who join **English stand-ups, weekly meetings, and sprint sync-ups** with **live subtitles**.
- Learners who first want to **understand subtitles**, then **give short updates**, ask questions, and respond.
- People without an English-speaking environment who learn through real meetings, documents, and tools.

Listening is not the main focus because subtitles exist. Subtitles, however, are **transcribed speech**: loose sentences, restarts, non-native grammar, and recognition errors. The real challenge is **parsing spoken sentences quickly**, which requires solid grammar.

## Outcomes

| Phase | Goal | Check |
| --- | --- | --- |
| Phase 1 (weeks 1–4) | Understand short stand-up lines: who, what, done or not | Pass [checkpoint test 1](practice/02-checkpoint-tests.md); write a 3-sentence stand-up update |
| Phase 2 (weeks 5–8) | Follow item-by-item sprint updates; state your module's status | Pass test 2; speak a 1-minute update without notes |
| Phase 3 (weeks 9–12) | Understand sentences with if / because / which; ask and clarify | Pass test 3; ask one clarifying question in a meeting |
| Phase 4 (weeks 13–16) | Follow the main points of a whole meeting; write notes and action items | Pass test 4 and the final test; complete the [12 subtitle drills](practice/01-subtitle-reading-drills.md) |

## The Evidence: Data From Your Real Meetings

Subtitles from 25 real meetings (about 80,000 words; stand-ups, scrum sync-ups, grooming, demos) were analyzed to decide how deeply to teach each grammar point.

**Most frequent structures (per 10,000 words):**

| Structure | Count | Example (adapted, anonymized) |
| --- | --- | --- |
| `so` (result / topic opener) | 174 | `So for this sprint, we will focus on the CI pipeline.` |
| `can` | 146 | `Can you see my screen?` |
| `will` | 98 | `I will update the ticket after the meeting.` |
| `to` + verb (want to / need to / try to) | 95 | `We need to make sure the build is stable.` |
| `if` | 86 | `If you have any questions, let me know.` |
| Present continuous | 59 | `Alex is working on the login page.` |
| `I think` / `I guess` | 58 | `I think that works for us.` |
| Passive voice | 44 | `The PR was merged yesterday.` |
| Present perfect | 32 | `We have finished the integration.` |

**Almost never used:** past perfect (0.4), `used to` (0.2), `if I were` (0.1), third conditional (0), subjunctive `suggest that he be` (0), inversion (0.5). These are covered **briefly** and marked "not needed".

## Frequency Tags

| Tag | Meaning | How to study |
| --- | --- | --- |
| 🔴 Must learn | Very frequent in meetings, or basic to any sentence | Understand, practice, and produce it |
| 🟡 Common | Appears regularly | Understand and practice the most common forms |
| 🟢 Recognize only | Appears occasionally | Understand it in subtitles; no need to produce it |
| ⚪ Not needed | Almost never appears | Skim or skip |

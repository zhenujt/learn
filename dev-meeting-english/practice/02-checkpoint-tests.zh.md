## 怎么用这份测验

学完一个阶段就做对应的那一套，不要等全部学完再做。

| 测验 | 范围 | 什么时候做 |
| --- | --- | --- |
| 阶段一 | G01–G06：句子骨架、名词冠词、代词、be 与 there be、疑问否定、祈使句 | 学完 G06 后 |
| 阶段二 | G07–G10：各种时态 | 学完 G10 后 |
| 阶段三 | G11–G17：情态动词、被动、非谓语、短语动词、形容词副词、介词、连词 | 学完 G17 后 |
| 阶段四 | G18–G24：从句、条件句、转述、口语语法、高级语法 | 学完 G24 后 |
| 总测验 | M01–M07：会议中的实际用法 | 学完 M07 后 |

## 评分标准

- **每题 5 分**，20 题满分 100 分。
- 一题有两个空的，每空 2.5 分。
- 翻译题、情景题：意思对、语法正确得 5 分；意思对但有小的语法错误（冠词、单复数）得 3 分；意思不对得 0 分。答案不必和参考答案一字不差。
- **70 分及格**，可以进入下一阶段。**90 分以上**说明掌握得很好。
- **没及格怎么办：** 每道题的答案后面都标了对应的课。把错题对应的课重读一遍，尤其是「常见错误」和「练习」两节，过两三天再做一次。课程列表见 [语法目录](../grammar/README.zh.md) 和 [会议目录](../meetings/README.zh.md)。
- 即使及格了，某一课错了 2 题以上，也建议回看那一课。

## 阶段一：G01–G06

**A. 找出主语和谓语动词**

1. For the web part, most stories are completed.
2. The PR that Ken opened yesterday needs one more approval.

**B. 判断句型**（主谓 / 主系表 / 主谓宾 / 主谓双宾 / 主谓宾宾补）

3. We need more time.
4. This change makes the test unstable.

**C. 填空：冠词、名词、数量**

5. I found ___ issue in ___ login API.
6. We still have two ___ (subtask) left.
7. How ___ time do we need? (much / many)
8. 改错：We need more informations about the bug.

**D. 代词**

9. Ken and Mia finished the API. ___ will demo it tomorrow.
10. Is this the latest build, or is there a newer ___? (one / it)
11. 改错：Me and Ken will check it.

**E. be 与 there be**

12. ___ two options for the runner.
13. 改错：There have some issues in the pipeline.
14. Ken ___ out of office yesterday.

**F. 疑问句、否定句、简短回答**

15. 改成疑问句：The build is green.
16. 改成否定句：We need a new ticket.
17. Did you merge the PR? — Yes, I ___.

**G. 祈使句与 Let's**

18. 哪一句更适合在会议里请同事帮忙？A. Give me the link. B. Could you send me the link, please?
19. ___ move to the next topic.
20. 改错：Let's to check the logs first.

<details>
<summary>答案</summary>

1. 主语 `most stories`，谓语 `are completed`（`For the web part` 是话题）→ G01
2. 主语 `The PR`，谓语 `needs`（`that Ken opened yesterday` 是修饰语）→ G01
3. 主谓宾 → G01
4. 主谓宾宾补（`the test` 是宾语，`unstable` 是宾补）→ G01
5. an, the → G02
6. subtasks → G02
7. much（`time` 不可数）→ G02
8. We need more information about the bug.（`information` 不可数）→ G02
9. They → G03
10. one（指同类中的另一个）→ G03
11. Ken and I will check it. → G03
12. There are → G04
13. There are some issues in the pipeline. → G04
14. was → G04
15. Is the build green? → G05
16. We don't need a new ticket. → G05
17. did → G05
18. B → G06
19. Let's → G06
20. Let's check the logs first.（`let's` 后接动词原形）→ G06

</details>

## 阶段二：G07–G10

**A. 用括号里动词的正确形式填空**

1. I ___ (work) on the login bug right now.
2. The pipeline usually ___ (take) about 20 minutes.
3. She ___ (join) the team last month.
4. I ___ already ___ (fix) the issue.
5. ___ you ___ (test) it on iOS yet?
6. Yesterday I ___ (talk) to the PM, and she ___ (say) it's fine.
7. We ___ (release) on Thursday. It's already on the calendar.

**B. 选择**

8. Ken ___ out of office since Monday. (was / has been)
9. A: The build just failed. B: Okay, I ___ check it now. (will / am going to)（当场决定）
10. 下面哪一句是在说"已经安排好的计划"？A. I'll do it. B. I'm meeting the PM tomorrow.

**C. 改错**

11. I am knowing the root cause.
12. I have finished it yesterday.
13. I will to send it tomorrow.
14. He don't work on Fridays.
15. When it will be ready, I'll let you know.

**D. 翻译成英文**

16. 我们正在等设计团队的反馈。
17. 我已经提交了 PR。
18. 我明天会更新工单。

**E. 字幕里的时态：说出时态和意思**

19. We were working on it when the server went down.
20. By Friday, we will have finished the migration.

<details>
<summary>答案</summary>

1. am working → G07
2. takes → G07
3. joined → G08
4. have, fixed → G08
5. Have, tested → G08
6. talked, said → G08
7. are releasing（进行时表示已安排的将来）→ G09
8. has been（since + 起点，用现在完成时）→ G08
9. will（当场决定用 will）→ G09
10. B → G09
11. I know the root cause.（`know` 是状态动词，不用进行时）→ G07
12. I finished it yesterday.（有 yesterday 用一般过去时）→ G08
13. I will send it tomorrow. → G09
14. He doesn't work on Fridays. → G07
15. When it's ready, I'll let you know.（时间从句用现在时表将来）→ G09
16. We're waiting for feedback from the design team. → G07
17. I've submitted the PR. → G08
18. I'll update the ticket tomorrow. → G09
19. 过去进行时：服务器宕机的时候，我们正在做这件事。→ G10
20. 将来完成时：到周五，我们会完成迁移。（🟢 认得即可）→ G10

</details>

## 阶段三：G11–G17

**A. 情态动词**

1. We ___ finish it today; the release is tomorrow. (need to / might)
2. ___ you share your screen, please?
3. It ___ be a cache issue, but I'm not sure.
4. 改错：We should to check it first.

**B. 被动语态**

5. The PR ___ (approve) yesterday.
6. The bug ___ (fix) in the next release.
7. 改错：The ticket was create by Mia.

**C. to do / doing / done**

8. We need ___ (update) the docs.
9. Thanks for ___ (share) the link.
10. I'm looking forward to ___ (hear) your feedback.

**D. 短语动词与搭配**

11. Can you ___ ___ this issue?（调查一下）
12. We need to ___ a decision this week. (make / do)

**E. 形容词、副词、比较**

13. The new runner is much ___ (fast) than the old one.
14. All the tests ran ___ (successful).

**F. 介词**

15. The story is ready ___ review.
16. Please finish it ___ Friday.（最晚周五）
17. 改错：We need to discuss about the timeline.

**G. 连词**

18. The build failed, ___ we couldn't deploy.
19. 改错：Although it's done, but we need more tests.
20. 用 `because` 把两句连起来：We postponed the release. QA found a bug.

<details>
<summary>答案</summary>

1. need to → G11
2. Could（或 Can）→ G11
3. might / may / could → G11
4. We should check it first. → G11
5. was approved → G12
6. will be fixed → G12
7. The ticket was created by Mia. → G12
8. to update → G13
9. sharing → G13
10. hearing（`look forward to` 里的 `to` 是介词）→ G13
11. look into → G14
12. make → G14
13. faster → G15
14. successfully → G15
15. for → G16
16. by → G16
17. We need to discuss the timeline. → G16
18. so → G17
19. Although it's done, we need more tests.（或 It's done, but we need more tests.）→ G17
20. We postponed the release because QA found a bug. → G17

</details>

## 阶段四：G18–G24

**A. 名词性从句**

1. 改错：I'm not sure what is the problem.
2. Can you check ___ the build passed?（是否）
3. 翻译：我觉得我们可以先放一放。

**B. 定语从句**

4. This is the bug ___ Ken reported last week.
5. We need someone ___ knows Android well.
6. This is the page ___ you can find all the docs.

**C. 状语从句**

7. ___ the PR is approved, we'll merge it.（一旦）
8. 改错：Once it will be ready, I'll tell you.
9. We can't release ___ QA signs off.（直到……才）

**D. 条件句**

10. If the build ___ (fail), we'll roll back.
11. `If I were you, I'd ask the PM.` 是哪种条件句？会议里常用吗？

**E. 间接引语**

12. 转述：Ken said, "I'm working on it."
13. 改错：He said me that it's fine.
14. 改错：She asked when will it be ready.
15. 改错：Priya suggested us to wait.

**F. 口语语法**

16. 补全碎片句：Sounds good.
17. `Actually, it's not a bug.` 里的 `actually` 发什么信号？
18. 字幕 `Let's move to the next face.` 里，`face` 原本是哪个词？
19. 整理字幕，写出主干：So we, we can, I mean, we should merge it today, right?

**G. 高级语法**

20. 用 `What we need is…` 改写：We need a clear owner.

<details>
<summary>答案</summary>

1. I'm not sure what the problem is.（陈述语序）→ G18
2. if / whether → G18
3. I think we can leave it for now. → G18
4. that / which，或不填 → G19
5. who → G19
6. where → G19
7. Once → G20
8. Once it's ready, I'll tell you. → G20
9. until（`unless` 也说得通：除非 QA 签字，否则不能发布）→ G20
10. fails → G21
11. 第二条件句（与现在事实相反的假设）。会议里很少用，🟢 认得即可；给建议时更常说 `Maybe you could ask the PM.` → G21
12. Ken said he's working on it.（内容仍成立，不后移）或 Ken said he was working on it. → G22
13. He told me that it's fine. 或 He said that it's fine. → G22
14. She asked when it will be ready. → G22
15. Priya suggested that we wait. 或 Priya suggested waiting. → G22
16. That sounds good. → G23
17. 纠正或补充新信息："其实……" → G23
18. phase → G23
19. We should merge it today, right?（取 `I mean` 后面的版本）→ G23
20. What we need is a clear owner. → G24

</details>

## 总测验：会议实际用法（M01–M07）

情景题没有唯一答案，参考答案之外，意思对、语气合适都可以得分。

**M01 站会**

1. 用三句话做站会汇报：昨天完成了登录页；今天写单元测试；没有阻塞。
2. 被点名，但你这边没有更新，怎么说？
3. 翻译：我还在做 CI 的问题，应该明天能完成。

**M02 Sprint 同步**

4. The story is ___ track and should be done by Friday.
5. 翻译：这个 Story 会顺延到下个 Sprint。
6. 改写字幕：`two subtask are completed already and the rest is in progress.`

**M03 主持与共享屏幕**

7. 你开始共享屏幕后，想确认大家能看到，怎么说？
8. 你讲完 Web 部分，想进入 Native 部分，怎么说？
9. 请 Ken 接着讲他的部分，怎么说？

**M04 提问与澄清**

10. 你没听清对方最后一句话，怎么说？
11. 你想确认自己的理解：对方是不是说"周四发布"？
12. 对方说了一个你不懂的词 `canary release`，怎么问？

**M05 看法与建议**

13. 礼貌地表示不同意：你觉得这个方案太复杂了。
14. 提一个建议：先在测试环境试一下。
15. 对方的解释你觉得有道理，怎么回应？

**M06 阻塞、风险与求助**

16. 说明你被阻塞了：在等平台团队的权限审批。
17. 请人帮忙看一个构建失败的问题。
18. 提醒风险：这个功能可能周五做不完。

**M07 收尾与分工**

19. 会议结束前确认分工：Ken 周五前更新工单。
20. 主持人结束会议，怎么说？

<details>
<summary>答案</summary>

1. Yesterday I finished the login page. Today I'm going to write the unit tests. No blockers. → M01
2. Nothing from my side. / No updates from me today. → M01
3. I'm still working on the CI issue. It should be done by tomorrow. → M01
4. on → M02
5. This story will carry over to the next sprint. → M02
6. Two subtasks are already completed, and the rest are in progress. → M02
7. Can everyone see my screen? / Is my screen visible? → M03
8. That's all for the web part. Let's move on to the native part. → M03
9. Ken, would you like to go next? / Ken, go ahead. → M03
10. Sorry, I didn't catch the last part. Could you say it again? → M04
11. So the release is on Thursday, right? / Just to confirm, you mean we release on Thursday? → M04
12. Sorry, what do you mean by "canary release"? → M04
13. I see your point, but I think this solution might be a bit too complex. → M05
14. How about trying it in the test environment first? / Maybe we could try it in the test environment first. → M05
15. That makes sense. / Good point. → M05
16. I'm blocked by the access approval from the platform team. / I'm waiting for the platform team to approve my access. → M06
17. Could someone help me take a look at this build failure? → M06
18. There's a risk that we won't finish this feature by Friday. → M06
19. So Ken will update the ticket by Friday, right? → M07
20. That's all for today. Thanks, everyone. → M07

</details>

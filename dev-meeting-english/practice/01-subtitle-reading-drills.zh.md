## 怎么用这份练习

下面 12 段字幕都改编自真实的站会和 Sprint 周会，人名、产品名都已匿名。为了贴近真实，**故意保留了**填充词、重复、非母语说法和语音识别（ASR）错误。

每一段都按同样的五步来做：

1. **① 找主干**：谁 + 做了什么 / 在做什么 / 要做什么。先删掉 `okay`、`so`、`I mean` 等填充词，见 [G23](../grammar/23-spoken-grammar.zh.md)。
2. **② 标出语法点**：说出 2–4 个你认出的语法点，并想想对应哪一课。
3. **③ 标准改写**：把它改成自然、正确的英语。
4. **④ 中文意思**：用自然的中文说出意思，不要逐字翻译。
5. **⑤ 学一句自己说**：从这一段里挑一句，换成自己的工作内容。

先自己做，再打开「答案」对照。改写不必和答案一模一样，意思对、语法对就可以。

**ASR 提示：** 看到放在句子里不通的普通词（`face`、`conference`、`brands`、`relief`），先怀疑是技术词被听错了。

## 练习 1　站会开场　★

> **Mia：** Hi, good morning, good afternoon, good evening, everyone.
> **Ken：** Hello, good evening.
> **Mia：** OK, let's get it started. So let's go from the phase one and, um, let me check.
> **Mia：** Okay, hi guys, is my screen visible?

<details>
<summary>答案</summary>

**① 主干：** `let's get started` / `let's start from phase one` / `is my screen visible?`

**② 语法点：**

- `let's` + 动词原形：提议大家一起做 → [G06](../grammar/06-imperatives-lets-please.zh.md)
- `is my screen visible?`：be 动词提问 → [G05](../grammar/05-questions-and-negatives.zh.md)
- `the phase one`：名词 + 编号前一般不加 `the`，说 `phase one` → [G02](../grammar/02-nouns-articles-quantifiers.zh.md)
- `get it started`：口语里常见，标准说法是 `get started`

**③④ 标准改写和中文意思：**

```text
Okay, let's get started. Let's start with phase one.
好，我们开始吧。先从第一阶段开始。

Hi everyone, can you see my screen?
大家好，能看到我的屏幕吗？
```

**⑤ 学一句自己说：**

```text
Okay, let's get started. Can everyone see my screen?
好，我们开始吧。大家能看到我的屏幕吗？
```

</details>

## 练习 2　轮到你了：没有更新　★

> **Mia：** And Ken, do you have any update or?
> **Ken：** Oh no, nothing from my side.
> **Mia：** Okay. Anna?
> **Anna：** Yeah, just one. The login page is ready for review. Yeah, that's all from my side, and Leo, you can go ahead.

<details>
<summary>答案</summary>

**① 主干：** `Do you have any updates?` / `(I have) nothing (to update)` / `The login page is ready for review.` / `Leo, you can go ahead.`

**② 语法点：**

- `do you have any update or?`：do 问句；句尾的 `or?` 是 `or not?` 的省略，意思是"有没有？" → [G05](../grammar/05-questions-and-negatives.zh.md)
- `Nothing from my side.`、`Just one.`：碎片句 → [G23](../grammar/23-spoken-grammar.zh.md)
- `ready for review`：for + 用途 → [G16](../grammar/16-prepositions.zh.md)
- `go ahead`：短语动词，"请继续 / 你说吧" → [G14](../grammar/14-phrasal-verbs-and-collocations.zh.md)

**③④ 标准改写和中文意思：**

```text
Ken, do you have any updates?
Ken，你有什么更新吗？

No, nothing from my side.
没有，我这边没有更新。

Just one: the login page is ready for review. That's all from me. Leo, go ahead.
就一个：登录页面可以评审了。我就这些。Leo，你来吧。
```

**⑤ 学一句自己说：**

```text
Just one update: the settings page is ready for review. That's all from me.
就一个更新：设置页面可以评审了。我就这些。
```

</details>

## 练习 3　一句话进展（有 ASR 错误）　★☆

> **Ken：** Yesterday, and thanks for Leo's help, we already merged this to our main brands to unblock others.
> **Ken：** So, yeah, the, the build is green now.

<details>
<summary>答案</summary>

**① 主干：** `we merged this to our main branch` / `the build is green now`

**② 语法点：**

- `brands` 是 ASR 错误，原词是 `branch` → [G23](../grammar/23-spoken-grammar.zh.md)
- `Yesterday … we already merged`：有 `yesterday` 用一般过去时，`already` 可以不要 → [G08](../grammar/08-past-simple-and-present-perfect.zh.md)
- `to unblock others`：不定式表目的 → [G13](../grammar/13-to-do-doing-done.zh.md)
- `thanks for Leo's help` 放在句中，标准说法是 `thanks to Leo's help`（多亏了）

**③④ 标准改写和中文意思：**

```text
Thanks to Leo's help, we merged this into our main branch yesterday to unblock others.
多亏 Leo 帮忙，我们昨天把它合进了主分支，这样别人就不会被卡住。

The build is green now.
现在构建是绿的。
```

**⑤ 学一句自己说：**

```text
I merged the fix into the main branch yesterday, so the build is green now.
我昨天把修复合进了主分支，所以现在构建是绿的。
```

</details>

## 练习 4　gonna 和共享屏幕　★☆

> **Emma：** Uh, we're gonna be remapping the, the touch libraries as a, as a first step.
> **Emma：** Okay, okay, I'm gonna share my screen. So can you see my screen?
> **Ken：** Yes, we can see it.

<details>
<summary>答案</summary>

**① 主干：** `we're going to remap the touch libraries` / `I'm going to share my screen` / `can you see my screen?`

**② 语法点：**

- `gonna` = `going to`：计划好的将来 → [G09](../grammar/09-future-will-going-to.zh.md)
- `going to be remapping`：将来进行时，表示"那段时间会在做"，口语常见 → [G10](../grammar/10-other-tenses.zh.md)
- 重复 `the, the`、`as a, as a`：合并成一个 → [G23](../grammar/23-spoken-grammar.zh.md)
- `can you see…?`：情态动词提问 → [G11](../grammar/11-modal-verbs.zh.md)

**③④ 标准改写和中文意思：**

```text
As a first step, we're going to remap the touch libraries.
第一步，我们要重新映射触控组件库。

Okay, I'm going to share my screen. Can you see it?
好，我来共享屏幕。你们能看到吗？
```

**⑤ 学一句自己说：**

```text
As a first step, we're going to update the API contract.
第一步，我们会先更新 API 契约。
```

</details>

## 练习 5　设计同事的口语更新（英式口语）　★★

> **Emma：** The only update I have, we've started the Sprint 1 components and we are also looking at remapping the icon library as well. On the design side, Lily is going to be taking care of that. So just as an FYI to you guys for the native pod.
> **Emma：** And Leo is also going to share, not today, don't worry, Leo, I'm not putting you on the spot, but share the kind of token structure and strategy there as well for us all to kind of discuss and get aligned on. So maybe not today, but maybe sometime this week or next would be really cool.

<details>
<summary>答案</summary>

**① 主干：** `We've started the Sprint 1 components.` / `Lily is going to take care of the icon library.` / `Leo is going to share the token structure and strategy (this week or next).`

**② 语法点：**

- `we've started`：现在完成时，强调"已经开始了" → [G08](../grammar/08-past-simple-and-present-perfect.zh.md)
- `we are looking at remapping`：现在进行时 + 介词后接 `-ing` → [G07](../grammar/07-present-simple-and-continuous.zh.md)、[G13](../grammar/13-to-do-doing-done.zh.md)
- 插入语 `not today, don't worry, Leo, I'm not putting you on the spot`：说话中途插话，之后用 `but share…` 接回原句 → [G23](../grammar/23-spoken-grammar.zh.md)
- `for us all to discuss`：`for + 人 + to do` → [G13](../grammar/13-to-do-doing-done.zh.md)
- `kind of` 两次：语气变模糊，可删
- `put someone on the spot`：习语，"当众为难某人、让人措手不及"

**③④ 标准改写和中文意思：**

```text
My only update is that we've started the Sprint 1 components. We're also looking at remapping the icon library.
我唯一的更新是：我们已经开始做 Sprint 1 的组件了，也在研究重新映射图标库。

Lily will take care of that on the design side. This is just an FYI for the native pod.
设计这边由 Lily 负责。这只是给 Native 小组同步一下。

Leo will also share the token structure and strategy, so we can all discuss it and get aligned. Not today, but maybe this week or next.
Leo 之后也会分享 Token 的结构和策略，方便大家讨论、达成一致。不是今天，可能这周或下周。
```

**⑤ 学一句自己说：**

```text
Just an FYI: Lily will take care of the icon updates on the design side.
同步一下：设计这边的图标更新由 Lily 负责。
```

</details>

## 练习 6　用 right? 确认理解　★★

> **Ken：** Okay, so this one is like the self-hosted one, which will not require any like software purchasing. We can just use that like in the self-hosted AWS EC2 instance, right?
> **Priya：** Yes, yes, exactly.

<details>
<summary>答案</summary>

**① 主干：** `This one is the self-hosted one.` / `We can use it in a self-hosted AWS EC2 instance, right?`

**② 语法点：**

- 三个 `like`：都是思考停顿，删掉 → [G23](../grammar/23-spoken-grammar.zh.md)
- `which will not require…`：非限制性定语从句，补充说明 → [G19](../grammar/19-relative-clauses.zh.md)
- `We can just use…`：`just` 软化语气 → [G11](../grammar/11-modal-verbs.zh.md)、[G23](../grammar/23-spoken-grammar.zh.md)
- 句尾 `right?`：附加疑问，求确认 → [G23](../grammar/23-spoken-grammar.zh.md)

**③④ 标准改写和中文意思：**

```text
So this is the self-hosted option, which doesn't require buying any software.
所以这是自托管方案，不需要购买任何软件。

We can just run it on a self-hosted AWS EC2 instance, right?
我们直接在自托管的 AWS EC2 实例上跑就行，对吧？
```

**⑤ 学一句自己说：**

```text
So we can reuse the existing runner, right?
所以我们可以复用现有的执行机，对吧？
```

</details>

## 练习 7　主持人过渡（regarding to + ASR）　★★

> **Mia：** Okay, so if no question or comment regarding to the Sprint 1 scope, I will give an update for the status.
> **Mia：** …
> **Mia：** Okay, that's all for the web part. OK, I think we can move to the next face.

<details>
<summary>答案</summary>

**① 主干：** `If (there are) no questions, I will give a status update.` / `We can move to the next phase.`

**② 语法点：**

- `if no question or comment`：省略了 `there are`；第一条件句 → [G21](../grammar/21-conditionals.zh.md)
- `regarding to`：非母语说法，标准是 `regarding` 或 `about` → [G16](../grammar/16-prepositions.zh.md)
- `give an update for the status`：不自然，说 `give a status update`
- `face` 是 ASR 错误，原词是 `phase` → [G23](../grammar/23-spoken-grammar.zh.md)
- `That's all for the web part.`：for 表示范围、收尾 → [G16](../grammar/16-prepositions.zh.md)

**③④ 标准改写和中文意思：**

```text
Okay, if there are no questions or comments about the Sprint 1 scope, I'll give a status update.
好，如果大家对 Sprint 1 的范围没有问题或意见，我来更新一下状态。

Okay, that's all for the web part. I think we can move on to the next phase.
好，Web 部分就是这些。我们可以进入下一个阶段了。
```

**⑤ 学一句自己说：**

```text
If there are no more questions, let's move on to the next topic.
如果没有其他问题，我们进入下一个议题。
```

</details>

## 练习 8　转述别人的结论　★★

> **Tom：** Yes, I checked with Ken today and he said that for this analysis currently, there is no further action for the component level, Node.js version bump or even SSR code change at this point. Yeah.
> **Mia：** Okay, got it. Thanks, Tom.

<details>
<summary>答案</summary>

**① 主干：** `I checked with Ken.` / `He said (that) there is no further action.`

**② 语法点：**

- `he said that … there is…`：间接引语，内容现在仍然成立，所以不后移 → [G22](../grammar/22-reported-speech.zh.md)
- `there is no further action`：there be 句型 → [G04](../grammar/04-be-and-there-be.zh.md)
- `for this analysis`：for 引出话题 → [G16](../grammar/16-prepositions.zh.md)
- `currently` 和 `at this point` 意思重复，留一个即可
- `Got it.`：碎片句 → [G23](../grammar/23-spoken-grammar.zh.md)

**③④ 标准改写和中文意思：**

```text
I checked with Ken today. He said that, based on this analysis, no further action is needed at this point.
我今天和 Ken 确认过了。他说根据这次分析，目前不需要进一步处理。

That means no component-level changes, no Node.js version bump, and no SSR code changes.
也就是说，不用改组件，不用升级 Node.js 版本，也不用改 SSR 代码。
```

**⑤ 学一句自己说：**

```text
I checked with Ken, and he said it's not a blocker at this point.
我和 Ken 确认过，他说目前这不算阻塞。
```

</details>

## 练习 9　边想边问（重说和 I mean）　★★☆

> **David：** I do have one question regarding the website. I mean, I'm not really sure if we have finalized, like, how we gonna approach for the website. I mean, we have done the comparison, but have we concluded anything?
> **Mia：** Not yet. We, we are still waiting for the, the feedback from the design team.

<details>
<summary>答案</summary>

**① 主干：** `I have one question.` / `I'm not sure if we have decided how we're going to approach the website.` / `Have we concluded anything?` / `We are still waiting for feedback.`

**② 语法点：**

- `I do have`：强调 do，"我确实有" → [G24](../grammar/24-advanced-grammar-overview.zh.md)
- `I'm not sure if…`：if 引导宾语从句，意思是"是否" → [G18](../grammar/18-noun-clauses.zh.md)
- `how we gonna approach for`：漏了 `are`；`approach` 直接接宾语，不加 `for` → [G23](../grammar/23-spoken-grammar.zh.md)
- `we have done` / `have we concluded`：现在完成时 → [G08](../grammar/08-past-simple-and-present-perfect.zh.md)
- `Not yet.`：碎片句；`waiting for`：固定搭配 → [G16](../grammar/16-prepositions.zh.md)

**③④ 标准改写和中文意思：**

```text
I have one question about the website. Have we decided how we're going to approach it?
我有一个关于网站的问题。我们决定好要怎么做了吗？

We've done the comparison, but have we reached a conclusion?
我们已经做了对比，但有结论了吗？

Not yet. We're still waiting for feedback from the design team.
还没有。我们还在等设计团队的反馈。
```

**⑤ 学一句自己说：**

```text
I'm not sure if we've decided how to handle the old API. Have we reached a conclusion?
我不确定我们有没有决定怎么处理旧 API。有结论了吗？
```

</details>

## 练习 10　平台组进展（多个 ASR 错误）　★★☆

> **Nina：** For Sigma token sync, Lily is updating the POC conference page according to the comments we got last week, and we can have more detailed updates when Lily is back from POC tomorrow.
> **Nina：** For the Sigma plugin, according to your feedback yesterday, so we added a new backlog which to support the auto Teams notification for the submitter when a ticket is created. So, and we also planned it into a current space, current sprint.

<details>
<summary>答案</summary>

**① 主干：** `Lily is updating the POC page.` / `We will have more updates when she is back.` / `We added a new backlog item.` / `We also planned it into the current sprint.`

**② 语法点：**

- ASR 错误：`Sigma → Figma`，`conference → Confluence`，`back from POC → back from PTO`（休假回来），`current space → current sprint`（说话人自己改正了）→ [G23](../grammar/23-spoken-grammar.zh.md)
- `For Figma token sync, …`：for 引出话题 → [G16](../grammar/16-prepositions.zh.md)
- `the comments we got last week`：省略 that 的定语从句 → [G19](../grammar/19-relative-clauses.zh.md)
- `when Lily is back tomorrow`：时间状语从句用现在时表将来 → [G20](../grammar/20-adverbial-clauses.zh.md)
- `according to …, so we added`：`so` 多余；`a new backlog which to support` 应为 `a new backlog item to support`
- `when a ticket is created`：被动语态 → [G12](../grammar/12-passive-voice.zh.md)

**③④ 标准改写和中文意思：**

```text
For the Figma token sync, Lily is updating the POC page in Confluence based on last week's comments.
关于 Figma Token 同步，Lily 正在根据上周的意见更新 Confluence 上的 POC 页面。

We'll have more details when she's back from PTO tomorrow.
她明天休假回来后，我们会有更详细的更新。

For the Figma plugin, based on your feedback yesterday, we added a new backlog item to send an automatic Teams notification to the submitter when a ticket is created.
关于 Figma 插件，根据你昨天的反馈，我们新增了一个待办项：工单创建时自动给提交人发 Teams 通知。

We've also added it to the current sprint.
我们也已经把它加进了当前 Sprint。
```

**⑤ 学一句自己说：**

```text
Based on your feedback, we added a new backlog item and put it into the current sprint.
根据你的反馈，我们新增了一个待办项，并放进了当前 Sprint。
```

</details>

## 练习 11　Sprint 同步长段落：逐个 Story 汇报　★★★

> **Mia：** Next one is a provide browser enable Harness container for web test suite, and currently we already completed two subtests under the story based on the solution last week we checked with Leo. We use the browser-enabled solution instead of image, and to continue, our developer will focus on other subtasks on this story for Linux and Windows operation system to build up cross-browser CI test lanes.
> **Mia：** And the visual test and E2E test are all completed in this brand. And the next one is a backward compatibility for the framework and Browder version support. I saw Ken just shared the document with all engineers in the channel and also requested Leo's review for the conference documents.

<details>
<summary>答案</summary>

**① 主干：**

- `We have completed two subtasks.`
- `We use the browser-enabled solution.`
- `Our developers will focus on the other subtasks.`
- `The visual tests and E2E tests are completed.`
- `Ken shared the document and requested Leo's review.`

**② 语法点：**

- 第一句开头是**把 Story 标题直接读出来**：`provide browser-enabled Harness container for web test suite`，所以语法看起来很怪。遇到这种情况，把标题当成一个名词看。
- ASR 错误：`subtests → subtasks`，`this brand → this sprint`，`Browder → browser`，`conference → Confluence` → [G23](../grammar/23-spoken-grammar.zh.md)
- `currently we already completed`：应该用现在完成时 `we have completed` → [G08](../grammar/08-past-simple-and-present-perfect.zh.md)
- `the solution last week we checked with Leo`：语序乱，应为 `the solution (that) we checked with Leo last week` → [G19](../grammar/19-relative-clauses.zh.md)
- `to build up … test lanes`：不定式表目的 → [G13](../grammar/13-to-do-doing-done.zh.md)
- `are all completed`：被动 / 形容词性的完成状态 → [G12](../grammar/12-passive-voice.zh.md)
- `I saw Ken just shared…`：转述 → [G22](../grammar/22-reported-speech.zh.md)
- `operation system → operating system`；`instead of image → instead of an image` → [G02](../grammar/02-nouns-articles-quantifiers.zh.md)

**③④ 标准改写和中文意思：**

```text
The next story is about providing a browser-enabled Harness container for the web test suite.
下一个 Story 是为 Web 测试套件提供带浏览器的 Harness 容器。

We've completed two subtasks, based on the solution we agreed with Leo last week.
根据上周和 Leo 确认的方案，我们已经完成了两个子任务。

We're using the browser-enabled solution instead of a custom image.
我们用带浏览器的方案，而不是自定义镜像。

Next, our developers will focus on the remaining subtasks to set up cross-browser CI test lanes for Linux and Windows.
接下来，开发会专注剩下的子任务，为 Linux 和 Windows 搭建跨浏览器的 CI 测试通道。

The visual tests and E2E tests are all completed in this sprint.
视觉测试和端到端测试在这个 Sprint 都已完成。

The next one is backward compatibility for framework and browser versions.
下一个是框架和浏览器版本的向后兼容。

Ken has shared the document with all engineers in the channel and asked Leo to review the Confluence pages.
Ken 已经在频道里把文档发给了所有工程师，并请 Leo 评审 Confluence 页面。
```

**⑤ 学一句自己说：**

```text
We've completed two subtasks, and next we'll focus on the remaining ones.
我们已经完成了两个子任务，接下来会专注剩下的部分。
```

## 练习 12　讨论：节前还是节后发布？　★★★

> **Mia：** And another request for the release, we informed the customer that it will be released in the early of October. It's still in development. So if this ticket could be ready for test tomorrow, and the no issue found, that we can release it as well in tomorrow release. Otherwise, we need to consider to push the release to when we back from the holiday.
> **Ben：** Okay, sorry, which team is asking for the release?
> **Mia：** Let me check.
> **Ben：** Yeah, I think it's better to do the release after the holiday, just in case if they have any follow-up questions, we can answer them when we are available. If we do pre, like before the holiday, probably they will reset the questions while team members are taking the time off, and we are not able to get back to them.

<details>
<summary>答案</summary>

**① 主干：**

- `We informed the customer that it will be released in early October.`
- `If the ticket is ready and no issues are found, we can release it tomorrow.`
- `Otherwise, we need to push the release.`
- `It's better to release after the holiday.`
- `If we release before the holiday, they may raise questions, and we won't be able to answer.`

**② 语法点：**

- `informed the customer that it will be released`：转述 + 被动 → [G22](../grammar/22-reported-speech.zh.md)、[G12](../grammar/12-passive-voice.zh.md)
- `in the early of October` → `in early October`
- `if this ticket could be ready … and the no issue found, that we can…`：条件句结构混乱，应为 `if this ticket is ready … and no issues are found, we can…` → [G21](../grammar/21-conditionals.zh.md)
- `consider to push` → `consider pushing`：`consider` 后接 `-ing` → [G13](../grammar/13-to-do-doing-done.zh.md)
- `when we back` → `when we're back`：漏 be → [G04](../grammar/04-be-and-there-be.zh.md)
- `Otherwise`：否则 → [G17](../grammar/17-conjunctions-and-linking.zh.md)
- `it's better to do`：比较级 + 不定式 → [G15](../grammar/15-adjectives-adverbs-comparison.zh.md)
- `just in case if` → `just in case`；`If we do pre, like before` 是重说；`reset` 是 ASR 错误，原词 `raise` → [G23](../grammar/23-spoken-grammar.zh.md)
- `while team members are taking time off`：while 从句 → [G20](../grammar/20-adverbial-clauses.zh.md)

**③④ 标准改写和中文意思：**

```text
For the other release request, we told the customer it would be released in early October, but it's still in development.
另一个发布请求，我们跟客户说过会在十月初发布，但它还在开发中。

If the ticket is ready for testing tomorrow and no issues are found, we can include it in tomorrow's release.
如果这个工单明天能进入测试，并且没发现问题，就可以放进明天的版本一起发布。

Otherwise, we'll need to push the release to after the holiday.
否则，我们就得把发布推迟到假期之后。

I think it's better to release after the holiday, just in case they have follow-up questions.
我觉得假期后再发布更好，以防他们有后续问题。

If we release before the holiday, they might raise questions while the team is off, and we won't be able to get back to them.
如果节前发布，他们可能会在团队休假时提问，而我们没法及时回复。
```

**⑤ 学一句自己说：**

```text
I think it's better to release it next week, just in case we find any issues.
我觉得下周再发布更好，以防我们发现什么问题。
```

</details>

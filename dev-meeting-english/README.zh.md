# 软件开发会议英语：从看懂字幕到开口汇报

> [English version](README.md) · [学习计划](00-study-plan.zh.md) · [怎么读会议字幕](01-how-to-read-subtitles.zh.md) · [语法目录](grammar/README.zh.md) · [会议场景](meetings/README.zh.md)

这是本仓库**现在唯一的主线教材**。它把以前分散在多套教材里的语法和职场表达，按知识点合并成一套。重复的内容已经去掉，旧资料保留作存档，去向见文末的表。

## 这套教材适合谁

- 在中国工作的软件工程师，英语基础薄弱，或者多年没用、需要重新捡起来。
- 每天或每周参加**英文站会、周会、Sprint 同步会**，会议有**实时字幕**。
- 希望先**看懂字幕**，再能**简短汇报自己的进度**、提问和回应。
- 身边没有英语环境，只能靠工作中的会议、文档和工具来学。

听力不是这套教材的重点，因为会议有字幕。但字幕是**口语转写**，句子松散、有口误、有非母语说法，还有识别错误，所以真正的难点是：**快速读懂口语句子的结构**。这需要扎实的语法。

## 学完能做到什么

| 阶段 | 目标 | 检验方法 |
| --- | --- | --- |
| 第 1 阶段（第 1–4 周） | 看懂站会里的短句：谁、在做什么、做完没有 | [阶段测验一](practice/02-checkpoint-tests.zh.md) 及格；能写 3 句站会更新 |
| 第 2 阶段（第 5–8 周） | 看懂周会里逐项汇报的长句，能说出自己模块的状态 | 阶段测验二及格；能脱稿说 1 分钟更新 |
| 第 3 阶段（第 9–12 周） | 看懂带 if / because / which 的复杂句，能提问和澄清 | 阶段测验三及格；能在会上问 1 个澄清问题 |
| 第 4 阶段（第 13–16 周） | 跟上整场会议的主要信息，会后能写出会议纪要和行动项 | 阶段测验四和总测验及格；独立完成 [字幕精读 12 练](practice/01-subtitle-reading-drills.zh.md) |

## 教材的依据：你们真实会议的数据

我统计了 25 场真实会议的字幕（约 8 万词，包括站会、Scrum 同步会、需求梳理会和演示），按出现频率决定每个语法点该学多深。

**最高频的结构（每万词出现次数）：**

| 结构 | 次数 | 例子（已改写、匿名化） |
| --- | --- | --- |
| `so`（所以 / 那么 / 话题开头） | 174 | `So for this sprint, we will focus on the CI pipeline.` |
| `can` | 146 | `Can you see my screen?` |
| `will` | 98 | `I will update the ticket after the meeting.` |
| `to` + 动词（want to / need to / try to） | 95 | `We need to make sure the build is stable.` |
| `if` | 86 | `If you have any questions, let me know.` |
| 现在进行时 | 59 | `Alex is working on the login page.` |
| `I think` / `I guess` | 58 | `I think that works for us.` |
| 被动语态 | 44 | `The PR was merged yesterday.` |
| 现在完成时 | 32 | `We have finished the integration.` |

**几乎不出现的结构：** 过去完成时（0.4）、`used to`（0.2）、`if I were`（0.1）、第三类条件句（0）、虚拟语气 `suggest that he be`（0）、倒装（0.5）。这些在教材里只做**简单介绍**，并标注「用不到」。

## 频率标记

每一课、每一个小知识点都有标记，帮你决定花多少时间：

| 标记 | 含义 | 怎么学 |
| --- | --- | --- |
| 🔴 必学 | 会议高频，或者造句的基础 | 读懂、做练习、能自己说出来 |
| 🟡 常用 | 会议中经常出现 | 读懂、做练习，能用最常见的几个说法 |
| 🟢 认得即可 | 会议中偶尔出现 | 字幕里看到能懂就行，不用主动说 |
| ⚪ 用不到 | 会议中几乎不出现 | 扫一眼，知道有这回事；可以直接跳过 |

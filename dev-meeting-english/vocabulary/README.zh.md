## 三年级：先认出人、物和数量

| 词 | 中文意思 | 读字幕时怎么认 |
| --- | --- | --- |
| name | 名词：名字、名称 | `the file name` 是文件名 |
| this | 代词或限定词：这个、这件事 | `this works` 是「这个方案可行」，要从上一句找「这个」 |
| look | 动词：看；看起来 | `look at the screen` 是「看屏幕」；`looks good` 是「看起来不错」 |
| many | 限定词：许多（接可数名词复数） | `how many tickets` 问「多少张工单」 |
| new | 形容词：新的 | `a new issue` 可以是「一个新问题」或「一张新工单」 |

## 四年级：弄清时间、地点和对象

| 词 | 中文意思 | 读字幕时怎么认 |
| --- | --- | --- |
| next | 形容词或副词：下一个；接下来 | `next week` 是「下周」，`what's next?` 问「接下来做什么？」 |
| right | 形容词：正确的；句尾可表示「对吧？」 | `the right branch` 是「正确的分支」，不是「右边的分支」 |
| before | 介词或连词：在……之前 | `before the demo` 给的是时间界限 |
| ready | 形容词：准备好，可用了 | `ready for review` 表示可以开始评审，不表示评审结束 |
| with | 介词：和……一起；用；关于某个对象 | `check with Alex` 是「和 Alex 确认一下」 |

## 五年级：辨认习惯、计划和顺序

| 词 | 中文意思 | 读字幕时怎么认 |
| --- | --- | --- |
| usually | 副词：通常 | `we usually run tests first` 说惯例，不是在报告本次已跑完 |
| sometimes | 副词：有时 | `it sometimes fails` 说偶尔失败，不是每次都失败 |
| first | 形容词或副词：第一个；先 | `check the logs first` 是「先看日志」 |
| need | 动词：需要 | `we need to check` 表示有事要做，不表示已经做了 |
| keep | 动词：保留；继续 | `keep testing` 是「继续测试」；`keep the old version` 是「保留旧版本」 |

## 六年级：听懂工作进行到哪一步

| 词 | 中文意思 | 读字幕时怎么认 |
| --- | --- | --- |
| start | 动词或名词：开始；起点 | `we started testing` 表示开始测了，不等于测完 |
| finish | 动词：做完、结束 | `finished testing` 表示测试这个动作结束，不等于测试全通过 |
| still | 副词：仍然、还 | `it's still running` 表示还在跑 |
| change | 动词或名词：更改；改动 | `one more change` 是「还有一处改动」 |
| wait | 动词：等 | `waiting for approval` 是「正在等审批」，不是已获批准 |

## 七年级（初一）：看懂会上的提问、说明与汇报

| 词 | 中文意思 | 读字幕时怎么认 |
| --- | --- | --- |
| join | 动词：加入、参加 | `join the call` 是「加入通话」 |
| share | 动词：分享、共享 | `share my screen` 是「共享我的屏幕」 |
| mean | 动词：意思是；指的是 | `do you mean the test environment?` 是确认对方指的是不是测试环境 |
| check | 动词：查看、检查、确认 | `I'll check` 是「我去确认」，还没有结论 |
| fix | 动词或名词：修复；修复方案 | `we have a fix` 表示已有修复方案，不一定已部署 |

## 八年级（初二）：理解原因、条件和建议

| 词 | 中文意思 | 读字幕时怎么认 |
| --- | --- | --- |
| unless | 连词：除非；如果不 | `unless we get access` 给出例外条件：「除非我们拿到权限」 |
| issue | 名词：问题；工单（视工具和语境） | `open an issue` 是「创建工单」；`we have an issue` 是「我们遇到了问题」 |
| suggest | 动词：建议；表明、暗示 | `I suggest ...` 提方案；`the logs suggest ...` 是根据日志推断 |
| expect | 动词：预计；期望 | `we expect it by Friday` 是预计周五前到位，不是保证 |
| depend | 动词：取决于；依赖 | `it depends on approval` 说明审批是前置条件 |

## 九年级（初三）：读懂结论、风险和行动项

| 词 | 中文意思 | 读字幕时怎么认 |
| --- | --- | --- |
| confirm | 动词：确认、证实 | `can you confirm the date?` 是请人核实日期 |
| require | 动词：需要；要求 | `this requires approval` 说明必须先审批 |
| affect | 动词：影响 | `affect the release` 指影响发布；名词常用 `effect` |
| resolve | 动词：解决（问题、争议等） | `we resolved the blocker` 表示阻塞已解决，不等于整个任务已完成 |
| follow up | 短语动词：跟进 | `I'll follow up with the team` 表示说话人会去联系团队、追问进展 |

**怎么用：** 先用每个年级的五个词自测。遮住中文，看自己能否从搭配判断含义；有两三个拿不准，就先复习这一级。遇到 `ready`、`expect` 这类表示状态的词，多问一句：「这是事实、计划，还是条件？」如果能判断出来，比背完一份单词表更有助于读会议字幕。

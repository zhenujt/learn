# G22 间接引语与时态呼应

<!-- sentence-audio: fenced-only -->

> **频率：🟡 常用** ｜ 阶段：初中 → 高中 ｜ 会议数据：`said / mentioned` 类转述每万词约 12 次；`as I mentioned`、`like I said` 这类插入语约 3 次；`confirmed that…` 约 1.6 次；时态后移需要的过去完成时只有 0.4 次
>
> [English version](22-reported-speech.md) · [上一课：G21 条件句](21-conditionals.zh.md) · [下一课：G23 口语语法](23-spoken-grammar.zh.md) · [语法目录](README.zh.md)

## 这一课解决什么问题

会议里大家经常"转述"别人说过的话：主持人提醒刚才谁说了什么，开发同事汇报和别人确认过的结论。例如：

```text
As Mia just mentioned, each story must have a feature as its parent.
就像 Mia 刚才说的，每个 Story 都必须挂在一个 Feature 下面。

Ken confirmed that the Linux step can pull the Docker image.
Ken 确认了 Linux 这一步可以拉取 Docker 镜像。
```

这两句里真正的信息在后半句。前面的 `As Mia just mentioned`、`Ken confirmed that` 只是告诉你"**这话是谁说的、是什么态度**"。

课本讲间接引语，重点是"时态后移"。但会议数据显示：**大家转述时很少后移时态**，过去完成时每万词只有 0.4 次。你真正需要的是认出转述结构、分清 `say` 和 `tell`、用对几个转述动词。

**学完这一课，你应该能：**

1. 一眼认出 `as I mentioned`、`like I said`、`he said that…` 这类转述，并跳到真正的信息。
2. 分清 `say`、`tell`、`ask` 后面分别接什么。
3. 知道时态后移的规则，也知道口语里什么时候可以不后移。
4. 用 `mention`、`confirm`、`suggest`、`point out`、`explain` 转述别人的话。

## 1. 直接引语和间接引语

**直接引语**是原话照搬，加引号。**间接引语**是用自己的话转述，不加引号，通常用 `that` 或 `if` 连接。

```text
Ken said, "The build is green."
Ken 说："构建是绿的。"（直接引语）

Ken said that the build was green.
Ken 说构建是绿的。（间接引语）

Ken said the build is green now.
Ken 说构建现在是绿的。（口语：省掉 that，也不后移）
```

会议里几乎只用间接引语。直接引语偶尔出现在读邮件、读评论的时候。

转述句的骨架永远是：

**公式：** `谁 + 转述动词 + (that) + 完整的句子`

后面那个"完整的句子"就是 [G18 名词性从句](18-noun-clauses.zh.md) 里讲的宾语从句。`that` 在口语里经常省略。

## 2. 插入语：as I mentioned / like I said（最常听到）

会议里最常见的转述，其实不是完整的 `he said that…`，而是一个短短的插入语，放在句首或句中，意思是"刚才说过了，我再提一下"。

**公式：** `As + 人 + (just / already) + mentioned / said, + 主句`

```text
As I mentioned, we need to verify the solution first.
我刚才说过，我们需要先验证这个方案。

As we already mentioned, the initiative is at the company level.
我们之前也提到了，这个计划是公司层面的。

Like I said, it only supports tables right now.
就像我说的，它现在只支持表格。

As you said, if we only have one runner per host, only six sessions can run.
像你说的那样，如果每台主机只有一个执行机，就只能跑六个会话。

As Lily pointed out last week, the cost is still too high.
正如 Lily 上周指出的，成本还是太高。
```

**怎么认：** 句首出现 `As + 人 + mentioned/said,` 或 `Like I said,`，后面有逗号。读字幕时可以直接跳过这一段，看逗号后面。

> `like I said` 是口语说法，`as I said` 更标准一点，两个都可以用。`as I mentioned before` 也很常见，完全正确。

## 3. 转述陈述句：say 和 tell

这是中国学生最常错的地方。

| 动词 | 后面接什么 | 例句 |
| --- | --- | --- |
| `say` | 直接接内容，**不能直接接人** | `He said (that) it's fine.` |
| `say to + 人` | 少用，多用于直接引语 | `She said to me, "Thanks."` |
| `tell + 人` | **必须接人**，再接内容 | `He told me (that) it's fine.` |
| `tell + 人 + to do` | 让某人做某事 | `She told us to wait.` |

```text
He said the release is on Thursday.
他说发布在周四。

He told me the release is on Thursday.
他告诉我发布在周四。

They told me that the sandbox environment should be fine.
他们告诉我沙箱环境应该没问题。
```

❌ `He said me that…` ✅ `He told me that…` / `He said that…`

**记法：** `tell` 一定有"听的人"，`say` 只关心"说的内容"。

## 4. 转述问题：ask if / ask what

转述别人问的问题时，有两个变化：

1. 是非问句用 `if` 或 `whether` 连接。
2. **语序变回陈述句**：主语在前，动词在后，不再倒装，也不再用 `do / does / did`。

**公式：** `ask (+ 人) + if / whether + 主语 + 动词` ；`ask (+ 人) + what / when / how + 主语 + 动词`

| 原来的问题 | 转述 |
| --- | --- |
| `"Is the PR ready?"` | `She asked if the PR was ready.` |
| `"Do we need a new ticket?"` | `He asked whether we need a new ticket.` |
| `"When will it be released?"` | `They asked when it will be released.` |
| `"What's the plan?"` | `Grace asked what the plan is.` |

```text
Anna asked if the testing covers the website.
Anna 问测试是否覆盖了网站。

The PM asked me when we can release it.
产品经理问我什么时候能发布。

Someone asked in the chat whether we have the AWS environment already.
有人在聊天里问我们是否已经有 AWS 环境了。
```

❌ `She asked what is the plan.` ✅ `She asked what the plan is.`

会议里还有一种"自己转述自己的问题"，非常礼貌：`I wonder if…`、`I'm not sure if…`、`I was wondering if…`，详见 [G18](18-noun-clauses.zh.md)。

## 5. 转述请求和建议：ask / tell + to do，suggest

**请求和命令：** `ask / tell + 人 + to do`

```text
Ken asked me to update the ticket.
Ken 让我更新一下工单。

The lead told us not to merge it before Friday.
负责人让我们周五之前不要合并。
```

**建议：** `suggest` 有两种正确用法，但**不能接"人 + to do"**。

**公式：** `suggest + doing` ；`suggest (that) + 主语 + 动词原形`

```text
Priya suggested using the GitHub Actions runner.
Priya 建议用 GitHub Actions 的执行机。

Priya suggested that we post the details in the wider group.
Priya 建议我们把细节发到更大的群里。
```

❌ `Priya suggested us to post the details.`
✅ `Priya suggested that we post the details.`

> `suggest that we post` 里的 `post` 用的是动词原形，这是虚拟语气的残留。会议里大家通常直接说 `suggested we post` 或 `suggested we should post`，都没问题。详见 [G24](24-advanced-grammar-overview.zh.md)。

## 6. 时态后移：规则和口语里的例外

### 6.1 课本规则

当转述动词是**过去时**（`said`、`told`、`asked`），从句里的时态通常往"过去"退一步：

| 原话 | 转述后 |
| --- | --- |
| `am / is / are` | `was / were` |
| `do / does` | `did` |
| `am doing` | `was doing` |
| `did` / `have done` | `had done` |
| `will` | `would` |
| `can` | `could` |
| `may` | `might` |

时间词也可能跟着变：`today → that day`，`tomorrow → the next day`，`yesterday → the day before`。

```text
He said he was working on the hydration test.
他说他在做 hydration 测试。（原话：I'm working on…）

She said she would send the doc by Friday.
她说她周五前会把文档发出来。（原话：I will send…）

Leo said he had already fixed the pipeline.
Leo 说他已经修好了流水线。（原话：I have already fixed…）
```

### 6.2 会议里什么时候不后移 🔴 重要

真实会议里，大部分转述**都不后移**。以下几种情况，不后移是完全正确的：

1. **内容现在仍然成立。** 例如 `He said the release is on Thursday.`——发布确实还在周四。
2. **刚刚才说的话。** `As you just said, we need more data.`
3. **转述动词是现在时或现在完成时。** `He says…`、`She has confirmed that…`，从句不用变。
4. **说的是将来的计划，计划没变。** `She said she will send it tomorrow.`（"明天"仍然是明天。）

```text
He said that for this analysis, there is no further action at this point.
他说就这个分析来说，目前没有后续动作。

Ken has confirmed that the runner supports Docker.
Ken 已经确认执行机支持 Docker。

Mia said she will update the page tomorrow.
Mia 说她明天会更新页面。
```

**什么时候一定要后移？** 内容已经不成立，或者你想强调"那是当时的说法"：

```text
I thought it was a small change, but it wasn't.
我以为是个小改动，结果不是。

He said it would be ready yesterday, but it's still in review.
他说昨天就能好，但现在还在评审。
```

**结论：** 自己说的时候，不确定就**跟着事实走**：现在还对就用现在时，已经不对了就用过去时。不要为了"语法规则"把还成立的事说成过去。

## 7. 会议里常用的转述动词

| 动词 | 意思 | 常用结构 | 例句 |
| --- | --- | --- | --- |
| `mention` | 提到（顺便说） | `mention + 名词 / that…` | `You mentioned two vulnerability issues.` |
| `say` | 说 | `say (that)…` | `He said it's not finalized yet.` |
| `tell` | 告诉 | `tell + 人 + (that)… / to do` | `They told me it should be fine.` |
| `ask` | 问；请求 | `ask if / what…`；`ask + 人 + to do` | `She asked if we need a review.` |
| `confirm` | 确认 | `confirm (that)…`；`confirm + 名词` | `Ken confirmed that it works.` |
| `suggest` | 建议 | `suggest doing`；`suggest (that) we…` | `Lily suggested using AWS.` |
| `point out` | 指出（问题、风险） | `point out that…`；`point out + 名词` | `Tom pointed out a gap in the test plan.` |
| `explain` | 解释 | `explain + 名词 / how / why…` | `Anna explained how the workflow works.` |
| `share` | 分享（信息） | `share that…`；`share + 名词` | `Leo shared that he finished the review.` |

> ⚠️ `mention`、`discuss`、`explain` 都直接接宾语，**不加** `about`。❌ `mention about it` ✅ `mention it`。
>
> ⚠️ `explain` 后面不能直接接人：❌ `explain me` ✅ `explain it to me`。

## 8. 真实会议例句（改编）

```text
As Mia just mentioned, each story must have a feature as its parent.
就像 Mia 刚才说的，每个 Story 都必须有一个父级 Feature。

I remember Grace said it's not finalized yet, but we can double-check with her.
我记得 Grace 说过还没最终定下来，不过我们可以再跟她确认一下。

Ken has confirmed that the Linux step can pull the Docker image, so it's not blocked now.
Ken 已经确认 Linux 步骤可以拉取 Docker 镜像，所以现在不阻塞了。

I talked with the platform team, and they told me the sandbox environment should be fine.
我和平台团队聊过，他们告诉我沙箱环境应该没问题。

Okay, so Leo, you just mentioned two critical vulnerability issues.
好，Leo，你刚才提到了两个严重的漏洞问题。

Like Priya suggested, we'll post the details in the wider group.
按 Priya 的建议，我们会把细节发到更大的群里。

As I confirmed with you, we will send a notification once someone is assigned to review the PR.
就像我跟你确认过的，PR 一旦分配了评审人，我们就发通知。

I saw someone mentioned it in the email thread.
我看到有人在邮件里提到过这件事。
```

## 9. 字幕里怎么认

1. **先找转述动词：** `said`、`mentioned`、`told`、`asked`、`confirmed`、`suggested`。它后面才是真正的信息。
2. **`As … mentioned,` 当成括号看。** 跳过它，读逗号后面的主句。
3. **`if` 不一定是"如果"。** `asked if`、`check if`、`confirm if` 里的 `if` 是"是否"。
4. **时态没后移很正常。** 看到 `He said it is…` 不要以为说错了。

非母语同事常见的转述说法：

| 字幕里可能听到 | 标准说法 |
| --- | --- |
| `He said me that…` | `He told me that…` |
| `as mentioned about before` | `as mentioned before` |
| `She suggested us to use it.` | `She suggested that we use it.` / `She suggested using it.` |
| `He asked what is the status.` | `He asked what the status is.` |
| `I saw Lily mentioned us some questions.` | `I saw Lily mentioned some questions to us.` / `Lily raised some questions.` |
| `I'm wondering if any information could share.` | `I'm wondering if you could share any information.` |

## 10. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `He said me the build failed.` | `He told me the build failed.` | `say` 不直接接人 |
| `She told that it's ready.` | `She said that it's ready.` / `She told us that…` | `tell` 必须接人 |
| `He asked me did I finish it.` | `He asked me if I finished it.` | 转述问题用 `if` + 陈述语序 |
| `They asked where is the doc.` | `They asked where the doc is.` | 陈述语序 |
| `Ken suggested me to wait.` | `Ken suggested that I wait.` / `Ken told me to wait.` | `suggest` 不接"人 + to do" |
| `As I mentioned about, …` | `As I mentioned, …` | `mention` 不加 `about` |
| `Can you explain me the flow?` | `Can you explain the flow to me?` | `explain` 不直接接人 |

## 11. 你可以直接用的句子

```text
As I mentioned last week, the API changes are done.
上周我提过，API 的改动已经完成了。

Like I said, we can leave it for now.
就像我说的，我们可以先放一放。

I checked with Ken, and he said it's not a blocker.
我跟 Ken 确认过了，他说这不算阻塞。

Mia confirmed that the fix is in the main branch.
Mia 确认修复已经合进主分支了。

Tom pointed out that we haven't tested it on iOS yet.
Tom 指出我们还没在 iOS 上测过。

Sorry, you mentioned a new ticket. Which one was it?
不好意思，你刚才提到一个新工单，是哪一个？

The PM asked if we can finish it in this sprint.
产品经理问我们能不能在这个 Sprint 做完。

```

## 12. 练习

**A. 选 `say` 或 `tell` 的正确形式**

1. He ___ me the PR is approved.
2. She ___ that the meeting is moved to Friday.
3. Can you ___ Anna to join the call?
4. They ___ it's not finalized yet.

**B. 把直接引语改成间接引语（口语里内容仍然成立，不必后移）**

1. Lily asked, "Is the environment ready?"
2. Ben asked, "When will the release be?"
3. Kevin said, "I'm working on the CI issue."
4. Nina told me, "Please review my PR."

**C. 改错**

1. Priya suggested us to use the self-hosted runner.
2. He asked me what is the root cause.
3. As I mentioned about before, the doc is in Confluence.
4. Can you explain me how it works?

<details>
<summary>答案</summary>

**A.** 1 told　2 said　3 tell（`ask` 也可以）　4 said

**B.**
1. Lily asked if the environment is ready.（或 was ready）
2. Ben asked when the release will be.（或 would be）
3. Kevin said he's working on the CI issue.（或 he was working）
4. Nina asked me to review her PR.（转述请求用 `ask / tell + 人 + to do`）

**C.**
1. Priya suggested that we use the self-hosted runner.（或 suggested using…）
2. He asked me what the root cause is.
3. As I mentioned before, the doc is in Confluence.
4. Can you explain to me how it works?（或 Can you explain how it works?）

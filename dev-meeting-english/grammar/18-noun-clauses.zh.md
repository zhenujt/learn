# G18 名词性从句：I think…、I'm not sure if…

<!-- sentence-audio: fenced-only -->

> **频率：🔴 必学** ｜ 阶段：初中 → 高中 ｜ 会议数据：`I think` 每万词约 56 次，`see / check / confirm / not sure / wonder + if` 约 25 次，that 从句约 11 次，`what` 从句约 15 次，`whether` 约 1.4 次
>
> [English version](18-noun-clauses.md) · [上一课：G17 连词与连接](17-conjunctions-and-linking.zh.md) · [下一课：G19 定语从句](19-relative-clauses.zh.md) · [语法目录](README.zh.md)

## 这一课解决什么问题

会议里大量的句子，开头都是一个很短的"外壳"，后面才是真正的内容：

```text
I'm not sure if the platform team is working on it already.
我不确定平台团队是不是已经在做了。

Can you check if the build is green?
你能看一下构建是不是通过了吗？
```

`I'm not sure if …`、`Can you check if …` 后面装着一个完整的句子。这个"装进去的句子"就是**名词性从句**。

中国同学最常见的错误也在这里：想说"我不知道它是什么"，脱口而出 `I don't know what is it.`。正确的是 `I don't know what it is.`。

**学完这一课，你应该能：**

1. 看懂并说出 `I think (that) …`，知道 `that` 什么时候能省。
2. 用 `if / whether` 说"是否"：`I'm not sure if …`、`Can you check if …`、`I wonder if …`。
3. 把一个问题装进句子里，并且用**陈述语序**：`Do you know when it will be ready?`
4. 认出放在主语、表语、同位语位置的从句：`What we need is …`、`The problem is that …`、`the fact that …`。

## 1. 先建立一个正确的认识

**名词性从句 = 一个完整的句子，放在名词的位置上。** 可以把它想象成一个"盒子"：盒子外面是主句，盒子里面是一个完整的句子。

```text
I know the answer.
我知道答案。（the answer：普通名词）

I know what the answer is.
我知道答案是什么。（what the answer is：一个句子当名词用）
```

**盒子的开头有三类词：**

| 开头词 | 装的是什么 | 中文 | 例子 |
| --- | --- | --- | --- |
| `that`（常省略） | 一个陈述 | ……这件事 | `I think (that) it works.` |
| `if / whether` | 一个是非问题 | 是否、是不是 | `I'm not sure if it works.` |
| `what / how / when / who / why / where / which` | 一个特殊疑问 | 什么、怎么、什么时候…… | `I don't know how it works.` |

**盒子可以放在四个位置：**

| 位置 | 例子 | 会议频率 |
| --- | --- | --- |
| 宾语（动词后面） | `I think it's ready.` | 🔴 绝大多数 |
| 表语（`is` 后面） | `The problem is that the API is slow.` | 🟡 |
| 主语（句首） | `What we need is a clear owner.` | 🟡 |
| 同位语（名词后面，解释它） | `the fact that it's free` | 🟢 |

**最重要的规则：盒子里面永远用陈述语序（主语 + 动词），不倒装，不加 do / does / did。**

## 2. I think (that) …：说看法 🔴

**公式：** `I think / guess / believe / know / hope / mean / feel + (that) + 完整句子`

`I think` 是会议里最常见的开头之一（每万词约 56 次）。后面的 `that` 在口语里几乎总是省略：

```text
I think we can start.
我觉得我们可以开始了。

I think the setup is finished now.
我觉得配置已经完成了。

I guess we need a separate service account.
我想我们需要一个单独的服务账号。

I hope it will be fixed by Friday.
希望周五前能修好。

I mean the web team should own this part.
我的意思是，这部分应该由 Web 团队负责。

I know Alex is going to work on the native part.
我知道 Alex 会去做 Native 部分。
```

**同样的结构还有：**

```text
Please make sure that the PR passes CI.
请确保 PR 通过 CI。

It seems the issue is fixed.
问题好像已经修好了。

I'm sure it's a config issue.
我确定是配置问题。
```

`make sure (that) …` 在会议里非常高频（`to make sure` 是最常见的四词组合之一）。

### 2.1 否定放在 think 前面

想说"我觉得不需要"，英语习惯把 `not` 放在 `think` 前面：

```text
I don't think we need to vote.
我觉得我们不需要投票。
```

字幕里常听到 `I think we don't need to vote.`，能听懂，语法也不算错，但不如 `I don't think …` 自然。

### 2.2 I think 插在句子中间

口语里 `I think` 可以插在任何地方，只是"我觉得、大概"的意思，读字幕时可以先跳过：

```text
We need to update the branch protection rule, I think.
我觉得我们需要更新分支保护规则。

The deadline is, I think, October 1st.
截止日期，我记得是 10 月 1 号。
```

### 2.3 I think that's all：这里的 that 不是连接词

```text
I think that's all for today.
我觉得今天就这些了。
```

这里的 `that` 是代词"那个"，是盒子里的主语：`I think (that) [that's all for today]`。所以 `I think that's …` 的 `that` 不能省。

## 3. if / whether：是否 🔴

**公式：** `动词 / 形容词 + if / whether + 陈述句`

`if` 在会议里每万词约 86 次，其中**约 25 次不是"如果"，而是"是否"**。它们几乎都跟在这些词后面：

| 前面的词 | 例子 |
| --- | --- |
| `not sure` | `I'm not sure if it's feasible.` |
| `check` | `Can you check if the build is green?` |
| `see` | `Let's see if anyone can pick it up.` |
| `confirm` | `I will confirm with Ken if we need it.` |
| `wonder` | `I wonder if we can use GitHub Actions.` |
| `know` | `Do you know if the runner is ready?` |
| `ask` | `Let me ask if they have a deadline.` |

```text
I'm not sure if it's feasible, but we can try.
我不确定可不可行，但我们可以试试。

Can you check if the build is green?
你能看一下构建是不是通过了吗？

Let's see if anyone can pick it up.
我们看看有没有人能接手。

I wonder if we can try the GitHub Actions runner.
我在想我们能不能试一下 GitHub Actions 的执行机。

Do you know if the macOS runner is for the release pipeline?
你知道 macOS 执行机是不是给发布流水线用的吗？
```

**`I wonder if …` 是会议里非常礼貌的提问方式**（每万词约 4 次）。它没有问号，但其实在问问题或提建议：

```text
I wonder if anyone has other topics.
不知道大家还有没有其他议题？
```

### 3.1 if 还是 whether？

在会议里，大多数时候用 `if` 就行。以下情况**只能**用 `whether`：

```text
It depends on whether the license is approved.
这取决于许可证有没有批下来。（介词后面）

Whether we need it is still unclear.
我们到底需不需要它，目前还不清楚。（放在句首当主语，🟢）

We need to decide whether or not to upgrade.
我们需要决定要不要升级。（紧跟 or not）
```

### 3.2 盒子里的将来时可以用 will

"是否"的盒子里，将来的事照常用 `will`：

```text
I'm not sure if Ken will join today.
我不确定 Ken 今天会不会来。（是否：可以用 will）

If Ken joins today, we can ask him.
如果 Ken 今天来，我们可以问他。（如果：不用 will）
```

第二句是条件句，规则见 [G20](20-adverbial-clauses.zh.md) 和 [G21](21-conditionals.zh.md)。

## 4. wh- 从句：把问题装进句子 ⭐ 中国同学最常错

**公式：** `… + 疑问词 + 主语 + 动词 …`（**陈述语序**，不加 do / does / did）

直接问句要倒装；一旦装进盒子，就恢复成陈述语序：

| 直接问句 | 装进句子以后 |
| --- | --- |
| `Where is the log?` | `Do you know where the log is?` |
| `When will it be ready?` | `Do you know when it will be ready?` |
| `What does this flag do?` | `Can you explain what this flag does?` |
| `Why did the build fail?` | `I'm checking why the build failed.` |
| `How can we fix it?` | `We need to figure out how we can fix it.` |
| `Who is working on it?` | `Do you know who is working on it?` |

```text
Do you know when it will be ready?
你知道它什么时候能好吗？

I don't know what the root cause is.
我不知道根本原因是什么。

Can you show me where the setting is?
你能给我看一下这个设置在哪里吗？

Let me know what you think.
告诉我你的想法。

We need to understand which pipeline is using this feature.
我们需要弄清楚是哪条流水线在用这个功能。
```

**三个要点：**

- 去掉 `do / does / did`，动词恢复时态：`What does it do?` → `what it does`。
- `is / will / can` 放回主语后面：`Where is it?` → `where it is`。
- **疑问词本身就是主语时，语序不变**：`Who is sharing?` → `Do you know who is sharing?`

> 口语里，母语者有时也会说 `Can you tell me what's the difference?`，这在字幕里能见到。自己说和写的时候，用标准的 `what the difference is`。

**疑问词 + to do** 也是名词性的盒子，更短更常用：

```text
I don't know how to fix it.
我不知道怎么修。

We need to decide which tool to use.
我们需要决定用哪个工具。
```

## 5. 从句当主语和表语 🟡

### 5.1 表语从句：The problem is that …

**公式：** `The problem / issue / thing / idea / reason / good news + is + (that) + 句子`

先用一个名词说"问题 / 好消息 / 想法是"，再用盒子说具体内容：

```text
The problem is that the API is not stable.
问题是 API 不稳定。

The good news is that most stories are completed.
好消息是大部分 Story 都完成了。

The idea is that designers can catch issues early.
想法是让设计师能早点发现问题。

The question is whether we have enough time.
问题在于我们有没有足够的时间。
```

口语里 `that` 常常省略，或者换成停顿，字幕上就是一个逗号：

```text
The thing is, we don't have a test account yet.
问题是，我们还没有测试账号。
```

`The reason is that …` 是标准说法；口语里常听到 `The reason is because …`，母语者也这么说，但写作时用 `that` 更规范。

### 5.2 主语从句：What we need is …

**公式：** `What + 主语 + 动词 + is + 名词 / 句子`

`What we need` = "我们需要的东西"。它整体当主语，用来**强调后面的内容**：

```text
What we need is a clear owner for this task.
我们需要的是这个任务有一个明确的负责人。

What I want to say is that the plan is still flexible.
我想说的是，这个计划还可以调整。

What we can do now is ask the platform team for help.
我们现在能做的是请平台团队帮忙。
```

`whether` 和 `that` 开头的主语从句更书面，会议里很少，认得即可（🟢）：

```text
Whether we need it is still unclear.
我们需不需要它，目前还不清楚。
```

口语里更常把它挪到后面，前面用 `it` 占位：

```text
It's still unclear whether we need it.
目前还不清楚我们需不需要它。

It's important that everyone updates their tickets.
每个人都更新自己的工单，这一点很重要。
```

## 6. 同位语从句：the fact that … 🟢

**公式：** `抽象名词（fact / idea / question / news / concern）+ that / of whether + 句子`

同位语从句**解释前面那个名词的内容**。它在文档、邮件里比会议里多：

```text
We should consider the fact that the license is not free.
我们应该考虑到许可证不是免费的这一点。

There is a concern that the change may break old versions.
有人担心这个改动可能会影响旧版本。

We discussed the question of whether we should publish each component separately.
我们讨论了是否要把每个组件单独发布的问题。
```

**和定语从句怎么分？** 同位语从句里的 `that` 只是连接词，盒子里句子是完整的；定语从句里的 `that` 在从句中当主语或宾语，从句缺一个成分。详见 [G19 定语从句](19-relative-clauses.zh.md)。

## 7. that 什么时候可以省

| 位置 | 能否省略 | 例子 |
| --- | --- | --- |
| `think / know / say / hope / make sure` 后面 | ✅ 口语几乎都省 | `I think (that) it works.` |
| `The problem is` 后面 | 可以，但保留更清楚 | `The problem is (that) it's slow.` |
| 句首当主语 | ❌ 不能省 | `That it works is good.`（⚪ 很少用） |
| `the fact` 等名词后面 | ❌ 一般不省 | `the fact that it's free` |

**读字幕的提示：** 看到 `think / sure / know / mean / hope` 后面直接跟一个"主语 + 动词"，就说明中间省略了 `that`，盒子从这里开始。

## 8. 真实会议例句（改编）

以下句子来自真实会议字幕，已修正识别错误并做了匿名处理：

```text
I think in general it looks good.
我觉得总体上看起来不错。

I'm not sure if there's any risk if we bump the version.
我不确定升级版本有没有风险。

I'm not sure if Mia and David are aware of the email.
我不确定 Mia 和 David 有没有看到那封邮件。

I will check with Ben tomorrow to see if he has any other concerns.
我明天会和 Ben 确认一下，看他还有没有其他顾虑。

We need to do a quick prototype to figure out if it's feasible.
我们需要做一个快速原型，看看是否可行。

Do you know who will be working on the native design specs?
你知道谁会负责 Native 的设计规格吗？

The good news is that the SSR support story is completed.
好消息是 SSR 支持的 Story 已经完成了。

The description says we need to confirm whether Harness provides macOS runners.
描述里说，我们需要确认 Harness 是否提供 macOS 执行机。

Let everybody read it and understand what we want to propose.
让大家先读一下，了解我们想提议的内容。
```

## 9. 字幕里怎么认

1. **找"外壳"：** `I think`、`I'm not sure if`、`check if`、`see if`、`I wonder if`、`do you know`、`let me know what`。外壳后面就是重点。
2. **外壳后面的 `if` 先读成"是否"。** 判断方法：能换成 `whether` 就是"是否"。
3. **盒子里找主语和动词。** `Do you know when [it] [will be] ready?`
4. **非母语说法能看懂就行，不要模仿：**

| 字幕里可能听到 | 标准说法 |
| --- | --- |
| `I don't know what is it.` | `I don't know what it is.` |
| `Can you check how is the performance?` | `Can you check how the performance is?` |
| `I want to see what's the next step.` | `I want to see what the next step is.` |
| `We need to discuss that whether we need it.` | `We need to discuss whether we need it.` |
| `I want to double confirm that.` | `I want to double-check that.` |
| `I think we don't need it.` | `I don't think we need it.`（更自然） |

## 10. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `I don't know what is it.` | `I don't know what it is.` | 从句用陈述语序 |
| `Do you know when will it be ready?` | `Do you know when it will be ready?` | 从句用陈述语序 |
| `Can you tell me what does it mean?` | `Can you tell me what it means?` | 从句不加 `does` |
| `I'm not sure that it works.`（想说"是否"） | `I'm not sure if it works.` | "是否"用 `if / whether` |
| `It depends on if it's approved.` | `It depends on whether it's approved.` | 介词后用 `whether` |
| `I think so that it works.` | `I think it works.` | `so` 和从句不能同时用 |
| `What we need is we need more time.` | `What we need is more time.` | 不要重复主语和动词 |

I'm not sure if I understand the question correctly.
我不确定我是否正确理解了这个问题。

Can you check if the fix is deployed?
你能看一下修复有没有部署吗？

Do you know when the design will be ready?

## 12. 练习

**A. 把两句合成一句**（注意语序）

1. Where is the release note? I don't know.
2. When will the API be ready? Do you know?
3. Is the build green? Can you check?
4. What does this script do? Can you explain?
5. Who approved the PR? I'm not sure.

**B. 用 that / if / whether / what / how 填空**（`that` 可省略的写 that）

1. I think ___ the setup is done.
2. It depends on ___ we get the budget.
3. ___ we need is more test data.
4. I'm not sure ___ the fix works on iOS.
5. We need to figure out ___ to reproduce the bug.
6. The problem is ___ nobody owns this module.

**C. 改错**

1. Do you know what time is the meeting?
2. I don't know why did the job fail.
3. I think we don't need a new branch.（改得更自然）

<summary>答案</summary>

**A.**
1. I don't know where the release note is.
2. Do you know when the API will be ready?
3. Can you check if (whether) the build is green?
4. Can you explain what this script does?
5. I'm not sure who approved the PR.（who 是主语，语序不变）

**B.** 1 that（可省略）　2 whether　3 What　4 if / whether　5 how　6 that

**C.**
1. Do you know what time the meeting is?
2. I don't know why the job failed.
3. I don't think we need a new branch.

## 这一课解决什么问题

主持人经常这样说：

```text
Ken, can you go ahead? Then let's go through the board and see who can pick up the remaining tasks.
Ken，你先讲吧。然后我们过一遍看板，看看谁能接剩下的任务。
```

每个词都认识：`go`、`ahead`、`through`、`pick`、`up`。可是 `go ahead` 不是"往前走"，`pick up` 也不是"捡起来"。这种"**动词 + 小词**"组成新意思的结构叫**短语动词**。会议里最常用的动作，几乎都是短语动词。

**学完这一课，你应该能：**

1. 理解短语动词为什么不能逐字翻译，以及怎样从小词推测意思。
2. 掌握 25 个会议最高频的短语动词。
3. 知道哪些可以拆开：`set it up` 可以，`work it on` 不行。
4. 用对 20 组"动词 + 名词"搭配，比如 `make a decision`、`raise a concern`、`leave a comment`、`create a ticket`。

## 1. 什么是短语动词

**短语动词 = 动词 + 小词（副词或介词）**，整体表示一个新意思。

小词常常带着一种"方向感"，记住它能帮你猜意思：

| 小词 | 核心感觉 | 例子 |
| --- | --- | --- |
| `up` | 完成、出现、提起来 | `set up`、`wrap up`、`bring up`、`pick up`、`follow up` |
| `out` | 弄清楚、向外、发出去 | `figure out`、`reach out`、`roll out`、`point out` |
| `through` | 从头到尾 | `go through` |
| `on` | 继续、针对某件事 | `work on`、`move on` |
| `over` | 转交 | `hand over` |
| `back` | 返回 | `roll back`、`get back to` |
| `down` | 分解、往下 | `break down` |
| `into` | 进入内部 | `look into` |

> 💡 短语动词是口语；书面语常用一个正式动词代替。例如 `figure out` ≈ `determine`，`set up` ≈ `configure`，`look into` ≈ `investigate`。会议里用短语动词更自然。

## 2. 25 个会议高频短语动词

按会议里的用途分成五组。

### 2.1 汇报自己在做什么

| 短语 | 意思 | 常见搭配 |
| --- | --- | --- |
| `work on` | 正在做（某任务） | `work on the login page` |
| `pick up` | 接手（任务） | `pick up a ticket` |
| `set up` | 搭建、配置 | `set up the pipeline / a meeting` |
| `figure out` | 弄清楚、想出办法 | `figure out why it fails` |
| `look into` | 调查、研究 | `look into the issue` |

```text
I'm still working on the login page.
我还在做登录页。

Who can pick up this ticket?
谁能接一下这个工单？

We need to set up the pipeline before we start.
开始之前我们得把流水线搭好。

We need to figure out why the build is failing.
我们得弄清楚构建为什么失败。

I'll look into it after the meeting.
会后我查一下。
```

> 💡 `set up`（动词，两个词）和 `setup`（名词，一个词）：`set up the environment` / `The setup is done.`

### 2.2 主持和推进会议

| 短语 | 意思 | 常见搭配 |
| --- | --- | --- |
| `go ahead` | 请开始、请继续、去做吧 | `go ahead and merge it` |
| `go through` | 过一遍、逐项看 | `go through the board` |
| `move on (to)` / `move to` | 进入下一项 | `move on to the next topic` |
| `take a look (at)` | 看一下 | `take a look at the PR` |
| `bring up` | 提出（话题、问题） | `bring up a concern` |
| `wrap up` | 收尾、结束 | `wrap up the meeting` |

```text
Mia, you can go ahead.
Mia，你可以开始了。

I will go through the status one by one.
我逐个过一下状态。

Okay, let's move on to the native part.
好，我们接着看 Native 部分。

Can you take a look at my PR when you have time?
你有空的时候能看一下我的 PR 吗？

Is there anything you want to bring up today?
今天有什么想提的吗？

Let's wrap up here. Thanks, everyone.
今天就到这里，谢谢大家。
```

### 2.3 沟通与协作

| 短语 | 意思 | 常见搭配 |
| --- | --- | --- |
| `follow up (on / with)` | 跟进 | `follow up with the design team` |
| `check with` | 跟某人确认 | `check with Priya` |
| `reach out (to)` | 联系 | `reach out to the admin team` |
| `sync up` | 同步一下 | `sync up tomorrow` |
| `align with` | 和……对齐 | `align with the backend team` |
| `catch up` | 补上进度、碰个头 | `catch up after the meeting` |
| `hand over (to)` | 交接、交给 | `hand it over to Ken` |

```text
I'll follow up with the design team.
我会跟设计团队跟进。

Let me check with Priya and get back to you.
我跟 Priya 确认一下再回复你。

Feel free to reach out to me if you have questions.
有问题随时联系我。

Let's sync up tomorrow morning.
我们明早同步一下。

We need to align with the backend team on the API format.
我们需要和后端团队对齐 API 格式。

Let's catch up after the meeting.
会后我们碰一下。

I'll hand it over to Ken for the platform update.
接下来交给 Ken 讲平台组的进展。
```

### 2.4 发布与问题处理

| 短语 | 意思 | 常见搭配 |
| --- | --- | --- |
| `roll out` | （逐步）发布、上线 | `roll out the new version` |
| `roll back` | 回滚 | `roll back the release` |
| `break down (into)` | 拆分 | `break down the epic into stories` |
| `come up with` | 想出（方案） | `come up with a better solution` |
| `point out` | 指出 | `as Anna pointed out` |

```text
We will roll out the new version to 10% of users first.
我们会先把新版本发布给 10% 的用户。

We had to roll back the release last night.
我们昨晚不得不回滚了发布。

Let's break down the epic into smaller stories.
我们把这个 Epic 拆成更小的 Story。

We need to come up with a better solution.
我们需要想一个更好的方案。

As Anna pointed out, the API is not backward compatible.
正如 Anna 指出的，这个 API 不向后兼容。
```

### 2.5 两个固定表达：make sure、keep in mind

它们严格说不是短语动词，但和短语动词一样要整体记：

```text
Please make sure the tests pass before merging.
合并前请确保测试通过。

Please keep in mind that the code freeze starts on Friday.
请记住，代码冻结从周五开始。
```

`make sure` 的语法见 [G13](13-to-do-doing-done.zh.md)。另外两个会议高频说法：`double-check`（再确认一下，39 次）和 `get back to someone`（回复某人）。

## 3. 可分与不可分：宾语放哪里

这是短语动词最容易出错的地方。

### 3.1 可分的：宾语是代词时必须放中间

`set up`、`pick up`、`figure out`、`bring up`、`hand over`、`roll out`、`roll back`、`break down`、`point out`、`wrap up` 的小词是副词，**可以拆开**：

- 宾语是名词：放中间或后面都行。`set up the pipeline` = `set the pipeline up`
- 宾语是代词（`it`、`them`、`this`）：**必须放中间**。

```text
I'll set it up tomorrow.
我明天把它搭好。

Can you pick it up this sprint?
你这个 Sprint 能接手吗？

Thanks for bringing it up.
谢谢你提出来。

Let's break it down into smaller tasks.
我们把它拆成更小的任务。
```

❌ `set up it`、`pick up it`、`bring up it`

### 3.2 不可分的：宾语永远在后面

`work on`、`look into`、`go through`、`check with`、`look at`、`align with`、`wait for` 的小词是介词，**不能拆开**：

```text
I'm working on it.
我在做了。

I'll look into it.
我查一下。

Let's go through them one by one.
我们一个一个过。
```

❌ `work it on`、`look it into`

### 3.3 三个词的短语动词：不能拆

`come up with`、`catch up on`、`follow up on / with`、`reach out to`、`get back to`、`look forward to`：宾语都放在最后。

```text
I'll get back to you by tomorrow.
我明天前回复你。
```

### 3.4 不带宾语的

`go ahead`、`move on`、`catch up`、`sync up` 一般不带宾语，后面要接东西时加介词：`move on to the next item`、`sync up with the QA team`。

## 4. 名词形式：一个词或加连字符

很多短语动词有名词形式。**动词是两个词，名词连写或加连字符**：

| 动词 | 名词 | 例句 |
| --- | --- | --- |
| `set up` | `setup` | `The setup is done.` |
| `follow up` | `follow-up` | `Let's schedule a follow-up meeting.` |
| `roll out` | `rollout` | `The rollout will take two weeks.` |
| `roll back` | `rollback` | `The rollback took ten minutes.` |
| `break down` | `breakdown` | `Here is the task breakdown.` |
| `hand over` | `handover` | `We had a handover session.` |
| `sync up` | `sync-up` | `We have a daily sync-up.` |
| `work around` | `workaround` | `Is there a workaround?` |

## 5. 动词 + 名词固定搭配

中文说"做决定"，英文是 `make a decision`，不是 `do a decision`。**名词前用哪个动词，是固定的**，只能整体记。

| 动词 | 常见搭配 |
| --- | --- |
| `make` | `make a decision`、`make a change`、`make progress`、`make a suggestion`、`make a mistake` |
| `do` | `do a demo`、`do some research`、`do the estimation`、`do a code review` |
| `take` | `take a look`、`take notes`、`take ownership`、`take this offline` |
| `give` | `give an update`、`give a demo`、`give feedback`、`give an estimate` |
| `raise` | `raise a concern`、`raise a question`、`raise a PR`、`raise your hand` |
| `leave` | `leave a comment`、`leave a message` |
| `create` / `open` / `file` | `create a ticket`、`open a PR`、`file a bug` |
| `have` | `have a meeting`、`have a discussion`、`have a question` |
| `share` | `share my screen`、`share an update`、`share the link` |
| `run` | `run the tests`、`run the pipeline` |
| `fix` / `resolve` | `fix a bug`、`resolve an issue`、`resolve comments` |
| `meet` | `meet the deadline`、`meet the requirements` |
| `hit` | `hit an issue`、`hit a blocker` |
| `keep` | `keep an eye on`、`keep you posted` |
| `reach` | `reach an agreement` |

```text
We need to make a decision by Friday.
我们需要在周五前做决定。

I'd like to raise a concern about the timeline.
我想对时间安排提一个顾虑。

I left a comment on the PR.
我在 PR 上留了评论。

Can you create a ticket for this?
你能为这个建个工单吗？

Let's take this offline.
这个我们会后再聊。

We hit a blocker on the macOS build.
macOS 构建遇到了阻塞。

I'll keep you posted.
有进展我会随时告诉你。

We need to keep an eye on the error rate.
我们需要盯着错误率。
```

## 6. 真实会议例句（改编）

以下句子来自真实会议字幕，修正了识别错误，人名和项目名已替换：

```text
Okay, if no questions, Mia, you can go ahead with the platform team.
好，如果没有问题，Mia，你可以开始讲平台组了。

Leo has just picked up the task under the pipeline story.
Leo 刚接手了流水线 Story 下的任务。

We need to do a quick prototype to figure out if it's feasible.
我们需要做个快速原型，弄清楚是否可行。

We can check with the design team first.
我们可以先跟设计团队确认一下。

If you need a new parent epic, you can reach out to Priya.
如果需要新的父级 Epic，可以联系 Priya。

We plan to have a daily sync-up for each pod.
我们打算每个小组每天同步一次。

Is there anyone who wants to bring up a topic for the post-scrum?
有谁想在站会后讨论环节提个话题吗？

I'll discuss it with Anna tomorrow to see if any subtasks need to be handed over to the web team.
我明天和 Anna 讨论一下，看看有没有子任务需要交给 Web 组。

Under each feature, we can further break it down into user stories.
每个 Feature 下面还可以进一步拆成用户故事。

Okay, I will look into that and update you.
好的，我查一下再告诉你。

I will take a look at the Confluence page. I think we should be fine, but I'll double-check.
我去看一下 Confluence 页面。应该没问题，但我会再确认一下。
```

## 7. 字幕里怎么认

1. **逐字翻译说不通时，想想是不是短语动词。** 把"动词 + 小词"当成一个词去理解或查词典。
2. **注意被拆开的短语动词。** `set it up`、`pick them up`：小词跑到了后面。
3. **注意名词形式。** `the setup`、`a follow-up`、`the rollout` 是名词，不是句子的谓语。
4. **非母语说法能看懂就行，不要模仿：**

| 字幕里可能听到 | 标准说法 |
| --- | --- |
| `take a look on the page` | `take a look at the page` |
| `we have to pick up it` | `we have to pick it up` |
| `we need to keep eye on that` | `we need to keep an eye on that` |
| `sync hub` / `sink up` | `sync up`（识别错误） |
| `we will follow up the SSR` | `we will follow up on the SSR work` |
| `it can be break down to stories` | `it can be broken down into stories` |
| `you can bring up to me` | `you can bring it up with me` |
| `discuss with Ken about it` | `discuss it with Ken` |

## 8. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `Can you take a look on my PR?` | `Can you take a look at my PR?` | `take a look at` |
| `I'll set up it tomorrow.` | `I'll set it up tomorrow.` | 代词放中间 |
| `I'm working it on.` | `I'm working on it.` | `work on` 不可拆 |
| `We need to do a decision.` | `We need to make a decision.` | `make a decision` |
| `I'll reach out the admin team.` | `I'll reach out to the admin team.` | `reach out` 后接人要加 `to` |
| `The set up is done.` | `The setup is done.` | 名词连写 |
| `We need to rollback the release.` | `We need to roll back the release.` | 动词分开写 |
| `I want to raise a question to Ken.` | `I want to ask Ken a question.` | `ask sb a question` 更自然 |

## 10. 练习

**A. 从词库中选短语动词填空**（work on / pick up / look into / go through / check with / wrap up / roll back / figure out）

1. I'm still ___ the API changes.
2. Let's ___ the action items before we finish.
3. The release caused errors, so we had to ___ it.
4. I'm not sure. Let me ___ Ken first.
5. We need to ___ why the test is flaky.
6. Who can ___ this bug? It's not assigned yet.
7. I'll ___ the error logs after the meeting.
8. Okay, let's ___ here. Thanks, everyone.

**B. 代词位置：哪句对？**

1. a. I'll set up it.　b. I'll set it up.
2. a. I'm working on it.　b. I'm working it on.
3. a. Thanks for bringing it up.　b. Thanks for bringing up it.
4. a. Let's break down it.　b. Let's break it down.

**C. 选择正确的动词**（make / do / take / give / raise / leave / create）

1. We need to ___ a decision today.
2. Can you ___ a quick demo on Friday?
3. I'd like to ___ a concern about the deadline.
4. Please ___ a comment on the PR.
5. Let me ___ a look.
6. Can you ___ a ticket for this bug?
7. Mia will ___ an update on the native part.

<details>
<summary>答案</summary>

**A.** 1 working on　2 go through　3 roll back　4 check with　5 figure out　6 pick up　7 look into　8 wrap up

**B.** 1 b　2 a　3 a　4 b

**C.** 1 make　2 do（或 give）　3 raise　4 leave　5 take　6 create　7 give

</details>

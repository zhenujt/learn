# G09 将来表达：will、be going to、进行时表将来

<!-- sentence-audio: fenced-only -->

> **频率：🔴 必学** ｜ 阶段：小学 → 初中 ｜ 会议数据：`will / 'll` 每万词约 98 次，`going to / gonna` 约 9 次，`tomorrow` 约 6 次，`plan to / planning to` 约 2 次，`will be + -ing` 约 2 次
>
> [English version](09-future-will-going-to.md) · [上一课：G08 一般过去时与现在完成时](08-past-simple-and-present-perfect.zh.md) · [下一课：G10 其他时态与 16 种时态总表](10-other-tenses.zh.md) · [语法目录](README.zh.md)

## 这一课解决什么问题

站会最后一段通常说"接下来做什么"，会议结尾要认领任务。听听下面几句：

```text
I'll take a look after the meeting.
我会后看一下。

We're going to release it next week.
我们打算下周发布。

I'm planning to finish the tests by Friday.
我计划周五前完成测试。

Once the PR is merged, I'll deploy it to staging.
PR 一合并，我就部署到预发布环境。
```

中文一个"会/要/打算"就够了，英语却有好几种说法。好消息是：**会议里 `will` 占了绝大多数**（每万词约 98 次，是 `going to` 的十倍）。先把 `will` 用好，再学其他说法的细微区别。

**学完这一课，你应该能：**

1. 用 `will / 'll` 认领任务、做承诺、做预测、讲流程。
2. 用 `be going to` 说已经打算好的计划；在字幕里认出 `gonna`、`wanna`、`gotta`。
3. 用 `I'm planning to`、`I'm about to`、`It should be …`、现在进行时和一般现在时说计划与安排。
4. 掌握"主将从现"：`once / when / if / after` 后面用现在时。

## 1. 先看全局：英语没有一个万能"将来时"

| 说法 | 核心意思 | 会议频率 | 例子 |
| --- | --- | --- | --- |
| `will + 原形` | 当场决定、承诺、预测、流程 | 🔴 | `I'll check it.` |
| `be going to + 原形` | 已经打算好的计划、有迹象的预测 | 🟡 | `We're going to migrate it.` |
| `be planning to / plan to` | 计划（还在打算阶段） | 🟢 | `I'm planning to refactor it.` |
| `be + -ing`（现在进行时） | 已经约好的安排 | 🟢 | `I'm meeting Ken tomorrow.` |
| 一般现在时 | 日程表、时间表 | 🟡 | `The sprint starts on Monday.` |
| `will be + -ing` | 将来某段时间正在做 | 🟢 | `I'll be working on it next week.` |
| `be about to` | 马上就要 | 🟢 | `I'm about to push it.` |

## 2. will：会议里最主要的将来表达

### 2.1 公式

| 句型 | 例子 |
| --- | --- |
| 肯定 | `I will check it.` = `I'll check it.` |
| 否定 | `I will not merge it.` = `I won't merge it.` |
| 疑问 | `Will you join the demo?` |

`will` 后面**永远是动词原形**：不加 `to`，不加 `-s`，不加 `-ed`。`won't` 读作 /wəʊnt/，不要和 `want` 混淆。

### 2.2 用法一：当场决定、主动认领 ⭐ 最常用

会上听到一个问题，你当场说"我来"——这时只能用 `will`：

```text
I'll take a look.
我看一下。

I'll create a ticket to track this.
我建个工单跟踪一下。

I'll follow up with the design team.
我会去跟进设计团队。

Okay, I'll share it in the channel after the meeting.
好的，会后我发到频道里。
```

### 2.3 用法二：承诺和保证

```text
I'll send you the document by end of day.
我今天下班前把文档发给你。

We won't merge it before QA signs off.
QA 确认之前我们不会合并。

Don't worry, I'll fix it today.
别担心，我今天会修好。
```

### 2.4 用法三：预测和判断

常和 `I think`、`probably`、`maybe` 一起用：

```text
I think it will take about two days.
我觉得大概要两天。

It probably won't affect the native part.
它大概不会影响 Native 部分。

This will be a breaking change.
这会是一个破坏性改动。
```

### 2.5 用法四：讲流程和安排（主持人最爱）

主持人介绍团队流程时，几乎每句都用 `will`：

```text
In the grooming session, we will review all the requirements.
在梳理会上，我们会过一遍所有需求。

After that, QA will test the story.
之后，QA 会测试这个 Story。

By the end of the sprint, we will demo the completed work.
Sprint 结束时，我们会演示已完成的工作。
```

### 2.6 won't 的一个特殊意思：就是不行

`won't` 用在东西上，表示"怎么都不肯……"，描述 Bug 很好用：

```text
The app won't start.
应用就是启动不了。

The page won't load on Safari.
这个页面在 Safari 上就是加载不出来。
```

### 2.7 中文"会"不等于 will

中文的"会"有好几个意思，只有表示将来时才用 `will`：

| 中文 | ✅ 英语 | ❌ 不要说 |
| --- | --- | --- |
| 我会说英语（能力） | `I can speak English.` | `I will speak English.` |
| 他每天都会跑测试（习惯） | `He runs the tests every day.` | `He will run the tests every day.` |
| 我明天会提 PR（将来） | `I'll raise a PR tomorrow.` | — |

## 3. be going to / gonna 🟡

### 3.1 公式

**公式：** `am / is / are + going to + 动词原形`

```text
We're going to migrate the pipeline next sprint.
我们下个 Sprint 要迁移流水线。

Are we going to support SSR?
我们要支持 SSR 吗？

I'm not going to change the API.
我不打算改 API。
```

### 3.2 用法一：已经打算好的计划

说话之前就已经决定了：

```text
I'm going to work with the design team on the roadmap.
我打算和设计团队一起做路线图。

We're going to use a different font family.
我们打算用另一套字体。
```

### 3.3 用法二：有迹象的预测

眼前有证据，"看样子要……了"：

```text
Look at this graph. We're going to run out of quota this week.
看这个图，这周配额要用完了。

This change is going to break the old API.
这个改动会把旧 API 弄坏。
```

### 3.4 用法三：演示时宣布下一步

```text
I'm going to share my screen.
我来共享一下屏幕。

Now I'm going to show you the new tokens.
现在我给大家看一下新的 Token。
```

### 3.5 gonna、wanna、gotta：字幕里怎么认 🟢

母语者说快了，`going to` 会变成 `gonna`。字幕有时照音写出来：

| 字幕里看到 | 完整形式 | 意思 | 例子 |
| --- | --- | --- | --- |
| `gonna` | `going to` | 将要 | `I'm gonna share my screen.` |
| `wanna` | `want to` | 想要 | `I wanna add one thing.` |
| `gotta` | `have got to` = `have to` | 必须 | `We gotta fix this first.` |
| `lemme` | `let me` | 我来 | `Lemme check.` |
| `dunno` | `don't know` | 不知道 | `I dunno.` |
| `kinda` | `kind of` | 有点 | `It's kinda slow.` |

```text
Okay, I'm gonna share my screen.
好，我来共享屏幕。

I wanna add one thing about the timeline.
关于时间线我想补充一点。

We gotta fix this before the release.
发布前必须把这个修好。
```

注意：

- `gonna` 只代替**表将来的** `going to`。`I'm going to the office.`（我要去办公室）里的 `going to` 是"去"，不能写成 `gonna`。
- 字幕里的 `we gonna have …` 漏了 `are`，标准是 `we're going to have …`。
- 开会口头可以说 `gonna`、`wanna`；写 Jira、邮件、文档时要用完整形式。

## 4. will 和 be going to 怎么选

| 场景 | 用 | 例子 |
| --- | --- | --- |
| 会上**当场**决定 | `will` | `— The build failed. — Oh, I'll check it.` |
| 会前**已经**决定 | `be going to` | `I'm going to check the logs after the meeting.` |
| 承诺、保证 | `will` | `I'll send it by Friday.` |
| 有证据的预测 | `be going to` | `It's going to fail again.` |
| 一般判断 | 两者都行 | `I think it'll / it's going to take two days.` |
| 介绍流程、正式文档 | `will` | `QA will test the story.` |

```text
The build failed. I'll check it.
构建失败了，我来看看。（当场决定）

I'm going to check the logs after the meeting.
我打算会后查一下日志。（之前就打算好了）
```

**实际建议：** 区别很小，母语者也常混用。拿不准就用 `will`，永远不会错得太离谱。

## 5. 其他说计划的方式

### 5.1 按确定程度排列

| 说法 | 确定程度 | 例子 |
| --- | --- | --- |
| `will` / `be going to` | 很确定 | `I'll finish it today.` |
| `I'm planning to` / `We plan to` | 计划中 | `I'm planning to finish it today.` |
| `I'm hoping to` / `We expect to` | 希望、预计 | `We're hoping to finish it today.` |
| `It should be …` | 应该会（有把握但留余地） | `It should be done today.` |
| `It might …` / `maybe` | 不确定 | `It might slip to tomorrow.` |

```text
We plan to submit the PR for review tomorrow.
我们计划明天提交 PR 评审。

I'm hoping to get the access by Wednesday.
我希望周三前拿到权限。

It should hopefully be finished today.
希望今天能完成。

It might slip to next sprint.
可能会拖到下个 Sprint。
```

`should`、`might` 的更多用法见 [G11 情态动词](11-modal-verbs.zh.md)。

### 5.2 be about to：马上就要 🟢

```text
I'm about to push the fix.
我正要推修复。

We were about to discuss it in the daily sync.
我们本来正要在每日同步会上讨论这个。
```

### 5.3 be supposed to：按计划应该 🟢

表示"原定的安排"，常暗示"可能没按计划来"：

```text
It's supposed to be released on Friday.
原定是周五发布。

Wasn't QA supposed to test it yesterday?
QA 不是昨天就该测了吗？
```

## 6. 现在进行时表将来：已经约好的事 🟢

人和人之间**已经约好、安排好**的事，用现在进行时，必须带将来时间：

```text
I'm meeting the design team tomorrow.
我明天要和设计团队开会。

Ken is joining us next week.
Ken 下周加入我们。

We're releasing on Friday.
我们周五发布。
```

## 7. 一般现在时表将来：时间表 🟡

日程表、发布计划、会议时间这种**按表执行**的事，用一般现在时：

```text
The sprint starts on Monday.
Sprint 周一开始。

The meeting is at 3 PM.
会议下午 3 点开。

The code freeze begins next Wednesday.
代码冻结下周三开始。
```

## 8. will be + -ing：将来某段时间正在做 🟢

表示"到那时我正在做……"，也常用来**客观、礼貌地**说安排：

```text
I'll be working on the migration next week.
下周我会在做迁移。

We'll be assigning epics based on the roadmap.
我们会按路线图分配 Epic。

Will you be joining the demo?
你会参加演示吗？
```

`Will you be joining …?` 比 `Will you join …?` 更客气，只是问安排，没有"请求"的意思。

## 9. 主将从现：once / when / if 后面用现在时 🔴

**规则：** 在 `if`、`when`、`once`、`after`、`before`、`until`、`as soon as` 引导的从句里，**将来的事用现在时**；主句才用 `will`。

**公式：** `Once / When / If + 现在时, 主语 + will + 原形.`

```text
Once the PR is merged, I'll deploy it to staging.
PR 一合并，我就部署到预发布环境。

When I get more information, I'll share it in the channel.
等我有更多消息，会发到频道里。

If the tests pass, we'll release it tomorrow.
如果测试通过，我们明天发布。

I'll ping you as soon as I finish the fix.
我一修好就通知你。

Once I've finished the tests, I'll update the ticket.
等我做完测试，我就更新工单。（从句也可以用现在完成时）
```

❌ `When I will finish it, I will tell you.`
✅ `When I finish it, I'll tell you.`

## 10. 真实会议例句（改编）

以下句子来自真实会议字幕，已修正识别错误并匿名化：

```text
I'll create a backlog item to track this.
我建一个 Backlog 条目来跟踪这件事。

I think we should be fine, but I'll double-check.
我觉得应该没问题，不过我再确认一下。

Once Mia is back, I'll check with her as well.
等 Mia 回来，我也和她确认一下。

Once the planning session is finished, we'll share the final sprint scope with you.
计划会结束后，我们会把最终的 Sprint 范围发给你们。

I'm going to double-check with Mia whether we already have a direction for that, and I'll get back to you.
我会和 Mia 再确认一下这件事有没有定方向，然后回复你们。

We're going to publish each platform to a different package.
我们打算把每个平台发布到不同的包里。

Are we going to do regression testing on the website as well?
网站也要做回归测试吗？

Okay, I'm gonna share my screen.
好，我来共享屏幕。

I know I've been saying that for a while, but it should be finished today.
我知道这话我说了好一阵了，不过今天应该能完成。

Ken plans to submit a PR for review tomorrow.
Ken 计划明天提交 PR 评审。
```

非母语原句 vs 标准说法：

| 字幕原文 | 标准说法 |
| --- | --- |
| `So once the planning session finished, we will provide …` | `Once the planning session is finished, we will provide …` |
| `how this report will going to be used` | `how this report will be used` / `is going to be used` |
| `we gonna have another round of review` | `we're going to have another round of review` |
| `and we will plan to implement them` | `and we plan to implement them` / `and we will implement them` |
| `I'll thinking that five is okay.` | `I'm thinking that five is okay.` / `I think five is okay.` |
| `when he back office tomorrow` | `when he's back in the office tomorrow` |

## 11. 字幕里怎么认

1. **`'ll` 很容易被吞掉。** 字幕里 `I check it after the meeting` 很可能是 `I'll check it …`。看到 `tomorrow`、`after the meeting`、`next week` 这类词，就按将来理解。
2. **`going to` 后面是动词原形 → 将来；后面是地点名词 → "去"。** `going to test` vs `going to the office`。
3. **`gonna` = `going to`（将来）**，`wanna` = `want to`，`gotta` = `have to`。
4. **`once` / `when` 开头的句子**，先找逗号后面的 `will`，那是要做的动作；`once` 后面是前提条件。
5. **`should` 在进度汇报里通常是"预计"**：`It should be done today.` = 预计今天完成。

## 12. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `I will to check it.` | `I will check it.` | `will` 后不加 `to` |
| `He will checks it.` | `He will check it.` | `will` 后用原形 |
| `I will going to fix it.` | `I'm going to fix it.` / `I'll fix it.` | 两种结构不能叠加 |
| `I going to fix it.` | `I'm going to fix it.` | 漏了 `am` |
| `I'm going to checking it.` | `I'm going to check it.` | `going to` 后用原形 |
| `When I will finish, I'll tell you.` | `When I finish, I'll tell you.` | 主将从现 |
| `If it will fail, …` | `If it fails, …` | 主将从现 |
| `I will be finish it today.` | `I will finish it today.` | 多余的 `be` |
| `He will run the tests every day.`（表习惯） | `He runs the tests every day.` | 习惯用一般现在时 |
| `I will speak English.`（表能力） | `I can speak English.` | "会"表能力用 `can` |

I'm planning to finish the tests by Friday.
我计划周五前完成测试。

## 14. 练习

**A. 选择 will 或 be going to**

1. — The build failed again. — Oh, I (will / am going to) check it now.
2. We've already decided: we (will / are going to) migrate to Harness next sprint.
3. Look at the error rate. The service (will / is going to) go down.
4. Don't worry, I (will / am going to) send it by end of day.

**B. 用括号里的动词填空（注意主将从现）**

1. Once the PR ___ (be) merged, I ___ (deploy) it.
2. If the tests ___ (pass), we ___ (release) it tomorrow.
3. I ___ (ping) you when I ___ (finish) the fix.
4. The sprint ___ (start) on Monday.（时间表）

**C. 把字幕改成标准说法**

1. we gonna have another review next week
2. I will to update the ticket
3. when he will be back I will ask him
4. I'm going to checking the logs

**D. 按确定程度从高到低排列**

It might be done today. / I'll finish it today. / It should be done today. / I'm hoping to finish it today.

<details>
<summary>答案</summary>

**A.** 1 will（当场决定）　2 are going to（已经决定）　3 is going to（有迹象的预测）　4 will（承诺）

**B.** 1 is, will deploy　2 pass, will release　3 will ping, finish　4 starts

**C.**
1. We're going to have another review next week.
2. I will update the ticket. / I'll update the ticket.
3. When he's back, I'll ask him.
4. I'm going to check the logs.

**D.** I'll finish it today. → It should be done today. → I'm hoping to finish it today. → It might be done today.

</details>

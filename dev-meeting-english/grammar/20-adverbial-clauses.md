## What This Lesson Solves

When people talk about plans in meetings, almost every sentence carries a time or a condition:

```text
Once the PR is approved, we can merge it and close the task.

When the setup is done, I will let you know.
```

Both sentences are about the future, yet `is approved` and `is done` are in the **present simple**. Chinese speakers often say `When the setup will be done`. This lesson explains the rule.

**After this lesson, you can:**

1. Recognize adverbial clauses: find the main clause first, then see what the clause adds (time, reason, purpose, concession).
2. Order your work with `when / once / before / after / until / as soon as`.
3. Remember: in time and condition clauses, **use the present for the future**.
4. Understand `so that`, `so … that`, `although`, `even though`, `while`, and `in case`.

## 1. The Right Way to Think About Adverbial Clauses

**Adverbial clause = linking word + full clause.** It tells the main clause when, why, for what purpose, or despite what.

**Pattern:**

- `clause, main clause.` (clause first, with a comma)
- `main clause + clause.` (clause second, usually no comma)

```text
When the design is ready, we will start development.

We will start development when the design is ready.
```

**Common types:**

| Type | Linking words | Frequency |
| --- | --- | --- |
| Time | `when`, `once`, `before`, `after`, `until`, `as soon as`, `while` | 🔴 / 🟡 |
| Reason | `because`, `since`, `as` | 🔴 |
| Condition | `if`, `unless`, `as long as` | 🔴, see [G21](21-conditionals.md) |
| Purpose | `so that`, `in case` | 🟡 / 🟢 |
| Result | `so … that`, `such … that` | 🟢 |
| Concession / contrast | `although`, `even though`, `while`, `whereas` | 🟢 / ⚪ |

## 2. Time Clauses

### 2.1 when 🔴

```text
When the setup is done, I will let you know.

When we have the official channel, we can set up the notifications.

When I move the ticket to Done, the status doesn't change.
```

`when` can be followed by `-ing` when both clauses share the subject:

```text
Did you have any issues when moving the status?
```

> ⚠️ Do not confuse this with `when` in a question or noun clause: in `Do you know when it will be ready?`, `when` means "at what time" and `will` is allowed; see [G18](18-noun-clauses.md).

### 2.2 once: As Soon As Something Is Complete 🟡

`once` stresses that **one step must finish before the next starts**. It is perfect for describing a process:

```text
Once QA signs off, we can mark the task as done.

Once it's finalized, we will share it with the team.

Once Ken is back, I'll check with him.
```

In speech, the subject and `is` are often dropped:

```text
We will share it with the team once finalized.
```

### 2.3 before / after 🟡

`before` and `after` can take a **clause** (conjunction), a **noun** (preposition), or **-ing**:

```text
Let's fix the tests before we merge the PR.

Let's fix the tests before the release.

Let's fix the tests before merging the PR.

After the regression is finished, we can prioritize the bugs.
```

`after that` ("then, next") is very common for the next step in a process:

```text
After that, the story is ready for development.
```

### 2.4 as soon as 🟢

Stronger than `once`: "immediately when".

```text
As soon as I have the results, I'll share them with the team.
```

`as soon as possible` (ASAP) is a fixed phrase and more common than the clause.

### 2.5 until 🟢

```text
We will hold the story until we get your input.

I'll wait until it's provisioned.
```

**`not … until` = "only when"**. Chinese speakers often read it the wrong way round:

```text
We can't start until the design is ready.
```

In speech `till` = `until`: `waiting till QA`.

### 2.6 while: During 🟢

```text
Please don't push to main while the release is running.
```

`while` can also mean "whereas" (section 6). `for a while` is a noun phrase, not a clause.

## 3. ⭐ Present Tense for the Future in Time and Condition Clauses

**Rule:** after `when / once / before / after / until / as soon as / if / unless`, use the **present simple** for future events (present perfect to stress completion). **Put `will` only in the main clause.**

| ❌ Wrong | ✅ Right |
| --- | --- |
| `When the setup will be done, I will tell you.` | `When the setup is done, I will tell you.` |
| `Once QA will sign off, we can close it.` | `Once QA signs off, we can close it.` |
| `I'll wait until it will be ready.` | `I'll wait until it's ready.` |
| `Before we will merge it, …` | `Before we merge it, …` |

**Why?** The main clause (`will / can / let's`) already shows the future. The clause is only a time point or a precondition.

**Present perfect stresses "after it is finished":**

```text
Once I've finished the review, I'll merge it.

After we have tested it on iOS, we will release it.
```

**Contrast:** noun clauses use `will` normally:

```text
I don't know when it will be ready.

I'll tell you when it's ready.
```

**Another common slip: a missing `be`.** Subtitles often show `once the PR approved` or `when he back`:

```text
Once the PR is approved, we can merge the code.

He can take a look when he is back.
```

## 4. Reason Clauses: because, since, as

`because` was covered in [G17](17-conjunctions-and-linking.md): **with `because`, do not add `so`.**

```text
I'm looking into it now because I think we gave him edit access.

Since everyone is here, let's start.
```

`since` here means "given that" (🟢). `as` for reason is formal and rare in meetings. `since` can also mean "from a time" (`since Monday`); check whether a time or a clause follows.

## 5. Purpose and Result: so that, so … that, such … that 🟡

### 5.1 so that: Purpose 🟡

**Pattern:** `main clause + so that + subject + can / will + verb`

```text
Let's set up the telemetry server so that we don't need another review.

I'll prioritize this work so that we can finalize the variables.
```

In speech, often just `so`: `Send me the link so I can check it.` (see [G17](17-conjunctions-and-linking.md))

### 5.2 so … that / such … that: Result 🟢

**Pattern:**

- `so + adjective / adverb + that + result`
- `such + (a) + adjective + noun + that + result`

```text
The change is so small that we don't need a full regression.

It was such a busy sprint that we couldn't finish the docs.
```

Less than once per 10k words in meetings. Speakers usually say two clauses instead: `The change is really small, so we don't need a full regression.`

> ⚠️ Do not confuse it with `so that` (purpose): `so that` stays together; `so … that` has an adjective in the middle.

## 6. Concession and Contrast: although, even though, while, whereas 🟢

### 6.1 although / though / even though

**Pattern:** `Although + clause, main clause.` (**no `but`**)

```text
Although some members are out of office, we will keep the release date.

Even though it doesn't change any logic, it's still a code change.
```

`even though` is stronger than `although`. `though` can also go at the **end** of a sentence, meaning "however"; this is common in speech:

```text
It's not a hard blocker for us, though.
```

### 6.2 while / whereas: Contrast

Besides "during", `while` can **contrast two facts**:

```text
Android is done, while iOS is still in progress.

The current version is 16, while we proposed 18 or 20.
```

`whereas` means the same but is very formal; it almost never appears in meetings. Recognize it and move on (⚪):

```text
The web team uses React, whereas the native team uses Compose.
```

## 7. Condition and Prevention: if, unless, in case

`if`, `unless`, and `as long as` are covered in [G21 Conditionals](21-conditionals.md).

`in case` means "**as a precaution**": you do something now because something might happen:

```text
Let's keep the old branch in case we need to roll back.

Just in case, I'll share the link in the chat.
```

> ⚠️ `in case` is not `if`. `Take an umbrella in case it rains` means "take it now, because it might rain". Subtitles often show `in case if …`; the standard form is just `in case`.

## 8. Reading Several Clauses in One Sentence

Real subtitles often chain clauses:

```text
So once we get the design approved and we decide which approach to take, we can start this task.
```

Split:

```text
Once we get the design approved.

And we decide which approach to take.

We can start this task.
```

**Method:** find the main clause after the comma (`we can start this task`), then read `once …` as the precondition.

## 9. Real Meeting Examples (Adapted)

From real subtitles, with recognition errors fixed and names replaced:

```text
Once the planning session is finished, we will share the final sprint scope with you.

And once approved, our developer will continue the work.

When the power automation is ready, we can start to work on that task.

We will try to fix the accessibility issues before QA starts.

Before Grace joins the meeting, I just want to double-check one thing.

I'm still going through the answers, but as soon as I have the summary, I'll share it.

We can bump the version directly, just in case.
```

## 10. Recognizing Adverbial Clauses in Subtitles

1. **When a line starts with `when / once / before / after / until / because / although`, find the comma.** The main clause follows it.
2. **When the clause comes second, there is no comma.** Split at the linking word.
3. **Read `once` as "after … is done", `until` as "up to the time", and `not … until` as "only when".**
4. **Recognize, but do not copy, non-native forms:**

| Heard in subtitles | Standard form |
| --- | --- |
| `Once the PR approved, we can merge it.` | `Once the PR is approved, we can merge it.` |
| `He can take a look when he back.` | `He can take a look when he is back.` |
| `When you ready for test, …` | `When you're ready for testing, …` |
| `When the setup will be done, …` | `When the setup is done, …` |
| `Even though it's small, but it's a code change.` | `Even though it's small, it's a code change.` |
| `in case if someone asks` | `in case someone asks` |

## 11. Common Mistakes

| ❌ Wrong | ✅ Right | Reason |
| --- | --- | --- |
| `I'll tell you when it will be ready.` | `I'll tell you when it's ready.` | present for future in time clauses |
| `Once he return, we can align.` | `Once he returns, we can align.` | third-person -s |
| `Although it works, but it's slow.` | `Although it works, it's slow.` | no `but` with `although` |
| `We can start until the design is ready.` | `We can't start until the design is ready.` | "only when" = `not … until` |
| `Please review it before merge.` | `Please review it before merging.` / `before we merge it` | -ing after a preposition |
| `It's so a small change that …` | `It's such a small change that …` | `such` before a noun |
| `in case if we need it` | `in case we need it` | no `if` after `in case` |

## 12. Sentences You Can Use Today

```text
I'll let you know when it's ready.

Once the PR is approved, I'll merge it.

Let's double-check before we release it.

I'll wait until the design is final.

I'll share the results as soon as I have them.

Let's keep the old config in case we need to roll back.

Although it's a small change, we still need a review.
```

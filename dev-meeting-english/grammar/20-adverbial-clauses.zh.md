# G20 状语从句：when、once、before、until、although

<!-- sentence-audio: fenced-only -->

> **频率：🔴 必学（when、because）/ 🟡 常用（once、before、after、so that）** ｜ 阶段：初中 → 高中 ｜ 会议数据：`because` 每万词约 19 次，`when` 约 16 次，`before` 约 8 次，`after` 约 7 次，`once` 约 6 次，`so that` 约 3 次，`while` 约 1.7 次，`although / though` 约 1.4 次，`until` 约 1.1 次，`in case` 约 0.9 次，`as soon as` 约 0.6 次
>
> [English version](20-adverbial-clauses.md) · [上一课：G19 定语从句](19-relative-clauses.zh.md) · [下一课：G21 条件句](21-conditionals.zh.md) · [语法目录](README.zh.md)

## 这一课解决什么问题

会议里讲计划时，几乎每句都带一个"条件 / 时间"：

```text
Once the PR is approved, we can merge it and close the task.
PR 一批准，我们就可以合并并关闭这个任务。

When the setup is done, I will let you know.
配置好了我会告诉你。
```

这两句说的都是将来的事，但 `is approved`、`is done` 用的却是**一般现在时**。中国同学很容易说成 `When the setup will be done`。这一课把这条规则讲透。

**学完这一课，你应该能：**

1. 认出状语从句，先找主句，再看从句补充了什么（时间、原因、目的、让步）。
2. 熟练使用 `when / once / before / after / until / as soon as` 安排工作顺序。
3. 牢记：时间和条件从句里，**用现在时表示将来**。
4. 看懂 `so that`、`so … that`、`although`、`even though`、`while`、`in case`。

## 1. 先建立一个正确的认识

**状语从句 = 连接词 + 完整句子**，用来给主句补充"什么时候、为什么、为了什么、尽管什么"。

**公式：**

- `从句, 主句.`（从句在前，中间加逗号）
- `主句 + 从句.`（从句在后，一般不加逗号）

```text
When the design is ready, we will start development.
设计好了以后，我们就开始开发。

We will start development when the design is ready.
设计好了以后，我们就开始开发。
```

**常见类型：**

| 类型 | 连接词 | 中文 | 频率 |
| --- | --- | --- | --- |
| 时间 | `when`、`once`、`before`、`after`、`until`、`as soon as`、`while` | 当……、一……就、在……之前/之后、直到 | 🔴 / 🟡 |
| 原因 | `because`、`since`、`as` | 因为、既然 | 🔴 |
| 条件 | `if`、`unless`、`as long as` | 如果、除非、只要 | 🔴，见 [G21](21-conditionals.zh.md) |
| 目的 | `so that`、`in case` | 以便、以防 | 🟡 / 🟢 |
| 结果 | `so … that`、`such … that` | 如此……以至于 | 🟢 |
| 让步 / 对比 | `although`、`even though`、`while`、`whereas` | 虽然、即使、而 | 🟢 / ⚪ |

## 2. 时间从句

### 2.1 when：当……的时候 🔴

```text
When the setup is done, I will let you know.
配置好了我会告诉你。

When we have the official channel, we can set up the notifications.
等我们有了正式频道，就可以配置通知了。

When I move the ticket to Done, the status doesn't change.
我把工单拖到"完成"时，状态并没有变。
```

`when` 后面也可以直接接 `-ing`，主语和主句相同时：

```text
Did you have any issues when moving the status?
你在改状态的时候遇到问题了吗？
```

> ⚠️ 别和问句、名词性从句里的 `when` 混淆：`Do you know when it will be ready?` 里的 `when` 是"什么时候"，可以用 `will`，见 [G18](18-noun-clauses.zh.md)。

### 2.2 once：一……就、等……之后 🟡

`once` 强调"**某件事完成之后，下一步才开始**"，非常适合讲流程：

```text
Once QA signs off, we can mark the task as done.
QA 一签字确认，我们就可以把任务标为完成。

Once it's finalized, we will share it with the team.
定稿以后，我们会分享给团队。

Once Ken is back, I'll check with him.
等 Ken 回来，我会跟他确认。
```

口语里常常省掉主语和 `is`，只留 `once + 过去分词`：

```text
We will share it with the team once finalized.
定稿以后我们会分享给团队。（= once it is finalized）
```

### 2.3 before / after：在……之前 / 之后 🟡

`before` 和 `after` 后面可以接**句子**（连词）、**名词**（介词）或 **-ing**：

```text
Let's fix the tests before we merge the PR.
我们在合并 PR 之前把测试修好。（+ 句子）

Let's fix the tests before the release.
我们在发布前把测试修好。（+ 名词）

Let's fix the tests before merging the PR.
我们在合并 PR 之前把测试修好。（+ -ing）

After the regression is finished, we can prioritize the bugs.
回归测试结束后，我们可以给 Bug 排优先级。
```

会议里 `after that`（在那之后）非常常见，用来讲流程的下一步：

```text
After that, the story is ready for development.
在那之后，这个 Story 就可以进入开发了。
```

### 2.4 as soon as：一……就（马上）🟢

比 `once` 更强调"马上"：

```text
As soon as I have the results, I'll share them with the team.
我一拿到结果就分享给团队。
```

`as soon as possible`（尽快，缩写 ASAP）是固定短语，比从句更常见。

### 2.5 until：直到 🟢

```text
We will hold the story until we get your input.
在收到你的意见之前，我们先不动这个 Story。

I'll wait until it's provisioned.
我等它配置好再说。
```

**`not … until` = "直到……才"**，中国同学常常理解反：

```text
We can't start until the design is ready.
设计好了我们才能开始。
```

口语里 `till` 和 `until` 一样：`waiting till QA`。

### 2.6 while：在……期间 🟢

```text
Please don't push to main while the release is running.
发布进行期间请不要往 main 推代码。
```

`while` 还有"而"的意思，见第 6 节。`for a while`（一阵子）是名词短语，不是从句。

## 3. ⭐ 时间和条件从句：用现在时表示将来

**规则：** 在 `when / once / before / after / until / as soon as / if / unless` 引导的从句里，**将来的事用一般现在时**（强调"完成"时用现在完成时）。**`will` 只放在主句里。**

| ❌ 错误 | ✅ 正确 |
| --- | --- |
| `When the setup will be done, I will tell you.` | `When the setup is done, I will tell you.` |
| `Once QA will sign off, we can close it.` | `Once QA signs off, we can close it.` |
| `I'll wait until it will be ready.` | `I'll wait until it's ready.` |
| `Before we will merge it, …` | `Before we merge it, …` |

**为什么？** 主句已经用 `will / can / let's` 说明了这是将来的事，从句只是一个"时间点"或"前提"，不需要再说一遍"将来"。

**现在完成时强调"做完以后"：**

```text
Once I've finished the review, I'll merge it.
我评审完就合并。

After we have tested it on iOS, we will release it.
在 iOS 上测完以后，我们就发布。
```

**对比：** 名词性从句里照常用 `will`：

```text
I don't know when it will be ready.
我不知道它什么时候能好。（名词性从句：可以用 will）

I'll tell you when it's ready.
好了我就告诉你。（时间状语从句：不用 will）
```

**另一个常见错误：漏掉 be。** 字幕里常见 `once the PR approved`、`when he back`，都缺了 `is`：

```text
Once the PR is approved, we can merge the code.
PR 批准以后，我们就可以合并代码。

He can take a look when he is back.
他回来以后可以看一下。
```

## 4. 原因从句：because、since、as

`because` 在 [G17](17-conjunctions-and-linking.zh.md) 已经讲过：**说了 `because` 就不说 `so`**。

```text
I'm looking into it now because I think we gave him edit access.
我正在查，因为我觉得我们给过他编辑权限。

Since everyone is here, let's start.
既然大家都到了，我们开始吧。（since：既然 🟢）
```

`as` 表示原因比较书面，会议里少见。`since` 还有"自从"的意思（`since Monday`），看后面是时间还是句子来判断。

## 5. 目的和结果：so that、so … that、such … that 🟡

### 5.1 so that：目的（以便、这样就能）🟡

**公式：** `主句 + so that + 主语 + can / will + 动词`

```text
Let's set up the telemetry server so that we don't need another review.
我们把遥测服务器搭起来，这样就不需要再走一次评审了。

I'll prioritize this work so that we can finalize the variables.
我会优先做这项工作，这样我们就能把变量定下来。
```

口语里常常只说 `so`：`Send me the link so I can check it.`（详见 [G17](17-conjunctions-and-linking.zh.md)）

### 5.2 so … that / such … that：结果（如此……以至于）🟢

**公式：**

- `so + 形容词 / 副词 + that + 结果`
- `such + (a) + 形容词 + 名词 + that + 结果`

```text
The change is so small that we don't need a full regression.
这个改动很小，我们不需要做完整回归测试。

It was such a busy sprint that we couldn't finish the docs.
这个 Sprint 太忙了，我们没能把文档写完。
```

会议里每万词不到 1 次。口语里更常直接说成两句：`The change is really small, so we don't need a full regression.`

> ⚠️ 别和 `so that`（目的）搞混：`so that` 是连在一起的；`so … that` 中间夹着一个形容词。

## 6. 让步和对比：although、even though、while、whereas 🟢

### 6.1 although / though / even though：虽然、即使

**公式：** `Although + 句子, 主句.`（**不再加 `but`**）

```text
Although some members are out of office, we will keep the release date.
虽然有些成员休假，我们还是保持原定发布日期。

Even though it doesn't change any logic, it's still a code change.
即使它没改任何逻辑，它仍然是一次代码改动。
```

`even though` 比 `although` 语气更强（"即便如此"）。`though` 还可以放在**句末**，意思是"不过"，口语里很常见：

```text
It's not a hard blocker for us, though.
不过这对我们来说不算硬性阻塞。
```

### 6.2 while / whereas：而（对比）

`while` 除了"在……期间"，还可以表示**两件事的对比**：

```text
Android is done, while iOS is still in progress.
Android 做完了，而 iOS 还在进行中。

The current version is 16, while we proposed 18 or 20.
目前的版本是 16，而我们提议的是 18 或 20。
```

`whereas` 意思一样，但很书面，会议中几乎用不到，了解即可，可以跳过（⚪）：

```text
The web team uses React, whereas the native team uses Compose.
Web 团队用 React，而 Native 团队用 Compose。
```

## 7. 条件和预防：if、unless、in case

`if`、`unless`、`as long as` 是条件从句，详见 [G21 条件句](21-conditionals.zh.md)。

`in case` 表示"**以防万一**"，是为了预防而提前做某事：

```text
Let's keep the old branch in case we need to roll back.
我们保留旧分支，以防需要回滚。

Just in case, I'll share the link in the chat.
以防万一，我把链接发到聊天里。
```

> ⚠️ `in case` 不等于 `if`。`Take an umbrella in case it rains` 是"带伞以防下雨"，不是"如果下雨就带伞"。字幕里常听到 `in case if …`，标准说法只说 `in case`。

## 8. 一句里有多个从句怎么读

真实字幕经常把好几个从句串在一起：

```text
So once we get the design approved and we decide which approach to take, we can start this task.
等设计批下来、我们也决定了用哪种方案，就可以开始这个任务了。
```

拆开：

```text
Once we get the design approved.
等设计批下来。

And we decide which approach to take.
并且我们决定了用哪种方案。

We can start this task.
我们就可以开始这个任务。
```

**方法：** 先找逗号后面的主句（`we can start this task`），再回头把 `once …` 当成"前提条件"。

## 9. 真实会议例句（改编）

以下句子来自真实会议字幕，已修正识别错误并做了匿名处理：

```text
Once the planning session is finished, we will share the final sprint scope with you.
计划会结束后，我们会把最终的 Sprint 范围发给你。

And once approved, our developer will continue the work.
批准以后，我们的开发会继续推进。

When the power automation is ready, we can start to work on that task.
等自动化流程准备好，我们就可以开始做那个任务了。

We will try to fix the accessibility issues before QA starts.
我们会尽量在 QA 开始之前修掉无障碍问题。

Before Grace joins the meeting, I just want to double-check one thing.
在 Grace 进会之前，我想先确认一件事。

I'm still going through the answers, but as soon as I have the summary, I'll share it.
我还在看所有的回答，但一整理好我就分享出来。

We can bump the version directly, just in case.
我们可以直接升级版本，以防万一。
```

## 10. 字幕里怎么认

1. **看到 `when / once / before / after / until / because / although` 开头，先找逗号**，逗号后面才是主句。
2. **从句在主句后面时没有逗号**，在连接词处断开即可。
3. **`once` 读成"等……之后"，`until` 读成"在……之前一直"，`not … until` 读成"……才"。**
4. **非母语说法能看懂就行，不要模仿：**

| 字幕里可能听到 | 标准说法 |
| --- | --- |
| `Once the PR approved, we can merge it.` | `Once the PR is approved, we can merge it.` |
| `He can take a look when he back.` | `He can take a look when he is back.` |
| `When you ready for test, …` | `When you're ready for testing, …` |
| `When the setup will be done, …` | `When the setup is done, …` |
| `Even though it's small, but it's a code change.` | `Even though it's small, it's a code change.` |
| `in case if someone asks` | `in case someone asks` |

## 11. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `I'll tell you when it will be ready.` | `I'll tell you when it's ready.` | 时间从句用现在时表将来 |
| `Once he return, we can align.` | `Once he returns, we can align.` | 第三人称单数 |
| `Although it works, but it's slow.` | `Although it works, it's slow.` | 不和 `but` 连用 |
| `We can start until the design is ready.` | `We can't start until the design is ready.` | "……才"用 `not … until` |
| `Please review it before merge.` | `Please review it before merging.` / `before we merge it` | 介词后用 -ing |
| `It's so a small change that …` | `It's such a small change that …` | 名词前用 `such` |
| `in case if we need it` | `in case we need it` | `in case` 不加 `if` |

## 12. 你可以直接用的句子

```text
I'll let you know when it's ready.
好了我会告诉你。

Once the PR is approved, I'll merge it.
PR 一批准我就合并。

Let's double-check before we release it.
我们发布之前再确认一下。

I'll wait until the design is final.
我等设计定稿再说。

I'll share the results as soon as I have them.
我一拿到结果就分享。

Let's keep the old config in case we need to roll back.
我们保留旧配置，以防需要回滚。

Although it's a small change, we still need a review.
虽然是个小改动，我们仍然需要评审。
```

## 13. 练习

**A. 用括号里的动词填空**（注意现在时表将来）

1. When the build ___ (finish), I will deploy it.
2. Once QA ___ (sign) off, we can close the ticket.
3. I'll wait until Ken ___ (be) back.
4. I don't know when the API ___ (be) ready.
5. As soon as I ___ (get) access, I'll start testing.

**B. 用 once / until / before / although / in case / so that 填空**

1. Let's keep a backup ___ something goes wrong.
2. We can't release it ___ the security check passes.
3. ___ the tests pass, we can merge it.
4. Please update the ticket ___ the team can see the status.
5. ___ it works on Android, it still fails on iOS.
6. Let's review the design ___ we start coding.

**C. 改错**

1. When the design will be ready, we will start.
2. Even though we fixed it, but the test still fails.
3. Once the ticket approved, we can start.

<details>
<summary>答案</summary>

**A.** 1 finishes　2 signs　3 is　4 will be（名词性从句，可以用 will）　5 get

**B.** 1 in case　2 until　3 Once　4 so that　5 Although　6 before

**C.**
1. When the design is ready, we will start.
2. Even though we fixed it, the test still fails.
3. Once the ticket is approved, we can start.

</details>

# G04 The Verb Be and There Be

<!-- sentence-audio: fenced-only -->

> **Frequency: 🔴 Must learn** | Level: primary → junior high | Meeting data per 10,000 words: `is/are/am` (including `it's`, `that's`, `I'm`, etc.) ≈ 320 — the most common verb in meetings; `was/were` ≈ 10.5; There be (`there is / there are`, etc.) ≈ 13.5

## What This Lesson Solves

More than half of a stand-up update is built on `be` and `there be`:

```text
The login page is done, the API is still in progress, and there are two bugs left.
```

The Chinese version of this sentence has no word for "is", but the English uses `be` three times. On the other hand, with `agree` English must not add `be` at all (❌ `I am agree`). Almost every `be` error made by Chinese speakers comes from treating `be` as the Chinese word *shì* ("is").

**After this lesson, you can:**

1. Choose `am / is / are / was / were` and their contractions by subject and time.
2. Report progress with "be + status word": `done`, `blocked`, `on track`, `out of office`…
3. Recognize the three helper uses of `be`: continuous, passive, and `be going to`.
4. Use `There is / There are` to say something exists, instead of `Have a problem in the build.`

## 1. The Core Idea: be Is Not Chinese *shì*

`be` **links the subject to a state, identity, or place**. Chinese often needs no verb here; English always needs `be`:

| Meaning | English | Note |
| --- | --- | --- |
| busy | `I'm busy.` | `be` before an adjective |
| not here today | `He's out today.` | `be` before a place or state |
| still being built | `It's still in progress.` | `be` before a prepositional phrase |
| a bug | `This is a bug.` | `be` before a noun |
| agree | `I agree.` | `agree` is a verb — **no** `be` |
| failed | `The build failed.` | there is already a verb — **no** `be` |

**Rule:** `be` is followed by a **noun, adjective, prepositional phrase, or place adverb**. Do not put `be` directly before an ordinary verb, unless it is an `-ing` form (continuous) or a past participle (passive); see section 4.

## 2. Forms of be 🔴

| Subject | Present | Past | Present negative | Past negative |
| --- | --- | --- | --- | --- |
| I | am (I'm) | was | I'm not | wasn't |
| he / she / it / singular noun | is (he's / it's) | was | isn't | wasn't |
| you / we / they / plural noun | are (you're / we're / they're) | were | aren't | weren't |

Other forms:

| Form | Used | Example |
| --- | --- | --- |
| `be` (base) | after modals, `to`, imperatives | `It will be ready.`, `Be careful.` |
| `been` | perfect tenses | `It has been broken since Monday.` |
| `being` | continuous passive, or "behaving" 🟢 | `It's being reviewed.` |

The contractions you hear most: `I'm`, `it's`, `that's`, `there's`, `we're`, `what's`.

```text
I'm not sure.

It's not ready yet.

We're almost done.

They aren't available today.
```

> ⚠️ There is no `amn't`; in questions English uses `Aren't I …?` (🟢, rare in meetings).

## 3. be + Complement: The All-Purpose Status Pattern 🔴

**Pattern:** `subject + be + status (adjective / prepositional phrase / noun / place adverb)`

### 3.1 be + Adjective

```text
The PR is ready for review.

I'm blocked by the access issue.

Are you available after the meeting?

I'm not sure about the timeline.

I'm good with that.
```

### 3.2 be + Prepositional Phrase

Most common progress phrases are prepositional phrases:

| Phrase | Meaning | Phrase | Meaning |
| --- | --- | --- | --- |
| `be on track` | going as planned | `be in progress` | being worked on |
| `be on hold` | paused | `be in QA` | being tested |
| `be under review` | being reviewed | `be behind schedule` | late |
| `be out of office` | away from work | `be on leave` | on leave |
| `be on mute` | muted | `be in a meeting` | in a meeting |

```text
Most of the stories are on track.

The ticket is on hold until we get approval.

Ken is out of office this week.
```

### 3.3 be + Noun

```text
This is the PR I mentioned.

It's a known issue.

I'm the owner of this ticket.
```

### 3.4 be + Place Adverb

```text
Is Mia here?

I'm back.

Sorry, I'm here now.
```

### 3.5 be + Adjective + Preposition: Fixed Combinations 🔴

Learn these as chunks; the preposition cannot change:

| Combination | Meaning | Example |
| --- | --- | --- |
| `be ready for` | prepared for | `It's ready for QA.` |
| `be responsible for` | in charge of | `Who is responsible for this?` |
| `be blocked by` | stopped by | `We're blocked by the approval.` |
| `be aware of` | know about | `Are you aware of this change?` |
| `be familiar with` | know well | `I'm not familiar with this repo.` |
| `be fine with / good with` | accept | `I'm fine with that.` |
| `be related to` | connected to | `Is this related to the cache?` |
| `be similar to` | like | `It's similar to the old version.` |
| `be different from` | not like | `iOS is different from Android here.` |
| `be busy with` | occupied by | `I'm busy with the release.` |

## 4. be as a Helper Verb: Three Structures to Recognize 🔴

`be` is also a building block. When you see `be` followed by a verb form, decide which structure it is:

| Structure | Formula | Example | See |
| --- | --- | --- | --- |
| Continuous | be + `-ing` | `I'm working on it.` | [G07](07-present-simple-and-continuous.md) |
| Passive | be + past participle | `It was deployed yesterday.` | [G12](12-passive-voice.md) |
| Future | be going to + base verb | `We're going to release next week.` | [G09](09-future-will-going-to.md) |

```text
I'm still working on the login page.

The PR is merged.

The fix was deployed this morning.

We're going to demo it on Friday.
```

Other common structures 🟡:

```text
I'm not able to access the server.

The build is supposed to run every night.

We're about to release it.
```

`be able to` = can; `be supposed to` = should, according to a rule or plan; `be about to` = will very soon.

> ⚠️ `be` is never followed directly by a base verb: ❌ `I'm work on it`, ❌ `It's happen again`. Use `-ing` (`I'm working on it`) or remove `be` (`It happened again`).

## 5. was / were: Past States 🟡

About 10.5 per 10,000 words, mostly for "how things were yesterday or last week".

```text
It was fine yesterday.

We were blocked last week.

Sorry, I was on mute.

I was out of office on Monday.

The meeting was a bit long.
```

### 5.1 I was wondering if … 🟡

The past continuous sounds more polite, but the meaning is still "I want to ask now":

```text
I was wondering if you could review my PR today.
```

> `If I were you, …` (subjunctive) almost never appears in meetings (⚪); see [G21](21-conditionals.md).

## 6. be with Modals and Perfect Tenses 🔴

```text
It will be ready tomorrow.

It should be fine.

It might be a cache issue.

It can be a bit slow on Android.

It has been broken since Monday.
```

**Pattern:** `will / should / might / can / must + be`; `have / has + been`. Always the base form `be` or `been`, never `is`: ❌ `It will is ready.`

## 7. There be: Saying Something Exists 🟡

### 7.1 Meaning and Pattern

`There is / There are` means **something exists somewhere or at some time**. `there` here does not mean "over there"; it just fills the subject position.

**Pattern:** `There + be + noun + (place / time / other detail)`

```text
There is a bug in the login page.

There are two options.

There's a meeting at 3 PM.
```

### 7.2 Singular or Plural: Look at the First Noun After be

```text
There is one more thing.

There are three subtasks under this story.

There is a bug and two warnings.
```

> ⚠️ In speech you often hear `there's` + plural, such as `There's two issues.` or `There's no open issues now.` Native speakers say it too, so understand it; when you speak, `there are` is the safer choice.

### 7.3 Negatives and Questions

```text
There's no update from the design team.

There aren't any blockers.

Is there any update on this?

Are there any questions?

Is there anything else?
```

Hosts often shorten these to `Any questions?` and `Anything else?`.

### 7.4 Other Tenses and Modals 🟡

```text
There was an issue with the deployment yesterday.

There will be a short demo after the sync.

There might be a delay.

There has been a lot of discussion about this.

There seems to be a problem with the VPN.
```

`There seems to be` is 🟢.

### 7.5 There be + Noun + Tail 🟡

The noun often carries a "tail" that describes it:

```text
There are two items to follow up.

There is one thing I want to mention.

There are four subtasks left.

There is something wrong with the pipeline.

There are some discussions going on about the tool.
```

### 7.6 There be vs have 🔴

The Chinese word *yǒu* means both "own" and "exist". English separates them:

| Meaning | ✅ English | ❌ Chinglish |
| --- | --- | --- |
| We own two options | `We have two options.` / `There are two options.` | — |
| A problem exists in the build | `There's a problem with the build.` / `The build has a problem.` | `Have a problem in the build.` |
| A meeting exists today | `There's a meeting today.` / `We have a meeting today.` | `Today have a meeting.` |
| Any other questions? | `Are there any other questions?` | `Have other questions?` |

**Rule:** when there is no "owner" subject, use `There is / There are`.

### 7.7 Here is / Here are 🟡

Use `here` when you point something out:

```text
Here is the link.

Here are the results from last night.
```

## 8. Real Meeting Examples (Adapted)

```text
I'm not sure if this is related to the cache.

The fix is ready, but it's not merged yet.

I think we are good to move forward with this approach.

There are a couple of pages with detailed explanations under this folder.

There are four subtasks that need to continue in the next sprint.

There's no topic from team members, so let's move on.

We were about to discuss it in the daily sync.
```

## 9. Reading Subtitles

1. **Contractions are easy to miss.** `it's`, `that's`, `there's`, `we're` all contain `be`. Subtitles may also confuse `it's`/`its` and `there's`/`theirs`.
2. **Non-native speech often drops `be`.** If you can't find a verb, try adding `is/are` (see [G01](01-sentence-skeleton.md)).
3. **There be sentences sometimes contain two verbs.** Remove `there is` and check whether the rest is a full sentence.

| Seen in subtitles | Standard form |
| --- | --- |
| `When you ready for test, …` | `When you are ready for testing, …` |
| `when he back tomorrow` | `when he is back tomorrow` |
| `I'm agree with that.` | `I agree with that.` |
| `there is an issue has raised` | `an issue has been raised` / `there is an issue that was raised` |
| `there are left two subtasks` | `there are two subtasks left` |
| `there is no something blocked` | `nothing is blocked` |
| `there's no much updates` | `there aren't many updates` |

## 10. Common Mistakes

| ❌ Wrong | ✅ Right | Reason |
| --- | --- | --- |
| `I busy today.` | `I'm busy today.` | adjectives need `be` |
| `I am agree.` | `I agree.` | `agree` is a verb |
| `I'm work on it.` | `I'm working on it.` | `be` + `-ing` |
| `It's happen again.` | `It happened again.` | no `be` before an ordinary verb |
| `The PR already merged.` | `The PR is already merged.` | a state needs `be` |
| `It will is ready.` | `It will be ready.` | base `be` after modals |
| `Have a problem in the build.` | `There's a problem with the build.` | existence with no owner → there be |
| `There have two options.` | `There are two options.` | `there` + `be`, not `have` |
| `There is two bugs.` | `There are two bugs.` | match the noun |
| `Yesterday is fine.` | `It was fine yesterday.` | past state → `was` |

## 11. Sentences You Can Use Today

```text
I'm still working on the API changes.

The PR is ready for review.

I'm blocked by the access issue.

Most of my tasks are on track.

It should be ready by tomorrow.

There's one thing I want to mention.

There are no blockers on my side.

Sorry, I was on mute.
```

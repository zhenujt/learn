# G10 其他时态与 16 种时态总表

<!-- sentence-audio: fenced-only -->

> **频率：🟢 认得即可 / ⚪ 用不到** ｜ 阶段：初中 → 高中 ｜ 会议数据：过去进行时每万词约 2.6 次，现在完成进行时约 0.2 次，过去完成时约 0.2–0.4 次，将来完成时 0 次
>
> [English version](10-other-tenses.md) · [上一课：G09 将来表达](09-future-will-going-to.zh.md) · [下一课：G11 情态动词](11-modal-verbs.zh.md) · [语法目录](README.zh.md)

## 这一课解决什么问题

课本上有 16 种时态，但真实会议里，**G07–G09 的五六种时态就占了 99% 以上**。剩下的时态要么偶尔出现、看懂就行，要么几乎不出现。比如字幕里偶尔会看到：

```text
I was working on the pipeline when the runner went down.
我正在弄流水线的时候，执行机挂了。

That job has been running for almost 15 minutes.
那个任务已经跑了快 15 分钟了。
```

这一课帮你**快速认出**这些不常用的时态，并用一张总表告诉你：哪些要会说，哪些认得就行，哪些可以直接跳过。

**学完这一课，你应该能：**

1. 认出过去进行时，并会用礼貌说法 `I was wondering if …`。
2. 认出现在完成进行时，知道它强调"一直在做、做了多久"。
3. 了解过去完成时、将来完成时、过去将来时，在字幕里看到时不慌。
4. 看懂 16 种时态总表，知道会议里真正需要哪几种。

## 2. 过去进行时：was / were + -ing 🟢

### 2.1 公式

**公式：** `was / were + 动词-ing`

```text
I was debugging the test when you called.
你打电话的时候我正在调试测试。

We were discussing this yesterday.
我们昨天正在讨论这个。
```

### 2.2 用法一：过去某个时刻正在做

```text
At 3 PM yesterday, I was still waiting for the build.
昨天下午 3 点我还在等构建。

When I was working on the Harness pipeline, I found another issue.
我在弄 Harness 流水线时又发现了一个问题。
```

### 2.3 用法二：背景 + 突发事件

长动作用过去进行时做背景，短动作用一般过去时打断它：

```text
The pipeline was running when the runner went down.
流水线正在跑，执行机就挂了。

While we were testing, QA found two more bugs.
我们测试的时候，QA 又发现了两个 Bug。
```

`while` 后面通常是进行中的长动作；`when` 后面通常是一下子发生的短动作。

### 2.4 用法三：委婉、礼貌 ⭐ 最值得学

用过去进行时说现在的想法，语气更软，像是"我刚才在想……"：

```text
I was wondering if there is any document about the new workflow.
我想问一下，有没有关于新工作流的文档？

I was thinking maybe we could use the same naming on both sides.
我在想，也许两边可以用同一套命名。

I was just checking the status with Ken.
我刚才只是在和 Ken 确认状态。
```

`I was saying …` 常用来**重复或澄清自己刚才的话**：

```text
No, actually, I was saying that we're still open to other options.
不是，我刚才说的是，我们还可以考虑其他方案。
```

## 3. 现在完成进行时：have / has been + -ing 🟢

### 3.1 公式和意思

**公式：** `have / has been + 动词-ing`

意思是：**从过去开始，一直做到现在**（可能还在继续，也可能刚停下）。它强调**过程和持续时间**。

```text
That job has been running for almost 15 minutes.
那个任务已经跑了快 15 分钟了。

I know I've been saying that for a while.
我知道这话我已经说了好一阵了。

We've been waiting for access since last week.
我们从上周就一直在等权限。

I've been looking into this issue all morning.
我一上午都在查这个问题。
```

### 3.2 和现在完成时的区别

| 现在完成时 | 现在完成进行时 |
| --- | --- |
| 强调结果、数量 | 强调过程、持续时间 |
| `I've fixed three bugs.` | `I've been fixing bugs all day.` |
| `I've written the doc.`（写完了） | `I've been writing the doc.`（一直在写，不一定写完） |

```text
I've fixed three bugs today.
我今天修了三个 Bug。

I've been fixing bugs all day.
我一整天都在修 Bug。
```

> 状态动词（`know`、`need`、`understand`）不用这个时态：说 `I've known it for a while.`，不说 `I've been knowing`。

## 4. 过去完成时：had + 过去分词 ⚪

> 会议中几乎用不到，了解即可，可以跳过。

**公式：** `had + 过去分词`。意思是"**过去的过去**"：两件过去的事，先发生的那件用过去完成时。

```text
I thought Ken had already reviewed it.
我以为 Ken 已经评审过了。

By the time we noticed, the job had failed twice.
等我们发现时，任务已经失败两次了。
```

**字幕提醒：** 非母语同事有时把 `had` 当普通过去时用，比如 `I think Mia had reviewed the Figma file.`，其实就是 `Mia reviewed / has reviewed it`。按"已经做过"理解即可。

`If we had known …`（要是我们早知道……）是虚拟语气，见 [G21 条件句](21-conditionals.zh.md)。

## 5. 将来完成时：will have + 过去分词 ⚪

> 会议中几乎用不到，了解即可，可以跳过。

**公式：** `will have + 过去分词`，常和 `by + 将来时间` 连用，意思是"到某时为止将已经完成"。

```text
By Friday, we will have finished the migration.
到周五我们就会完成迁移了。
```

会议里大家更常用简单的说法：

```text
We'll finish the migration by Friday.
我们周五前完成迁移。

The migration should be done by Friday.
迁移应该周五前能完成。
```

## 6. 过去将来时：would / was going to ⚪

> 会议中几乎用不到，了解即可，可以跳过。

**公式：** `would + 原形` 或 `was / were going to + 原形`，意思是"**从过去的角度看将来**"。

### 6.1 would：主要出现在转述里

```text
Mia said she would send the doc today.
Mia 说她今天会发文档。
```

这种用法属于间接引语，详见 [G22](22-reported-speech.zh.md)。

### 6.2 was going to：原本打算（但没做）🟢

这个说法在会议里反而有用，表示"**我本来想/打算……**"：

```text
I was going to ask the same question.
我正想问同一个问题。

We were going to release it on Friday, but QA found a blocker.
我们本来打算周五发布，但 QA 发现了一个阻塞问题。
```

## 7. 16 种时态总表

英语时态 = **4 种时间 × 4 种状态**。下表以 `he / work` 为例，并标出会议频率：

| | 一般 | 进行 | 完成 | 完成进行 |
| --- | --- | --- | --- | --- |
| **现在** | `works` 🔴 | `is working` 🔴 | `has worked` 🔴 | `has been working` 🟢 |
| **过去** | `worked` 🔴 | `was working` 🟢 | `had worked` ⚪ | `had been working` ⚪ |
| **将来** | `will work` 🔴 | `will be working` 🟢 | `will have worked` ⚪ | `will have been working` ⚪ |
| **过去将来** | `would work` ⚪ | `would be working` ⚪ | `would have worked` ⚪ | `would have been working` ⚪ |

逐个说明，按"会议里怎么对待"分类：

| # | 时态 | 结构 | 频率 | 会议例句 | 建议 |
| --- | --- | --- | --- | --- | --- |
| 1 | 一般现在时 | `do / does` | 🔴 | `It works on Android.` | 必须会说 |
| 2 | 现在进行时 | `am/is/are doing` | 🔴 | `I'm working on the API.` | 必须会说 |
| 3 | 现在完成时 | `have/has done` | 🔴 | `I've fixed the bug.` | 必须会说 |
| 4 | 现在完成进行时 | `have/has been doing` | 🟢 | `It's been running for 15 minutes.` | 认得，会说更好 |
| 5 | 一般过去时 | `did` | 🔴 | `I fixed it yesterday.` | 必须会说 |
| 6 | 过去进行时 | `was/were doing` | 🟢 | `I was wondering if …` | 认得，礼貌用法要会说 |
| 7 | 过去完成时 | `had done` | ⚪ | `I thought he had reviewed it.` | 认得即可 |
| 8 | 过去完成进行时 | `had been doing` | ⚪ | `We had been waiting for a week.` | 跳过 |
| 9 | 一般将来时 | `will do` / `be going to do` | 🔴 | `I'll take a look.` | 必须会说 |
| 10 | 将来进行时 | `will be doing` | 🟢 | `I'll be working on it next week.` | 认得即可 |
| 11 | 将来完成时 | `will have done` | ⚪ | `We'll have finished it by Friday.` | 跳过 |
| 12 | 将来完成进行时 | `will have been doing` | ⚪ | — | 跳过 |
| 13 | 过去将来时 | `would do` / `was going to do` | ⚪ | `I was going to ask that.` | `was going to` 认得 |
| 14 | 过去将来进行时 | `would be doing` | ⚪ | — | 跳过 |
| 15 | 过去将来完成时 | `would have done` | ⚪ | `It would have saved time.`（多见于虚拟语气） | 见 G21 |
| 16 | 过去将来完成进行时 | `would have been doing` | ⚪ | — | 跳过 |

## 8. 站会时态速查

| 站会要说的 | 首选时态 | 例子 |
| --- | --- | --- |
| 昨天做了什么 | 一般过去时 | `Yesterday I fixed the login bug.` |
| 已经完成了什么 | 现在完成时 | `I've raised a PR.` |
| 今天在做什么 | 现在进行时 | `Today I'm working on the tests.` |
| 接下来做什么 | `will` / `be going to` | `I'll start the migration next.` |
| 阻塞和状态 | 一般现在时 / 现在进行时 / 现在完成时 | `I'm blocked by the access issue.` / `I'm waiting for the API.` / `I still haven't got access.` |
| 一直在做、还没完 | 现在完成进行时 | `I've been looking into it since Monday.` |

```text
Yesterday I fixed the login bug, and I've raised a PR. Today I'm working on the tests. I'm still waiting for the API, so I'll start the migration next.
昨天我修了登录的 Bug，也提了 PR。今天在写测试。我还在等 API，所以接下来会开始做迁移。
```

## 9. 真实会议例句（改编）

以下句子来自真实会议字幕，已修正识别错误并匿名化：

```text
So I was wondering if there is any document to onboard onto the new workflow.
我想问一下，有没有新工作流的上手文档。

When I was working on the Harness pipeline setup, I noticed we were using a shared runner.
我在配置 Harness 流水线时，注意到我们用的是共享执行机。

We were about to discuss it in the daily sync.
我们本来正要在每日同步会上讨论这个。

Yeah, I was just checking with Leo on the status.
嗯，我刚才在和 Leo 确认状态。

That one has been running for almost 15 minutes.
那个已经跑了快 15 分钟了。

So yeah, I know I've been saying that for a while, but it should hopefully be finished today.
嗯，我知道这话我说了好一阵了，不过希望今天能完成。

Whatever Ken just explained has also been mapped in this workflow diagram.
Ken 刚才讲的内容也都画在这张流程图里了。
```

非母语原句 vs 标准说法：

| 字幕原文 | 标准说法 |
| --- | --- |
| `I was having some query regarding regarding this.` | `I had a question about this.` / `I was wondering about this.` |
| `I think Mia had reviewed the Figma structure.` | `I think Mia reviewed / has reviewed the Figma structure.` |
| `Whatever Ken had just explained, it is also been mapped …` | `Whatever Ken just explained has also been mapped …` |
| `I just was checking with Leo` | `I was just checking with Leo` |

## 10. 字幕里怎么认

1. **`was / were + -ing`** → 过去进行时。如果开头是 `I was wondering / I was thinking`，那是委婉提问或建议，不是在讲过去。
2. **`been + -ing`** → 完成进行时，看后面的 `for / since` 知道持续了多久。
3. **`had + 过去分词`** → 过去完成时；但非母语同事说的 `had` 常常就是普通过去。
4. **`'d` 的两种意思：** `I'd` + 过去分词 = `I had`（`I'd already left`）；`I'd` + 原形 = `I would`（`I'd suggest …`）。
5. **`was going to`** → "本来打算"，后面常跟 `but`。

## 11. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `I have been knowing it for a while.` | `I've known it for a while.` | 状态动词不用进行 |
| `It is running for 15 minutes.` | `It has been running for 15 minutes.` | `for` 持续到现在用完成进行时 |
| `I am waiting since Monday.` | `I've been waiting since Monday.` | `since` 要用完成（进行）时 |
| `When I was work on it, …` | `When I was working on it, …` | 过去进行要 `-ing` |
| `I had sent it yesterday.` | `I sent it yesterday.` | 没有"过去的过去"就用一般过去时 |
| `I was wonder if …` | `I was wondering if …` | 过去进行要 `-ing` |

## 13. 练习

**A. 判断时态，并标出频率标签（🔴 / 🟢 / ⚪）**

2. It has been failing since this morning.
3. I thought Ken had merged it.
4. By Friday we will have finished it.
5. I'm working on the login page.
6. We were going to release it today.

**B. 用括号里的动词填空**

1. The job ___ (run) for 20 minutes now, and it still hasn't finished.
2. I ___ (wonder) if you could help me with the setup.
3. While we ___ (test), the server crashed.
4. I ___ (look into) this bug all morning.

**C. 改错**

1. I am waiting for the access since last week.
2. I was wonder if we can skip this.
3. I have been knowing this issue for a long time.

<details>
<summary>答案</summary>

**B.** 1 has been running　2 was wondering　3 were testing　4 have been looking into

**C.**

2. I was wondering if we could skip this.

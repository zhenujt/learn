# G04 be 动词与 There be

<!-- sentence-audio: fenced-only -->

> **频率：🔴 必学** ｜ 阶段：小学 → 初中 ｜ 会议数据：`is/are/am`（含 `it's`、`that's`、`I'm` 等缩写）每万词约 320 次，是会议里最常用的动词；`was/were` 约 10.5 次；`there is / there are` 等 There be 句型约 13.5 次
>
> [English version](04-be-and-there-be.md) · [上一课：G03 代词与指代](03-pronouns-and-reference.zh.md) · [下一课：G05 疑问句、否定句与简短回答](05-questions-and-negatives.zh.md) · [语法目录](README.zh.md)

## 这一课解决什么问题

站会汇报，一大半句子都靠 `be` 和 `there be` 撑起来：

```text
The login page is done, the API is still in progress, and there are two bugs left.
登录页做完了，接口还在开发中，还剩两个 Bug。
```

中文这句话里没有一个"是"，英语却用了三次 `be`。反过来，中文说"我同意"，英语却不能加 `be`（❌ `I am agree`）。中国同学用 `be` 的错误几乎都来自"把 be 当成'是'"。

**学完这一课，你应该能：**

1. 根据主语和时间，用对 `am / is / are / was / were` 和它们的缩写。
2. 用"be + 状态词"汇报进度：`done`、`blocked`、`on track`、`out of office`……
3. 认出 `be` 作助动词的三种结构：进行时、被动语态、`be going to`。
4. 用 `There is / There are` 表达"有"，不再说 `Have a problem in the build.`

## 1. 先建立一个正确的认识：be 不等于"是"

`be` 的作用是**把主语和后面的"状态/身份/位置"连起来**。中文里这种句子常常不需要"是"，英语却必须有 `be`：

| 中文 | 英语 | 说明 |
| --- | --- | --- |
| 我很忙。 | `I'm busy.` | 形容词前要 `be` |
| 他今天不在。 | `He's out today.` | 位置、状态前要 `be` |
| 还在开发中。 | `It's still in progress.` | 介词短语前要 `be` |
| 这个是 Bug。 | `This is a bug.` | 名词前要 `be` |
| 我同意。 | `I agree.` | `agree` 是动词，**不加** `be` |
| 构建失败了。 | `The build failed.` | 有动词就**不加** `be` |

**规则：** `be` 后面接**名词、形容词、介词短语、地点副词**。普通动词前面**不能**直接加 `be`，除非是 `-ing`（进行时）或过去分词（被动），见第 4 节。

## 2. be 的形式 🔴

| 主语 | 现在 | 过去 | 现在否定 | 过去否定 |
| --- | --- | --- | --- | --- |
| I | am（I'm） | was | I'm not | wasn't |
| he / she / it / 单数名词 | is（he's / it's） | was | isn't | wasn't |
| you / we / they / 复数名词 | are（you're / we're / they're） | were | aren't | weren't |

其他形式：

| 形式 | 用在哪 | 例子 |
| --- | --- | --- |
| `be`（原形） | 情态动词、`to`、祈使句后面 | `It will be ready.`、`Be careful.` |
| `been` | 完成时 | `It has been broken since Monday.` |
| `being` | 进行时的被动，或"表现得" 🟢 | `It's being reviewed.` |

会议里最常听到的缩写：`I'm`、`it's`、`that's`、`there's`、`we're`、`what's`。

```text
I'm not sure.
我不太确定。

It's not ready yet.
还没准备好。

We're almost done.
我们快做完了。

They aren't available today.
他们今天没空。
```

> ⚠️ `I'm not` 没有 `amn't` 这种缩写；问句里说 `Aren't I …?`（🟢，会议很少用）。

## 3. be + 表语：汇报状态的万能句型 🔴

**公式：** `主语 + be + 状态（形容词 / 介词短语 / 名词 / 地点副词）`

### 3.1 be + 形容词

```text
The PR is ready for review.
PR 可以评审了。

I'm blocked by the access issue.
我被权限问题卡住了。

Are you available after the meeting?
会后你有空吗？

I'm not sure about the timeline.
我不确定时间安排。

I'm good with that.
我没问题。
```

### 3.2 be + 介词短语

会议里最常见的进度说法几乎都是介词短语：

| 说法 | 意思 | 说法 | 意思 |
| --- | --- | --- | --- |
| `be on track` | 按计划进行 | `be in progress` | 进行中 |
| `be on hold` | 暂停 | `be in QA` | 在测试中 |
| `be under review` | 在评审中 | `be behind schedule` | 落后于计划 |
| `be out of office` | 休假 / 不在 | `be on leave` | 请假 |
| `be on mute` | 静音中 | `be in a meeting` | 在开会 |

```text
Most of the stories are on track.
大部分 Story 都按计划进行。

The ticket is on hold until we get approval.
拿到审批之前，这个工单先暂停。

Ken is out of office this week.
Ken 这周休假。
```

### 3.3 be + 名词

```text
This is the PR I mentioned.
这就是我提到的 PR。

It's a known issue.
这是已知问题。

I'm the owner of this ticket.
我是这个工单的负责人。
```

### 3.4 be + 地点副词

```text
Is Mia here?
Mia 在吗？

I'm back.
我回来了。

Sorry, I'm here now.
抱歉，我现在在了。
```

### 3.5 be + 形容词 + 介词：固定搭配 🔴

这些搭配要整体记，介词不能随便换：

| 搭配 | 意思 | 例子 |
| --- | --- | --- |
| `be ready for` | 准备好…… | `It's ready for QA.` |
| `be responsible for` | 负责 | `Who is responsible for this?` |
| `be blocked by` | 被……卡住 | `We're blocked by the approval.` |
| `be aware of` | 知道、意识到 | `Are you aware of this change?` |
| `be familiar with` | 熟悉 | `I'm not familiar with this repo.` |
| `be fine with / good with` | 可以接受 | `I'm fine with that.` |
| `be related to` | 和……有关 | `Is this related to the cache?` |
| `be similar to` | 和……类似 | `It's similar to the old version.` |
| `be different from` | 和……不同 | `iOS is different from Android here.` |
| `be busy with` | 忙于 | `I'm busy with the release.` |

## 4. be 作助动词：三种结构要认得 🔴

`be` 不只是"连接"，它还是很多语法结构的"零件"。在字幕里看到 `be` 后面跟着动词，先判断是哪一种：

| 结构 | 公式 | 例子 | 详见 |
| --- | --- | --- | --- |
| 进行时 | be + `-ing` | `I'm working on it.` | [G07](07-present-simple-and-continuous.zh.md) |
| 被动语态 | be + 过去分词 | `It was deployed yesterday.` | [G12](12-passive-voice.zh.md) |
| 将来 | be going to + 动词原形 | `We're going to release next week.` | [G09](09-future-will-going-to.zh.md) |

```text
I'm still working on the login page.
我还在做登录页。

The PR is merged.
PR 已经合并了。

The fix was deployed this morning.
修复今天上午上线了。

We're going to demo it on Friday.
我们周五会演示。
```

其他常见结构 🟡：

```text
I'm not able to access the server.
我访问不了服务器。（be able to = can）

The build is supposed to run every night.
构建本应每晚跑一次。（be supposed to = 按规定应该）

We're about to release it.
我们马上就要发布了。（be about to = 即将）
```

> ⚠️ `be` 后面**不能**直接接动词原形：❌ `I'm work on it`、❌ `It's happen again`。要么用 `-ing`（`I'm working on it`），要么去掉 `be`（`It happened again`）。

## 5. was / were：过去的状态 🟡

会议里 `was/were` 每万词约 10.5 次，主要用来说"昨天、上周是什么情况"。

```text
It was fine yesterday.
昨天还是好的。

We were blocked last week.
我们上周被卡住了。

Sorry, I was on mute.
抱歉，我刚才开着静音。

I was out of office on Monday.
我周一休假了。

The meeting was a bit long.
会开得有点长。
```

### 5.1 I was wondering if … 🟡

用过去进行时显得更礼貌，意思还是"现在想问"：

```text
I was wondering if you could review my PR today.
不知道你今天能不能帮我评审一下 PR。
```

> `If I were you, …` 这种虚拟语气在会议里几乎用不到（⚪），见 [G21](21-conditionals.zh.md)。

## 6. be 和情态动词、完成时一起用 🔴

```text
It will be ready tomorrow.
明天会好。

It should be fine.
应该没问题。

It might be a cache issue.
可能是缓存的问题。

It can be a bit slow on Android.
在 Android 上可能会有点慢。

It has been broken since Monday.
从周一起就坏了。
```

**公式：** `will / should / might / can / must + be`；`have / has + been`。这里一定用原形 `be` 或 `been`，不用 `is`：❌ `It will is ready.`

## 7. There be：表达"有" 🟡

### 7.1 意思和公式

`There is / There are` 表示"**某处/某时存在某物**"。`there` 本身不是"那里"，只是一个占位的主语。

**公式：** `There + be + 名词 + （地点 / 时间 / 其他修饰）`

```text
There is a bug in the login page.
登录页有一个 Bug。

There are two options.
有两个方案。

There's a meeting at 3 PM.
下午 3 点有个会。
```

### 7.2 单复数：看 be 后面的第一个名词

```text
There is one more thing.
还有一件事。

There are three subtasks under this story.
这个 Story 下有三个子任务。

There is a bug and two warnings.
有一个 Bug 和两个警告。（第一个名词是单数，用 is）
```

> ⚠️ 口语里常听到 `there's` + 复数，比如 `There's two issues.`、`There's no open issues now.`。母语者也这么说，能听懂即可；自己说时用 `there are` 更稳妥。

### 7.3 否定和疑问

```text
There's no update from the design team.
设计团队那边没有更新。

There aren't any blockers.
没有阻塞。

Is there any update on this?
这个有进展吗？

Are there any questions?
有问题吗？

Is there anything else?
还有别的吗？
```

主持人常把问句缩短成 `Any questions?`、`Anything else?`。

### 7.4 不同时态和情态 🟡

```text
There was an issue with the deployment yesterday.
昨天部署出了个问题。

There will be a short demo after the sync.
同步会后会有一个简短演示。

There might be a delay.
可能会延期。

There has been a lot of discussion about this.
关于这个已经讨论了很多。

There seems to be a problem with the VPN.
VPN 好像有问题。（🟢）
```

### 7.5 There be + 名词 + 修饰：名词后面挂"尾巴" 🟡

名词后面常常挂一个"尾巴"，说明这个东西怎么样：

```text
There are two items to follow up.
有两件事要跟进。（to do）

There is one thing I want to mention.
有一件事我想提一下。（从句）

There are four subtasks left.
还剩四个子任务。（left = 剩下的）

There is something wrong with the pipeline.
流水线有点问题。

There are some discussions going on about the tool.
关于这个工具正在讨论。（-ing）
```

### 7.6 There be 和 have 的区别 🔴

中文"有"可以表示"拥有"，也可以表示"存在"。英语分开说：

| 中文 | ✅ 英语 | ❌ 中式英语 |
| --- | --- | --- |
| 我们有两个方案。（拥有） | `We have two options.` / `There are two options.` | — |
| 构建有问题。（存在） | `There's a problem with the build.` / `The build has a problem.` | `Have a problem in the build.` |
| 今天有个会。 | `There's a meeting today.` / `We have a meeting today.` | `Today have a meeting.` |
| 还有问题吗？ | `Are there any other questions?` | `Have other questions?` |

**规则：** 句子没有"谁拥有"的主语时，就用 `There is / There are`。

### 7.7 Here is / Here are 🟡

指给别人看时用 `here`：

```text
Here is the link.
链接在这儿。

Here are the results from last night.
这是昨晚的结果。
```

## 8. 真实会议例句（改编）

```text
I'm not sure if this is related to the cache.
我不确定这是不是和缓存有关。

The fix is ready, but it's not merged yet.
修复已经好了，但还没合并。

I think we are good to move forward with this approach.
我觉得可以按这个方案推进了。

There are a couple of pages with detailed explanations under this folder.
这个文件夹下面有几个页面，里面有详细说明。

There are four subtasks that need to continue in the next sprint.
有四个子任务需要在下个 Sprint 继续做。

There's no topic from team members, so let's move on.
大家没有提新议题，那我们继续。

We were about to discuss it in the daily sync.
我们本来正要在每日同步会上讨论这个。
```

## 9. 字幕里怎么认

1. **缩写很容易看漏。** `it's`、`that's`、`there's`、`we're` 里都藏着 `be`；`it's` 和 `its`、`there's` 和 `theirs` 在字幕里也会被识别混。
2. **非母语口语常漏掉 `be`。** 找不到动词时，先试着补一个 `is/are`（见 [G01](01-sentence-skeleton.zh.md)）。
3. **there be 句子常常"一句里两个谓语"。** 先把 `there is` 拿掉，看剩下的部分是不是一个完整句子。

| 字幕里可能看到 | 标准说法 |
| --- | --- |
| `When you ready for test, …` | `When you are ready for testing, …` |
| `when he back tomorrow` | `when he is back tomorrow` |
| `I'm agree with that.` | `I agree with that.` |
| `there is an issue has raised` | `an issue has been raised` / `there is an issue that was raised` |
| `there are left two subtasks` | `there are two subtasks left` |
| `there is no something blocked` | `nothing is blocked` |
| `there's no much updates` | `there aren't many updates` |

## 10. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `I busy today.` | `I'm busy today.` | 形容词前要 `be` |
| `I am agree.` | `I agree.` | `agree` 是动词 |
| `I'm work on it.` | `I'm working on it.` | `be` + `-ing` |
| `It's happen again.` | `It happened again.` | 有动词就不要 `be` |
| `The PR already merged.` | `The PR is already merged.` | 状态要用 `be` |
| `It will is ready.` | `It will be ready.` | 情态动词后用原形 `be` |
| `Have a problem in the build.` | `There's a problem with the build.` | 没有主语的"有"用 there be |
| `There have two options.` | `There are two options.` | `there` 后面用 `be`，不用 `have` |
| `There is two bugs.` | `There are two bugs.` | 看后面名词的单复数 |
| `Yesterday is fine.` | `It was fine yesterday.` | 过去的状态用 `was` |

## 12. 练习

**A. 填入正确的 be 形式（am / is / are / was / were / be / been）**

1. The tests ___ green now.
2. I ___ out of office yesterday.
3. It will ___ ready tomorrow.
4. The pipeline has ___ broken since Monday.
5. ___ you available this afternoon?
6. We ___ blocked last week, but now it's fine.

**B. 用 There be 改写（或改正）**

1. Have a bug in the login page.
2. Today have a demo at 4 PM.
3. There is three open PRs.
4. There have some questions from the QA team.

**C. 改错**

1. I'm agree with Grace.
2. The ticket on hold now.
3. I'm test it on iOS.
4. It might is a network issue.

3. There are three open PRs.
4. There are some questions from the QA team.

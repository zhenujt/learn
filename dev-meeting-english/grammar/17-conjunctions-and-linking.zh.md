# G17 连词与连接：and、but、so、because、also、then

<!-- sentence-audio: fenced-only -->

> **频率：🔴 必学** ｜ 阶段：小学 → 初中 ｜ 会议数据：`and` 每万词约 284 次，`so` 约 174 次（约一半在句首），`or` 约 67 次，`also` 约 44 次，`but` 约 37 次，`then` 约 22 次，`because` 约 19 次
>
> [English version](17-conjunctions-and-linking.md) · [上一课：G16 介词](16-prepositions.zh.md) · [下一课：G18 名词性从句](18-noun-clauses.zh.md) · [语法目录](README.zh.md)

## 这一课解决什么问题

会议字幕里，`so` 几乎每句都有。同一个 `so`，有时是"所以"，有时只是"好，那……"。如果每次都译成"所以"，整段话就读不通。

例如：

```text
So for the web part, the login page is done, but the API is not ready, so we will test it tomorrow.
那 Web 部分，登录页做完了，但 API 还没好，所以我们明天再测。
```

句首的 `So` 只是"开场 / 换话题"，后面那个 `so` 才是"所以"。中间的 `but` 是转折。三个小词，把一段进度汇报串了起来。

**学完这一课，你应该能：**

1. 分清 `so` 的 5 种角色：开场换话题、结果、总结、`so that` 目的、代替前文。
2. 用 `and`、`but`、`or`、`also`、`then` 把自己的进度汇报串起来。
3. 分清 `because` 和 `so`，不再说 `Because …, so …`。
4. 认出 `as well`、`too`、`either`、`both … and`、`not only … but also`。

## 1. 先建立一个正确的认识

**连接词把两个意思连在一起，并说明它们的关系**：追加（and）、转折（but）、选择（or）、结果（so）、原因（because）、顺序（then）。

```text
I fixed the bug, and I updated the test.
我修了这个 Bug，也更新了测试。

I fixed the bug, but the test is still failing.
我修了这个 Bug，但测试还是失败。

I fixed the bug, so we can close the ticket.
我修了这个 Bug，所以可以关掉这个工单了。
```

**公式：** `句子 A + , + and / but / or / so + 句子 B`

两个和中文不同的地方：

- **中文喜欢成对用：** "因为……所以……"、"虽然……但是……"。**英文一次只用一个**：用了 `because` 就不用 `so`，用了 `although` 就不用 `but`。
- **中文常常不用连接词**，靠语序就能懂。英文两个完整句子之间**必须**有连接词或句号，不能只用逗号硬接。

> 术语小贴士：`and / but / or / so` 叫**并列连词**，连接两个地位相同的部分；`because / when / if` 叫**从属连词**，引导"从句"，详见 [G20 状语从句](20-adverbial-clauses.zh.md)。`also / then` 严格说是副词，但在会议里同样起"连接"作用，所以放在这一课。

## 2. so：会议里出现最多的连接词

我统计了 25 场会议里的 `so`，主要有这几种角色：

| 角色 | 中文理解 | 典型说法 | 频率 |
| --- | --- | --- | --- |
| 开场 / 换话题 | 那、好、那么 | `So, let's get started.` | 🔴 约一半 |
| 结果 | 所以、因此 | `…, so we will test it tomorrow.` | 🔴 |
| 总结 | 那……就是 | `So that's all for today.` | 🔴 |
| 目的 `so that` | 以便、这样就能 | `…so that QA can test it.` | 🟢 每万词约 3 次 |
| 代替前文 | 这样、是的 | `I think so.`、`If so, …` | 🟡 |

另外，`so many`、`so much`、`so far` 里的 `so` 不是连接词，见 2.6。

### 2.1 So, … ：开场、换话题 ⭐ 最高频

**公式：** `(Okay / Yeah,) so + 新话题或新问题`

主持人和汇报人一开口、一换话题，几乎都先说 `so`：

```text
So, let's get started.
好，我们开始吧。

Okay, so the next one is the CI pipeline.
好，下一个是 CI 流水线。

So, any questions or comments from the design side?
那设计这边有什么问题或意见吗？

Yeah, so Ken, you can go ahead.
好，Ken，你开始吧。

So basically, we have three options here.
那么基本上，我们这里有三个方案。
```

**怎么认：** `so` 在句首（或 `okay`、`yeah` 之后），**前面没有原因**，后面是一个新话题、一个问题或一个邀请。

**怎么理解：** 它相当于中文的"那……""好……"，作用是"我要开始说了"。读字幕时可以直接跳过，**不要译成"所以"**。

### 2.2 …, so …：表示结果（所以）

**公式：** `原因, so + 结果.`

```text
The API is not ready yet, so we will test it tomorrow.
API 还没准备好，所以我们明天再测。

Ken is out of office today, so Mia will give the update.
Ken 今天休假，所以由 Mia 来汇报。

It's a small change, so I don't think we need a full regression.
这是个小改动，所以我觉得不需要做完整回归测试。

The build failed again, so we still need help from the platform team.
构建又失败了，所以我们还需要平台团队帮忙。
```

**怎么认：** `so` **前面有一个原因**，后面是因此要做的事或产生的后果。

**两种 so 的快速判断：**

| 看什么 | 开场的 so | 结果的 so |
| --- | --- | --- |
| 位置 | 句首、换人说话的开头 | 两个句子中间 |
| 前面 | 没有原因，或是上一个话题刚结束 | 一个原因 |
| 中文 | 那、好 | 所以 |

### 2.3 So that's …：总结、收尾

**公式：** `So that's + all / it / the plan / the update …`

```text
So that's all for my part.
那我这部分就这些。

So that's the plan for this sprint.
这就是这个 Sprint 的计划。

So that means we need one more sprint.
这就意味着我们还需要一个 Sprint。
```

> ⚠️ `So that's …` 是 `So` + `that's`（那就是），**不是** 2.4 的 `so that`（以便）。看 `that` 后面：接 `'s / is / means` 就是总结；接一个完整句子（`we can …`）才是目的。

### 2.4 so that：目的（以便、这样就能）🟢

**公式：** `主句 + so that + 主语 + can / will / could + 动词`

```text
Please add the label so that QA can find the ticket.
请加上这个标签，这样 QA 就能找到这个工单。

Let's merge it today so that we can test it tomorrow.
我们今天合并吧，这样明天就能测试。

You can change this column to Assignee so that you can see who is working on it.
你可以把这一列改成"负责人"，这样就能看到是谁在做。
```

口语里经常把 `that` 省掉，只说 `so`：

```text
Send me the link so I can check it.
把链接发我，我好看一下。
```

**和"结果"的区别：** 目的的 `so (that)` 后面通常有 `can / will / could`，说的是"希望达到的效果"；结果的 `so` 说的是"已经或必然发生的后果"。

### 2.5 so 代替前文：I think so、If so

`so` 可以代替前面整句话，避免重复：

```text
Is it ready for QA? I think so.
可以提测了吗？我觉得可以。

Will it be done this week? I hope so.
这周能做完吗？希望可以。

Is that a blocker? I don't think so.
这是阻塞吗？我觉得不是。

Do we need a new repo? If so, I will create one today.
需要新仓库吗？如果需要，我今天就建一个。
```

否定时说 `I don't think so`，不要说 `I think not so`。`If so` 的反义是 `If not`，详见 [G21 条件句](21-conditionals.zh.md)。

### 2.6 不是连接词的 so

```text
Thank you so much.
非常感谢。（so：这么、非常）

We have so many tickets this sprint.
这个 Sprint 我们的工单太多了。

So far, everything looks good.
到目前为止，一切都正常。（so far：目前为止）
```

## 3. and：追加、列举、顺序

**公式：** `A and B`；`A, B, and C`；`…, and then …`

```text
I finished the API changes, and I opened a PR.
我完成了 API 改动，并提了一个 PR。

We need to update the docs, the tests, and the release notes.
我们需要更新文档、测试和发布说明。

I will review it first, and then I will merge it.
我先评审，然后再合并。
```

`And` 也常在句首用来**接着上一个话题**或**追加一点**：

```text
And for the native part?
那 Native 部分呢？

And also for the PR template, we added a checklist.
另外，关于 PR 模板，我们加了一个检查清单。
```

`and also for the …` 是会议里的高频组合，意思是"另外，关于……"。`and also` 在书面里有点重复，但口语里完全正常。

> ⚠️ 列举三项以上时，最后一项前面要有 `and`。中文说"我修了 Bug，更新了文档，写了测试"，英文要说 `I fixed the bug, updated the docs, and wrote the tests.`

## 4. but：转折

**公式：** `A, but B.`

```text
We tried a fix, but it didn't work.
我们试了一个修复，但没用。

I think it makes sense, but I'm not sure about the risk.
我觉得说得通，但我不确定风险。

Maybe not today, but sometime this week would be great.
也许不是今天，但这周找个时间就很好。
```

字幕里常见的 `but yeah`、`but anyway` 只是"不过……总之"，意思很弱：

```text
But anyway, we can take a look tomorrow.
不过总之，我们明天可以看一下。
```

`however` 意思和 `but` 一样，但更书面，会议里每万词只有约 0.1 次，读邮件和文档时会见到。

## 5. or：或者、还是

**公式：** `A or B`；问句里是"还是"

```text
We can do it today or tomorrow.
我们今天或明天做都可以。

Is it a bug, or is it expected behavior?
这是 Bug，还是预期行为？

Do you want to go first, or should I?
你想先讲，还是我先讲？
```

**否定句里用 `or`，不用 `and`：**

```text
We don't have the access or the license.
我们既没有权限，也没有许可证。
```

字幕里的 `or something`、`or whatever` 是"之类的"，表示说话人不想说得太精确：

```text
Maybe we need a new service account or something.
也许我们需要一个新的服务账号之类的。
```

## 6. also、as well、too、either：也

| 说法 | 位置 | 每万词 | 例句 |
| --- | --- | --- | --- |
| `also` | 实义动词前；`be` / 情态动词后 | 约 44 | `I also checked the logs.` |
| `as well` | 句末 | 约 10.5 | `I checked the logs as well.` |
| `too` | 句末 | 约 2 | `I checked the logs, too.` |
| `either` | 否定句句末 | 约 1 | `I didn't see it either.` |

```text
I also checked the logs.
我也查了日志。

We will also update the ticket.
我们也会更新工单。

It's also blocked by the license issue.
它也被许可证问题卡住了。

Can you take a look at the PR as well?
你也能看一下这个 PR 吗？

I didn't see the email either.
我也没看到那封邮件。
```

**两个提醒：**

- **否定句的"也"用 `either`**，放在句末：`I didn't see it either.` 比 `I also didn't see it.` 更自然。简短回答说 `Me too.`（肯定）/ `Me neither.`（否定）。
- **一句里只用一个"也"。** 字幕里常听到 `I will also take a look at the PR as well.`，`also` 和 `as well` 重复了，保留一个即可。

## 7. then：然后、那么

**公式：** `First …, then …`；`Okay, then …`；`If …, then …`

```text
First we fix the CI, then we merge the PR.
我们先修 CI，然后合并 PR。

Okay, then let's move to the next topic.
好，那我们进入下一个议题。

If everything is ready, then we can release it on Friday.
如果都准备好了，那我们周五就能发布。
```

`then` 有两个意思：**顺序**（然后）和**推论**（那么、那就）。句首的 `Okay, then …` 几乎都是"那就……"。

> 书面里 `then` 不能单独连接两个完整句子：写成 `…, and then …` 或用句号分开。口语里无所谓。

## 8. because 和 so：原因和结果只说一个

```text
We can't test it because the API is down.
我们没法测，因为 API 挂了。

The API is down, so we can't test it.
API 挂了，所以我们没法测。
```

两句意思相同：**`because` 后面是原因，`so` 后面是结果。** 选一个，不要两个一起用。

❌ `Because the API is down, so we can't test it.`
✅ `Because the API is down, we can't test it.`
✅ `The API is down, so we can't test it.`

**because 和 because of：**

```text
It's delayed because the design changed.
因为设计改了，所以延期了。（because + 句子）

It's delayed because of the design change.
因为设计变更，所以延期了。（because of + 名词）
```

**其他说原因的方式：**

```text
That's why we need one more sprint.
这就是我们还需要一个 Sprint 的原因。

The reason is that the license is not approved yet.
原因是许可证还没批下来。
```

口语里回答"为什么"时，可以直接用 `Because …` 开头，这是完整的回答，不算错：

```text
Why is it delayed? Because the API changed last week.
为什么延期了？因为 API 上周改了。
```

## 9. 成对连接词 🟢

会议里很少用，读文档和邮件时会见到，认得即可：

| 说法 | 意思 | 例句 |
| --- | --- | --- |
| `both A and B` | A 和 B 都 | `It supports both iOS and Android.` |
| `either A or B` | 要么 A 要么 B | `We can use either Harness or GitHub Actions.` |
| `neither A nor B` | 既不 A 也不 B ⚪ | `Neither option is ready.` |
| `not only A but also B` | 不仅 A 而且 B | `It's not only for the design system but also for other teams.` |

```text
We need to pass both the function test and the accessibility test.
功能测试和无障碍测试我们都要通过。

Either way, we need to decide by the end of the sprint.
不管哪种方式，我们都要在 Sprint 结束前做决定。
```

`either way`（不管哪种方式）在会议里比 `either … or` 更常见。

## 10. 用连接词串起一段汇报

站会汇报的骨架几乎就是连接词：

```text
Yesterday I finished the login page, and I opened a PR.
昨天我完成了登录页，并提了一个 PR。

Today I'm going to fix the review comments, and then I will start the next story.
今天我会改评审意见，然后开始下一个 Story。

But the API is still not ready, so I can't test it end to end.
但 API 还没好，所以我没法做端到端测试。

I also need some help from the platform team.
我也需要平台团队帮一下忙。

So that's all for my part.
那我这部分就这些。
```

记住这条链：**and（追加）→ and then（下一步）→ but（问题）→ so（影响）→ also（补充）→ So that's all（收尾）**。

## 11. 真实会议例句（改编）

以下句子来自真实会议字幕，已修正识别错误并做了匿名处理：

```text
We had an issue today, but Ken just said it should be fixed, so we will double-check tomorrow.
我们今天遇到了一个问题，但 Ken 刚说应该修好了，所以我们明天再确认一下。

I think Nina hasn't joined yet, so let's start with the web updates.
我觉得 Nina 还没进会，所以我们先从 Web 的更新开始。

I also have a review with Grace today, so I will confirm with her if we need it.
我今天和 Grace 也有个评审会，所以我会跟她确认我们是否需要它。

We will add more details, but right now the workflow looks good.
我们会补充更多细节，但目前这个流程看起来没问题。

So instead of waiting for QA, the designer can fix the color contrast.
那这样就不用等 QA，设计师可以直接修颜色对比度。

So if you have any comments, please let us know.
那如果大家有意见，请告诉我们。

Leo tried to help, but it didn't work, so we still need support from Tom.
Leo 试着帮忙了，但没成功，所以我们还需要 Tom 的支持。

Both web and native teams will join the review.
Web 和 Native 两个团队都会参加评审。
```

## 12. 字幕里怎么认

1. **句首的 `So` / `Okay, so` / `Yeah, so` 先跳过。** 它只是开场，真正的内容在后面。
2. **句中的 `so` 前后切开：** 前面是原因，后面是结果。
3. **`but` 后面往往是重点。** 前面是客套或已完成的部分，后面才是问题和风险。
4. **重复的连接词是口误，直接忽略。** 例如 `so, so the first part`、`and, and also`。
5. **非母语说法能看懂就行，不要模仿：**

| 字幕里可能听到 | 标准说法 |
| --- | --- |
| `Because it is blocked, so we can't use it.` | `Because it is blocked, we can't use it.` |
| `Even though it's a small change, but it's still a code change.` | `Even though it's a small change, it's still a code change.` |
| `I will also take a look at the PR as well.` | `I will also take a look at the PR.` |
| `I also didn't see it.` | `I didn't see it either.` |
| `If no, let's move on.` | `If not, let's move on.` |

## 13. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `Because the API is down, so we can't test.` | `The API is down, so we can't test.` | `because` 和 `so` 只用一个 |
| `Although it works, but it's slow.` | `Although it works, it's slow.` | `although` 和 `but` 只用一个 |
| `I fixed the bug, I updated the docs.` | `I fixed the bug and updated the docs.` | 两个句子不能只用逗号连接 |
| `We don't have time and budget.` | `We don't have time or budget.` | 否定句里用 `or` |
| `I also don't know.` | `I don't know either.` | 否定的"也"用 `either` |
| `I think not so.` | `I don't think so.` | 固定说法 |
| `It's delayed because the design change.` | `It's delayed because of the design change.` | `because` + 句子，`because of` + 名词 |

## 14. 你可以直接用的句子

```text
So, let's get started.
好，我们开始吧。

I finished the API changes, and I opened a PR for review.
我完成了 API 改动，并提了一个 PR 等评审。

It's almost done, but I still need to fix one test.
差不多做完了，但我还需要修一个测试。

The API is not ready yet, so I will test it tomorrow.
API 还没准备好，所以我明天再测。

I will also update the ticket after the meeting.
会后我也会更新工单。

Can you share the link so that I can take a look?
你能把链接发一下吗？我好看一看。

```

## 15. 练习

**A. 判断每句中 `so` 的角色**（开场 / 结果 / 总结 / 目的 / 代替前文）

1. So, any updates from the platform side?
2. The license is not approved, so we can't use the tool.
3. Is it a blocker? I don't think so.
4. Please assign it to me so that I can track it.
5. So that's all for today.
6. Okay, so next one is the release plan.

**B. 用 and / but / or / so / because / either / also 填空**

1. I checked the logs, ___ I didn't find anything.
2. We can't merge it ___ the CI is failing.
3. Do you want to present today ___ next week?
4. Ken didn't see the email, and I didn't see it ___.
5. The design is ready, ___ we can start development.
6. I will ___ update the release notes.

**C. 改错**

1. Because Mia is on leave, so Tom will give the update.
2. Although the build passed, but some tests are skipped.
3. We don't have the access and the license.
4. I will also review it as well.

<details>
<summary>答案</summary>

**A.** 1 开场　2 结果　3 代替前文　4 目的　5 总结　6 开场

**B.** 1 but　2 because　3 or　4 either　5 so　6 also

**C.**
1. Because Mia is on leave, Tom will give the update.（或 Mia is on leave, so Tom will give the update.）
2. Although the build passed, some tests are skipped.（或 The build passed, but some tests are skipped.）
3. We don't have the access or the license.
4. I will also review it.（或 I will review it as well.）

</details>

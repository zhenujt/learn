# G13 非谓语动词：to do、doing、done

<!-- sentence-audio: fenced-only -->

> **频率：🔴 必学** ｜ 阶段：初中 → 高中 ｜ 会议数据：`want / need / try / plan` 等动词后接 `to do` 每万词约 95 次；`to make sure` 是会议高频四词组（61 次）；介词后接 `-ing` 约 13 次
>
> [English version](13-to-do-doing-done.md) · [上一课：G12 被动语态](12-passive-voice.zh.md) · [下一课：G14 短语动词与固定搭配](14-phrasal-verbs-and-collocations.zh.md) · [语法目录](README.zh.md)

## 这一课解决什么问题

中文可以把动词一个接一个地排：我们"需要""确保"流水线"搭好"再"开始""做"组件。英文不行。**一个句子（一个分句）只能有一个真正的谓语动词**，其他动词都要变形，变成 `to do`、`doing` 或 `done`。

```text
We need to make sure the pipeline is set up before we start working on the components.
我们需要确保在开始做组件之前，流水线已经搭好。
```

这句里有 `to make`（to do）、`set up`（done，被动）、`working`（doing）。看懂这三种形式，长句就不难拆了。

**学完这一课，你应该能：**

1. 知道一个分句只有一个谓语动词，其他动词要变成 `to do`、`doing` 或 `done`。
2. 记住会议高频的"动词 + to do"和"动词 + doing"搭配。
3. 分清 `stop to do` 和 `stop doing` 这类意思不同的搭配。
4. 区分 `interesting` 和 `interested` 这类 `-ing / -ed` 形容词，看懂字幕里的分词短语。

## 1. 三种形式，三种感觉

| 形式 | 核心感觉 | 例子 |
| --- | --- | --- |
| `to do` | 还没做、要去做、目的 | `I plan to fix it.` |
| `doing` | 正在做、已有的动作、把动作当名词 | `I finished testing it.` |
| `done` | 被做的、已完成的状态 | `the tickets assigned to me` |

```text
I want to share my screen.
我想共享一下屏幕。（to do：想去做）

Thanks for sharing.
谢谢分享。（doing：已经发生的动作）

Here is the updated document.
这是更新后的文档。（done：被更新过的）
```

记住这三种感觉，遇到没学过的搭配也能猜个大概。

## 2. to do：要去做、为了做

### 2.1 动词 + to do 🔴

这些动词后面接 `to do`，因为它们都指向**还没发生的动作**：

| 动词 | 意思 | 例句 |
| --- | --- | --- |
| `want` / `would like` | 想 | `I want to give a quick update.` |
| `need` | 需要 | `We need to confirm it with QA.` |
| `try` | 尽量、努力 | `I'll try to finish it today.` |
| `plan` | 计划 | `We plan to release it next week.` |
| `decide` | 决定 | `We decided to go with AWS.` |
| `hope` / `expect` | 希望 / 预计 | `We expect to finish it by Friday.` |
| `forget` / `remember` | 忘了 / 记得（去做） | `I forgot to update the ticket.` |
| `manage` | 设法做成 | `We managed to fix the build.` |
| `agree` | 同意（做） | `They agreed to share the API spec.` |
| `start` / `continue` | 开始 / 继续 | `We started to work on it.`（也可接 `doing`） |

```text
I'm planning to finish the API changes by Friday.
我打算周五前完成 API 的改动。

We decided to go with the hybrid approach.
我们决定采用混合方案。

Sorry, I forgot to update the status.
抱歉，我忘了更新状态。
```

### 2.2 动词 + 人 + to do

`ask`、`want`、`need`、`remind`、`allow`、`encourage`、`expect` 后面可以先接人，再接 `to do`：

```text
Can I ask Ken to review it?
我能请 Ken 评审一下吗？

I want you to take a look at the error log.
我想请你看一下错误日志。

Please remind me to send the notes.
请提醒我发会议纪要。
```

> ⚠️ `let`、`make` 后面是**人 + 动词原形**，不加 `to`：`Let me share my screen.`、`Let's move on.`、`Let me know.`。字幕里的 `let us to decide` 是错的。`help` 后面加不加 `to` 都可以：`Can you help me (to) check it?`

### 2.3 to do 表示目的：为了……

```text
I'm sharing my screen to show you the demo.
我共享屏幕是为了给大家看演示。

We use Harness to run the pipeline.
我们用 Harness 来跑流水线。

We need to do a quick prototype to figure out if it's feasible.
我们需要做个快速原型，看看是否可行。
```

更正式的说法是 `in order to`，会议里少见。

### 2.4 make sure：会议高频 🔴

`make sure` 在 25 场会议里出现了 77 次。它有两种接法：

**公式：** `make sure + 完整的句子` 或 `make sure to + 动词原形`

```text
We need to make sure the pipeline is working properly.
我们需要确保流水线正常运行。

Please make sure all tests pass before merging.
合并之前请确保所有测试都通过。

Please make sure to update the ticket status.
请务必更新工单状态。
```

`make sure` 后面接句子时，那个句子要有完整的谓语：`make sure the pipeline works`，不能说 `make sure the pipeline work`。

### 2.5 形容词 / 名词 + to do

```text
It's easy to set up.
这个很容易搭建。

It's hard to say at this point.
目前还不好说。

I'm happy to help.
我很乐意帮忙。

Is it possible to move the meeting to Thursday?
会议能改到周四吗？

The plan is to release it next sprint.
计划是下个 Sprint 发布。

Do we have any other topics to discuss?
还有别的议题要讨论吗？
```

### 2.6 疑问词 + to do 🟡

```text
I'm not sure how to set it up.
我不确定怎么搭建。

We need to decide which option to choose.
我们需要决定选哪个方案。
```

## 3. doing：动作当名词用

### 3.1 介词 + doing 🔴

介词后面不能接动词原形，必须用 `-ing`（介词见 [G16](16-prepositions.zh.md)）：

```text
Thanks for bringing that up.
谢谢你提出这一点。

Thank you for joining.
谢谢大家参加。

I'm only responsible for updating the Jira tickets.
我只负责更新 Jira 工单。

You can add people to the channel by using the workflow.
你可以用这个工作流把人加进频道。

Let's test it on staging before releasing it.
发布前先在预发环境测一下。

How about creating a separate story for it?
要不单独为它建一个 Story？
```

> ⚠️ 有几个 `to` 是介词，后面也要接 `-ing`：`look forward to hearing from you`、`be used to working remotely`。

### 3.2 动词 + doing

这些动词后面接 `-ing`，多数和**已有的、持续的动作**有关：

| 动词 | 意思 | 例句 |
| --- | --- | --- |
| `finish` | 做完 | `I finished testing the login flow.` |
| `avoid` | 避免 | `We should avoid making breaking changes.` |
| `suggest` / `recommend` | 建议 | `I suggest creating a separate ticket.` |
| `consider` | 考虑 | `We can consider moving the release.` |
| `mind` | 介意 | `Would you mind sharing your screen?` |
| `keep` | 一直、继续 | `Let's keep working on it.` |
| `spend + 时间` | 花时间做 | `We spent two days fixing the build.` |
| `start` / `continue` | 开始 / 继续 | `The designers have started working on it.` |

> ⚠️ `suggest` 后面**不能**接"人 + to do"。❌ `I suggest you to create a ticket.` ✅ `I suggest creating a ticket.` 或 `I suggest (that) we create a ticket.`

### 3.3 doing 作主语

```text
Testing on Safari takes a lot of time.
在 Safari 上测试很花时间。

Adding a new runner is not difficult.
加一台新的执行机并不难。
```

## 4. 意思会变的搭配：stop / remember / forget / try

同一个动词，接 `to do` 和 `doing` 意思不同。记住核心：**`to do` 指向之后的动作，`doing` 指当前或之前的动作**。

| 搭配 | 意思 | 例句 |
| --- | --- | --- |
| `stop doing` | 停止正在做的事 | `I'll stop sharing now.` |
| `stop to do` | 停下来，去做另一件事 | `Let's stop here to take questions.` |
| `remember to do` | 记得要去做 | `Remember to update the status.` |
| `remember doing` | 记得做过 | `I remember fixing this bug before.` |
| `forget to do` | 忘了去做 | `I forgot to push the change.` |
| `try to do` | 努力去做 | `I'll try to finish it today.` |
| `try doing` | 试试这个办法 | `Try clearing the cache.` |

```text
Okay, if there are no questions, I'll stop sharing.
好，如果没有问题，我就停止共享了。

Let's stop here to take a few questions.
我们在这里停一下，回答几个问题。

Have you tried restarting the runner?
你试过重启执行机吗？
```

`start` 和 `continue` 接 `to do` 或 `doing` 意思基本一样。

## 5. done：被做的、已完成的

### 5.1 放在名词后面作修饰

过去分词短语放在名词后面，意思是"**被……的**"。这其实是省略了 `which is / that was` 的定语从句（见 [G19](19-relative-clauses.zh.md)）。

```text
Here are the tickets assigned to me.
这些是分配给我的工单。

The issues reported by QA are all fixed.
QA 报的问题都修好了。

The components migrated from the old library work fine.
从旧组件库迁移过来的组件都正常。
```

### 5.2 have / get + 东西 + done：让某事被做好 🟡

```text
We need to get the access approved first.
我们得先把权限批下来。

I'll get it done by Friday.
我周五前把它搞定。
```

`be + done` 就是被动语态，见 [G12](12-passive-voice.zh.md)。

## 6. -ing 和 -ed 形容词

很多动词的 `-ing` 和 `-ed` 形式可以当形容词，意思不一样：

- **`-ing`：** 事物"**让人**觉得……"。
- **`-ed`：** 人"**自己**觉得……"。

| -ing（描述事物） | -ed（描述人的感受） |
| --- | --- |
| `interesting` 有意思的 | `interested` 感兴趣的 |
| `confusing` 让人糊涂的 | `confused` 感到糊涂的 |
| `surprising` 令人惊讶的 | `surprised` 感到惊讶的 |
| `frustrating` 让人恼火的 | `frustrated` 感到恼火的 |
| `exciting` 令人兴奋的 | `excited` 感到兴奋的 |
| `tiring` 累人的 | `tired` 累了的 |

```text
The new workflow is a bit confusing.
新的流程有点让人糊涂。

I'm a little bit confused about the QA process.
我对 QA 流程有点没搞懂。

If you are interested, you can stay online.
如果感兴趣，可以留在会议里。
```

❌ `I'm interesting in this topic.`（意思变成"我这个人很有趣"）✅ `I'm interested in this topic.`

**名词前的分词形容词**在字幕和工单里特别多，要能一眼认出：

| -ing（主动、进行中） | -ed（被动、已完成） |
| --- | --- |
| `the remaining tasks` 剩下的任务 | `the updated document` 更新后的文档 |
| `the existing pipeline` 现有的流水线 | `the proposed solution` 提议的方案 |
| `the following steps` 接下来的步骤 | `the related tickets` 相关工单 |
| `the upcoming release` 即将到来的发布 | `the attached screenshot` 附上的截图 |
| `a breaking change` 破坏性变更 | `the expected result` 预期结果 |
| `failing tests` 失败的测试 | `the selected option` 选中的选项 |

## 7. 字幕和标题里的分词短语

### 7.1 句首的分词短语：背景信息

字幕里常有一个 `-ing` 或 `-ed` 短语放在句首，后面有逗号。它只是**背景信息**，主句在逗号后面。

```text
Based on the feedback, we will update the design.
根据反馈，我们会更新设计。

Compared with the old version, it's much faster.
和旧版本比，它快多了。

Looking at the board, most stories are in progress.
从看板上看，大部分 Story 都在进行中。

Starting next week, we will have a daily sync.
从下周开始，我们每天同步一次。

Going forward, please create a ticket first.
以后请先建工单。
```

`-ing` 开头 → 主语自己做的动作；`-ed` 开头 → 被动的意思。`including`、`depending on`、`regarding`、`according to` 这些词也来自分词，现在当介词用。

### 7.2 工单标题和提交信息

Jira 标题、PR 标题、提交信息常常省略主语，只留分词：

```text
Setting up the CI pipeline for Android
为 Android 搭建 CI 流水线（-ing：正在做的任务）

Updated the README with new steps
更新了 README，补充了新步骤（-ed：已经做完）
```

## 8. 真实会议例句（改编）

以下句子来自真实会议字幕，修正了识别错误，人名已替换：

```text
I just want to quickly double-check with you.
我就想快速跟你确认一下。

We need to do a quick prototype to figure out if it's feasible.
我们需要做个快速原型，弄清楚是否可行。

Thanks for bringing that up.
谢谢你提出这个问题。

Thank you for taking this one in the current sprint.
谢谢你在这个 Sprint 接下这个任务。

I'm only responsible for updating the Jira tickets.
我只负责更新 Jira 工单。

The designers have started working on restructuring the foundations.
设计师已经开始重构基础样式了。

I'll share it with Mia before sharing it with the team.
我会先发给 Mia，再发给团队。

I'm a little bit confused about how the QA team can use this plugin.
我有点不明白 QA 团队要怎么用这个插件。

We need to make sure the pipeline is set up properly before we start the actual work.
在真正开工前，我们得确保流水线已经搭好。
```

## 9. 字幕里怎么认

1. **先找谓语动词。** 一个分句只有一个；其他带 `to`、`-ing`、`-ed` 的动词都是"配角"。
2. **看到 `to` + 动词原形**，理解成"要去做 / 为了做"。
3. **看到介词 + `-ing`**，理解成"做……这件事"。
4. **句首分词短语加逗号**，先跳过，找逗号后的主句。
5. **非母语说法能看懂就行，不要模仿：**

| 字幕里可能听到 | 标准说法 |
| --- | --- |
| `I will stop share.` | `I'll stop sharing.` |
| `let us to decide` | `let us decide` |
| `we need to consider to push the release` | `we need to consider pushing the release` |
| `I would recommend to do that` | `I'd recommend doing that` |
| `he is start to do the POC` | `he has started doing the POC` |
| `continue to working on it` | `continue working on it` / `continue to work on it` |
| `thanks for your share` | `thanks for sharing` |
| `make sure the pipeline work` | `make sure the pipeline works` |

## 10. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `We need make sure it works.` | `We need to make sure it works.` | `need` 后接 `to do` |
| `I want share my screen.` | `I want to share my screen.` | `want` 后接 `to do` |
| `Thanks for share.` | `Thanks for sharing.` | 介词后接 `-ing` |
| `I suggest you to create a ticket.` | `I suggest creating a ticket.` | `suggest` 不接"人 + to do" |
| `Let me to share my screen.` | `Let me share my screen.` | `let` 后接动词原形 |
| `I'm interesting in it.` | `I'm interested in it.` | 人的感受用 `-ed` |
| `I finished to test it.` | `I finished testing it.` | `finish` 后接 `-ing` |
| `We should avoid to break the API.` | `We should avoid breaking the API.` | `avoid` 后接 `-ing` |
| `I look forward to hear from you.` | `I look forward to hearing from you.` | 这里的 `to` 是介词 |

## 12. 练习

**A. 用括号里动词的正确形式填空**（to do / doing / done / 原形）

1. I want ___ (share) my screen.
2. Thanks for ___ (join) the call.
3. We need to make sure the build ___ (pass).
4. I suggest ___ (move) the demo to Friday.
5. Let me ___ (check) the logs.
6. Here are the tickets ___ (assign) to me.
7. We should avoid ___ (change) the API now.
8. I'm planning ___ (release) it next week.

**B. 选择正确的形式**

1. Okay, I'll stop (to share / sharing) now.
2. Please remember (to update / updating) the ticket after the meeting.
3. The build still fails. Have you tried (to clear / clearing) the cache?
4. I'm a little (confusing / confused) about the new process.
5. The demo was really (interesting / interested).

**C. 改错**

1. I suggest you to create a new story.
2. Let us to decide later.
3. I finished to review the PR.
4. I look forward to work with you.

<details>
<summary>答案</summary>

**A.** 1 to share　2 joining　3 passes　4 moving　5 check　6 assigned　7 changing　8 to release

**B.** 1 sharing　2 to update　3 clearing　4 confused　5 interesting

**C.**
1. I suggest creating a new story.（或 I suggest (that) you create a new story.）
2. Let us decide later.
3. I finished reviewing the PR.
4. I look forward to working with you.

</details>

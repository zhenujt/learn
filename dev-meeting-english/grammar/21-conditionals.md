## What This Lesson Solves

Meeting hosts say these sentences again and again:

```text
If you have any questions, please let me know.

If there are no questions, let's move to the native part.

If that's the case, we don't need to pick up those tasks for now.
```

`if` is one of the most frequent linking words in meetings (≈ 86 per 10k). The good news: **almost all of them use only the two simplest patterns.** The subjunctive and third conditional that textbooks spend pages on did not appear once in 25 meetings.

**After this lesson, you can:**

1. Tell apart the two jobs of `if`: condition ("on condition that") and noun clause ("whether").
2. Use the zero and first conditionals and fixed phrases such as `if you have any questions`, `if that's the case`, `if possible`, and `let me know if …`.
3. Understand the second conditional `if … would / could` and use the polite `It would be great if you could …`.
4. Say "unless", "as long as", "in case", and "otherwise".

## 1. First: Is if "On Condition That" or "Whether"?

| Job | Position | Example |
| --- | --- | --- |
| Condition | at the start, or after the main clause | `If it fails, we will roll back.` |
| Whether | after `check / see / not sure / wonder / know / ask` | `Can you check if it fails?` |

**Test:** replace `if` with `whether`. If the meaning stays the same, it means "whether" (see [G18](18-noun-clauses.md)). If not, it is a condition.

```text
If the build fails, we will roll back.

Can you check if the build fails on main?
```

About one in three meeting `if`s means "whether". So when you see `if`, **first check whether `check / see / sure / wonder` comes before it**.

## 2. The Four Conditionals at a Glance

| Type | Use | if clause | Main clause | Meeting frequency |
| --- | --- | --- | --- | --- |
| Zero | rules, system behavior | present simple | present simple | 🔴 |
| First | real future possibility | present simple | `will / can / let's / imperative` | 🔴 |
| Second | imaginary, unlikely, polite | past simple | `would / could + base verb` | 🟢 ≈ 2 per 10k |
| Third | imaginary past | `had + past participle` | `would have + past participle` | ⚪ 0 |

## 3. Zero Conditional: Rules and System Behavior 🔴

**Pattern:** `If + present simple, present simple.`

"Whenever A happens, B happens". Ideal for describing **how a system works**:

```text
If the pipeline fails, the PR can't be merged.

If you change the token, the color updates everywhere.

If I set it to phone size, the text resizes.

If a story has code changes, it needs a verification step.
```

Here `if` is close to `when` ("whenever").

## 4. First Conditional: Real Future Possibility 🔴

**Pattern:** `If + present simple, will / can / should / let's / imperative + base verb.`

Plans, risks, and next steps all use this pattern:

```text
If we see any limitation, we will switch to the other tool.

If 4.45 is the latest version, we can go with that.

If you need any help, just ping me.

If we already have a service account, I'll reuse it.
```

**The key rule: no `will` in the if clause.** It is the same rule as `when / once` in [G20](20-adverbial-clauses.md):

❌ `If we will publish it to npm, we can skip the private registry.`
✅ `If we publish it to npm, we can skip the private registry.`

**The if clause can come second,** usually without a comma:

```text
We can skip the private registry if we publish it to npm.
```

## 5. High-Frequency Meeting Phrases 🔴

| Phrase | Meaning | When to use it |
| --- | --- | --- |
| `If you have any questions, …` | in case of questions | end of an update or training |
| `If (there are) no questions, …` | when nobody has questions | the host moves on |
| `If not, …` / `If so, …` | if no / if yes | after a question |
| `If that's the case, …` | if that is true | reacting to new information |
| `if possible` / `if needed` | when possible / when needed | at the end of a request |
| `Let me know if …` | tell me if … | closing a conversation |
| `if any` | if there are any | after a noun |
| `What if …?` | how about …? | making a suggestion |
| `even if` | regardless of whether | the result stays the same |

```text
If you have any questions, feel free to reach out.

If no questions, let's move to the platform part.

Is everyone here? If not, let's wait one more minute.

If that's the case, I think we are good.

Please review it today if possible.

Let me know if that works for you.

Please add your comments, if any.

What if we split this story into two?

Even if we finish the code today, QA still needs two days.
```

> `If no questions` is a short form of `If there are no questions` and is fine in speech. But on its own, "if not" is `If not`, not `If no`.

## 6. Second Conditional: Imaginary and Polite 🟢

**Pattern:** `If + past simple, would / could / might + base verb.`

The past tense here **does not mean the past**. It means **distance from reality**: unlikely, imaginary, or softened for politeness.

### 6.1 Imaginary: Reality Is Different

```text
If we had more people, we could finish it this sprint.

If it were my decision, I would wait for the next release.
```

### 6.2 Polite Requests and Offers (the Most Useful Use in Meetings)

```text
It would be great if you could review it today.

If you could share the link, that would be helpful.

If you'd like, I could give a quick demo.
```

Note: in polite requests, `could / would` **can** appear inside the if clause (`if you could`, `if you would like`). This does not break the rule in section 4, because here `could / would` express ability or willingness, not future time.

### 6.3 if I were ⚪

In formal English, the second conditional uses `were` for every person:

```text
If I were you, I would ask the platform team.
```

`If I was …` is also common in speech. Almost never used in meetings (≈ 0.1 per 10k); recognize it and move on.

## 7. Third and Mixed Conditionals ⚪

Almost never used in meetings; recognize them and move on. The third conditional appeared 0 times in 25 meetings.

**Third conditional:** imagining a different past. `If + had + past participle, would have + past participle.`

```text
If we had started earlier, we would have finished on time.
```

**Mixed conditional:** an imagined past with a present result.

```text
If we had fixed it last week, we wouldn't be blocked now.
```

To talk about what should have happened, meetings use `should have done` (see [G11 Modal Verbs](11-modal-verbs.md)): `We should have tested it on iOS.`

## 8. unless, as long as, in case, otherwise 🟢

| Word | Meaning | Pattern | Per 10k |
| --- | --- | --- | --- |
| `unless` | if … not | `unless + present simple` | ≈ 1 |
| `as long as` | only if, provided that | `as long as + present simple` | ≈ 0.2 |
| `in case` | as a precaution | `in case + present simple` | ≈ 0.9 |
| `otherwise` | if not, or else | `. Otherwise, + clause` | ≈ 0.5 |

### 8.1 unless

```text
We won't merge it unless QA signs off.

It's three points, unless we're doing a POC.
```

`unless` already contains "not", so **do not add `not`** in the clause, and **do not add `if`**.

### 8.2 as long as

```text
As long as we have code changes, we need a verification step.

It's fine as long as the tests pass.
```

### 8.3 in case

```text
Let's keep the old branch in case we need to roll back.

Here is the link, in case anyone asks for it.
```

`in case` = **do it now as a precaution**; `if` = **do it only when it happens**:

```text
I'll bring my laptop in case the demo fails.

I'll fix it if the demo fails.
```

### 8.4 otherwise

```text
We need to fix it today. Otherwise, we need to push the release.

If we already have an account, I'll reuse it. Otherwise, I'll create a new one.
```

`otherwise` is an adverb and usually starts a new sentence. `or else` is a spoken alternative.

## 10. Reading Conditionals in Subtitles

1. **Decide the job of `if` first:** after `check / see / sure / wonder / know` → "whether"; at the start or after the main clause → condition.
2. **Find the comma:** the main clause comes after `If …,`. With no comma, find the second "subject + verb".
3. **Don't panic at `would / could`:** in meetings they are usually polite forms, not complex subjunctives.
4. **Non-native and speech-recognition variants:**

| Heard in subtitles | Standard form |
| --- | --- |
| `If no, let's move on.` | `If not, let's move on.` |
| `Okay, if you know, that's all for this topic.` | `Okay, if no (questions), that's all for this topic.` (recognition error) |
| `If we will publish it, …` | `If we publish it, …` |
| `Unless if someone finds a problem, …` | `Unless someone finds a problem, …` |
| `If we would like, I could give a demo.` | `If you'd like, I could give a demo.` |
| `just in case if someone asks` | `just in case someone asks` |

## 11. Common Mistakes

| ❌ Wrong | ✅ Right | Reason |
| --- | --- | --- |
| `If it will fail, we will roll back.` | `If it fails, we will roll back.` | present for future in the if clause |
| `If no, we can skip it.` | `If not, we can skip it.` | standalone "if not" |
| `We won't merge it unless QA doesn't sign off.` | `We won't merge it unless QA signs off.` | `unless` already means "if not" |
| `If we have more time, we would test it.` | `If we had more time, we would test it.` / `If we have more time, we will test it.` | match the tenses |
| `If I am you, I will ask Ken.` | `If I were you, I would ask Ken.` | imaginary = second conditional |
| `Bring the laptop if the demo fails.` (meaning "as a precaution") | `Bring the laptop in case the demo fails.` | precaution = `in case` |

## 12. Sentences You Can Use Today

If you have any questions, please let me know.

## 13. Practice

**A. Does `if` mean "on condition that" or "whether"?**

2. Can you check if the job is still running?
3. I'm not sure if Mia is joining today.
4. If the job is still running, let's wait.
5. I wonder if we can reuse the old config.
6. Let's see if anyone can pick it up.

**B. Use the verb in brackets**

1. If the API ___ (change), we will update the docs.

# G05 疑问句、否定句与简短回答

## 这一课解决什么问题

会议是"一问一答"的场合。主持人每讲完一段就会问：

```text
Does anyone have any questions or comments?
大家有什么问题或意见吗？
```

有人可能会这样问你：

```text
Isn't the PR merged yet?
PR 还没合并吗？
```

如果还没合并，中文习惯说"对，还没"，但英语要说 `No, not yet.`——说 `Yes` 就变成"已经合并了"。这类回答错误会直接造成误会。

**学完这一课，你应该能：**

1. 用"助动词提前"造一般疑问句：`Is …?`、`Do you …?`、`Did you …?`、`Can you …?`、`Have you …?`
2. 用 `what / when / who / how` 提问，分清 `Who is working on it?` 和 `What did you change?` 两种语序。
3. 用对否定：`don't / doesn't / didn't`、`not yet`、`no + 名词`、`I don't think …`
4. 用简短回答自然地回应，并按事实正确回答否定疑问句。

## 1. 先建立一个正确的认识：一个"助动词"管疑问和否定

英语的疑问和否定都靠**谓语里的第一个助动词**（也叫"操作词"）来完成：

- **问：** 把它提到主语前面。
- **否定：** 在它后面加 `not`。

| 陈述句 | 否定句 | 疑问句 | 操作词 |
| --- | --- | --- | --- |
| `It is ready.` | `It isn't ready.` | `Is it ready?` | `is` |
| `You can see it.` | `You can't see it.` | `Can you see it?` | `can` |
| `He has checked it.` | `He hasn't checked it.` | `Has he checked it?` | `has` |
| `You need help.` | `You don't need help.` | `Do you need help?` | 没有 → 补 `do` |
| `It works.` | `It doesn't work.` | `Does it work?` | 没有 → 补 `does` |
| `She fixed it.` | `She didn't fix it.` | `Did she fix it?` | 没有 → 补 `did` |

**规则：** 句子里没有 `be`、情态动词或完成时的 `have` 时，就补一个 `do / does / did`，**后面的动词变回原形**：`Does it work?`（不是 `Does it works?`）。

## 2. 一般疑问句：用 Yes / No 回答 🔴

### 2.1 be 开头

```text
Is it ready for review?
可以评审了吗？

Are you still there?
你还在吗？

Is my screen visible?
能看到我的屏幕吗？

Was the build green yesterday?
昨天构建是通过的吗？
```

### 2.2 do / does / did 开头

```text
Do you have any questions?
有问题吗？

Do we need to vote for this one?
这个需要投票吗？

Does it work on iOS?
在 iOS 上能用吗？

Does anyone have other topics?
还有人有别的议题吗？

Did you check the logs?
你看日志了吗？
```

### 2.3 情态动词开头

```text
Can you see my screen?
能看到我的屏幕吗？

Could you share the link in the chat?
能把链接发到聊天里吗？

Should we skip this one for now?
这个我们先跳过吗？

Will it be ready by Friday?
周五前能好吗？
```

### 2.4 have / has 开头（现在完成时）

```text
Have you checked the latest build?
你看过最新的构建了吗？

Has the PR been merged?
PR 合并了吗？
```

## 3. 特殊疑问句：what、who、when、how… 🔴

**公式：** `疑问词 + 一般疑问句语序`

| 疑问词 | 问什么 | 会议例句 |
| --- | --- | --- |
| `what` | 什么 | `What's the status of this ticket?` |
| `who` | 谁 | `Who is working on this?` |
| `when` | 什么时候 | `When will it be ready?` |
| `where` | 在哪 | `Where can I find the doc?` |
| `which` | 哪一个 | `Which option is better?` |
| `why` | 为什么 | `Why did the build fail?` |
| `how` | 怎么样、如何 | `How does it work?` |
| `how long` | 多久 | `How long will it take?` |
| `how many / how much` | 多少（可数 / 不可数） | `How many tickets are left?`、`How much time do we need?` |

```text
What do you think?
你怎么看？

When is the next release?
下一次发布是什么时候？

Why do we need a new pipeline?
为什么我们需要新的流水线？

How long will the migration take?
迁移要多长时间？
```

### 3.1 问主语时不加 do 🔴

如果疑问词本身就是**主语**（问"谁做了""什么发生了"），直接按陈述句语序，不加 `do`：

| 问主语（不加 do） | 问宾语（要加 do） |
| --- | --- |
| `Who is working on this?` 谁在做？ | `What are you working on?` 你在做什么？ |
| `What happened?` 发生了什么？ | `What did you change?` 你改了什么？ |
| `Who can take this ticket?` 谁能接这个工单？ | `Who did you ask?` 你问了谁？ |
| `Which test failed?` 哪个测试失败了？ | `Which test did you run?` 你跑了哪个测试？ |

❌ `Who did fix it?`　✅ `Who fixed it?`

### 3.2 中国同学最常见的两个问句错误

```text
What do you think?
你怎么看？（不是 How do you think?）

Why don't we use GitHub Actions?
为什么我们不用 GitHub Actions？（不是 Why we don't use…?）

How about Thursday?
周四怎么样？（提建议，不需要助动词）
```

中文"你**怎么**看"让人想用 `how`，但英语问"看法的内容"用 `what`。`How do you feel about it?` 也可以，但会议里最常说的是 `What do you think?`。

## 4. 选择疑问句：A 还是 B？ 🟡

**公式：** `一般疑问句 + A or B?` 回答时直接选一个，不用 `yes / no`。

```text
Do you want to demo it today or tomorrow?
你想今天演示还是明天演示？

Is it a bug or a feature request?
这是 Bug 还是功能需求？

Should we fix it now, or can we postpone it?
我们现在修，还是可以往后放？
```

回答：`Tomorrow, please.`、`It's a bug.`、`We can postpone it.`

## 5. 反意疑问句与句尾的 right? 🟡

**标准的反意疑问句**：陈述句后面加一个短问句，用来确认。规则是"前肯后否、前否后肯"，助动词要对应：

```text
It's ready, isn't it?
已经好了，对吧？

You checked it, didn't you?
你检查过了，对吧？

We don't need it, do we?
我们不需要它，对吧？
```

**但在会议里，母语者和非母语者都更常用一个简单的 `right?`**（也有 `correct?`、`is that right?`）。它不需要变助动词，非常好用：

```text
So we skip this one for now, right?
所以这个我们先跳过，对吧？

The macOS runner is for the iOS pipeline, right?
macOS 执行机是给 iOS 流水线用的，对吗？

You mean the web part, correct?
你说的是 Web 部分，对吗？
```

还有一种更省事的问法：**陈述句 + 升调**（字幕里只有一个问号）：`You mean the web part?`、`So it's not blocked now?`

`right?`、`you know?`、`okay?` 这些口语"尾巴"的更多用法见 [G23](23-spoken-grammar.zh.md)。

## 6. 否定句 🔴

### 6.1 怎么构成

| 类型 | 公式 | 例子 |
| --- | --- | --- |
| be | be + not | `It isn't ready yet.` |
| 情态动词 | can / will / should + not | `I can't access it.`、`It won't work.` |
| 完成时 | have / has + not + 过去分词 | `I haven't checked it yet.` |
| 普通动词 | do / does / did + not + 原形 | `It doesn't work.`、`I didn't see the message.` |

```text
I don't have any updates today.
我今天没有更新。

We don't need to wait for the final design.
我们不需要等最终设计稿。

It doesn't work on Android.
在 Android 上不能用。

I didn't see that in the calendar.
我在日历里没看到。

I haven't started it yet.
我还没开始。
```

### 6.2 not 开头的短回答 🔴

会议里经常只说半句：

```text
Not yet.
还没有。

Not really.
不太是 / 不怎么样。

Not sure.
不确定。

Not right now.
现在不行。

Not at all.
一点也不。/ 不客气。
```

### 6.3 no + 名词、nothing、never 🔴

`no` 直接放在名词前，比 `don't have any` 更简洁，站会里非常常见：

```text
No updates from my side.
我这边没有更新。

No blockers.
没有阻塞。

Nothing to add.
没有要补充的。

I've never used this tool.
我从没用过这个工具。（🟡）
```

> ⚠️ 不要双重否定：❌ `I don't have no questions.`　✅ `I don't have any questions.` 或 `I have no questions.`

### 6.4 I don't think … ：把否定放在前面 🟡

中文说"我觉得**不**需要"，英语更自然的说法是"我**不**觉得需要"：

```text
I don't think we need it.
我觉得我们不需要。

I don't think so.
我觉得不是。/ 我觉得不用。
```

`I think we don't need it.` 语法上没错，但听起来不太自然。`I don't think …` 和 `I think …` 的更多用法见 [G18](18-noun-clauses.zh.md)。

### 6.5 部分否定 🟢

```text
Not all the tests passed.
不是所有测试都通过了。
```

`All the tests didn't pass.` 有歧义（"全都没通过"还是"不是全都通过"），会议里用 `Not all …` 或 `Some tests failed.` 更清楚。

## 7. 否定疑问句：怎么回答才不会误会 🟡

否定疑问句表示"惊讶"或"希望确认"：

```text
Isn't it merged yet?
还没合并吗？

Don't you have access?
你没有权限吗？

Can't you see my screen?
你看不到我的屏幕吗？
```

**回答规则：英语只看事实，不看问句的形式。** 事实是肯定的就说 `Yes`，事实是否定的就说 `No`：

| 问题 | 事实 | ✅ 英语回答 | 中文习惯 |
| --- | --- | --- | --- |
| `Isn't it merged yet?` | 还没合并 | `No, not yet.` | 对，还没。 |
| `Isn't it merged yet?` | 已经合并了 | `Yes, it is. It was merged this morning.` | 不，已经合了。 |
| `Don't you have access?` | 没有权限 | `No, I don't.` | 对，我没有。 |

**最保险的办法：** 不要只说 `Yes` 或 `No`，**后面一定补一句完整的话**：`No, it's not merged yet.`

## 8. 简短回答与自然回应 🔴

**标准简短回答：** 用问句里的操作词回答，不重复整句。

| 问句 | 肯定 | 否定 |
| --- | --- | --- |
| `Is it ready?` | `Yes, it is.` | `No, it isn't.` |
| `Do you have access?` | `Yes, I do.` | `No, I don't.` |
| `Did you check it?` | `Yes, I did.` | `No, I didn't.` |
| `Can you see my screen?` | `Yes, I can.` | `No, I can't.` |
| `Have you tested it?` | `Yes, I have.` | `No, I haven't.` |

❌ `Yes, I can see.`（缺宾语）　✅ `Yes, I can.` 或 `Yes, I can see it.`

**会议里更自然的回应：**

```text
Yeah, sure.
好的，没问题。

I think so.
我觉得是。

I don't think so.
我觉得不是。

I hope so.
希望如此。

Sounds good.
听起来不错。

Me too.
我也是。

Me neither.
我也不。（🟡，回应否定句）
```

`So do I.`、`Neither do I.` 这类倒装回应在会议里很少听到（🟢）。

## 9. 真实会议例句（改编）

```text
Do you have any updates from the design side?
设计那边有什么更新吗？

Do we have the AWS environment already?
我们已经有 AWS 环境了吗？

So, do you mean there's no additional research for the Android part?
所以你的意思是 Android 部分不需要额外调研了？

Who is responsible for updating the Jira ticket status?
谁负责更新 Jira 工单的状态？

Where is the source code repo?
源代码仓库在哪儿？

We don't need to mention that in the document for now.
目前不需要在文档里提这个。

I've created a task, but I don't think it's started yet.
我已经建了任务，不过我觉得还没开始做。

No, I don't have any questions.
没有，我没有问题。
```

## 10. 字幕里怎么认

1. **问句不一定有倒装。** 口语里常用"陈述句 + 问号"：`You can see my screen?`、`So we skip it?`。看到句尾问号，就当成问句。
2. **句尾的 `right?`、`correct?` 是在确认，不是在问新问题。** 回答 `Yes` / `Right` / `Correct` 或纠正即可。
3. **否定词在字幕里容易丢。** `can` 和 `can't` 发音很像，语音识别常常弄错。重要的事情（能不能上线、有没有阻塞）不确定时，直接问一句：`Sorry, can or can't?`
4. **非母语说法能看懂即可：**

| 字幕里可能看到 | 标准说法 |
| --- | --- |
| `Does anyone else has questions?` | `Does anyone else have questions?` |
| `How do you think?` | `What do you think?` |
| `Why we don't use the existing pipeline?` | `Why don't we use the existing pipeline?` |
| `When you ready for test, do we need to move the status?` | `When you're ready for testing, do we need to move the status?` |
| `Can let me share my screen?` | `Can I share my screen?` / `Let me share my screen.` |
| `I think the scope is not contain the external team.` | `I don't think the scope includes the external team.` |
| `Did you, did you mean the AWS one?` | `Did you mean the AWS one?` |

## 11. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `Does it works?` | `Does it work?` | `does` 后用原形 |
| `You have any questions?` | `Do you have any questions?` | 正式提问要加 `do`（陈述句加升调只用于确认） |
| `Who did fix it?` | `Who fixed it?` | 问主语不加 `did` |
| `How do you think?` | `What do you think?` | 问看法用 `what` |
| `Why you didn't tell me?` | `Why didn't you tell me?` | 疑问词后要倒装 |
| `I not sure.` | `I'm not sure.` | 需要 `be` |
| `It not work.` | `It doesn't work.` | 普通动词用 `doesn't` 否定 |
| `I don't have no questions.` | `I don't have any questions.` | 不要双重否定 |
| `— Isn't it done? — Yes.`（实际没做完） | `— Isn't it done? — No, not yet.` | 按事实回答 |
| `Yes, I can see.` | `Yes, I can.` / `Yes, I can see it.` | `see` 后要宾语，或只用操作词 |

# G21 条件句：if 的四种用法

<!-- sentence-audio: fenced-only -->

> **频率：🔴 必学（零条件句、第一条件句）/ 🟢 认得即可（第二条件句）/ ⚪ 用不到（第三条件句、混合条件句）** ｜ 阶段：初中 → 高中 ｜ 会议数据：`if` 每万词约 86 次（其中约 25 次是"是否"），`if … would / could` 约 2.1 次，`if I were` 约 0.1 次，第三条件句 0 次，`unless` 约 1.0 次，`otherwise` 约 0.5 次，`as long as` 约 0.2 次
>

## 这一课解决什么问题

主持人在会议里一遍又一遍说的，就是这几句：

```text
If you have any questions, please let me know.
如果有任何问题，请告诉我。

If there are no questions, let's move to the native part.
如果没有问题，我们接着看 Native 部分。

If that's the case, we don't need to pick up those tasks for now.
如果是这样，我们暂时不需要接这些任务。
```

`if` 是会议里第三常见的连接词（每万词约 86 次）。好消息是：**会议里绝大多数 `if` 只用最简单的两种句型**。教科书花大量篇幅讲的虚拟语气、第三条件句，在 25 场会议里一次都没出现。

**学完这一课，你应该能：**

1. 分清 `if` 的两种身份：条件"如果"和名词性从句的"是否"。
2. 熟练使用零条件句、第一条件句，以及 `if you have any questions`、`if that's the case`、`if possible`、`let me know if …` 等固定说法。
3. 看懂第二条件句 `if … would / could`，会用礼貌说法 `It would be great if you could …`。
4. 用 `unless`、`as long as`、`in case`、`otherwise` 表达"除非、只要、以防、否则"。

## 1. 先分清：if 是"如果"还是"是否"

| 身份 | 中文 | 位置 | 例子 |
| --- | --- | --- | --- |
| 条件 | 如果 | 句首，或主句后面 | `If it fails, we will roll back.` |
| 是否 | 是不是、有没有 | 跟在 `check / see / not sure / wonder / know / ask` 后面 | `Can you check if it fails?` |

**判断方法：** 把 `if` 换成 `whether`，意思不变 → 是"是否"（见 [G18](18-noun-clauses.zh.md)）；意思不通 → 是"如果"。

```text
If the build fails, we will roll back.
如果构建失败，我们就回滚。（条件：不能换成 whether）

Can you check if the build fails on main?
你能看一下 main 分支上构建是不是失败吗？（是否：可以换成 whether）
```

在会议的 `if` 里，大约每三个就有一个是"是否"。所以字幕里看到 `if`，**先看它前面是不是 `check / see / sure / wonder`**。

## 2. 四种条件句总览

| 类型 | 说什么 | if 从句 | 主句 | 会议频率 |
| --- | --- | --- | --- | --- |
| 零条件句 | 规律、系统行为 | 一般现在时 | 一般现在时 | 🔴 |
| 第一条件句 | 真实可能的将来 | 一般现在时 | `will / can / let's / 祈使句` | 🔴 |
| 第二条件句 | 假设、不太可能、礼貌 | 一般过去时 | `would / could + 动词原形` | 🟢 每万词约 2 次 |
| 第三条件句 | 对过去的假设 | `had + 过去分词` | `would have + 过去分词` | ⚪ 0 次 |

## 3. 零条件句：规律和系统行为 🔴

**公式：** `If + 一般现在时, 一般现在时.`

说"只要 A 发生，B 就一定发生"——非常适合描述**系统怎么工作**：

```text
If the pipeline fails, the PR can't be merged.
如果流水线失败，PR 就不能合并。

If you change the token, the color updates everywhere.
如果你改了这个 Token，所有地方的颜色都会跟着变。

If I set it to phone size, the text resizes.
如果我把它设成手机尺寸，文字就会调整大小。

If a story has code changes, it needs a verification step.
如果一个 Story 有代码改动，它就需要一个验证步骤。
```

这里的 `if` 意思接近 `when`（每当）。

## 4. 第一条件句：真实可能的将来 🔴

**公式：** `If + 一般现在时, will / can / should / let's / 祈使句 + 动词原形.`

讲计划、讲风险、讲下一步，用的都是这个句型：

```text
If we see any limitation, we will switch to the other tool.
如果发现什么限制，我们就换用另一个工具。

If 4.45 is the latest version, we can go with that.
如果 4.45 是最新版本，我们就用它。

If you need any help, just ping me.
如果需要帮忙，直接找我。

If we already have a service account, I'll reuse it.
如果我们已经有服务账号了，我就复用它。
```

**最重要的规则：if 从句里不用 `will`。** 这和 [G20](20-adverbial-clauses.zh.md) 的 `when / once` 规则一样：

❌ `If we will publish it to npm, we can skip the private registry.`
✅ `If we publish it to npm, we can skip the private registry.`

**if 从句可以放在后面**，这时中间一般不加逗号：

```text
We can skip the private registry if we publish it to npm.
如果发布到 npm，我们就可以不用私有仓库。
```

## 5. 会议高频固定说法（整体记）🔴

| 说法 | 意思 | 用在什么时候 |
| --- | --- | --- |
| `If you have any questions, …` | 如果有任何问题 | 汇报结尾、培训结尾 |
| `If (there are) no questions, …` | 如果没有问题 | 主持人换话题 |
| `If not, …` / `If so, …` | 如果不是 / 如果是 | 接在一个问题后面 |
| `If that's the case, …` | 如果是这样 | 对别人的信息做出反应 |
| `if possible` / `if needed` | 如果可以 / 如果需要 | 放在请求的末尾 |
| `Let me know if …` | 如果……告诉我 | 结束一段对话 |
| `if any` | 如果有的话 | 放在名词后面 |
| `What if …?` | 要是……会怎样？/ 要不…… | 提建议 |
| `even if` | 即使 | 强调结果不变 |

```text
If you have any questions, feel free to reach out.
如果有任何问题，随时联系我。

If no questions, let's move to the platform part.
如果没有问题，我们看平台部分。

Is everyone here? If not, let's wait one more minute.
大家都到了吗？如果没有，我们再等一分钟。

If that's the case, I think we are good.
如果是这样，我觉得我们没问题了。

Please review it today if possible.
如果可以的话，请今天评审一下。

Let me know if that works for you.
如果这样对你可行，告诉我一声。

Please add your comments, if any.
如果有意见，请补充上来。

What if we split this story into two?
要不我们把这个 Story 拆成两个？

Even if we finish the code today, QA still needs two days.
就算今天把代码写完，QA 也还需要两天。
```

> `If no questions` 是 `If there are no questions` 的省略说法，口语里没问题。但单独说"如果没有"时要用 `If not`，不要说 `If no`。

## 6. 第二条件句：假设和礼貌 🟢

**公式：** `If + 一般过去时, would / could / might + 动词原形.`

这里的"过去时"**不表示过去**，而是表示"**和现实有距离**"：不太可能、纯假设，或者为了礼貌把语气放软。

### 6.1 假设：现实不是这样

```text
If we had more people, we could finish it this sprint.
如果我们人手更多，这个 Sprint 就能做完。（实际上人手不够）

If it were my decision, I would wait for the next release.
如果由我决定，我会等下一个版本。（实际上不由我决定）
```

### 6.2 礼貌请求和提议（会议里最有用的用法）

```text
It would be great if you could review it today.
如果你今天能评审一下就太好了。

If you could share the link, that would be helpful.
如果你能分享一下链接，那会很有帮助。

If you'd like, I could give a quick demo.
如果你们愿意，我可以做个简短演示。
```

注意：表示礼貌请求时，`if you could`、`if you would like` 里**可以**出现 `could / would`，这不违反第 4 节的规则，因为这里的 `could / would` 表示"能力 / 意愿"，不是"将来"。

### 6.3 if I were ⚪

正式英语里，第二条件句的 `be` 对所有人称都用 `were`：

```text
If I were you, I would ask the platform team.
如果我是你，我会去问平台团队。
```

口语里也常听到 `If I was …`。会议中几乎用不到（每万词约 0.1 次），了解即可，可以跳过。

## 7. 第三条件句和混合条件句 ⚪

会议中几乎用不到，了解即可，可以跳过。25 场会议里第三条件句出现了 0 次。

**第三条件句：** 假设过去发生了不同的事。`If + had + 过去分词, would have + 过去分词.`

```text
If we had started earlier, we would have finished on time.
如果我们早点开始，就能按时完成了。（实际上开始得晚，没按时完成）
```

**混合条件句：** 过去的假设，影响现在。

```text
If we had fixed it last week, we wouldn't be blocked now.
如果我们上周就修好了，现在就不会被卡住。
```

会议里谈"过去本该怎样"，更常用 `should have done`（见 [G11 情态动词](11-modal-verbs.zh.md)）：`We should have tested it on iOS.`

## 8. unless、as long as、in case、otherwise 🟢

| 说法 | 意思 | 公式 | 频率 |
| --- | --- | --- | --- |
| `unless` | 除非 = `if … not` | `unless + 一般现在时` | 每万词约 1 次 |
| `as long as` | 只要 | `as long as + 一般现在时` | 约 0.2 次 |
| `in case` | 以防 | `in case + 一般现在时` | 约 0.9 次 |
| `otherwise` | 否则、不然 | `. Otherwise, + 句子` | 约 0.5 次 |

### 8.1 unless：除非

```text
We won't merge it unless QA signs off.
除非 QA 签字确认，否则我们不会合并。（= if QA doesn't sign off）

It's three points, unless we're doing a POC.
是三个点，除非我们是在做 POC。
```

`unless` 本身已经含有"不"，从句里**不要再加 `not`**，也**不要再加 `if`**。

### 8.2 as long as：只要

```text
As long as we have code changes, we need a verification step.
只要有代码改动，我们就需要一个验证步骤。

It's fine as long as the tests pass.
只要测试通过就没问题。
```

### 8.3 in case：以防

```text
Let's keep the old branch in case we need to roll back.
我们保留旧分支，以防需要回滚。

Here is the link, in case anyone asks for it.
这是链接，以防有人要。
```

`in case` 是"**为了预防，现在先做**"；`if` 是"**发生了才做**"。比较：

```text
I'll bring my laptop in case the demo fails.
我会带上电脑，以防演示出问题。（不管出不出问题，先带上）

I'll fix it if the demo fails.
如果演示出了问题，我会修。（出了问题才修）
```

### 8.4 otherwise：否则

```text
We need to fix it today. Otherwise, we need to push the release.
我们今天得修好，否则就要推迟发布。

If we already have an account, I'll reuse it. Otherwise, I'll create a new one.
如果已经有账号，我就复用；否则我就新建一个。
```

`otherwise` 是副词，通常放在新句子开头。口语里也常说 `or else`。

## 9. 真实会议例句（改编）

以下句子来自真实会议字幕，已修正识别错误并做了匿名处理：

```text
If you have any further questions, you can bring them to me.
如果还有其他问题，可以来找我。

Okay, if there are no questions, I will move on to the next session.
好，如果没有问题，我就进入下一个环节。

If the plugin is already available, we can definitely try to migrate it.
如果插件已经有了，我们当然可以试着迁移过来。

If there's no telemetry requirement, we can leave it for now.
如果没有遥测需求，我们可以先放一放。

If you'd like, I could give a brief demo of the variables file in Figma.
如果你们愿意，我可以简单演示一下 Figma 里的变量文件。

So if that's the case, we can have the platform team support that.
那如果是这样，可以让平台团队来支持。

You can read it in your free time and get back to us if you have any questions.
你可以有空的时候看一下，有问题再找我们。
```

## 10. 字幕里怎么认

1. **先判断 `if` 的身份：** 前面是 `check / see / sure / wonder / know` → "是否"；在句首或主句后 → "如果"。
2. **找逗号：** `If …,` 后面才是主句。如果没有逗号，就找第二个"主语 + 动词"。
3. **看到 `would / could` 别慌：** 会议里多半是礼貌说法，不是复杂的虚拟语气。
4. **非母语和语音识别的变体：**

| 字幕里可能听到 | 标准说法 |
| --- | --- |
| `If no, let's move on.` | `If not, let's move on.` |
| `Okay, if you know, that's all for this topic.` | `Okay, if no (questions), that's all for this topic.`（识别错误） |
| `If we will publish it, …` | `If we publish it, …` |
| `Unless if someone finds a problem, …` | `Unless someone finds a problem, …` |
| `If we would like, I could give a demo.` | `If you'd like, I could give a demo.` |
| `just in case if someone asks` | `just in case someone asks` |

## 11. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `If it will fail, we will roll back.` | `If it fails, we will roll back.` | if 从句用现在时表将来 |
| `If no, we can skip it.` | `If not, we can skip it.` | 单独的"如果不是"用 `If not` |
| `We won't merge it unless QA doesn't sign off.` | `We won't merge it unless QA signs off.` | `unless` 已经含有"不" |
| `If we have more time, we would test it.` | `If we had more time, we would test it.` / `If we have more time, we will test it.` | 时态要配套 |
| `If I am you, I will ask Ken.` | `If I were you, I would ask Ken.` | 假设用第二条件句 |
| `Bring the laptop if the demo fails.`（想说"以防"） | `Bring the laptop in case the demo fails.` | 预防用 `in case` |

## 12. 你可以直接用的句子

```text
If you have any questions, please let me know.
如果有任何问题，请告诉我。

If there are no questions, let's move on.
如果没有问题，我们继续。

If that's the case, I'll update the ticket.
如果是这样，我就更新一下工单。

If the fix works, I'll merge it today.
如果修复有效，我今天就合并。

Let me know if you need anything from my side.
如果需要我这边做什么，告诉我。

It would be great if you could review my PR today.
如果你今天能评审一下我的 PR 就太好了。

It's fine as long as the tests pass.
只要测试通过就没问题。

We need to finish it this week. Otherwise, the release will slip.
我们这周必须做完，否则发布会延期。
```

## 13. 练习

**A. 判断 `if` 是"如果"还是"是否"**

1. If you need help, just ping me.
2. Can you check if the job is still running?
3. I'm not sure if Mia is joining today.
4. If the job is still running, let's wait.
5. I wonder if we can reuse the old config.
6. Let's see if anyone can pick it up.

**B. 用括号里的动词填空**

1. If the API ___ (change), we will update the docs.
2. If you ___ (have) any questions, let me know.
3. It would be great if you ___ (can) join the review.
4. If we ___ (have) more time, we would add more tests.（但现实没有时间）
5. We won't release it unless the tests ___ (pass).

**C. 用 unless / as long as / in case / otherwise 填空**

1. Let's save a backup ___ the migration fails.
2. We can merge it ___ the CI is green.
3. Please update the status today. ___, the report will be wrong.
4. We can't start ___ we get the approval.

<details>
<summary>答案</summary>

**A.** 1 如果　2 是否　3 是否　4 如果　5 是否　6 是否

**B.** 1 changes　2 have　3 could　4 had　5 pass

**C.** 1 in case　2 as long as　3 Otherwise　4 unless

</details>

## What This Lesson Solves

Hosts often say something like this:

```text
Ken, can you go ahead? Then let's go through the board and see who can pick up the remaining tasks.
```

You know every word: `go`, `ahead`, `through`, `pick`, `up`. But `go ahead` does not mean "walk forward", and `pick up` does not mean "lift from the floor". A **verb + small word** with a new meaning is a **phrasal verb**. Most everyday meeting actions are phrasal verbs.

**After this lesson, you can:**

1. Explain why phrasal verbs can't be translated word by word, and guess meanings from the small word.
2. Use the 25 most frequent phrasal verbs in meetings.
3. Know which ones can be separated: `set it up` is fine; `work it on` is not.
4. Use 20 verb + noun collocations correctly, such as `make a decision`, `raise a concern`, `leave a comment`, and `create a ticket`.

## 1. What Is a Phrasal Verb?

**Phrasal verb = verb + particle (an adverb or preposition)**, with a meaning of its own.

The particle often carries a sense of direction that helps you guess:

| Particle | Core sense | Examples |
| --- | --- | --- |
| `up` | complete, appear, raise | `set up`, `wrap up`, `bring up`, `pick up`, `follow up` |
| `out` | discover, outward, send out | `figure out`, `reach out`, `roll out`, `point out` |
| `through` | from start to end | `go through` |
| `on` | continue, focus on | `work on`, `move on` |
| `over` | transfer | `hand over` |
| `back` | return | `roll back`, `get back to` |
| `down` | split, go down | `break down` |
| `into` | go inside | `look into` |

> 💡 Phrasal verbs are spoken style; writing often uses one formal verb instead: `figure out` ≈ `determine`, `set up` ≈ `configure`, `look into` ≈ `investigate`. In meetings, phrasal verbs sound more natural.

## 2. 25 High-Frequency Phrasal Verbs in Meetings

Grouped by what you use them for.

### 2.1 Reporting Your Own Work

| Phrase | Meaning | Common pattern |
| --- | --- | --- |
| `work on` | be busy with a task | `work on the login page` |
| `pick up` | take ownership of a task | `pick up a ticket` |
| `set up` | build, configure, arrange | `set up the pipeline / a meeting` |
| `figure out` | understand, find a solution | `figure out why it fails` |
| `look into` | investigate | `look into the issue` |

```text
I'm still working on the login page.

Who can pick up this ticket?

We need to set up the pipeline before we start.

We need to figure out why the build is failing.

I'll look into it after the meeting.
```

> 💡 `set up` (verb, two words) vs `setup` (noun, one word): `set up the environment` / `The setup is done.`

### 2.2 Hosting and Moving the Meeting Forward

| Phrase | Meaning | Common pattern |
| --- | --- | --- |
| `go ahead` | start, continue, do it | `go ahead and merge it` |
| `go through` | review item by item | `go through the board` |
| `move on (to)` / `move to` | go to the next item | `move on to the next topic` |
| `take a look (at)` | have a look | `take a look at the PR` |
| `bring up` | raise a topic or issue | `bring up a concern` |
| `wrap up` | finish, close | `wrap up the meeting` |

```text
Mia, you can go ahead.

I will go through the status one by one.

Okay, let's move on to the native part.

Can you take a look at my PR when you have time?

Is there anything you want to bring up today?

Let's wrap up here. Thanks, everyone.
```

### 2.3 Communication and Collaboration

| Phrase | Meaning | Common pattern |
| --- | --- | --- |
| `follow up (on / with)` | check progress later | `follow up with the design team` |
| `check with` | confirm with someone | `check with Priya` |
| `reach out (to)` | contact | `reach out to the admin team` |
| `sync up` | update each other | `sync up tomorrow` |
| `align with` | agree on the same approach | `align with the backend team` |
| `catch up` | get up to date, have a short chat | `catch up after the meeting` |
| `hand over (to)` | pass to someone | `hand it over to Ken` |

```text
I'll follow up with the design team.

Let me check with Priya and get back to you.

Feel free to reach out to me if you have questions.

Let's sync up tomorrow morning.

We need to align with the backend team on the API format.

Let's catch up after the meeting.

I'll hand it over to Ken for the platform update.
```

### 2.4 Releases and Problem Solving

| Phrase | Meaning | Common pattern |
| --- | --- | --- |
| `roll out` | release (often gradually) | `roll out the new version` |
| `roll back` | revert a release | `roll back the release` |
| `break down (into)` | split into parts | `break down the epic into stories` |
| `come up with` | think of (a plan) | `come up with a better solution` |
| `point out` | mention, highlight | `as Anna pointed out` |

```text
We will roll out the new version to 10% of users first.

We had to roll back the release last night.

Let's break down the epic into smaller stories.

We need to come up with a better solution.

As Anna pointed out, the API is not backward compatible.
```

### 2.5 Two Fixed Expressions: make sure, keep in mind

Strictly speaking these are not phrasal verbs, but learn them as chunks too:

```text
Please make sure the tests pass before merging.

Please keep in mind that the code freeze starts on Friday.
```

For the grammar of `make sure`, see [G13](13-to-do-doing-done.md). Two more very common chunks: `double-check` (39 times) and `get back to someone` (reply later).

## 3. Separable or Not: Where Does the Object Go?

This is where most phrasal verb mistakes happen.

### 3.1 Separable: a Pronoun Must Go in the Middle

In `set up`, `pick up`, `figure out`, `bring up`, `hand over`, `roll out`, `roll back`, `break down`, `point out`, and `wrap up`, the particle is an adverb, so **the verb can be split**:

- With a noun object, either position works: `set up the pipeline` = `set the pipeline up`.
- With a pronoun object (`it`, `them`, `this`), it **must go in the middle**.

```text
I'll set it up tomorrow.

Can you pick it up this sprint?

Thanks for bringing it up.

Let's break it down into smaller tasks.
```

❌ `set up it`, `pick up it`, `bring up it`

### 3.2 Inseparable: the Object Always Comes After

In `work on`, `look into`, `go through`, `check with`, `look at`, `align with`, and `wait for`, the particle is a preposition, so **the verb cannot be split**:

```text
I'm working on it.

I'll look into it.

Let's go through them one by one.
```

❌ `work it on`, `look it into`

### 3.3 Three-Word Phrasal Verbs: Never Split

`come up with`, `catch up on`, `follow up on / with`, `reach out to`, `get back to`, `look forward to`: the object always goes at the end.

```text
I'll get back to you by tomorrow.
```

### 3.4 No Object

`go ahead`, `move on`, `catch up`, and `sync up` usually take no object. To add one, use a preposition: `move on to the next item`, `sync up with the QA team`.

## 4. Noun Forms: One Word or Hyphenated

Many phrasal verbs have noun forms. **The verb is two words; the noun is one word or hyphenated.**

| Verb | Noun | Example |
| --- | --- | --- |
| `set up` | `setup` | `The setup is done.` |
| `follow up` | `follow-up` | `Let's schedule a follow-up meeting.` |
| `roll out` | `rollout` | `The rollout will take two weeks.` |
| `roll back` | `rollback` | `The rollback took ten minutes.` |
| `break down` | `breakdown` | `Here is the task breakdown.` |
| `hand over` | `handover` | `We had a handover session.` |
| `sync up` | `sync-up` | `We have a daily sync-up.` |
| `work around` | `workaround` | `Is there a workaround?` |

## 5. Verb + Noun Collocations

Chinese says "do a decision"; English says `make a decision`. **The verb before a noun is fixed by usage**, so learn the pair together.

| Verb | Common collocations |
| --- | --- |
| `make` | `make a decision`, `make a change`, `make progress`, `make a suggestion`, `make a mistake` |
| `do` | `do a demo`, `do some research`, `do the estimation`, `do a code review` |
| `take` | `take a look`, `take notes`, `take ownership`, `take this offline` |
| `give` | `give an update`, `give a demo`, `give feedback`, `give an estimate` |
| `raise` | `raise a concern`, `raise a question`, `raise a PR`, `raise your hand` |
| `leave` | `leave a comment`, `leave a message` |
| `create` / `open` / `file` | `create a ticket`, `open a PR`, `file a bug` |
| `have` | `have a meeting`, `have a discussion`, `have a question` |
| `share` | `share my screen`, `share an update`, `share the link` |
| `run` | `run the tests`, `run the pipeline` |
| `fix` / `resolve` | `fix a bug`, `resolve an issue`, `resolve comments` |
| `meet` | `meet the deadline`, `meet the requirements` |
| `hit` | `hit an issue`, `hit a blocker` |
| `keep` | `keep an eye on`, `keep you posted` |
| `reach` | `reach an agreement` |

```text
We need to make a decision by Friday.

I'd like to raise a concern about the timeline.

I left a comment on the PR.

Can you create a ticket for this?

Let's take this offline.

We hit a blocker on the macOS build.

I'll keep you posted.

We need to keep an eye on the error rate.
```

## 7. Reading Phrasal Verbs in Subtitles

1. **If a word-by-word reading makes no sense, suspect a phrasal verb.** Treat verb + particle as one word.
2. **Watch for split phrasal verbs.** In `set it up` and `pick them up`, the particle has moved to the end.
3. **Watch for noun forms.** `the setup`, `a follow-up`, `the rollout` are nouns, not the main verb.
4. **Recognize, but do not copy, non-native forms:**

| Heard in subtitles | Standard form |
| --- | --- |
| `take a look on the page` | `take a look at the page` |
| `we have to pick up it` | `we have to pick it up` |
| `we need to keep eye on that` | `we need to keep an eye on that` |
| `sync hub` / `sink up` | `sync up` (recognition error) |
| `we will follow up the SSR` | `we will follow up on the SSR work` |
| `it can be break down to stories` | `it can be broken down into stories` |
| `you can bring up to me` | `you can bring it up with me` |
| `discuss with Ken about it` | `discuss it with Ken` |

## 8. Common Mistakes

| ❌ Wrong | ✅ Right | Reason |
| --- | --- | --- |
| `Can you take a look on my PR?` | `Can you take a look at my PR?` | `take a look at` |
| `I'll set up it tomorrow.` | `I'll set it up tomorrow.` | pronoun in the middle |
| `I'm working it on.` | `I'm working on it.` | `work on` is inseparable |
| `We need to do a decision.` | `We need to make a decision.` | `make a decision` |
| `I'll reach out the admin team.` | `I'll reach out to the admin team.` | `reach out to` + person |
| `The set up is done.` | `The setup is done.` | the noun is one word |
| `We need to rollback the release.` | `We need to roll back the release.` | the verb is two words |
| `I want to raise a question to Ken.` | `I want to ask Ken a question.` | `ask someone a question` is more natural |

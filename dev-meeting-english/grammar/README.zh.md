# 语法目录：小学到高中，按会议使用频率排序

> [English version](README.md) · [返回课程首页](../README.zh.md) · [学习计划](../00-study-plan.zh.md) · [怎么读会议字幕](../01-how-to-read-subtitles.zh.md)

这里把以前四套语法教材的内容按知识点合并成 24 课，**每个知识点只讲一次**。每课都按同一个顺序写：解决什么问题 → 讲解与公式 → 真实会议例句 → 字幕里怎么认 → 常见错误 → 可以直接用的句子 → 练习与答案。

## 频率标记

数据来自 25 场真实会议字幕（约 8 万词），按"每万词出现次数"统计。

| 标记 | 含义 | 怎么学 |
| --- | --- | --- |
| 🔴 必学 | 会议高频，或者造句的基础 | 读懂、做练习、能自己说出来 |
| 🟡 常用 | 会议中经常出现 | 读懂，会用最常见的几个说法 |
| 🟢 认得即可 | 偶尔出现 | 字幕里看到能懂就行 |
| ⚪ 用不到 | 几乎不出现 | 可以跳过 |

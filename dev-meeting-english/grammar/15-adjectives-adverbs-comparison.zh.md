## 这一课解决什么问题

讨论技术方案时，大家一直在比较：哪个更稳定、哪个更容易、哪个最合适。

```text
I think the self-hosted runner is a bit more stable, and it's easier for us to maintain.
我觉得自托管的执行机稍微稳定一些，而且对我们来说更容易维护。
```

这句里有程度词 `a bit`、比较级 `more stable` 和 `easier`。用好这些小词，你的观点会更准确，也更委婉。

**学完这一课，你应该能：**

1. 知道形容词和副词分别修饰什么、放在哪里。
2. 用 `-ly` 副词、频率副词和程度词说清楚"怎么样""多常""多大程度"。
3. 用比较级、最高级、`as … as`、`the same as` 比较方案。

## 1. 形容词和副词：修饰的对象不同

- **形容词**修饰名词，说"什么样的东西"：`a stable version`。
- **副词**修饰动词、形容词或整个句子，说"怎么做""多么"：`It runs smoothly.`、`really slow`。

**公式：**

- `形容词 + 名词`：`a quick question`
- `be / look / sound / seem / get + 形容词`：`It looks good.`
- `动词（+ 宾语）+ 副词`：`It works properly.`

```text
That sounds good.
听起来不错。

The demo went well.
演示很顺利。

It's getting slower after the update.
更新之后越来越慢了。
```

> ⚠️ `look`、`sound`、`seem` 后面用形容词：`It looks good.`。`good` 是形容词，`well` 是副词：`It works well.`

## 2. 形容词放在哪里

| 位置 | 例子 |
| --- | --- |
| 名词前 | `a small change`、`the new login page` |
| `be` 等系动词后 | `The build is green.` |
| `something / anything / nothing` 后 | `anything else`、`something important`、`nothing new` |

**多个形容词**一起修饰名词时，大致顺序是：观点 → 大小 → 新旧 → 颜色 → 类别（名词作定语）+ 名词。会议里一般不超过两个：`a nice small fix`、`a big new feature`、`the old blue button`。

**名词作定语**在技术英语里非常多，前面的名词不加 `-s`：`the login page`、`the release date`、`the test environment`。

**连字符复合形容词**也很常见，里面的名词同样不加 `-s`：

```text
We have a two-week sprint.
我们的 Sprint 是两周。

This is only a short-term solution.
这只是一个短期方案。

Let me give you a high-level overview.
我先给大家做个整体介绍。
```

❌ `a two-weeks sprint` ✅ `a two-week sprint`

## 3. 副词：-ly 和位置

### 3.1 -ly 副词怎么来

多数副词是"形容词 + `-ly`"：`quick → quickly`、`proper → properly`、`direct → directly`、`current → currently`、`easy → easily`。

几个特殊的要记住：

| 形容词 | 副词 | 注意 |
| --- | --- | --- |
| `good` | `well` | `It works well.` |
| `fast` | `fast` | 没有 `fastly` |
| `hard` | `hard` | `hardly` 是"几乎不" |
| `late` | `late` | `lately` 是"最近" |

### 3.2 副词放在哪里

| 位置 | 作用 | 例子 |
| --- | --- | --- |
| 句首 | 评论整句 | `Currently, …`、`Actually, …`、`Hopefully, …` |
| 中间（`be` 后、实义动词前） | 补充语气 | `We probably need …`、`It's probably fine.` |
| 句末 | 说明方式 | `It works properly.`、`Let's go through this quickly.` |

```text
Currently, we are in the third week of the sprint.
目前我们在 Sprint 的第三周。

We probably need one more day.
我们可能还需要一天。

We need to make sure the pipeline is set up properly.
我们需要确保流水线配置正确。
```

> ⚠️ 副词不要插在动词和宾语中间：❌ `I checked carefully the logs.` ✅ `I checked the logs carefully.`

## 4. 频率副词：多常

| 频率 | 副词 |
| --- | --- |
| 100% | `always` |
| 约 80% | `usually` |
| 约 60% | `often` |
| 约 40% | `sometimes` |
| 约 10% | `rarely` |
| 0% | `never` |

**位置：** `be` 动词和情态动词之后，实义动词之前。

```text
It usually takes two or three sprints to finish a feature.
一个 Feature 通常要两三个 Sprint 才能完成。

The build sometimes fails on Safari.
构建在 Safari 上有时会失败。

We never deploy on Fridays.
我们从不在周五部署。

The native approach is always preferred if it's available.
如果有原生方案，总是优先用原生方案。
```

`every day`、`once a week`、`every sprint` 这种短语放在句末：`We sync up twice a week.`

## 5. 程度词：多大程度

| 强弱 | 程度词 | 例子 |
| --- | --- | --- |
| 弱 | `a bit`、`a little (bit)`、`slightly` | `a bit tricky` |
| 中 | `quite`、`pretty`、`fairly` | `pretty simple` |
| 强 | `very`、`really`、`so` | `really helpful` |
| 过头 | `too` | `too slow` |

几个要特别注意的：

- **`pretty` = 相当、挺**（口语），不是"漂亮"。`pretty much` = "差不多"：`That's pretty much it from my side.`
- **`quite`**：`quite simple` = 挺简单；`not quite sure` = 不太确定。
- **`a bit / a little bit`** 常用来委婉地说坏消息：`It's a bit slow.` 比 `It's slow.` 客气。
- **`too` 是"过于"，带负面意思**：`It's too slow.`（慢得不能接受）。夸奖要说 `really good`，不要说 `too good`。
- **`enough`** 放在形容词后面：`good enough`、`fast enough`。

```text
It's quite simple.
这个挺简单的。

Management is a little bit tricky.
管理起来有点麻烦。

That's pretty much it from my side.
我这边差不多就这些。

The test environment is too slow for load testing.
测试环境太慢了，没法做压测。
```

## 6. 比较级与最高级

### 6.1 怎么变

| 类型 | 比较级 | 最高级 |
| --- | --- | --- |
| 单音节：加 `-er / -est` | `fast → faster` | `the fastest` |
| 辅音 + `y`：变 `-ier / -iest` | `easy → easier`、`early → earlier` | `the easiest` |
| 多音节：加 `more / most` | `stable → more stable` | `the most stable` |
| 不规则 | `good → better`、`bad → worse`、`far → further` | `the best`、`the worst` |
| 少 | `less risky` | `the least risky` |

### 6.2 比较级：A 比 B 更……

**公式：** `A + be + 比较级 + than B`；只比较对谁更好时：`比较级 + for + 人`

```text
The new version is much faster than the old one.
新版本比旧版本快得多。

I think it's easier for us to use GitHub Actions.
我觉得用 GitHub Actions 对我们来说更容易。

It's a bit more stable now.
现在稍微稳定一些了。

Option B is less risky.
方案 B 风险更小。
```

修饰比较级要用 `much`、`a bit`、`a little`、`even`，**不能用 `very`**：❌ `very faster` ✅ `much faster`。

### 6.3 最高级：最……

```text
I think AWS would be the best option for us.
我觉得 AWS 对我们来说是最好的选择。

Is this the latest version?
这是最新版本吗？

This is one of the most common issues.
这是最常见的问题之一。
```

> ⚠️ `most of the …` 是"大部分"，不是最高级：`Most of the stories are done.`（大部分 Story 完成了）。不要加 `the`：❌ `the most of the tasks`。

### 6.4 as … as、the same as、different from

```text
Please fix it as soon as possible.
请尽快修复。

The new API is not as fast as we expected.
新 API 没有我们预期的那么快。

The Android setup is the same as the iOS one.
Android 的配置和 iOS 的一样。

The staging config is different from production.
预发环境的配置和生产环境不一样。
```

`the same` 前面一定有 `the`，后面用 `as`：`the same as before`。

## 7. 真实会议例句（改编）

以下句子来自真实会议字幕，修正了识别错误：

```text
It's quite simple. I'm just not quite sure about the timeline.
这个挺简单的，我只是不太确定时间安排。

I think it's better for us to have our own cloud for these runners.
我觉得对我们来说，最好有自己的云来跑这些执行机。

Sometimes even a bug fix can be a breaking change.
有时候即使是 Bug 修复，也可能是破坏性变更。

The task will be the smallest work item we have.
Task 会是我们最小的工作单元。

Most team members gave it a five, so let's go with five.
大部分组员都给了 5 分，那就定 5 分吧。

If this is the latest version, we can go with that.
如果这是最新版本，我们就用它。

I'll show you what we have really quickly.
我很快给大家看一下我们现在的进展。
```

## 8. 字幕里怎么认

1. **比较信号词：** `-er`、`more`、`less`、`than`、`as … as`、`the same`。看到它们，先找"谁和谁比"。
2. **`most of` 是"大部分"**，`the most + 形容词` 才是"最"。
3. **`pretty` 和 `quite` 多数是程度词**，不是"漂亮"和"完全"。
4. **非母语说法能看懂就行，不要模仿：**

| 字幕里可能听到 | 标准说法 |
| --- | --- |
| `more easier` | `easier` |
| `very less effort` | `much less effort` |
| `more better` | `better` |
| `the most of the tasks` | `most of the tasks` |
| `same with the old one` | `the same as the old one` |
| `there's no much updates` | `there aren't many updates` |
| `show you really quick` | `show you really quickly`（口语里 `quick` 作副词也常见） |

## 9. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `It looks well.`（想说"看起来不错"） | `It looks good.` | `look` 后接形容词 |
| `This way is more easier.` | `This way is easier.` | 不能双重比较 |
| `It's the most fast option.` | `It's the fastest option.` | 单音节用 `-est` |
| `It's very faster now.` | `It's much faster now.` | 比较级前用 `much` |
| `I checked carefully the logs.` | `I checked the logs carefully.` | 副词不插在动词和宾语中间 |
| `a two-weeks sprint` | `a two-week sprint` | 复合形容词里不加 `-s` |
| `I always am online.` | `I'm always online.` | 频率副词放在 `be` 后 |
| `It's same as before.` | `It's the same as before.` | `the same` |
| `The demo was too good!` | `The demo was really good!` | `too` 是"过于" |

## 10. 你可以直接用的句子

```text
That sounds good to me.
我觉得可以。

It's a bit tricky, but it's doable.
有点麻烦，但能做。

I think option A is easier for us.
我觉得方案 A 对我们来说更容易。

The new version is much more stable.
新版本稳定多了。

It usually takes about two days.
通常需要两天左右。

That's pretty much it from my side.
我这边差不多就这些。

I'll fix it as soon as possible.
我会尽快修好。
```

## 11. 练习

**A. 选择正确的形式**

1. The demo went (good / well).
2. That sounds (great / greatly).
3. It's (much / very) faster than before.
4. This is the (most easy / easiest) way.
5. The config is the same (as / with) production.
6. (Most of / The most of) the tasks are done.

**B. 把副词放到正确位置**

1. The build fails on Safari. (sometimes)
2. We are available in the morning. (usually)
3. I checked the logs. (carefully)

**C. 改错**

1. Option B is more cheaper.
2. We have a three-days workshop.
3. I'm not quite sure, but I think it's too good.

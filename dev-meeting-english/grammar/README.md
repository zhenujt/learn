# Grammar Index: Primary to Senior High School, Ordered by Meeting Frequency

> [中文版](README.zh.md) · [Course home](../README.md) · [Study Plan](../00-study-plan.md) · [How to Read Meeting Subtitles](../01-how-to-read-subtitles.md)

Four older grammar courses are merged here into 24 lessons, and **each grammar point is taught once**. Every lesson follows the same order: the problem it solves → explanation and patterns → real meeting examples → how to spot it in subtitles → common mistakes → ready-to-use sentences → practice with answers.

## Frequency Tags

Data: subtitles of 25 real meetings (about 80,000 words), counted per 10,000 words.

| Tag | Meaning | How to study |
| --- | --- | --- |
| 🔴 Must learn | Very frequent, or basic to any sentence | Understand, practice, produce |
| 🟡 Common | Appears regularly | Understand; use the most common forms |
| 🟢 Recognize only | Appears occasionally | Understand it in subtitles |
| ⚪ Not needed | Almost never appears | Skip |

# G09 Talking About the Future: will, be going to, and the Present Continuous

## What This Lesson Solves

The last part of a stand-up is usually "what I'll do next", and the end of a meeting is about taking action items. Listen to these:

```text
I'll take a look after the meeting.

We're going to release it next week.

I'm planning to finish the tests by Friday.

Once the PR is merged, I'll deploy it to staging.
```

Chinese can use one word (`会`, `要`, or `打算`) for all of these. English has several forms. The good news: **`will` dominates in meetings** (about 98 per 10,000 words — ten times more than `going to`). Master `will` first, then learn the small differences.

**After this lesson, you can:**

1. Use `will / 'll` to take tasks, make promises, predict, and describe processes.
2. Use `be going to` for decided plans, and recognize `gonna`, `wanna`, and `gotta` in subtitles.
3. Talk about plans with `I'm planning to`, `I'm about to`, `It should be …`, the present continuous, and the present simple.
4. Use the present tense after `once / when / if / after` for future meaning.

## 1. The Big Picture: English Has No Single "Future Tense"

| Form | Core meaning | Meeting frequency | Example |
| --- | --- | --- | --- |
| `will + base verb` | instant decision, promise, prediction, process | 🔴 | `I'll check it.` |
| `be going to + base verb` | decided plan, prediction with evidence | 🟡 | `We're going to migrate it.` |
| `be planning to / plan to` | a plan still being shaped | 🟢 | `I'm planning to refactor it.` |
| `be + -ing` (present continuous) | arranged appointment | 🟢 | `I'm meeting Ken tomorrow.` |
| present simple | timetable, schedule | 🟡 | `The sprint starts on Monday.` |
| `will be + -ing` | in progress at a future time | 🟢 | `I'll be working on it next week.` |
| `be about to` | very soon | 🟢 | `I'm about to push it.` |

## 2. will: The Main Future Form in Meetings

### 2.1 Pattern

| Sentence | Example |
| --- | --- |
| Positive | `I will check it.` = `I'll check it.` |
| Negative | `I will not merge it.` = `I won't merge it.` |
| Question | `Will you join the demo?` |

`will` is **always followed by the base verb**: no `to`, no `-s`, no `-ed`. `won't` rhymes with "don't". Do not confuse it with `want`.

### 2.2 Use 1: Instant Decisions and Taking Tasks ⭐ Most Common

When someone raises an issue and you decide on the spot to handle it, use `will`:

```text
I'll take a look.

I'll create a ticket to track this.

I'll follow up with the design team.

Okay, I'll share it in the channel after the meeting.
```

### 2.3 Use 2: Promises

```text
I'll send you the document by end of day.

We won't merge it before QA signs off.

Don't worry, I'll fix it today.
```

### 2.4 Use 3: Predictions and Judgments

Often with `I think`, `probably`, or `maybe`:

```text
I think it will take about two days.

It probably won't affect the native part.

This will be a breaking change.
```

### 2.5 Use 4: Describing Processes (Hosts Love This)

When a host explains how the team will work, almost every sentence uses `will`:

```text
In the grooming session, we will review all the requirements.

After that, QA will test the story.

By the end of the sprint, we will demo the completed work.
```

### 2.6 A Special Meaning of won't: It Refuses To

With things, `won't` means "it just doesn't work, no matter what". Very useful for describing bugs:

```text
The app won't start.

The page won't load on Safari.
```

### 2.7 Chinese `会` Is Not Always will

The Chinese word `会` has several meanings. Use `will` only for the future:

| Meaning of `会` | ✅ English | ❌ Avoid |
| --- | --- | --- |
| ability | `I can speak English.` | `I will speak English.` |
| habit | `He runs the tests every day.` | `He will run the tests every day.` |
| future | `I'll raise a PR tomorrow.` | — |

## 3. be going to / gonna 🟡

### 3.1 Pattern

**Pattern:** `am / is / are + going to + base verb`

```text
We're going to migrate the pipeline next sprint.

Are we going to support SSR?

I'm not going to change the API.
```

### 3.2 Use 1: Plans Already Decided

The decision was made before you spoke:

```text
I'm going to work with the design team on the roadmap.

We're going to use a different font family.
```

### 3.3 Use 2: Predictions With Evidence

You can see the signs now:

```text
Look at this graph. We're going to run out of quota this week.

This change is going to break the old API.
```

### 3.4 Use 3: Announcing the Next Step in a Demo

```text
I'm going to share my screen.

Now I'm going to show you the new tokens.
```

### 3.5 gonna, wanna, gotta: Recognizing Them in Subtitles 🟢

In fast speech, `going to` becomes `gonna`. Subtitles sometimes write what they hear:

| In subtitles | Full form | Meaning | Example |
| --- | --- | --- | --- |
| `gonna` | `going to` | will | `I'm gonna share my screen.` |
| `wanna` | `want to` | want to | `I wanna add one thing.` |
| `gotta` | `have got to` = `have to` | must | `We gotta fix this first.` |
| `lemme` | `let me` | let me | `Lemme check.` |
| `dunno` | `don't know` | don't know | `I dunno.` |
| `kinda` | `kind of` | somewhat | `It's kinda slow.` |

```text
Okay, I'm gonna share my screen.

I wanna add one thing about the timeline.

We gotta fix this before the release.
```

Notes:

- `gonna` replaces only the **future** `going to`. In `I'm going to the office.`, `going to` means movement and cannot become `gonna`.
- Subtitles showing `we gonna have …` are missing `are`. The standard form is `we're going to have …`.
- You can say `gonna` and `wanna` in a meeting. In Jira, email, and documents, write the full forms.

## 4. Choosing Between will and be going to

| Situation | Use | Example |
| --- | --- | --- |
| decided **right now** | `will` | `— The build failed. — Oh, I'll check it.` |
| decided **before** | `be going to` | `I'm going to check the logs after the meeting.` |
| promise | `will` | `I'll send it by Friday.` |
| prediction with evidence | `be going to` | `It's going to fail again.` |
| general opinion | either | `I think it'll / it's going to take two days.` |
| processes, formal documents | `will` | `QA will test the story.` |

```text
The build failed. I'll check it.

I'm going to check the logs after the meeting.
```

The first is an instant decision; the second was planned before the meeting.

**Practical advice:** the difference is small, and native speakers mix them. When in doubt, use `will`. It is never badly wrong.

## 5. Other Ways to Talk About Plans

### 5.1 Ordered by Certainty

| Form | Certainty | Example |
| --- | --- | --- |
| `will` / `be going to` | very sure | `I'll finish it today.` |
| `I'm planning to` / `We plan to` | planned | `I'm planning to finish it today.` |
| `I'm hoping to` / `We expect to` | hoped / expected | `We're hoping to finish it today.` |
| `It should be …` | likely, with some room | `It should be done today.` |
| `It might …` / `maybe` | uncertain | `It might slip to tomorrow.` |

```text
We plan to submit the PR for review tomorrow.

I'm hoping to get the access by Wednesday.

It should hopefully be finished today.

It might slip to next sprint.
```

For more on `should` and `might`, see [G11 Modal Verbs](11-modal-verbs.md).

### 5.2 be about to: Very Soon 🟢

```text
I'm about to push the fix.

We were about to discuss it in the daily sync.
```

### 5.3 be supposed to: The Original Plan 🟢

It describes what was arranged, often hinting that it may not happen as planned:

```text
It's supposed to be released on Friday.

Wasn't QA supposed to test it yesterday?
```

## 6. Present Continuous for the Future: Arrangements 🟢

For things **already arranged** between people, use the present continuous with a future time word:

```text
I'm meeting the design team tomorrow.

Ken is joining us next week.

We're releasing on Friday.
```

## 7. Present Simple for the Future: Timetables 🟡

For schedules, release calendars, and meeting times that **follow a timetable**, use the present simple:

```text
The sprint starts on Monday.

The meeting is at 3 PM.

The code freeze begins next Wednesday.
```

## 8. will be + -ing: In Progress at a Future Time 🟢

It means "I'll be in the middle of doing …". It is also a **neutral, polite** way to talk about arrangements:

```text
I'll be working on the migration next week.

We'll be assigning epics based on the roadmap.

Will you be joining the demo?
```

`Will you be joining …?` is softer than `Will you join …?`. It only asks about plans; it does not sound like a request.

## 9. Present Tense After once / when / if 🔴

**Rule:** in clauses with `if`, `when`, `once`, `after`, `before`, `until`, and `as soon as`, **use the present tense for future events**. Only the main clause uses `will`.

**Pattern:** `Once / When / If + present tense, subject + will + base verb.`

```text
Once the PR is merged, I'll deploy it to staging.

When I get more information, I'll share it in the channel.

If the tests pass, we'll release it tomorrow.

I'll ping you as soon as I finish the fix.

Once I've finished the tests, I'll update the ticket.
```

The last example shows that the clause can also use the present perfect.

❌ `When I will finish it, I will tell you.`
✅ `When I finish it, I'll tell you.`

## 10. Real Meeting Examples (Adapted)

These sentences come from real meeting subtitles. Recognition errors are fixed and names are anonymized.

```text
I'll create a backlog item to track this.

I think we should be fine, but I'll double-check.

Once Mia is back, I'll check with her as well.

Once the planning session is finished, we'll share the final sprint scope with you.

I'm going to double-check with Mia whether we already have a direction for that, and I'll get back to you.

We're going to publish each platform to a different package.

Are we going to do regression testing on the website as well?

Okay, I'm gonna share my screen.

I know I've been saying that for a while, but it should be finished today.

Ken plans to submit a PR for review tomorrow.
```

Non-native original vs standard form:

| Subtitle original | Standard form |
| --- | --- |
| `So once the planning session finished, we will provide …` | `Once the planning session is finished, we will provide …` |
| `how this report will going to be used` | `how this report will be used` / `is going to be used` |
| `we gonna have another round of review` | `we're going to have another round of review` |
| `and we will plan to implement them` | `and we plan to implement them` / `and we will implement them` |
| `I'll thinking that five is okay.` | `I'm thinking that five is okay.` / `I think five is okay.` |
| `when he back office tomorrow` | `when he's back in the office tomorrow` |

## 11. Reading the Future in Subtitles

1. **`'ll` is easily lost.** A subtitle such as `I check it after the meeting` is probably `I'll check it …`. Words like `tomorrow`, `after the meeting`, and `next week` signal the future.
2. **`going to` + base verb → future; `going to` + place → movement.** `going to test` vs `going to the office`.
3. **`gonna` = `going to` (future)**, `wanna` = `want to`, `gotta` = `have to`.
4. **For sentences starting with `once` / `when`**, find the `will` after the comma. That is the action; the `once` part is the condition.
5. **In progress reports, `should` usually means "expected"**: `It should be done today.`

## 12. Common Mistakes

| ❌ Wrong | ✅ Right | Reason |
| --- | --- | --- |
| `I will to check it.` | `I will check it.` | no `to` after `will` |
| `He will checks it.` | `He will check it.` | base verb after `will` |
| `I will going to fix it.` | `I'm going to fix it.` / `I'll fix it.` | do not stack the two forms |
| `I going to fix it.` | `I'm going to fix it.` | missing `am` |
| `I'm going to checking it.` | `I'm going to check it.` | base verb after `going to` |
| `When I will finish, I'll tell you.` | `When I finish, I'll tell you.` | present tense in time clauses |
| `If it will fail, …` | `If it fails, …` | present tense in if-clauses |
| `I will be finish it today.` | `I will finish it today.` | extra `be` |
| `He will run the tests every day.` (habit) | `He runs the tests every day.` | habits → present simple |
| `I will speak English.` (ability) | `I can speak English.` | ability → `can` |

## 14. Practice

**A. Choose will or be going to**

1. — The build failed again. — Oh, I (will / am going to) check it now.
2. We've already decided: we (will / are going to) migrate to Harness next sprint.
3. Look at the error rate. The service (will / is going to) go down.
4. Don't worry, I (will / am going to) send it by end of day.

**B. Fill in the verbs (remember the time-clause rule)**

1. Once the PR ___ (be) merged, I ___ (deploy) it.
2. If the tests ___ (pass), we ___ (release) it tomorrow.
3. I ___ (ping) you when I ___ (finish) the fix.
4. The sprint ___ (start) on Monday. (timetable)

**C. Rewrite the subtitles in standard English**

1. we gonna have another review next week
2. I will to update the ticket
3. when he will be back I will ask him
4. I'm going to checking the logs

**D. Order from most to least certain**

It might be done today. / I'll finish it today. / It should be done today. / I'm hoping to finish it today.

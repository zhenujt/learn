## What This Lesson Solves

In meeting subtitles, small words such as `for`, `on`, and `to` often cause more trouble than new vocabulary. You know every word, but the sentence still feels unclear.

The most common example in real meetings:

```text
For the native part, most tasks are already done.
```

Here `for` does not mean "in order to" or "because". It introduces a **topic**: "as for the native part". Older lessons missed this use, but it is the most frequent one in meetings.

**After this lesson, you can:**

1. Recognize the seven meeting uses of `for`.
2. Explain the core relationship of `to`, `of`, `in`, `on`, `with`, `from`, `by`, `at`, and `about`.
3. Use about 30 high-frequency prepositional phrases such as `on track`, `in progress`, and `from my side`.
4. Recognize common non-native preposition errors in subtitles without copying them.

## 1. The Right Way to Think About Prepositions

**A preposition shows a relationship between two things.** It is followed by a noun, a pronoun, or an `-ing` form:

```text
for the web part
for us
for testing
```

Two rules:

- **Do not memorize one fixed translation.** Decide the relationship first.
- **Never put a base verb after a preposition.** Say `thanks for sharing`, not `thanks for share`.

## 2. for: The Most Important Preposition in Meetings

Uses of `for` in 25 real meetings (about 80,000 words), from most to least frequent:

| Rank | Use | Meaning | Typical phrase |
| --- | --- | --- | --- |
| 1 | Topic marker | as for, regarding | `For the web part, …` |
| 2 | Person affected | for someone, from someone's view | `Does that work for you?` |
| 3 | Purpose | used for, intended for | `ready for QA testing` |
| 4 | Scope / closing | limited to this part | `That's all for today.` |
| 5 | Reason | the reason for thanks or apology | `Thanks for sharing.` |
| 6 | Duration | how long, for the time being | `for two days`, `for now` |
| 7 | Example | for instance | `for example` |

Fixed collocations such as `wait for` and `responsible for` are covered in 2.8.

### 2.1 For X, …: Introducing a Topic ⭐ Most Frequent

**Pattern:** `For + topic, main clause.` or `And for + topic?`

```text
For the web part, most stories are completed.

For the native part, we have finished the interface integration.

For the backward compatibility, the document is ready for review.

And for the platform part?

So for this sprint, we will focus on the CI pipeline.
```

**How to recognize it:** `for` starts the sentence (or follows `and`, `so`, `okay`), a module, team, task, or time period follows, then a comma and the main clause.

**How to read it:** treat it as a **topic label**. It tells you which part comes next.

Similar expressions:

```text
As for the design side, we are still waiting for the final tokens.

Regarding the release date, we need to confirm it with the PM.

In terms of performance, the new version is much faster.
```

> ⚠️ Subtitles often show `regarding to the …`. The standard forms are `regarding the …` and `with regard to the …`.

### 2.2 for + Person: For Whom, From Whose View

```text
I think that will be easier for us.

Does that time work for you?

These docs are just references for the team.

Can you create a ticket for me?

Is this version suitable for them?
```

`for me` vs `to me`:

```text
It's important for me to finish it today.

It makes sense to me.

Send the link to me.
```

`for` marks the person affected. `to` marks a point of view or a direction.

### 2.3 for + Purpose: Used For, Intended For

```text
This page is for internal use only.

The flag is used for testing new features.

The story is ready for QA testing.

We need a runner for the macOS build.

I submitted a request for approval.
```

Purpose with `for` + noun vs `to` + verb:

```text
We use this channel for release updates.

We use this channel to share release updates.
```

❌ `for share updates` ✅ `for sharing updates` / `to share updates`

### 2.4 That's all for …: Scope and Closing

```text
That's all for today.

That's all for my part.

That's it for me.

So that's all for the web part. Let's move to the native part.
```

### 2.5 for + Reason: Thanks and Apologies

```text
Thanks for sharing.

Thank you for your time.

Thanks for the demo.

Sorry for the delay.

Sorry for being late.
```

### 2.6 for + Time: Duration and "for now"

```text
He will be out of office for two days.

I have been saying that for a while.

We can leave it for now.

Let's keep the current version for now.

We will work on it for this sprint.
```

`for` (a period) vs `since` (a starting point):

```text
I have worked here for three years.

I have worked here since 2023.
```

### 2.7 for example

```text
For example, we need some clarification on their ticket.

Some teams, for example the designers, need access too.
```

### 2.8 Fixed Collocations: Word + for

| Collocation | Example |
| --- | --- |
| `wait for` | `We are waiting for the design review.` |
| `look for` | `I'm looking for the latest build.` |
| `ask for` | `Let's ask for their feedback.` |
| `apply for` | `We need to apply for a new subscription.` |
| `vote for` | `Please vote for the ticket.` |
| `be responsible for` | `Mia is responsible for the release.` |
| `be ready for` | `It's ready for review.` |
| `be used for` | `This script is used for migration.` |
| `account for` | `Web issues account for most of the bugs.` |
| `a request for` | `a request for access` |
| `support for` | `support for Node 20` |

### 2.9 Three Steps to Decide the Meaning of for

1. **Position:** sentence-initial and followed by a comma → topic marker.
2. **The word before it:** `thanks/sorry` → reason; `wait/responsible/ready` → collocation; `easier/suitable/important` → person affected.
3. **The word after it:** a person → for whom; a period → duration; an action noun or `-ing` → purpose.

## 3. to: Direction and Receiver

```text
I will send the link to you.

Let's move to the next topic.

We need to talk to the design team.

The change is visible to all users.
```

> ⚠️ `to` is a preposition before a noun (`move to the next topic`) and an infinitive marker before a verb (`need to check`; see [G13](13-to-do-doing-done.md)). In a few fixed phrases the preposition `to` takes `-ing`: `look forward to hearing from you`, `be used to working remotely`.

## 4. of: Part, Belonging, Content

```text
Most of the stories are completed.

One of the tests is failing.

The cause of the issue is still unclear.

This is a list of open tickets.
```

## 5. in, on, at: Area, Surface or Platform, Point

| Preposition | Core | Time | Work context |
| --- | --- | --- | --- |
| `at` | a point | `at 3 PM`, `at this point` | `at the office` |
| `on` | a surface, platform, date | `on Monday` | `on Jira`, `on the screen`, `on my side` |
| `in` | an area or container | `in May`, `in two days`, `in this sprint` | `in production`, `in the repo` |

```text
The bug only happens in production.

I left a comment on the PR.

Can you see it on your screen?

At this point, we don't have a final decision.

We will finish it in two days.
```

`in two days` means "two days from now"; `within two days` means "no later than two days".

## 6. with: Together, Using, Having

```text
I will align with the backend team.

Can you help me with this ticket?

We fixed it with a small patch.

Is there any problem with the build?
```

## 7. from: Source and Starting Point

```text
Nothing from my side.

We got feedback from the design team.

The meeting is from 9 to 10.
```

## 8. by: Deadline, Agent, Method

```text
Please finish it by Friday.

The PR was reviewed by Ken.

We can reduce the cost by using a smaller VM.

I will be out of office until Friday.
```

`by Friday` = no later than Friday. `until Friday` = continuing up to Friday.

## 9. about: Topic of Talk

```text
Let's talk about the release plan.

Do you have any questions about this?
```

> ⚠️ `discuss` and `mention` take a direct object: `discuss the plan`, not `discuss about the plan`.

## 11. High-Frequency Prepositional Phrases

| Phrase | Phrase |
| --- | --- |
| `on track` | `in progress` |
| `on hold` | `in dev` / `in QA` |
| `on my side` | `from my side` |
| `at this point` | `at the moment` |
| `for now` | `in the meantime` |
| `out of office` | `up to date` |
| `by end of day` | `by the end of the sprint` |
| `ahead of schedule` | `behind schedule` |
| `in terms of` | `as for` |
| `on behalf of` | `in advance` |

```text
Most items are on track.

The story is still in progress.

He is out of office this week.

Thanks in advance.
```

## 12. Reading Prepositions in Subtitles

1. **Find the main clause first.** Prepositional phrases add detail and can be skipped on the first pass.
2. **Treat sentence-initial `For …,` as a heading.**
3. **Ignore repeated prepositions.** `for the, for the native part` is a restart.
4. **Recognize, but do not copy, non-native forms:**

| Heard in subtitles | Standard form |
| --- | --- |
| `regarding to the timeline` | `regarding the timeline` |
| `discuss about the issue` | `discuss the issue` |
| `mention about it` | `mention it` |
| `thanks for your share` | `thanks for sharing` |
| `in Monday` | `on Monday` |

## 13. Common Mistakes

| ❌ Wrong | ✅ Right | Reason |
| --- | --- | --- |
| `Thanks for share.` | `Thanks for sharing.` | `-ing` after a preposition |
| `I'm waiting the review.` | `I'm waiting for the review.` | `wait for` |
| `We use it for test.` | `We use it for testing.` / `to test` | purpose |
| `I'm responsible to the release.` | `I'm responsible for the release.` | collocation |
| `Please finish until Friday.` | `Please finish by Friday.` | deadline |
| `I will finish it after two days.` | `I will finish it in two days.` | future time |
| `I worked here since three years.` | `I have worked here for three years.` | duration |

## 14. Sentences You Can Use Today

```text
For my part, I finished the API changes yesterday.

Nothing from my side.

The ticket is in progress and on track.

Thanks for sharing. That's very helpful for us.

We can leave it for now and discuss it next week.

I'm waiting for the design team's feedback.

That's all for my part. Thank you.
```

## What This Lesson Solves

When teams discuss technical options, they compare all the time: which is more stable, which is easier, which is the best fit.

```text
I think the self-hosted runner is a bit more stable, and it's easier for us to maintain.
```

This sentence has a degree word (`a bit`) and two comparatives (`more stable`, `easier`). Using these small words well makes your opinions clearer and softer.

**After this lesson, you can:**

1. Explain what adjectives and adverbs modify and where they go.
2. Use `-ly` adverbs, frequency adverbs, and degree words to say how, how often, and how much.
3. Compare options with comparatives, superlatives, `as … as`, and `the same as`.

## 1. Adjectives vs Adverbs: Different Targets

- **Adjectives** modify nouns: what kind of thing? `a stable version`.
- **Adverbs** modify verbs, adjectives, or whole sentences: how? how much? `It runs smoothly.`, `really slow`.

**Patterns:**

- `adjective + noun`: `a quick question`
- `be / look / sound / seem / get + adjective`: `It looks good.`
- `verb (+ object) + adverb`: `It works properly.`

```text
That sounds good.

The demo went well.

It's getting slower after the update.
```

> ⚠️ After `look`, `sound`, and `seem`, use an adjective: `It looks good.` `good` is an adjective; `well` is an adverb: `It works well.`

## 2. Where Adjectives Go

| Position | Example |
| --- | --- |
| Before a noun | `a small change`, `the new login page` |
| After `be` and other linking verbs | `The build is green.` |
| After `something / anything / nothing` | `anything else`, `something important`, `nothing new` |

**With several adjectives**, the rough order is opinion → size → age → color → type (a noun used as an adjective) + noun. Meetings rarely use more than two: `a nice small fix`, `a big new feature`, `the old blue button`.

**Nouns used as adjectives** are everywhere in tech English, and they stay singular: `the login page`, `the release date`, `the test environment`.

**Hyphenated compound adjectives** are also common, and the noun inside stays singular:

```text
We have a two-week sprint.

This is only a short-term solution.

Let me give you a high-level overview.
```

❌ `a two-weeks sprint` ✅ `a two-week sprint`

## 3. Adverbs: -ly and Position

### 3.1 Forming -ly Adverbs

Most adverbs are adjective + `-ly`: `quick → quickly`, `proper → properly`, `direct → directly`, `current → currently`, `easy → easily`.

Learn these exceptions:

| Adjective | Adverb | Note |
| --- | --- | --- |
| `good` | `well` | `It works well.` |
| `fast` | `fast` | no `fastly` |
| `hard` | `hard` | `hardly` means "almost not" |
| `late` | `late` | `lately` means "recently" |

### 3.2 Where Adverbs Go

| Position | Role | Example |
| --- | --- | --- |
| Start | comments on the whole sentence | `Currently, …`, `Actually, …`, `Hopefully, …` |
| Middle (after `be`, before a main verb) | adds attitude | `We probably need …`, `It's probably fine.` |
| End | describes manner | `It works properly.`, `Let's go through this quickly.` |

```text
Currently, we are in the third week of the sprint.

We probably need one more day.

We need to make sure the pipeline is set up properly.
```

> ⚠️ Do not put an adverb between a verb and its object: ❌ `I checked carefully the logs.` ✅ `I checked the logs carefully.`

## 4. Frequency Adverbs: How Often

| Frequency | Adverb |
| --- | --- |
| 100% | `always` |
| about 80% | `usually` |
| about 60% | `often` |
| about 40% | `sometimes` |
| about 10% | `rarely` |
| 0% | `never` |

**Position:** after `be` and modal verbs, before main verbs.

```text
It usually takes two or three sprints to finish a feature.

The build sometimes fails on Safari.

We never deploy on Fridays.

The native approach is always preferred if it's available.
```

Phrases such as `every day`, `once a week`, and `every sprint` go at the end: `We sync up twice a week.`

## 5. Degree Words: How Much

| Strength | Degree words | Example |
| --- | --- | --- |
| Weak | `a bit`, `a little (bit)`, `slightly` | `a bit tricky` |
| Medium | `quite`, `pretty`, `fairly` | `pretty simple` |
| Strong | `very`, `really`, `so` | `really helpful` |
| Too much | `too` | `too slow` |

Points to watch:

- **`pretty` = fairly** (spoken), not "beautiful". `pretty much` = "almost": `That's pretty much it from my side.`
- **`quite`**: `quite simple` = fairly simple; `not quite sure` = not completely sure.
- **`a bit / a little bit`** softens bad news: `It's a bit slow.` is more polite than `It's slow.`
- **`too` means "more than acceptable"** and is negative: `It's too slow.` To praise, say `really good`, not `too good`.
- **`enough`** follows an adjective: `good enough`, `fast enough`.

```text
It's quite simple.

Management is a little bit tricky.

That's pretty much it from my side.

The test environment is too slow for load testing.
```

## 6. Comparatives and Superlatives

### 6.1 Forms

| Type | Comparative | Superlative |
| --- | --- | --- |
| One syllable: add `-er / -est` | `fast → faster` | `the fastest` |
| Consonant + `y`: `-ier / -iest` | `easy → easier`, `early → earlier` | `the easiest` |
| Longer words: `more / most` | `stable → more stable` | `the most stable` |
| Irregular | `good → better`, `bad → worse`, `far → further` | `the best`, `the worst` |
| Less | `less risky` | `the least risky` |

### 6.2 Comparatives: A Is More … Than B

**Pattern:** `A + be + comparative + than B`; to say who benefits: `comparative + for + person`

```text
The new version is much faster than the old one.

I think it's easier for us to use GitHub Actions.

It's a bit more stable now.

Option B is less risky.
```

Modify a comparative with `much`, `a bit`, `a little`, or `even`, **not `very`**: ❌ `very faster` ✅ `much faster`.

### 6.3 Superlatives: The Most …

```text
I think AWS would be the best option for us.

Is this the latest version?

This is one of the most common issues.
```

> ⚠️ `most of the …` means "the majority", not a superlative: `Most of the stories are done.` Don't add `the`: ❌ `the most of the tasks`.

### 6.4 as … as, the same as, different from

```text
Please fix it as soon as possible.

The new API is not as fast as we expected.

The Android setup is the same as the iOS one.

The staging config is different from production.
```

`the same` always takes `the`, and it is followed by `as`: `the same as before`.

## 7. Real Meeting Examples (Adapted)

These come from real meeting subtitles, with recognition errors fixed:

```text
It's quite simple. I'm just not quite sure about the timeline.

I think it's better for us to have our own cloud for these runners.

Sometimes even a bug fix can be a breaking change.

The task will be the smallest work item we have.

Most team members gave it a five, so let's go with five.

If this is the latest version, we can go with that.

I'll show you what we have really quickly.
```

## 8. Reading Comparisons in Subtitles

1. **Comparison signals:** `-er`, `more`, `less`, `than`, `as … as`, `the same`. When you see them, find what is compared with what.
2. **`most of` = "the majority"**; only `the most + adjective` means "the most".
3. **`pretty` and `quite` are usually degree words**, not "beautiful" or "completely".
4. **Recognize, but do not copy, non-native forms:**

| Heard in subtitles | Standard form |
| --- | --- |
| `more easier` | `easier` |
| `very less effort` | `much less effort` |
| `more better` | `better` |
| `the most of the tasks` | `most of the tasks` |
| `same with the old one` | `the same as the old one` |
| `there's no much updates` | `there aren't many updates` |
| `show you really quick` | `show you really quickly` (`quick` as an adverb is common in speech) |

## 9. Common Mistakes

| ❌ Wrong | ✅ Right | Reason |
| --- | --- | --- |
| `It looks well.` (meaning "looks fine") | `It looks good.` | adjective after `look` |
| `This way is more easier.` | `This way is easier.` | no double comparative |
| `It's the most fast option.` | `It's the fastest option.` | one syllable: `-est` |
| `It's very faster now.` | `It's much faster now.` | `much` before a comparative |
| `I checked carefully the logs.` | `I checked the logs carefully.` | no adverb between verb and object |
| `a two-weeks sprint` | `a two-week sprint` | singular inside a compound adjective |
| `I always am online.` | `I'm always online.` | frequency adverb after `be` |
| `It's same as before.` | `It's the same as before.` | `the same` |
| `The demo was too good!` | `The demo was really good!` | `too` = more than acceptable |

## 10. Sentences You Can Use Today

```text
That sounds good to me.

It's a bit tricky, but it's doable.

I think option A is easier for us.

The new version is much more stable.

It usually takes about two days.

That's pretty much it from my side.

I'll fix it as soon as possible.
```

## 11. Practice

**A. Choose the correct form**

1. The demo went (good / well).
2. That sounds (great / greatly).
3. It's (much / very) faster than before.
4. This is the (most easy / easiest) way.
5. The config is the same (as / with) production.
6. (Most of / The most of) the tasks are done.

**B. Put the adverb in the right place**

1. The build fails on Safari. (sometimes)
2. We are available in the morning. (usually)
3. I checked the logs. (carefully)

**C. Correct the sentences**

1. Option B is more cheaper.
2. We have a three-days workshop.
3. I'm not quite sure, but I think it's too good.

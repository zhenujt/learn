# G13 Non-Finite Verbs: to do, doing, done

> **Frequency: 🔴 Must learn** | Level: junior high → senior high | Meeting data per 10,000 words: `to do` after `want / need / try / plan` etc. ≈ 95; `to make sure` is a top four-word sequence (61 times); `-ing` after a preposition ≈ 13
>
> [中文版](13-to-do-doing-done.zh.md) · [Previous: G12 The Passive Voice](12-passive-voice.md) · [Next: G14 Phrasal Verbs and Collocations](14-phrasal-verbs-and-collocations.md) · [Grammar index](README.md)

## What This Lesson Solves

Chinese can line up verbs one after another. English cannot. **Each clause has only one main (finite) verb.** Every other verb must change form into `to do`, `doing`, or `done`.

```text
We need to make sure the pipeline is set up before we start working on the components.
```

This sentence has `to make` (to do), `set up` (done, passive), and `working` (doing). Once you can see these three forms, long sentences become easy to take apart.

**After this lesson, you can:**

1. Explain why a clause has only one main verb and the others become `to do`, `doing`, or `done`.
2. Use the most common "verb + to do" and "verb + doing" patterns in meetings.
3. Tell `stop to do` from `stop doing` and similar pairs.
4. Distinguish `-ing` / `-ed` adjectives such as `interesting` / `interested`, and read participle phrases in subtitles.

## 1. Three Forms, Three Feelings

| Form | Core feeling | Example |
| --- | --- | --- |
| `to do` | not done yet, going to do, purpose | `I plan to fix it.` |
| `doing` | ongoing or existing action, action as a noun | `I finished testing it.` |
| `done` | acted on, in a finished state | `the tickets assigned to me` |

```text
I want to share my screen.

Thanks for sharing.

Here is the updated document.
```

If you remember these three feelings, you can often guess patterns you haven't learned yet.

## 2. to do: Going to Do, In Order to Do

### 2.1 Verb + to do 🔴

These verbs take `to do` because they all point to **an action that hasn't happened yet**:

| Verb | Example |
| --- | --- |
| `want` / `would like` | `I want to give a quick update.` |
| `need` | `We need to confirm it with QA.` |
| `try` | `I'll try to finish it today.` |
| `plan` | `We plan to release it next week.` |
| `decide` | `We decided to go with AWS.` |
| `hope` / `expect` | `We expect to finish it by Friday.` |
| `forget` / `remember` | `I forgot to update the ticket.` |
| `manage` | `We managed to fix the build.` |
| `agree` | `They agreed to share the API spec.` |
| `start` / `continue` | `We started to work on it.` (also `-ing`) |

```text
I'm planning to finish the API changes by Friday.

We decided to go with the hybrid approach.

Sorry, I forgot to update the status.
```

### 2.2 Verb + Person + to do

`ask`, `want`, `need`, `remind`, `allow`, `encourage`, and `expect` can take a person, then `to do`:

```text
Can I ask Ken to review it?

I want you to take a look at the error log.

Please remind me to send the notes.
```

> ⚠️ `let` and `make` take **person + base verb**, with no `to`: `Let me share my screen.`, `Let's move on.`, `Let me know.` The subtitle form `let us to decide` is wrong. `help` works with or without `to`: `Can you help me (to) check it?`

### 2.3 to do for Purpose

```text
I'm sharing my screen to show you the demo.

We use Harness to run the pipeline.

We need to do a quick prototype to figure out if it's feasible.
```

`in order to` is more formal and rare in meetings.

### 2.4 make sure 🔴

`make sure` appeared 77 times in 25 meetings. It has two patterns:

**Pattern:** `make sure + full clause` or `make sure to + base verb`

```text
We need to make sure the pipeline is working properly.

Please make sure all tests pass before merging.

Please make sure to update the ticket status.
```

The clause after `make sure` needs a full verb: `make sure the pipeline works`, not `make sure the pipeline work`.

### 2.5 Adjective / Noun + to do

```text
It's easy to set up.

It's hard to say at this point.

I'm happy to help.

Is it possible to move the meeting to Thursday?

The plan is to release it next sprint.

Do we have any other topics to discuss?
```

### 2.6 Question Word + to do 🟡

```text
I'm not sure how to set it up.

We need to decide which option to choose.
```

## 3. doing: An Action Used as a Noun

### 3.1 Preposition + doing 🔴

A base verb cannot follow a preposition; use `-ing` (prepositions: [G16](16-prepositions.md)):

```text
Thanks for bringing that up.

Thank you for joining.

I'm only responsible for updating the Jira tickets.

You can add people to the channel by using the workflow.

Let's test it on staging before releasing it.

How about creating a separate story for it?
```

> ⚠️ In a few phrases `to` is a preposition and takes `-ing`: `look forward to hearing from you`, `be used to working remotely`.

### 3.2 Verb + doing

These verbs take `-ing`. Most relate to **an action that already exists or continues**:

| Verb | Example |
| --- | --- |
| `finish` | `I finished testing the login flow.` |
| `avoid` | `We should avoid making breaking changes.` |
| `suggest` / `recommend` | `I suggest creating a separate ticket.` |
| `consider` | `We can consider moving the release.` |
| `mind` | `Would you mind sharing your screen?` |
| `keep` | `Let's keep working on it.` |
| `spend + time` | `We spent two days fixing the build.` |
| `start` / `continue` | `The designers have started working on it.` |

> ⚠️ `suggest` **cannot** take "person + to do". ❌ `I suggest you to create a ticket.` ✅ `I suggest creating a ticket.` or `I suggest (that) we create a ticket.`

### 3.3 doing as a Subject

```text
Testing on Safari takes a lot of time.

Adding a new runner is not difficult.
```

## 4. Pairs That Change Meaning: stop / remember / forget / try

The same verb means different things with `to do` and `doing`. Core idea: **`to do` points to a later action; `doing` refers to a current or earlier action.**

| Pattern | Meaning | Example |
| --- | --- | --- |
| `stop doing` | end the current activity | `I'll stop sharing now.` |
| `stop to do` | pause in order to do something else | `Let's stop here to take questions.` |
| `remember to do` | don't forget a future task | `Remember to update the status.` |
| `remember doing` | have a memory of a past action | `I remember fixing this bug before.` |
| `forget to do` | fail to do a task | `I forgot to push the change.` |
| `try to do` | make an effort | `I'll try to finish it today.` |
| `try doing` | test a method | `Try clearing the cache.` |

```text
Okay, if there are no questions, I'll stop sharing.

Let's stop here to take a few questions.

Have you tried restarting the runner?
```

`start` and `continue` mean almost the same with `to do` or `doing`.

## 5. done: Acted On, Finished

### 5.1 After a Noun

A past participle phrase after a noun means "**that is/was …-ed**". It is a shortened relative clause (see [G19](19-relative-clauses.md)).

```text
Here are the tickets assigned to me.

The issues reported by QA are all fixed.

The components migrated from the old library work fine.
```

### 5.2 have / get + Thing + done 🟡

```text
We need to get the access approved first.

I'll get it done by Friday.
```

`be + done` is the passive voice; see [G12](12-passive-voice.md).

## 6. -ing and -ed Adjectives

Many verbs have `-ing` and `-ed` adjective forms with different meanings:

- **`-ing`:** the thing **causes** the feeling.
- **`-ed`:** the person **has** the feeling.

| -ing (describes a thing) | -ed (describes a person's feeling) |
| --- | --- |
| `interesting` | `interested` |
| `confusing` | `confused` |
| `surprising` | `surprised` |
| `frustrating` | `frustrated` |
| `exciting` | `excited` |
| `tiring` | `tired` |

```text
The new workflow is a bit confusing.

I'm a little bit confused about the QA process.

If you are interested, you can stay online.
```

❌ `I'm interesting in this topic.` (this means "I am an interesting person") ✅ `I'm interested in this topic.`

**Participle adjectives before nouns** are everywhere in subtitles and tickets:

| -ing (active, ongoing) | -ed (passive, finished) |
| --- | --- |
| `the remaining tasks` | `the updated document` |
| `the existing pipeline` | `the proposed solution` |
| `the following steps` | `the related tickets` |
| `the upcoming release` | `the attached screenshot` |
| `a breaking change` | `the expected result` |
| `failing tests` | `the selected option` |

## 7. Participle Phrases in Subtitles and Titles

### 7.1 Sentence-Initial Participle Phrases: Background

Subtitles often start with an `-ing` or `-ed` phrase and a comma. It is only **background information**; the main clause comes after the comma.

```text
Based on the feedback, we will update the design.

Compared with the old version, it's much faster.

Looking at the board, most stories are in progress.

Starting next week, we will have a daily sync.

Going forward, please create a ticket first.
```

An `-ing` phrase is active; an `-ed` phrase is passive. Words such as `including`, `depending on`, `regarding`, and `according to` come from participles and now work as prepositions.

### 7.2 Ticket Titles and Commit Messages

Jira titles, PR titles, and commit messages often drop the subject and keep only the participle:

```text
Setting up the CI pipeline for Android

Updated the README with new steps
```

The `-ing` title describes ongoing work; the `-ed` title describes finished work.

## 9. Reading Non-Finite Verbs in Subtitles

1. **Find the main verb first.** Each clause has one; verbs with `to`, `-ing`, or `-ed` around it are supporting players.
2. **`to` + base verb** → "going to do / in order to do".
3. **Preposition + `-ing`** → "the action of doing".
4. **A sentence-initial participle phrase with a comma** → skip it first and find the main clause.
5. **Recognize, but do not copy, non-native forms:**

| Heard in subtitles | Standard form |
| --- | --- |
| `I will stop share.` | `I'll stop sharing.` |
| `let us to decide` | `let us decide` |
| `we need to consider to push the release` | `we need to consider pushing the release` |
| `I would recommend to do that` | `I'd recommend doing that` |
| `he is start to do the POC` | `he has started doing the POC` |
| `continue to working on it` | `continue working on it` / `continue to work on it` |
| `thanks for your share` | `thanks for sharing` |
| `make sure the pipeline work` | `make sure the pipeline works` |

## 10. Common Mistakes

| ❌ Wrong | ✅ Right | Reason |
| --- | --- | --- |
| `We need make sure it works.` | `We need to make sure it works.` | `need to do` |
| `I want share my screen.` | `I want to share my screen.` | `want to do` |
| `Thanks for share.` | `Thanks for sharing.` | `-ing` after a preposition |
| `I suggest you to create a ticket.` | `I suggest creating a ticket.` | no "person + to do" after `suggest` |
| `Let me to share my screen.` | `Let me share my screen.` | base verb after `let` |
| `I'm interesting in it.` | `I'm interested in it.` | feelings use `-ed` |
| `I finished to test it.` | `I finished testing it.` | `finish doing` |
| `We should avoid to break the API.` | `We should avoid breaking the API.` | `avoid doing` |
| `I look forward to hear from you.` | `I look forward to hearing from you.` | `to` is a preposition here |

## 11. Sentences You Can Use Today

```text
I want to give a quick update on the login page.

I'm planning to finish the API changes by Friday.

We need to make sure all tests pass before merging.

Thanks for sharing. It's really helpful.

I'd suggest creating a separate story for this.

Let me stop sharing my screen.

I'm a bit confused about the new workflow. Could you explain it again?

I'll try to get it done today.

Would you mind taking a look at the updated document?
```

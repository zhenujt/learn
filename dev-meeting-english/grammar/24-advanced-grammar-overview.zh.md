# G24 高级语法速览：虚拟语气、倒装、强调句、独立主格

## 这一课解决什么问题

虚拟语气、倒装、独立主格是高中考试的重点，但在 25 场真实会议里，它们几乎没有出现。这一课只做一件事：**告诉你哪些可以跳过，哪些要能认出来。**

先看总表：

| 语法点 | 会议频率 | 标签 | 建议 |
| --- | --- | --- | --- |
| 强调句 `It is…that…`、`What we need is…` | 1.4 + 0.6 | 🟢 | 能认出来；`What we need is…` 可以学着说 |
| 强调 `do`：`I do have a question` | 约 2 | 🟢 | 能认出来 |
| 虚拟语气 `suggest that he be…` | 0 | ⚪ | 跳过；用 `should` 代替 |
| `wish`、`It's time that…` | 约 0 | ⚪ | 跳过 |
| 倒装 `Not only…`、`Only when…`、`Should you…` | 0.5 | ⚪ | 只在邮件里认得 `Should you…` |
| 独立主格 | 约 0 | ⚪ | 跳过 |
| 书面省略、平行结构 | 很少 | ⚪ | 写文档时有用 |
| 书面连接词 `however`、`therefore` | 0.4 | ⚪ | 写邮件、文档时用 |

**学完这一课，你应该能：**

1. 认出强调句，并能用 `What we need is…` 突出重点。
2. 知道虚拟语气、倒装、独立主格长什么样，在文档里遇到不慌。
3. 明确哪些内容可以放心跳过，把时间花在 G01–G23 上。

## 1. 强调句 🟢：It is…that… / What we need is…

这是本课**唯一在会议里真会出现**的结构。它把一个信息单独拎出来强调。

**公式：** `It is / was + 被强调部分 + that + 其余部分` ；`What + 主语 + 动词 + is + 被强调部分`

```text
It's the CI pipeline that is slowing us down, not the tests.
拖慢我们的是 CI 流水线，不是测试。

What we need is a final decision on the timeline.
我们需要的是一个关于时间线的最终决定。

What I remember clearly is that we all agreed on this earlier.
我记得很清楚的是，我们之前都同意过这一点。

The thing is, we don't have the approval yet.
问题是，我们还没拿到审批。
```

**强调 `do`：** 在动词前加 `do / does / did`，表示"确实、的确"。

```text
I do have one question regarding the website.
关于网站，我确实有一个问题。
```

> 注意区分：`It's an existing issue that we've had for a while.` 里的 `that` 是定语从句（"一个我们存在已久的问题"），不是强调句。判断方法：去掉 `It is` 和 `that`，剩下的能组成完整句子的才是强调句。

## 2. 虚拟语气 ⚪：suggest that…、wish、It's time that…

会议中几乎用不到，了解即可，可以跳过。

**① 建议、要求后的动词原形：** `suggest / recommend / require / It's important + that + 主语 + 动词原形`

```text
We recommend that the token be rotated every 90 days.
我们建议每 90 天轮换一次令牌。（安全文档里的写法）

We recommend that the token should be rotated every 90 days.
我们建议每 90 天轮换一次令牌。（英式写法，加 should）
```

会议里大家会直接说 `I suggest we rotate the token.` 或 `We should rotate the token.`，见 [G11](11-modal-verbs.zh.md)、[G22](22-reported-speech.zh.md)。

**② wish：** 表示和现实相反的愿望，从句时态往过去退一步。

```text
I wish we had more time for testing.
要是我们有更多时间测试就好了。（实际上没有）
```

**③ It's time that…：** "早该……了"，从句用过去时。

```text
It's time we cleaned up the old branches.
我们早该清理旧分支了。
```

**④ if I were / if we had done：** 见 [G21 条件句](21-conditionals.zh.md)。会议里第三条件句 0 次。

## 3. 倒装 ⚪：Not only…、Only when…、Should you…

倒装就是把助动词放到主语前面，像问句一样，但其实是陈述句。会议中几乎用不到，了解即可，可以跳过。

```text
Not only does it save time, but it also reduces errors.
它不仅节省时间，还能减少错误。

Only when the PR is approved can we merge it.
只有 PR 被批准后，我们才能合并。

Should you have any questions, please let me know.
如有任何问题，请告诉我。（邮件结尾常见，= If you have any questions）
```

会议里出现的 `not only` 基本不倒装：`This is not only for the agentic workflow; it's for the whole team.` 这是普通说法，很自然。

## 4. 独立主格 ⚪：名词 + 分词，作状语

独立主格是"带着自己主语的分词短语"，多见于书面语。会议中几乎用不到，了解即可，可以跳过。

```text
All tests having passed, we merged the PR.
所有测试都通过了，我们就合并了 PR。（书面）

With all tests passing, we can merge the PR.
所有测试都通过了，我们就可以合并 PR 了。（with + 名词 + -ing，稍口语）
```

口语里直接说：`All the tests passed, so we merged the PR.` 注意不能写成 `All tests passed, we merged the PR.`（两个句子之间只有逗号，不规范）。

## 5. 书面省略、替代与平行结构 ⚪

口语省略（`Sounds good.`、`Any questions?`）在 [G23](23-spoken-grammar.zh.md) 讲过，是 🔴 必学。这里是**书面**的省略和平行结构，写文档、写邮件时才需要。

```text
Ken will review the backend, and Mia the frontend.
Ken 评审后端，Mia 评审前端。（省略重复的 will review）

We need to fix the bug, update the docs, and notify the users.
我们需要修复 Bug、更新文档并通知用户。（平行结构：三个动词原形）
```

**平行结构**的规则：并列的部分要用**同样的形式**。

❌ `We need to fix the bug, updating the docs, and notification to users.`
✅ `We need to fix the bug, update the docs, and notify the users.`

## 6. 书面连接词 ⚪：however、therefore、moreover

这些词让文档更正式。会议里几乎不用，大家用 `but`、`so`、`also`，见 [G17](17-conjunctions-and-linking.zh.md)。

| 书面 | 口语对应 | 意思 |
| --- | --- | --- |
| `however` | `but` | 但是 |
| `therefore` / `thus` | `so` | 因此 |
| `moreover` / `furthermore` / `in addition` | `also`、`and` | 此外 |
| `nevertheless` | `but still` | 尽管如此 |
| `as a result` / `consequently` | `so` | 结果 |

```text
The fix works on Android. However, we still need to test it on iOS.
修复在 Android 上可以用了。但是我们还需要在 iOS 上测试。
```

> ⚠️ `however` 前面要用句号或分号，不能只用逗号：❌ `It works, however we need more tests.`

## 7. 真实会议例句（改编）

```text
This is not only for the agentic workflow; it's for the whole team.
这不只是针对智能体工作流的，而是针对整个团队的。

What we can do is post the details in the wider group.
我们能做的，是把细节发到更大的群里。

I do have a quick question about the vulnerability check.
关于漏洞检查，我确实有个小问题。

It's an existing issue that we've had for a while.
这是一个存在了一段时间的老问题。
```

## 8. 字幕里怎么认

- 句首是 `What we need / What I mean / The thing is`，后面接 `is` → 强调，重点在 `is` 后面。
- `It is / It's … that …`：去掉 `It is` 和 `that` 能成完整句子 → 强调句。
- 邮件里以 `Should you…` 开头 → 等于 `If you…`。
- 其他高级结构在会议字幕里基本不会出现。看到复杂句时，更可能是 [G23](23-spoken-grammar.zh.md) 里讲的重说和识别错误。

## 9. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `What we need is we need a decision.` | `What we need is a decision.` | 主语说了两次 |
| `Only when it's approved we can merge.` | `Only when it's approved can we merge.` / `We can merge only when it's approved.` | `Only when` 在句首要倒装；不想倒装就放后面 |
| `I suggest him to rotate the token.` | `I suggest that he rotate the token.` / `I suggest he should rotate…` | `suggest` 不接"人 + to do" |
| `It works, however we need more tests.` | `It works. However, we need more tests.` | `however` 不能连接两个句子 |

## 10. 你可以直接用的句子

```text
What we need is a clear owner for this ticket.
我们需要的是给这个工单一个明确的负责人。

The thing is, we're still waiting for approval.
问题是，我们还在等审批。

I do have one more question.
我确实还有一个问题。

Should you have any questions, feel free to reach out.
如有问题，随时联系我。（邮件用）
```

## 11. 练习

**A. 判断哪些是强调句**

1. It's the login API that is failing.
2. It's a known issue that we fixed last sprint.
3. What we need is more test coverage.

**B. 用口语说法改写**

1. Should you need access, please contact Ken.
2. We recommend that the cache be cleared.
3. The build failed. Therefore, we postponed the release.

<details>
<summary>答案</summary>

**A.** 1 是（去掉 It's 和 that：The login API is failing.）　2 不是（that 引导定语从句，修饰 issue）　3 是

**B.**
1. If you need access, please contact Ken.
2. We should clear the cache.（或 I suggest we clear the cache.）
3. The build failed, so we postponed the release.

</details>

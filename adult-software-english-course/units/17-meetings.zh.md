# 第 17 课：参与会议并确认行动

[English](17-meetings.md) · [目录](../README.zh.md) · [下一课](18-demos.zh.md)

## 目标与词汇

加入讨论、确认理解、记录决定。agenda 议程；interrupt 打断；decision 决定；action item 行动项；owner 负责人；due 到期的；summarize 概括；postpone 延后；unresolved 未决定的。

## 对话与阅读

A: Today's question is whether we can release on Friday. 今天讨论周五能否发布。
B: Sorry to interrupt. Is the large-file test complete? 抱歉打断，大文件测试完成了吗？
A: Not yet. Dana is running it this afternoon. 还没，Dana 今天下午跑。
C: Then let's decide after we have the result. 那拿到结果再决定。
B: So Friday is a target, not a confirmed release date. Is that correct? 所以周五是目标，不是确认日期，对吗？
A: Correct. Dana will post the result by four today, UTC+0. 对，Dana 今天 UTC+0 四点前发结果。
C: I'll arrange a decision call for tomorrow at ten, UTC+0. 我安排明天 UTC+0 十点的决策通话。
B: I'll note those actions. Who will make the release decision? 我记下来。谁决定发布？
A: Priya, the release owner, will decide on that call. 发布负责人 Priya 在会上决定。

阅读：**Agenda: release readiness. Evidence: small files passed; large files pending. Decision: postpone the release decision until tomorrow's call. Actions: Dana posts results today by 16:00 UTC+0; Chris arranges tomorrow's 10:00 UTC+0 call; Priya decides release readiness. Friday remains a target.** 小文件通过、大文件待测；决定延后决策；Dana 发结果、Chris 安排会、Priya 决定；周五仍只是目标。决定等待不等于决定发布。

## 句型说明

加入：`Could I add one point?` 我补充一点好吗？澄清：`Do you mean ...?` 你指的是……吗？补漏：`I missed the last point. Could you repeat it?` 最后一点没听到，能重复吗？收尾：`Can we confirm the owner and next step?` 确认负责人和下一步好吗？不必每轮都发言。

间接问句：`Could you confirm who owns this task?` 请确认谁负责。直接问 `Who owns this task?` 也对，who 就是主语，不需加 do。

转述注明来源：`Dana said the test was still running.` Dana 说测试还在跑。同日强调当前报告可说 `Dana says the test is still running.` 长期保存的纪要应核实后把 tomorrow 换成实际日期；本虚构材料没给日期，不要编造。

## 练习

1. 改错：Could you confirm when is the call?
2. 礼貌打断，问测试是否完成。
3. 已决定什么？什么还没决定？
4. 列三个负责人及行动。
5. 纠正误导总结：We agreed to release on Friday.

## 听说读写任务

隐藏文本听，记主题、决定、行动/负责人、时间。第二次换一个负责人和时间，核对新信息，不凭旧版记忆回答。

三角色：开发者待测试；协调者希望周五发布；发布负责人需要结果。讨论三分钟，每人问答，最后复述并允许纠正。独学可轮流扮演，之后仍要练陌生回复。

写 70–100 词纪要，分开确认决定、目标、开放问题，不逐句抄录。

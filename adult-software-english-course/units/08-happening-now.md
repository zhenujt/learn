# Unit 8: What Is Happening Now?

[中文](08-happening-now.zh.md) · [Course](../README.md) · [Next](09-yesterday.md)

## Goal and words

Distinguish a current activity from a habit. Words: run (operate), wait, load, test, now, usually, busy, available (free to help).

## Dialogue and reading

A: Are you available now?
B: Not yet. I'm testing the login page.
A: Is the test running?
B: Yes, it is. The page is loading slowly.
A: Do you usually test on this laptop?
B: No. I usually use another one, but I'm using this one today.

Read: **Nia usually works in the office. Today she is working at home. She is waiting for a test result. She knows the test takes five minutes.** `knows` describes a state of understanding, not an action unfolding visibly.

## Pattern

Present continuous: `am/is/are + verb-ing`. `I am testing`, `She is waiting`, `They are working`. All parts matter: not `I testing`, not `I am test`.

Question: `Are you testing?` Negative: `I'm not testing.` Spelling: work -> working; use -> using; run -> running. A few state verbs usually use the simple form: `I know`, `I need`, `I understand`, rather than `I'm knowing`.

Contrast `I test every day` (routine) and `I'm testing now` (current activity). `today` can describe temporary arrangements when used with continuous, not just this exact second.

## Practice

1. Fill: She is ___ (use) the laptop. They ___ waiting.
2. Correct: I am know the answer.
3. Ask if the page is loading.
4. Reading: where does Nia usually work? Where is she today?
5. Write two sentences contrasting your normal work with today.

## Listen, speak, and write

Listen to the dialogue and identify why B is unavailable. Repeat with `The test isn't running`; explain how the status changes.

Describe three visible activities in a safe video or imagined office. Partner asks one question about a routine and one about now. Write a four-sentence chat update, including a current action and a normal habit.

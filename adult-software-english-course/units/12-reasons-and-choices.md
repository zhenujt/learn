# Unit 12: Reasons, Choices, and Conditions

[中文](12-reasons-and-choices.zh.md) · [Course](../README.md) · [Next](13-tasks-and-standups.md)

## Goal and words

Connect short ideas accurately. Words: because, so, but, if, faster, safer, simpler, expensive, option, risk.

## Dialogue and reading

A: Which option do you prefer?
B: Option A. It's simpler than option B.
A: Is it faster, too?
B: No. It's slower, but it's easier to maintain.
A: Why does that matter?
B: Because our team is small. If we choose B, we'll need more support.

Read: **Option A takes two days and supports one file at a time. Option B takes five days and supports several files. We need single-file upload this week. Multi-file upload is not required yet.** Choosing an option requires matching facts to a goal.

## Pattern

`because` introduces a reason; `so` introduces a result. Say `We chose A because it is simpler` or `A is simpler, so we chose it`. Avoid `Because ..., so ...` in the same basic sentence.

Short comparisons often add `er`: fast/faster, safe/safer; long ones use `more`: more expensive. `easy` becomes `easier`; good -> better, bad -> worse. Use `than` for the comparison target. Do not say `more faster`.

Real future condition: `If + present, will/can + base verb`: `If the test passes, we can continue.` A condition is not a confirmed fact. `must` expresses a requirement, `should` advice, `might` possibility; these are not interchangeable.

## Practice

1. Correct: This option is more faster.
2. Join with because: We need help. The task is complex.
3. Fill: If the test ___ (pass), we can continue.
4. Reading: which option meets this week's stated need sooner? What does it not support?
5. Explain the difference: We might release today. / We must release today.

## Four-skill task

Listen and note one advantage and one disadvantage of A. Explain why the speaker still prefers it.

Compare two fictional travel routes or two software options. Partner changes one requirement; reconsider rather than repeat your original answer. Write 50-70 words stating a choice, reason, limitation, and condition. Start with four sentences if needed.

# 第 18 课：解释功能与演示

[English](18-demos.md) · [目录](../README.zh.md) · [下一课](19-messages-and-incidents.zh.md)

## 目标与词汇

说明用途、演示行为、应对不知道的问题。feature 功能；demo 演示；select 选择；upload 上传；preview 预览；confirm 确认；cancel 取消；limitation 限制；supported 在规定条件下受支持。

## 对话与阅读

A: What does this feature do? 这个功能做什么？
B: It lets users upload one PDF and check the file name before sending it. 让用户上传一个 PDF，发送前检查名称。
A: Could you show us? 能演示吗？
B: First, I select a PDF. The file name appears here. Then I click Upload. 先选 PDF，名称显示这里，然后点上传。
A: Can it accept several files? 支持多个文件吗？
B: Not in this version. It supports one file at a time. 这版不行，一次一个。
A: Does it work offline? 离线能用吗？
B: I haven't tested that. I'll check with the team and post an answer tomorrow. 还没测，会问团队，明天回复。

阅读：**Use a fictional test account and a harmless sample file. Show a valid upload, an over-limit file, and cancellation. Only PDF is supported. Upload requires a connection in the specification; offline behavior has not been tested.** 用虚构账号与安全文件，展示成功、超限、取消；只支持 PDF；规格要求联网，离线行为未测。规定和已验证结果不同。

## 句型说明

`It lets users upload ...`：let + 人 + 原形，不加 to。`It allows users to upload ...` 要 to。`Use this button to cancel` 用 to + 动词说明用途。

关系从句：`The button that opens the dialog is on the right.` 打开对话框的按钮在右边。that 后说明哪个按钮；口头难说就拆成 `This button opens the dialog. It's on the right.` 短而准确完全适合演示。

点击前说预期结果。演示失败时如实说明：`The upload hasn't completed.` 上传未完成。可以换已存在的录制样例，但没有录像就不能声称有。

## 练习

1. 改错：It allows users upload files. It lets users to cancel.
2. 用 to 说明 Cancel 的用途。
3. 离线行为验证了吗？规格要求联网吗？
4. 被问到没测过的浏览器，怎样不猜测地回答？
5. 拆句：The button that starts the upload is below the file name.

## 听说读写任务

听用途、顺序、限制、后续。第二次让搭档打乱提问顺序，你按实际问题答，不按背稿顺序。

在纸上或安全本地样例中演示两分钟：用途、成功、错误、限制。搭档插问“取消会怎样”和一个未测情况。不需要编程，不用真实生产变更练英语。

写 80–120 词提示式讲稿，再脱离全文录一版，检查不看鼠标是否也能理解顺序。

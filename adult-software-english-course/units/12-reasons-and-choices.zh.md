# 第 12 课：原因、选择与条件

[English](12-reasons-and-choices.md) · [目录](../README.zh.md) · [下一课](13-tasks-and-standups.zh.md)

## 目标与词汇

把短句准确连接。because 因为；so 所以；but 但是；if 如果；faster 更快；safer 更安全；simpler 更简单；expensive 贵；option 选项；risk 风险。

## 对话与阅读

A: Which option do you prefer? 更喜欢哪个方案？
B: Option A. It's simpler than option B. A，比 B 简单。
A: Is it faster, too? 也更快吗？
B: No. It's slower, but it's easier to maintain. 不，更慢，但容易维护。
A: Why does that matter? 为什么这很重要？
B: Because our team is small. If we choose B, we'll need more support. 因为团队小，选 B 就需要更多支持。

短文：**Option A takes two days and supports one file at a time. Option B takes five days and supports several files. We need single-file upload this week. Multi-file upload is not required yet.** A 两天、每次单文件；B 五天、多个文件；本周只要求单文件上传。

## 句型说明

because 引出原因，so 引出结果：`We chose A because it is simpler` 或 `A is simpler, so we chose it`。不要按中文习惯同句同时写 Because ... so ...。

比较级：fast/faster，safe/safer；长词常用 more expensive。easy → easier，good → better，bad → worse。比较对象前用 than。不要重复写 more faster。

真实未来条件：`If + 现在时，will/can + 原形`。`If the test passes, we can continue.` 如果测试通过就可以继续。条件不等于已发生事实。must 是要求，should 是建议，might 是可能，不要混用。

## 练习

1. 改错：This option is more faster.
2. 用 because 连接：We need help. The task is complex.
3. If the test ___ (pass), we can continue.
4. 哪个更早满足本周需求？不支持什么？
5. We might release today 与 We must release today 有什么区别？

## 听说读写任务

听出 A 一个优点与一个缺点，解释为什么仍选 A。

与搭档比较两条虚构出行路线或软件方案。对方改变一个要求，你重新考虑，别只重复答案。写 50–70 词选择说明：选择、原因、限制、条件；太难先写四句。

意思：选 A 因本周需单文件，两天更合适；不支持多文件，未来需要时重评，开工前与团队确认限制。

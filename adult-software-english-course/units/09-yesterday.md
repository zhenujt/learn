# Unit 9: Yesterday and What Happened

[中文](09-yesterday.zh.md) · [Course](../README.md) · [Next](10-plans.md)

## Goal and vocabulary

Describe a finished event in sequence. Words: yesterday, last night, first, then, finally, error, restart, happen. Review present actions from Unit 8.

## Dialogue and reading

A: What happened yesterday?
B: The app stopped at ten.
A: Did you restart it?
B: Yes. I restarted it, but it didn't work.
A: What did you do next?
B: I checked the settings and found the wrong address.
A: Was the address correct after the change?
B: Yes. The app worked again.

Read: **Yesterday, I went to the office. First, I checked a report. Then I called Dana. We found an error in the settings. We fixed it before lunch.** This is a finished sequence, not a claim about today's state.

## Pattern

Past simple: many verbs add `ed`: check -> checked, restart -> restarted. Others change: go -> went, find -> found, do -> did, have -> had, send -> sent, write -> wrote. Learn irregular forms in sentences, a few at a time.

Question: `Did you restart it?` Negative: `It didn't work.` After did/didn't use the base verb, not another past form. Be uses its own forms: `I/he/she/it was`, `you/we/they were`; ask `Was it ready?`, not `Did it was ready?`

Listen for endings: `checked` ends /t/, `called` /d/, `restarted` /ɪd/. Only the last type adds a syllable. The sound guide explains these in more detail.

## Practice

1. Fill: Yesterday I ___ (go) home and ___ (check) my email.
2. Correct: Did you found the error?
3. Make negative: The app worked.
4. Reading: who did the writer call? Was the error fixed before lunch?
5. Ask whether the app was ready yesterday.

## Four-skill task

Listen to the dialogue without text. Write the failure time and the steps taken. Listen again to distinguish an unsuccessful restart from the later successful change.

Tell a partner about an invented small problem in four steps. Partner asks two past questions. Write a 40-60 word event report using first/then/finally where useful. If that length is too difficult, start with four accurate sentences.

# 成年人软件开发英语：从第一句话到工作交流

[English version](README.md)

这是一套独立编写的零基础课程，不要求学过语法、音标或其他英语教材。软件工作只是应用场景，不会用技术术语代替基础英语教学。先学习日常与工作都需要的句子，再进入开发协作。

## 学完能做什么，不能保证什么

目标是逐步能够自我介绍、处理日常需求、读短消息、提问、描述工作，并参与熟悉话题的讨论。从第一课就同时练听、说、读、写。

读完不等于流利，也不保证达到某个 CEFR 等级。前期对应 A1 类型任务，随后进入 A2 类型交流和部分 B1 类型工作任务；这是选材方向，不是等级认证。陌生口音、多人快速讨论、复杂技术谈判仍需要后续训练。

本目录提供实际课文、解释、练习、答案和表现任务，不是只有大纲。**没有随附录制音频。** 请按听力实验室的方法使用老师、搭档或文字转语音朗读。合成语音可以帮助起步，但不能替代多种真人声音和真实对话反馈。

## 正规课程通常怎样设计

“新东方英语教程”不是一个统一产品：成人、少儿、考试、商务课程可能有不同教材、课时和目标。这里不声称复刻某个未经核实的现行产品，也不复制其课文。所有例句为本课程原创。

本课采用通用教学顺序：**分级目标 → 易懂例子 → 简短讲解 → 有提示练习 → 独立沟通 → 间隔复习 → 测评与纠错**。不是先背完所有语法再说，也不是完全不理解就硬模仿。反复练熟和换场景使用都需要。

## 时间怎么安排

可先按 **32–48 周**规划，每周约 5 天、每天 45 分钟；有条件时每周增加 15–30 分钟搭档或老师交流。这只是计划估算，有些人需要明显更久。每单元约 1–2 周，另留基础练习、复习与重测时间。单元编号不是必须完成的日期。

每个五天循环：

1. 读懂对话与词汇，看文本听，再按短语跟读。
2. 学句型，做练习，核对答案。
3. 隐藏脚本听材料，回答意思问题，再开文本核对。
4. 完成角色扮演与写作，寻求反馈或用清单自查。
5. 回忆旧内容，把当前任务换人物、时间或事实再做一次。

一天 45 分钟示例：5 分钟回忆旧句，10 分钟听读，10 分钟讲解与练习，15 分钟口语与写作，5 分钟纠错。根据任务调整；只有 20 分钟时拆成两天，不赶进度。

## 安全练习

使用虚构任务、样例数据和化名。未经许可，不向外部服务上传公司代码、客户信息、会议录音和内部文档。部署和故障练习只做角色扮演，不操作真实生产环境。

这份补充不替代原单元的基础时态、问句和发音教学。“常用”指日常生活和普通开发协作中有用，不是精确频率排名。第 1–4 节配合第 1–8 课，第 5–6 节配合第 5–12 课，第 7–12 节配合第 13–20 课。用的时候发现缺口就回查，**不要先读完本页才开始说英语**。

每节可以分两次：第一次理解例句、做四题；第二次做迁移任务。例句先懂意思，请搭档或 TTS 读出来，再遮住文本换一个事实说。本页没有录音。先答题再开答案，时间或否定说反了，即使形式正确也要改。每节四题都有答案；开放口语写作任务用检查点判断，不要求背唯一范文。

## 1. 词性与句子成分：词是什么，句中做什么

“词性”是词的类别，“成分”是它在句中的工作。test 在 The test passed（测试通过了）中是名词，在 We test it（我们测试它）中是动词。同一个词不能脱离句子死记词性。

| 词性 | 用处 | 例子 |
| --- | --- | --- |
| 名词、代词 | 给事物命名、代替它 | a server 一台服务器；it 它 |
| 动词 | 动作或状态 | run 运行；be 是；need 需要 |
| 形容词 | 描述名词或主语状态 | a slow server 慢服务器；The server is slow. 服务器慢。 |
| 副词 | 修饰动作、形容词或整句话 | run slowly 运行慢；very slow 很慢；usually 通常 |
| 限定词 | 哪一个、多少、谁的 | a、the、my、this、some |
| 介词 | 引出位置、时间等关系 | in the room 房间里；after lunch 午饭后 |
| 连词 | 连接词或分句 | and 和；because 因为；although 尽管 |

Our new app sends users a message every morning. 我们的新应用每天上午给用户发一条消息。主语是 Our new app，不只是第一个词 Our；谓语动词 sends；间接宾语 users（给谁）；直接宾语 a message（给什么）；every morning 是时间状语；new 修饰 app，作定语。

五种常见骨架：The app runs（主谓，应用运行）；The app is ready（主系表，应用准备好了）；We check the result（主谓宾，我们查结果）；We send users a message（双宾语，给用户发消息）；The change makes the page faster（宾语补足语，修改让页面更快）。表语说明主语状态或身份；宾补说明宾语变成什么、处于什么状态；状语增加何时、何地、怎样等信息。

Send me the file 和 Send the file to me 都是“把文件给我”。但 explain 不照套双宾语：Explain the problem to me（向我解释问题），不说 Explain me the problem。It is cold（天气冷）仍需要语法主语 it，不必找一个叫“它”的具体东西。

练习：1. 找 The two new tests passed yesterday 的主语和主要动词。2. 改 The page very slow。3. 改 Please explain me the error。4. The fix makes the test reliable 中 reliable 描述谁？

<details>
<summary>第 1 节答案</summary>

1. The two new tests；passed。两个新测试昨天通过。2. The page is very slow. 页面很慢，需要系动词。3. Please explain the error to me. 请向我解释错误。4. 描述 test（测试可靠），不是 fix，是宾补。

</details>

迁移：五种骨架各写一句，遮住说其中三句。搭档应能听出谁做、影响什么。沿用简单词汇，不同时挑战复杂翻译。

## 2. 冠词、数量与名词短语

普通句子中，单数可数名词通常选一个限定词：a request 一个请求、the request 那个请求、this request 这个请求、my request 我的请求，不说 the my request。首次引入非特定例子用 a/an；双方能识别用 the；泛指复数和不可数通常不加：Tests take time（测试费时间）；Software needs maintenance（软件需要维护）。

I need a test account 是“需要一个合用的测试账号”；I need the test account Sara created 是“需要 Sara 建的那个账号”。a university、an hour 看后面的声音而不是字母。Mina、Monday 等名字通常不加冠词，但名字和固定搭配有例外，整组记 at home 在家、go to work 去上班、in the office 在办公室。

information 信息、advice 建议、equipment 设备和一般表示软件的 software 不可数：some advice、two pieces of equipment。work 泛指工作不可数，a task 一项任务可数。词义变化会影响可数性：coffee 指咖啡，two coffees 点单可指两杯。

| 意思 | 可数复数 | 不可数 |
| --- | --- | --- |
| 很多 | many requests 很多请求 | much traffic 很多流量 |
| 有一些，偏肯定 | a few requests 有几个 | a little time 有一点时间 |
| 很少，常强调不足 | few requests 几乎没几个 | little time 没多少时间 |
| 更少 | fewer requests 更少请求 | less traffic 更少流量 |

a lot of 两者都可。some 常引出一些，any 常用于疑问否定，但 Would you like some tea?（喝点茶吗）是自然邀请。each/every file 后用单数动词；both files 两个都；either file 两个任选一个；neither file 两个都不。another test 再一个或另一个；the other test 剩下那个特定测试；other tests 其他测试。All tests did not pass 容易歧义，按事实说 No tests passed（全没过）或 Some tests failed（有些失败）。

练习：1. 填冠词 I found ___ error. ___ error is in the title。2. 改 We need two advices。3. 选 We have fewer / less time today。4. 改 Every files are ready。

<details>
<summary>第 2 节答案</summary>

1. an；the。发现一个错误，再指该错误。2. We need two pieces of advice. 需要两条建议；数量不重要可用 some advice。3. less，time 不可数。4. Every file is ready. 每个文件都就绪；Each file is ready 也可，更强调逐个。

</details>

迁移：请求一个新账号，再次指这个账号；用 fewer 和 less 比较两份工作量。搭档应能知道你说哪个账号。

## 3. 代词与主谓一致

I/me/my/mine 先看速查。myself 我自己、yourself 你自己、himself 他自己、herself 她自己、itself 它自己、ourselves 我们自己、yourselves 你们自己、themselves 他们自己是反身代词。She introduced herself（她介绍自己）；I checked it myself（我亲自查的）强调亲自。别为了正式乱用 myself：普通请求说 Send it to Lee and me（发给 Lee 和我），不必改成 myself。We help each other 是互相帮助，不是各自帮自己。

it 指同一个：I opened the file and read it（打开并读那个文件）。one 代替可数名词：This file is old. I need a new one（这份旧了，需要一份新的）；复数用 ones。指代不清时直接重复名字：Mina told Jo that her test failed 中 her 是谁的不清楚。

主谓一致找主语中心，不找离动词最近的名词：The list of errors is long（列表长，中心 list）；The errors in the list are serious（错误严重，中心 errors）。通常 and 连接两个主语用复数：Mina and Jo are ready。Everyone is ready、Each test has a name 用单数。There are two errors / There is one error。单数 they 仍搭配 are/have。team 等集合名词随地区和侧重点变化，要明确多人可说 The team members are ...。

练习：1. 选 The results of this test is / are ready。2. 改 Everyone have an account。3. 填 I need a newer laptop. This ___ is too slow。4. Rae told Kim that her account was locked 中已知账号属于 Kim，改明确。

<details>
<summary>第 3 节答案</summary>

1. are，中心 results。2. Everyone has an account. 每人都有账号。3. one，这一台太慢。4. Rae told Kim that Kim's account was locked. Rae 告诉 Kim，Kim 的账号被锁。重复名字比歧义好。

</details>

迁移：用 it/one 描述两个物品，写一条负责人明确的消息。读者应识别出你本来想指的人和物。

## 4. 形容词、副词、比较与介词搭配

形容词描述东西或状态：a careful reviewer 细心的评审者；The explanation sounds clear 解释听起来清楚。副词说明动作怎样：She checks carefully 她仔细检查；He explains clearly 他解释得清楚。seem/look/sound 等系动词后常接形容词。不是所有副词都有 -ly：The app runs fast（运行快）；friendly 通常是形容词。hard 是努力地、猛烈地；hardly 是几乎不：I can hardly hear you（几乎听不见）。

very useful 很有用；too slow 慢到不合适；clear enough 够清楚。enough 在名词前：enough time 足够时间。too 通常不只是“很”：too slow to use 慢到无法使用；fast enough to use 快到够用，把判断与用途连起来。

比较：faster、more reliable、better、worse，不说 more faster。as reliable as 一样可靠；not as reliable as 没那么可靠。much faster 快很多；a little faster 快一点，不说 very faster。the fastest option 要有明确比较集合，不是自动声称世界最快。

介词按组合记：depend on access 依赖权限、wait for a reply 等回复、reply to a message 回复消息、good at testing 擅长测试、interested in learning 对学习感兴趣。discuss the problem，不加 about。介词后接名词或 -ing：before deploying 部署前、without changing it 不改它。look forward to meeting you（期待见面）中的 to 是介词，不是不定式标记。

练习：1. 选 The explanation sounds clearly / clear。2. 改 This build runs more faster。3. 改 We don't have time enough。4. 改 I'm interested in learn more。

<details>
<summary>第 4 节答案</summary>

1. clear，描述解释。2. This build runs faster. 此构建运行更快。3. We don't have enough time. 没足够时间。4. I'm interested in learning more. 想进一步了解。

</details>

迁移：按速度和可靠性比较两个虚构工具，用 too/enough 说一个限制。是语言场景，不声称做过真实基准测试。

## 5. 问句、否定与实用句框

be、do/does/did、情态动词提问先看速查。Who changed it? 谁改的，who 本身是主语，普通问法不加 do；What did you change? 你改了什么，主语是 you。How long does it take? 问用时；How often does it fail? 问频率；How many attempts failed? 问次数。

嵌入问句用陈述顺序：Do you know why it failed? 你知道为什么失败吗；Could you tell me where the file is? 告诉我文件在哪。是非内容用 if/whether：Please check whether the account is active（查账号是否有效），这个 whether 不是条件。

否定有范围：I don't think it is ready 通常是“我认为还没准备好”。Not all tests passed 是“并非全过”，不等于“全没过”。We haven't approved it yet 是“尚未批准”，不保证未来一定批准。标准工作消息避免用双重否定表达一次否定：I didn't see anything（什么也没看见），不用 I didn't see nothing 表达这个意思。

实用框架：It takes ten minutes to run the test（跑测试需十分钟）；It is useful to record the steps（记录步骤有用）；There is a problem（存在问题）；I have a problem（我遇到问题），不能互相硬套。否定指令 Don't close the page（别关页面）；礼貌请求 Could you keep it open?（能保持打开吗）。

练习：1. 中性询问谁改设置，改 Who did changed the setting? 2. 改 Do you know where is the log? 3. 改 There have two errors。4. 已知五次测试三次通过，修正 No tests passed，别夸大。

<details>
<summary>第 5 节答案</summary>

1. Who changed the setting? 2. Do you know where the log is? 你知道日志在哪吗。3. There are two errors. 两个错误。4. Three of five tests passed; the other two did not pass. 或 Not all tests passed。精确次数通常更实用。

</details>

迁移：分别问时长、频率、位置。搭档故意答偏一次，你澄清需要哪类信息，不是只提高音量重复。

## 6. 时间：完成、持续与“过去之前”

先复习速查中的一般现在、现在进行、一般过去和将来表达，再增加下列对比。先想时间线，不靠某个“标志词”自动选时态。

| 对比 | 例句 | 意思 |
| --- | --- | --- |
| 过去事件与当前结果 | I fixed it yesterday. / I've fixed it. | 昨天修好 / 现在报告已修好 |
| 持续或刚结束活动 | I've been investigating it for an hour. | 已排查一小时，强调过程 |
| 完成数量 | I've checked three logs. | 查完三份，不只是花了时间 |
| 过去某时之前 | The service had stopped before I opened the page. | 打开页面前服务已停；had + 分词 |
| 将来某时正在做 | I'll be testing at two. | 两点预计在测试；will be + ing |

现在完成进行：have/has been + ing。否定 I haven't been working on that（我这段时间没在做那个）；提问 How long have you been waiting?（等了多久）。不保证此刻还继续：I've been running, so I'm tired（刚跑过，所以累）可以刚停。状态动词通常用完成式：I've known her for years（认识多年），一般不用 been knowing。I've worked here for two years 与 I've been working here for two years 都可表示仍在此工作，侧重点不同。

过去完成：When we started the demo, the session had expired（开始演示时会话已过期）。否定 It hadn't expired；提问 Had it expired before the demo? 不必把所有较早动作都写过去完成，顺序明确可用一般过去：We opened the page, signed in, and ran the test（开页面、登录、跑测试）。

used to + 原形表示过去如此、现在不同：I used to work at night（过去常夜间工作）；Did you use to work at night?；I didn't use to work at night。be used to + 名词/ing 是“习惯于”：I'm used to working remotely（习惯远程工作）；get used to 是逐渐习惯。

将来表达：will 可表示临时决定或帮助；going to 表意图；现在进行表安排；一般现在表时刻表：The train leaves at six（火车六点开）。不是固定的“哪个更确定”排名。

练习：1. 改 I've been knowing this tool for years。2. 会话先过期，演示后开始，用过去完成续写 When the demo began, ...。3. 改 I'm used to work remotely。4. 已完成恰好两份日志检查，要报告数量，选 I've checked two logs 或 I've been checking logs。

<details>
<summary>第 6 节答案</summary>

1. I've known this tool for years. 很多语境更自然说 I've used this tool for years（用多年）。2. When the demo began, the session had expired. 3. I'm used to working remotely. 4. I've checked two logs；完成进行句没交代数量。

</details>

迁移：四句汇报含结束事件、持续时间、过去之前的事、将来安排。搭档应能画出正确顺序并识别没完成的工作。

## 7. 被动语态与责任归属

主动 Jo approved the change（Jo 批准修改）；被动 The change was approved by Jo（修改由 Jo 批准）。原宾语成为主语，be 负责时间和单复数，动作动词用过去分词。关注受影响事物或不知道谁做时可用被动；负责人重要时说明谁做。

| 时间或功能 | 被动例句 |
| --- | --- |
| 惯例 | The logs are checked daily. 日志每天检查。 |
| 过去 | The account was created yesterday. 账号昨天创建。 |
| 进行中 | The issue is being investigated. 问题正在调查。 |
| 已完成 | The change has been approved. 修改已批准。 |
| 将来 | The result will be shared tomorrow. 结果明天分享。 |
| 要求 | The input must be checked. 必须检查输入。 |

否定 It hasn't been approved；提问 Has it been approved? The test passed 是主动表示通过；The test was passed by all candidates 是所有考生通过考试。不要每个过去动作都加 was。某些用法没有宾语：The error occurred（错误发生），不说 was occurred。

The door is closed 可能描述关着的状态；The door is being closed 描述正在关门。The issue is fixed（问题修好）与 The fix has been verified（修复已验证）不是同一证据，语法要保留真实状态。

练习：1. 改被动 Rin created the account yesterday。2. 表示有人正在查日志，改 The logs are checking now。3. 改 The error was occurred at noon。4. 用被动问是否已批准。

<details>
<summary>第 7 节答案</summary>

1. The account was created by Rin yesterday. 2. The logs are being checked now. 3. The error occurred at noon. 中午发生错误。4. Has it been approved? / Has the change been approved?

</details>

迁移：对同一任务写一句明确负责人，一句被动状态。检查“要求做、正在做、已批准”是否被混淆。

## 8. 不定式、动名词与分词

第二个动词形式由搭配控制：want/plan/decide/hope to check 想/计划/决定/希望检查；enjoy/avoid/finish/suggest checking 喜欢/避免/完成/建议检查；ask someone to check 请某人检查；let someone check 让某人检查；make someone wait 让某人等。help someone check 和 help someone to check 都可。

不定式表目的：I opened the log to find the error（打开日志为了找错）。动名词短语可作主语：Testing takes time（测试费时间）。介词后 -ing：Thanks for checking 谢谢检查、before sending 发送前、without restarting 不重启。区分 Checking takes time（检查这件事作主语）和 I am checking（我正在查，进行时）。

| 对比 | 含义 |
| --- | --- |
| stop testing / stop to test | 停止测试 / 停下别的事去测试 |
| remember to save / remember saving | 记得接下来要保存 / 记得过去保存过 |
| try restarting / try to restart | 试试重启能否解决 / 努力尝试重启这个动作 |
| interested person / interesting task | 感兴趣的人 / 令人感兴趣的任务 |

分词描述名词：a broken link 坏链接、a missing file 缺失文件、the person reviewing the change 正在评审的人。句首动作短语要主语一致：After checking the log, I found the error（查完日志，我发现错误）。After checking the log, the error was obvious 容易把“查”的主体错误挂到 error 上；改 After I checked the log, the error was obvious（我查后问题明显了）。

练习：1. 改 I suggest to add a test。2. 改 Thanks for help me。3. 提醒未来动作，选 Remember to save / saving the file before leaving。4. 已知我读报告，改 After reading the report, the problem was clear。

<details>
<summary>第 8 节答案</summary>

1. I suggest adding a test. 建议加测试。2. Thanks for helping me. 谢谢帮助。3. to save，走前记得存。4. After I read the report, the problem was clear. 或 After reading the report, I understood the problem。

</details>

迁移：说带目的的指令、感谢一个动作、建议尝试一个方案。搭档应能分清“试试解决”不是保证有效。

## 9. 常用从句：内容、描述、时间原因条件

从句通常有自己的主语和动词。主句能作完整陈述，从句嵌入或补充另一个结构。先找每部分主语和动词，再找连接关系。

内容从句说明想什么、说什么、问什么：I think (that) the test passed（认为测试通过）；We need to know whether it passed（需知道是否通过）；I don't know what changed（不知道什么变了，what 是 changed 的主语）。I know what you changed 是“知道你改了什么”，主语是 you。think/say 后 that 常可省，复杂时保留更清楚。

定语从句指定人或物：the colleague who helped me 帮过我的同事；the file that failed 出问题的文件；the tool which we use 我们用的工具。whose 表所属：the user whose account is locked 账号被锁的用户。关系词作宾语可省：the tool we use；作主语不能省：the tool that runs daily。别重复宾语：the file that I opened，不说 that I opened it。

逗号表示补充信息：My laptop, which is new, is slow（我的电脑是新的，但很慢，补充已知对象信息）；The laptop that is on the desk is slow（桌上的那台慢，指定哪台）。标准非限制性定语从句用 who/which，不用 that，也不省关系词。口头难说可拆两句。

状语从句：When it finishes, I'll call（完成后联系）；Because access is missing, testing is blocked（缺权限所以受阻）；Although it passed, we still need approval（尽管通过仍需批准）；If it fails, tell me（失败告诉我）。表将来时间的 when/until/as soon as 后通常现在式：I'll reply as soon as I know（一知道就回）。because + 句子：because the network failed；because of + 名词：because of a network failure，都是因网络故障。简单条件里 unless 表“除非”：We won't proceed unless access is approved（除非权限批准，否则不推进），不自动保证批准就一定推进。

练习：1. 改 I don't know why did it fail。2. 改 The file that I opened it is empty。3. 用 although 连接 The test passed. Approval is still pending。4. 改 We paused because of the account was locked。

<details>
<summary>第 9 节答案</summary>

1. I don't know why it failed. 2. The file that I opened is empty. 我开的文件为空。3. Although the test passed, approval is still pending. 4. We paused because the account was locked. 或 We paused because of the locked account。因账号锁定暂停。

</details>

迁移：读 The report that Jo sent says that testing is blocked because access is missing。找哪份报告、报告说什么、原因是什么；再用三句短口语复述同样事实。

## 10. 真实条件、假设方案与遗憾

| 场景 | 常用结构 | 例句 |
| --- | --- | --- |
| 一般规则 | if + 现在，主句现在 | If a file is empty, this tool rejects it. 此工具拒绝空文件。 |
| 未来可能发生 | if + 现在，will/can + 原形 | If access arrives, we can start. 权限到就能开始。 |
| 假想现在或未来 | if + 过去式，would/could + 原形 | If we reduced the scope, we could finish sooner. 假设缩范围，可更早完成。 |
| 与过去不同的假想 | if + had + 分词，would/could/might have + 分词 | If we had checked earlier, we might have found it sooner. 若早查，可能早发现。 |

假设中的过去式表示与现实拉开距离，不一定指过去。If I were you, I'd ask（换作我会问）是常用建议，此虚拟用法各人称可用 were。口语也会有 If I was ...，本句型先学 were。通常 if 内不放 would：If we had more time, we would test more（假设时间更多，会多测），不说 If we would have more time ...。

wish + 过去式：I wish I knew the answer（希望现在知道，其实不知道）。wish + had + 分词：I wish I had asked earlier（后悔没早问）。现实的未来期望用 hope：I hope we finish tomorrow（希望明天完成）。I wish you would ... 可能带不满，别当中性工作请求。

过去反事实在复盘中有用，但语法不能证明因果。不确定时说 might have prevented（可能本能避免），别无证据说 would definitely have prevented（一定能避免）。讨论改进而非借句型定责。

练习：1. 改 If we will get access, we can start。2. 假想现在填 If I ___ (know) the answer, I ___ (tell) you。3. 后悔没保存：I wish I ___ (save) the file。4. 现实未来目标选 I hope / wish we finish tomorrow。

<details>
<summary>第 10 节答案</summary>

1. If we get access, we can start. 2. knew；would tell。知道的话会告诉你。3. had saved，后悔没存。4. hope。这些是意思不同，不是可随意互换的礼貌等级。

</details>

迁移：说真实依赖、假设缩范围、过去改进机会。搭档应分清哪些事实、哪些方案、哪些过去已经无法改变。

## 11. 情态动词：请求、义务与推测

must not 禁止与 don't have to 不必先看速查。should 建议；may/might/could 可能；would 可礼貌表达偏好：I'd prefer a smaller change（更希望小一些的修改）；Would you check this?（请检查好吗）。might/may 不对应固定概率百分比。Can you ...? 也能是请求，不只是问能力。

We must test it（必须测）是义务；It must be a configuration issue（想必是配置问题）是强推测，不是亲眼证据。It can't be the same file 可指“推断不可能同一份”，不是文件没有能力。不确定就说 It may be ...; we haven't confirmed it（可能是……，尚未确认）。

过去用 情态动词 + have + 过去分词：It might have failed earlier（可能更早已失败）；We should have checked（过去本该查，常暗示没查）；They must have changed it（推测他们肯定改过）；It can't have finished that quickly（推测不可能那么快完成）。could have 可表示过去可能性或没用上的机会，按上下文澄清，不能当已观察事实。

could 表一般过去能力：I could read simple messages then（当时能读简单消息）。单次成功常用 I was able to restore the sample file 或 I managed to restore it（成功恢复样例文件）更清楚，不从 could 就断言成功。

练习：1. 表示不必：You ___ reply today; tomorrow is fine。2. 改 It might has failed。3. 区分 We should check 与 We should have checked。4. 证据不足，用 might 和未确认说明修正 The network definitely caused it。

<details>
<summary>第 11 节答案</summary>

1. don't have to / don't need to。2. It might have failed. 可能失败过。3. 现在/以后该检查，与对过去本应检查的判断。4. The network might have caused it, but the cause has not been confirmed. 网络可能导致，但根因未确认，没证明网络涉事。

</details>

迁移：提出礼貌请求、说明要求、报告不确定解释。让搭档指出哪句规则、哪句假设。

## 12. 转述与自然简答

转述看说话人、时间、来源。Mina 周一说 I'll send it tomorrow（明天发），你周三可说 Mina said she would send it on Tuesday（她说周二发）。这只报告承诺，不证明已发。过去转述常把 am/is 改 was、will 改 would、have done 改 had done；仍适用事实可保留现在：Jo said the office is closed on Sundays（Jo 说办公室每周日关门）。

say 后接内容，tell 后通常先接人：She said she was ready；She told me she was ready（她说/告诉我准备好了），不说 She said me ...。转述问句用陈述顺序：She asked whether I had access（问我有无权限）；She asked when I could start（问何时能开始）。请求转述：She asked me to check（请我检查）；She told me not to close the page（让我别关页）。

简答自然，不是语法不完整就错误：Have you sent it? Yes, I have（发了吗，发了）；Will you join? I think so（参加吗，想会）；Is it ready? I don't think so（好了吗，想还没）。do 替代普通动作：Rae uses this tool, and Kim does too（Rae 用，Kim 也用）。So do I 表“我也如此”；Neither do I 表“我也不”。匹配助动词：I'm ready. So am I（都好了）；I haven't tried it. Neither have I（都没试）。

反意疑问在口语常见：It's ready, isn't it?（好了，对吧）；You didn't send it, did you?（没发，是吗）。可能确认也可能带预期，语调重要。重要事实直接问并完整答：Has it been approved? It has not been approved（批准了吗，尚未批准），别依赖否定问句后的一个 yes。

练习：1. 改 She said me that it was ready。2. 过去语境转述 When can you start? 以 She asked ... 开始。3. 用 neither 回应 I haven't checked it，表示你也没查。4. 只知同事承诺发、未验证送达，修正 The report has been sent。

<details>
<summary>第 12 节答案</summary>

1. She told me that it was ready. 或 She said to me that it was ready。2. She asked when I could start. 3. Neither have I. 4. The colleague said they would send the report, but delivery has not been confirmed. 同事说会发，送达未确认。

</details>

迁移：搭档给带时间的计划，再修改一次。向第三人转述最新计划，不编造完成状态；再用正确助动词给两句自然简答。

# 从这里开始：零基础学习操作说明

[English](00-start-here.md) · [目录](README.zh.md) · [发音](01-sounds-and-spelling.zh.md) · [第 1 课](units/01-hello.zh.md)

## 准备什么

准备本教材、笔记本、录音工具，以及一种能听英文的方式：耐心的搭档、老师、词典音频或文字转语音（TTS）。本目录没有随附录音。TTS 可作稳定范例，之后还要听不同真人并练互动。手机足够，不要求购买服务或搭编程环境。

看不懂英文说明就先看中文版，不要求先懂英文才能开始。每次学一点、用出来，需要时再查参考页。

## 第一次三十分钟怎么做

1. 打开第 1 课中文版，先明白场景：两个人初次见面。
2. 请语音工具或搭档读 `Hello. I'm Mina.`。先听不说，再按一个短语跟说。
3. 把 Mina 换成自己名字，不看文本说。能替换自己的信息，比只能完美模仿更有用。
4. 听 `What's your name?` 并回答，再反问。独学可录两个角色。
5. 写 `My name is ...` 和 `I'm a developer`，职业可换。看教材核对，关上重写。
6. 从发音页学自己名字所用字母的名称。不必等全部音标学完才说话。

停顿多也算完成第一课时。今天不要试图背完整本语法。

## 最基本的术语

| 名称 | 是什么 | 例子 |
| --- | --- | --- |
| 字母 letter | 书写符号 | b、B |
| 音 sound | 听到、发出的声音 | book 开头的声音 |
| 单词 word | 有意义的词 | book 书 |
| 短语 phrase | 一起表达意思的一组词 | a new book 一本新书 |
| 句子 sentence | 本课中表达完整信息的话 | This is a book. 这是一本书。 |
| 问句 question | 索取信息 | Is it new? 是新的吗？ |
| 主语 subject | 句子主要在说谁或什么 | I work 中的 I |
| 动词 verb | 动作或状态词 | work；am |

英文词之间通常留空格，句首大写，句尾有标点。表示“我”的 I 始终大写。`I'm = I am` 是缩写，中间撇号不能随意漏。不懂英文快捷键也能打字学习。

## 每课重复的学习循环

每课按需要一至两周，后期项目可更久。课文是一套反复用的练习材料，不是读一次就算学完。

| 次数 | 主要工作 | 留下的成果 |
| --- | --- | --- |
| 第一次 | 看懂词、对话、短文，听范例 | 简短意思概括 |
| 第二次 | 学句型，先练再看答案 | 初次答案和改错 |
| 第三次 | 隐藏文本听，再核对重听 | 听到的信息记录 |
| 第四次 | 换细节，角色扮演，答追问 | 一段短录音 |
| 第五次 | 写作、脱稿说、复习旧内容 | 修订稿和下次目标 |

45 分钟示例：5 分钟回忆，10 分钟听读，10 分钟讲解和有提示练习，15 分钟说写，5 分钟纠错。忙时做 15 分钟最低版：回忆两句、听一小段、换信息答一次。最低版保持接触，不等于完整课时。

建议每周五次，再按条件加 15–30 分钟搭档或老师交流。32–48 周估计包含入门、20 课、复习、重测，只是规划范围，不是保证效果的研究结论。中断后从最后能用的任务恢复，不用惩罚式补大量进度。

## 怎样看答案才不自欺

先做再看，标记“独立完成”“看提示完成”“照范例完成”。三者都能学习，但证明的能力不同。改完后换一个名字、时间、物品或条件再做，背对原答案不等于听懂新消息。

错误记录四栏：想表达什么、实际说写、正确形式、新例句。例如：昨天 / I am check yesterday / I checked yesterday / I checked the page last night。每次重点改一两个，优先处理否定、时间、数量、所属等会改变意思的问题。

## 不紧张的起点记录

学前试五项：说姓名、听一个时间、读 This is my laptop、写一句自己、请求重复。时间请搭档或发音页语音来源帮助。记录现状，“还不会”也是有效结果。这不是正式分级考试或诊断。

第 4、8、12、16、20 课后做[测评](05-assessments.zh.md)。关键任务在可控帮助下能完成、误解能修复，就继续。薄弱项换细节再练，通常不用整套重来。

## 独学与反馈

听力只让 TTS 读英文脚本，不读题目答案。[听力训练室](04-listening-lab.zh.md)有独立脚本。口语先录，再核对事实和句型。语音识别也会误判口音，转写是线索，不是发音分数。

请搭档问“你想表达什么”“哪个时间”“完成了吗”，先纠正影响理解的错误。AI 可以生成对话，但语法反馈和事实判断也会错，自动评分不代表正式等级。

## 长期预期与安全

目标是越来越独立地处理日常和软件团队交流，不是消除口音或背完规则。听力、互动、阅读速度都需要教材外持续接触。技术英语之外也练吃饭、出行、社交。

用虚构工单、账号、名字和文件。没有授权，不上传雇主代码、客户数据、密钥、私人会议录音或截图。使用外部语言工具先遵循公司政策。事故案例教表达，不授予操作真实系统的权限。

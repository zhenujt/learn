# 可跳过的语法：见到能认出，暂时不用练熟

[English](07-optional-grammar.md) · [课程目录](README.zh.md) · [常用语法与练习](06-everyday-grammar.zh.md)

## 这一整页可以跳过

这里是对当前零基础口语路线优先级较低的结构，**不等于在所有英语中都少见**。一些在技术文档、计划和正式会议中会经常出现。遇到再看一段解释，需要自己使用时再练。本页没有考试或背诵要求。So do I 这类常用简答、普通被动、实用假设条件仍在常用页，不因名字看起来高级就跳过。

## 1. 将来完成与将来完成进行：目前可跳过

will have + 过去分词，从将来某时回看：By Friday, we will have completed the review（到周五时评审将已完成）。初学可说 We expect to finish the review by Friday（预计周五前完成）。保留是估计还是承诺，时态本身不能创造确定性。

will have been + ing 表活动持续到将来某时多久：By noon, we will have been testing for three hours（到中午就测了三小时）。可拆 We started at nine. At noon, that will be three hours of testing（九点开始，中午满三小时）。说的是持续时间，不是全部测试会通过。

## 2. 过去完成进行：目前可跳过

had been + ing 表持续到过去某时的活动：We had been testing for an hour when the power failed（停电时，已测试一小时）。活动在停电前开始。可说 We started testing an hour before the power failed（停电前一小时开始测试）。经常讲较长事故时间线时再练；入门许多任务可先用一般过去和过去完成。

## 3. 混合条件句：目前可跳过

过去的假设可以影响现在的假设结果：If we had documented it, we would know the reason now（当时记录了，现在就会知道原因）。没记录，现在想象知道，是有意混用时间。可拆 We didn't document it, so we don't know the reason now（没记录，所以现在不知道）。但拆句明确断言因果，只有证据支持才这样说，不是见到 if 就机械要求主从句同一时间。

## 4. 正式虚拟形式：先认识，主动掌握可跳过

We recommend that each change be reviewed（建议每个修改都接受评审）里，建议后的 be 用原形，即使 change 单数。It is essential that the owner approve it（必须由负责人批准）用 approve，不是 approves。这些在部分正式英语和规章中常见，也有 should be reviewed、should approve 等地区用法。

日常可说 We recommend reviewing each change（建议逐项评审）；表达要求可说 The owner must approve it（负责人必须批准）。推荐和义务不同，不要一律把 should 换 must。

## 5. 正式倒装：目前可跳过

否定或限制表达提前，可能让助动词跑到主语前：Only then did we notice the error = We noticed the error only then（直到那时才注意到错误）。Never have I seen this before = I have never seen this before（以前从未见过）。Had we known, we would have waited = If we had known, we would have waited（早知道就会等）。

读正式或强调性表达时认识即可。普通问句和 So do I 很常用，不能因为也改变语序就一起跳过。

## 6. 强调句：主动练习可跳过

It was the setting that caused the failure（导致失败的是那个设置）突出 setting。What we need is more evidence（我们需要的是更多证据）突出 evidence。口语中并非罕见，但当前可先用 The setting caused the failure、We need more evidence。事实强度要保留，强调不等于证明根因。

## 7. 独立主格与紧缩描述：目前可跳过

The review complete, we started testing（评审完成后，我们开始测试）的开头有独立主语 the review。可展开 After the review was complete, we started testing。With access restored, we could continue（权限恢复后，得以继续）也压缩了背景信息。

技术文字常见 the data collected yesterday（昨天收集的数据），按 data 作集合不可数名词的用法可展开 the data that was collected yesterday；the data to be reviewed 是待评审的数据。阅读时展开。常用页已教基本分词修饰和动作主体一致，不需要会写密集结构才算会沟通。

## 8. 非谓语的高级形式：目前可跳过

Having checked the logs, Jo sent an update（Jo 查完日志后发了更新）表示先查后发，可展开 After Jo checked the logs, Jo sent an update。She seems to have missed the message（她似乎之前漏看消息）仍是推断，不是确认事实。The file needs to be checked（文件需要检查）是不定式被动，值得早点认出，也可说 We need to check the file。

having been reviewed 等更长形式，把先完成和被动叠在一起。先展开成完整分句理解，不急着背公式清单。

## 9. 更复杂的关系结构：目前可跳过

The service returned three errors, two of which were timeouts（服务返回三项错误，其中两项超时）。The person to whom I spoke（我与之交谈的人）正式，口头用 the person I spoke to 即可。Whoever owns the task should update it（谁负责这任务，谁就应更新）泛指任何负责人。

第一句可拆 The service returned three errors. Two were timeouts。基础 who/which/that/whose 不跳过，这里只推迟较密集的变体。

## 10. 正式省略与压缩并列：目前可跳过

If necessary, restart the sample app（必要时重启样例应用）省了 it is，可展开 If it is necessary ...。Rae checked the client and Kim the server（Rae 查客户端，Kim 查服务器）省第二个 checked。口语完整说 Rae checked the client, and Kim checked the server 更容易跟上。

常规简答和形式平行的清单仍要用：We need to check, fix, and retest（需要检查、修复、重测）。各种从句省略、文学语序和修辞压缩暂不专门学。意思不清时展开缺词，涉及重要指令应请对方确认而非猜测。

## 什么时候回来学

某结构反复妨碍阅读，或工作中确实需要表达它的意思，再回来。先改成简单说法，再学一个与你有关的例句。现在跳过不妨碍二十单元主线，也不意味着英语所有语法已经穷尽。

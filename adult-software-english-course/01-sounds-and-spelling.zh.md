# 发音、拼写、数字与清楚表达

[English](01-sounds-and-spelling.md) · [目录](README.zh.md) · [听力训练室](04-listening-lab.zh.md)

## 从声音开始，不先考音标

字母名用来拼写，词里的声音用来读词。字母 A 的名称是 /eɪ/，但在 name、cat、about 中读音不同。英文拼写不是完全规则。先听词、连上意思和拼写、再说；下面音标是查阅标签，不是入学门槛。

用带音频词典或可靠朗读者听例词。本页没有录音。先选一个稳定范例，之后再听不同口音。英式和美式都有效，部分元音与 /r/ 会随口音变化。

## 拼名字用的字母名称

| 字母 | 名称音标 |
| --- | --- |
| A B C D E F G | /eɪ/ /biː/ /siː/ /diː/ /iː/ /ef/ /dʒiː/ |
| H I J K L M N | /eɪtʃ/ /aɪ/ /dʒeɪ/ /keɪ/ /el/ /em/ /en/ |
| O P Q R S T | /əʊ/ 或 /oʊ/；/piː/ /kjuː/ /ɑː/ 或 /ɑr/；/es/ /tiː/ |
| U V W X Y Z | /juː/ /viː/ /ˈdʌbəljuː/ /eks/ /waɪ/；/zed/ 或 /ziː/ |

会说 `Could you spell that?` 能拼一下吗？`Is that B or P?` 是 B 还是 P？听名称区分 B/P、D/T、M/N、G/J、E/I，不是看字母猜。重要标识完整复述，按团队约定的拼写方法确认。不要拿真实密码练口述。

符号：`.` dot 点；`-` hyphen/dash 连字符；`_` underscore 下划线；`/` slash 斜杠；`@` at。AB-20 可读 A, B, hyphen, two, zero。虚构邮箱 mina@example.com 要读清符号，不假设别人能猜。

## 小型发音地图

| 对比或特点 | 例词 | 注意什么 |
| --- | --- | --- |
| /iː/ 与 /ɪ/ | sheep 羊 / ship 船 | 音质也不同，不只是同一个音拉长缩短 |
| /e/ 与 /æ/ | bed 床 / bad 坏 | 常见范例中 /æ/ 张口更大 |
| /uː/ 与 /ʊ/ | food 食物 / good 好 | 音质、舌唇位置不同 |
| /v/ 与 /w/ | vest 背心 / west 西 | v 上齿近下唇；w 圆唇、不碰牙 |
| /θ/ 与 /s/ | thin 薄 / sin 罪 | θ 舌尖近齿或轻在齿间，气流通过，不咬舌 |
| /ð/ | this 这个、they 他们 | 舌位类似 θ，但声带振动 |
| /l/ 与 /r/ | light 光 / right 右 | l 舌接触上齿后齿龈；常见英语 r 不作这种接触 |
| 词尾辅音 | cap 帽 / cat 猫 / cab 出租车 | 保持词尾可辨，不加多余元音 |
| 辅音组合 | next 下一个、test 测试、script 脚本 | 先慢慢从词尾组合，再回正常速度 |
| 弱元音 /ə/ | about、support | 非重读位置常短而放松 |

不要用力压嗓或舌头。文字说明只能近似指导，老师可检查个人发音。不是所有中文母语者都难同一种音，按真实误解选择训练点。

## 词尾带有意思

复数或第三人称 s：多数清辅音后 /s/（tests）；浊音后 /z/（files）；/s z ʃ ʒ tʃ dʒ/ 这类咝音后 /ɪz/（changes）。最后一类多一个音节。看添加词尾之前最后的声音，不只是最后字母。

过去式 ed：除 /t/ 外的清辅音后 /t/（checked）；除 /d/ 外的浊音后 /d/（called）；/t d/ 后 /ɪd/（started、needed）。不要所有 ed 都独立读成一个音节。

练习：把 works、runs、fixes 分到 /s z ɪz/；把 helped、played、wanted 分到 /t d ɪd/。答案依次为 works /s/、runs /z/、fixes /ɪz/；helped /t/、played /d/、wanted /ɪd/。

## 重音与意群

单词有更突出的音节：TAble、comPUter、deVELoper。大写这里只标教学重音，不是正常拼写。词典重音符号可查，不要所有技术词都按字母猜。

句中重要和对比信息常突出：`I said FIFTEEN, not FIFTY.` 我说十五，不是五十。to、a、can 等在自然语流中可能弱读。先学听懂，再考虑模仿；不要为“流利”故意吞掉否定。

意群：`I've finished the page / but I haven't tested it yet.` 页面做完，但没测。按意思停，不每个词都停。语调随语境变化，不是所有问句都必须升调。

## 马上能用的数字

| 范围 | 英文 |
| --- | --- |
| 0–10 | zero, one, two, three, four, five, six, seven, eight, nine, ten |
| 11–19 | eleven, twelve, thirteen, fourteen, fifteen, sixteen, seventeen, eighteen, nineteen |
| 整十 | twenty, thirty, forty, fifty, sixty, seventy, eighty, ninety |
| 更大 | one hundred 一百；one hundred and five / one hundred five 一百零五；one thousand 一千 |
| 组合 | twenty-one 二十一；forty-eight 四十八；ninety-nine 九十九 |

单独读时 thirTEEN 与 THIRty 常有重音差异，连读时突出位置可能变化。重要数字逐位确认。容易混时 zero 比 oh 清楚。

时间：9:05 nine oh five 或 nine zero five；14:30 用 twenty-four-hour 方式读 fourteen thirty，或 two thirty p.m.。问清时区。2.5 two point five；50% fifty percent；$8.50 eight dollars and fifty cents。货币和时间习惯有地区差异。

星期：Monday 周一、Tuesday 周二、Wednesday 周三、Thursday 周四、Friday 周五、Saturday 周六、Sunday 周日。月份依次：January、February、March、April、May、June、July、August、September、October、November、December。跨地区日期写 6 July 2027 比 6/7/27 清楚，读 the sixth of July, twenty twenty-seven 或 July sixth, twenty twenty-seven。

常用序数：first 第一、second 第二、third 第三、fourth 第四、fifth 第五、sixth 第六、seventh 第七、eighth 第八、ninth 第九、tenth 第十、fifteenth 第十五、twentieth 第二十、twenty-first 第二十一。房间号常是标识，不是序数：Room 204 可读 room two oh four。

## 十分钟训练循环

1. 选真实混淆的一对词，听可靠范例，连上含义。
2. 搭档打乱读六次，你指认或写；独学可用预先打乱的 TTS 列表，听时不看。
3. 放进短句说并录音，对比词尾、重音、是否可懂，不比较波形好看与否。
4. 请听者说实际听到了哪个词，换句子避免只靠背诵猜。
5. 明天放进单元对话再练。

拼写任务：朗读者打乱 B-15、P-50、M-30、N-13，学习者写并复述。时间任务：打乱 9:15、9:50、14:30。答案是朗读者实际使用的顺序，听前不要给学习者看。

## 检查

对方能写对虚构标识吗？能听出短句里的否定、复数尾音、时间吗？不行就练小差别，同时继续有意义的课程，不在发音页无限停留。用[听力训练室](04-listening-lab.zh.md)从单音过渡到信息。

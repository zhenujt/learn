# 词汇、常用词组与主动回忆

[English](03-vocabulary-and-review.md) · [目录](README.zh.md) · [发音](01-sounds-and-spelling.zh.md)

## 学能用的内容，不追神奇词数

每课有少量核心词，先学它们，本页用于补缺与复习。认识书面词、听出声音、说话时想起来，是不同能力，分别记录。没有某个词数能保证工作流利。

新词连接五件事：意思、声音、拼写、常见词组、自己的真实或虚构例句。学 access to the data，不只学 access；学 ask someone to check，不只学 ask。读音听可靠来源，不只凭字母猜。

## 人物、日常动作与需求

| 类别 | 单词与意思 | 可用词句 |
| --- | --- | --- |
| 人 | person 人；friend 朋友；colleague 同事；family 家人；team 团队 | My colleague is here. 同事在这里。 |
| 职业角色 | developer 开发者；designer 设计师；tester 测试者；manager 经理；customer 顾客 | She is a designer. 她是设计师。 |
| 日常动作 | wake up 起床；eat 吃；drink 喝；go 去；come 来；work 工作；study 学习；sleep 睡 | I go to work at nine. 九点上班。 |
| 家居 | room 房间；door 门；window 窗；table 桌；chair 椅；kitchen 厨房；bathroom 卫生间 | Where is the bathroom? 卫生间在哪？ |
| 食物 | water 水；tea 茶；coffee 咖啡；bread 面包；rice 米饭；vegetables 蔬菜；chicken 鸡肉 | I'd like some rice. 想要米饭。 |
| 购物 | buy 买；pay 付款；price 价格；card 卡；cash 现金；receipt 收据 | Can I have a receipt? 能给收据吗？ |
| 出行 | bus 公交；train 火车；station 车站；ticket 票；stop 站点；entrance 入口；exit 出口 | Is this the right train? 是这班车吗？ |
| 健康 | tired 累；sick 生病；pain 痛；help 帮助；doctor 医生；appointment 预约 | I feel sick. I need help. 不舒服，需要帮助。 |
| 社交 | weekend 周末；hobby 爱好；music 音乐；film/movie 电影；walk 散步；enjoy 喜欢 | What do you do on weekends? 周末做什么？ |
| 时间 | now 现在；later 稍后；early 早；late 晚；yesterday 昨天；tomorrow 明天；minute 分钟；hour 小时 | I'll check it later. 稍后查。 |

真实紧急情况使用当地急救和可用语言帮助。这些词不等于医疗或应急培训。

## 连接、描述与数量

| 类别 | 内容 | 例句 |
| --- | --- | --- |
| 频率 | always 总是；usually 通常；often 经常；sometimes 有时；never 从不 | I sometimes work at home. 有时在家工作。 |
| 顺序 | first 首先；next 接着；then 然后；finally 最后；before 之前；after 之后 | First, open the page. 先开页面。 |
| 关系 | and 和；but 但是；because 因为；so 所以；if 如果；although 尽管 | I need help because the test failed. 测试失败，需要帮助。 |
| 数量 | one 一个；several 几个；all 全部；some 一些；none 没有；enough 足够；too much 太多 | We don't have enough time. 时间不够。 |
| 状态 | ready 准备好；busy 忙；available 有空；open 开；closed 关；empty 空；full 满 | The title is empty. 标题为空。 |
| 描述 | new 新；old 旧；small 小；large 大；slow 慢；fast 快；clear 清楚；unclear 不清楚 | The next step is unclear. 下一步不清楚。 |
| 比较 | faster 更快；easier 更容易；safer 更安全；better 更好；worse 更差；more reliable 更可靠 | This option is easier to test. 这方案更易测。 |

too slow 是慢过头；very slow 只强调很慢。enough 对目标足够：fast enough for this task，够本任务使用。比较要有语境。

## 软件词汇，用日常语言解释

| 词 | 本课程中的意思 | 常用组合 |
| --- | --- | --- |
| app/application | 用户使用的应用软件 | open the app 打开应用 |
| page | 应用或浏览器显示的页面 | load the page 加载页面 |
| browser | 打开网站的软件 | test in another browser 换浏览器测 |
| account | 用户身份与权限记录 | use a test account 用测试账号 |
| sign in / log in | 用账号进入服务 | sign in with a test account 用测试账号登录 |
| settings | 控制行为的设置 | check the settings 查设置 |
| request | 程序向服务发请求，也可指人的请求 | send a request 发请求 |
| response | 服务或人的回复 | check the response 查响应 |
| server | 提供服务的系统 | connect to the server 连接服务器 |
| API | 程序交流的接口 | call the API 调接口 |
| data | 系统使用的信息 | access to test data 测试数据权限 |
| database | 有组织存储的数据 | read from the database 读数据库 |
| log | 事件记录 | check the logs 查日志 |
| environment | 软件运行的配置环境 | in the test environment 在测试环境 |
| production | 真实用户使用的线上环境 | deploy to production 部署生产 |
| staging | 上线前环境，具体看团队用法 | test in staging 在预发布环境测 |
| bug / defect | 不符合要求的行为 | reproduce the bug 复现缺陷 |
| fix | 修正结果，也作修正动作 | test the fix 测修复 |
| test case | 要检查的情况和预期 | add a test case 加用例 |
| regression | 修改后原有行为出错 | add a regression test 加回归测试 |
| branch | 版本管理中的独立开发线 | create a branch 创建分支 |
| commit | 版本管理记录的一组修改 | review the commit 看提交 |
| pull request / PR | 提议评审并整合修改 | review the PR 评审 PR |
| merge | 合并修改 | merge the change 合并变更 |
| build | 生成可运行/分发产物，也指产物 | the build failed 构建失败 |
| deploy | 把版本放进某环境 | deploy to the test environment 部署测试环境 |
| release | 按团队流程使版本或功能可用 | approve the release 批准发布 |

各团队对 release、deployment、staging、owner 定义可能不同，要问，不假设公司都一样。API 常按字母名称读，代码标识遵循团队习惯。

## 状态与协作词组

| 目的 | 词句 | 不代表什么 |
| --- | --- | --- |
| 完成 | I've finished the page. 页面完成。 | 不自动表示测试、发布完成 |
| 进行 | I'm testing the download. 在测下载。 | 还不是结果 |
| 未完成 | I haven't tested large files yet. 大文件没测。 | 不等于测失败 |
| 阻碍 | I'm waiting for account access. 等账号权限。 | 还没说负责人 |
| 请求 | Could Pat provide a test account? Pat 能提供吗？ | 不代表 Pat 已答应 |
| 估计 | I expect to finish on Thursday. 预计周四完成。 | 不是无条件保证 |
| 更新承诺 | I'll post an update by 15:00 UTC+0. 三点前更新。 | 不保证三点前解决 |
| 假设 | It might be a browser issue. 可能浏览器问题。 | 未确认原因 |
| 证据 | It failed in two of three attempts. 三次失败两次。 | 不证明所有用户都失败 |
| 澄清 | Do you mean one file at a time? 指每次一个吗？ | 对方答之前未达成约定 |
| 边界 | Files above the limit are rejected. 超限拒绝。 | 不含正好到上限 |
| 不同意见 | I agree with the goal, but I'm concerned about the risk. 同意目标但担心风险。 | 不攻击个人 |
| 补漏 | Could you repeat the last point? 能重复最后一点吗？ | 是互动技能，不是失败 |
| 未知 | I haven't checked that. I'll find out. 没查，会查清。 | 不随意加做不到的期限 |

## 常见搭配与误区

- discuss the issue 讨论问题，标准直接结构不用 discuss about。
- explain the issue to me 向我解释，不说 explain me the issue。
- reply to the message 回复消息；answer the question 回答问题。
- depend on access 依赖权限；wait for approval 等批准；work on a task 做任务；be responsible for testing 负责测试。
- raise a concern 提出担忧；make a change 修改；run a test 跑测试；meet a deadline 赶上截止；miss a deadline 误期。
- actual 是实际的，不一定是当前；current 是当前。eventually 是最终，不是可能。
- issue 可指问题或跟踪条目；ticket 可指车票或工单，按语境判断。
- login 常作名词或修饰词：login page；log in 是动词：Please log in。产品标签可能另有用法。

## 做小型回忆卡组

卡片让你产出消息或提取信息，不只看译文选答案。可先每次五项新内容作为可调整工作量，不是人人最优数量。复习太多就减。

| 正面任务 | 背面一种答案 | 换信息再练 |
| --- | --- | --- |
| 请求重复最后一点 | Could you repeat the last point? | repeat 换 explain |
| 测试完成、没部署，说清两项 | I've finished the tests, but I haven't deployed it yet. | 交换完成项 |
| 问具体哪个文件夹，不是问词义 | Which folder do you mean? | 换哪个版本 |
| 缺账号，Pat 能帮，请求提供 | Could Pat provide a test account? | 换数据权限 |
| 确认 3:15 不是 3:50 | Three fifteen, one-five, not five-zero. | 换两个时间 |
| 任务依赖批准 | We need approval before we continue. | 写实际批准人 |

有授权录音或 TTS 输出时可做音频卡：正面音频，背面关键事实与脚本。纯文字卡不能测听力。云端卡组不能含公司秘密。

## 复习间隔与纠错

可在当天稍后、第 1、3、7、14、30 天回忆，作为起点，不是人人最优间隔。软件也可自动调度。失败就查原因、重学、提前再试；太容易就延长或增加未知细节。

新旧混练：学第 14 课前，问第 3 课时间、第 9 课过去经过、第 11 课当前状态。只记项目、上次独立完成、下次复习、常错点，不让整理卡组比说话耗时。

每周随机六卡口答，再写两个新例。搭档改两题细节。分别记意思、助动词形式、是否需要提示，回忆不是竞速。

## 练习与答案

1. We are waiting ___ approval. It depends ___ access.
2. actual/current status，哪个是现在的状态？
3. 改错：Could you explain me the error? Let's discuss about it.
4. 用 Pat 和测试账号把 blocked 改成具体请求。
5. not tested 等于 failed 吗？
6. 用一个日常词组和一个工作词组造新句，强行合并不自然就写两句。

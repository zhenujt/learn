# Vocabulary, Useful Phrases, and Retrieval

[中文](03-vocabulary-and-review.zh.md) · [Course](README.md) · [Sounds](01-sounds-and-spelling.md)

## Learn usable items, not an arbitrary word total

Each unit supplies a small active set. Start with those words and phrases; use this page to fill gaps and review. Knowing a word can mean recognizing it in print, recognizing its sound, or retrieving it while speaking. Record which kind you can do. There is no magic word count that guarantees work fluency.

For a new item, connect five things: meaning, sound, spelling, a common phrase, and a personal or fictional example. Learn `access to the data`, not only access; `ask someone to check`, not only ask. Hear pronunciation from a reliable source rather than guessing from letters.

## Connecting words and descriptions

| Group | Items | Example |
| --- | --- | --- |
| Frequency | always; usually; often; sometimes; never | I sometimes work at home. |
| Order | first; next; then; finally; before; after | First, open the page. |
| Relationship | and; but; because; so; if; although | I need help because the test failed. |
| Quantity | one; several; all; some; none; enough; too much | We don't have enough time. |
| State | ready; busy; available; open; closed; empty; full | The title is empty. |
| Description | new; old; small; large; slow; fast; clear; unclear | The next step is unclear. |
| Comparison | faster; easier; safer; better; worse; more reliable | This option is easier to test. |

`too slow` means excessively slow; `very slow` only emphasizes slowness. `enough` means sufficient for a goal: `fast enough for this task`. A comparison needs context.

## Status and coordination phrases

| Purpose | Phrase | What it does not mean |
| --- | --- | --- |
| Completion | I've finished the page. | Testing and release are not automatically complete |
| Ongoing work | I'm testing the download. | Not a result yet |
| Not complete | I haven't tested large files yet. | Not necessarily a failed test |
| Blocker | I'm waiting for account access. | Does not identify an owner unless you add one |
| Request | Could Pat provide a test account? | Not confirmation that Pat agreed |
| Estimate | I expect to finish on Thursday. | Not an unconditional guarantee |
| Update commitment | I'll post an update by 15:00 UTC+0. | Not a promise to resolve the issue by then |
| Hypothesis | It might be a browser issue. | Not a confirmed cause |
| Evidence | It failed in two of three attempts. | Not proof it fails for every user |
| Clarification | Do you mean one file at a time? | Not agreement until answered |
| Boundary | Files above the limit are rejected. | Does not reject files exactly at the limit |
| Disagreement | I agree with the goal, but I'm concerned about the risk. | Not an attack on a person |
| Recovery | Could you repeat the last point? | A useful interaction skill, not failure |
| Unknown | I haven't checked that. I'll find out. | Do not add a deadline you cannot meet |

## Common combinations and traps

- `discuss the issue`, not `discuss about the issue` in the standard direct pattern.
- `explain the issue to me`, not `explain me the issue`.
- `reply to the message`, but `answer the question`.
- `depend on access`, `wait for approval`, `work on a task`, `be responsible for testing`.
- `raise a concern`, `make a change`, `run a test`, `meet a deadline`, `miss a deadline`.
- `actual` means real, not necessarily current; `current` means now. `Eventually` means in the end, not possibly.
- `issue` can mean a problem or tracking item; `ticket` can mean a travel document or work record. Let context decide.
- `login` is commonly a noun/modifier (`login page`); `log in` is the verb (`Please log in`). Team product labels may differ.

## Build a small retrieval deck

Cards should make you produce a message or recover information, not merely recognize a translation. Start with five useful new items per session as an adjustable workload, not a universal optimum. Reduce the number when review becomes unmanageable.

| Card front: task | Back: one possible answer | Transfer |
| --- | --- | --- |
| Ask a colleague to repeat the final point | Could you repeat the last point? | Change repeat to explain |
| Tests complete; deployment not done. Say both | I've finished the tests, but I haven't deployed it yet. | Reverse which task is complete |
| Ask which folder, not what folder means | Which folder do you mean? | Ask which version |
| Missing account; Pat can help. Request it | Could Pat provide a test account? | Ask for data access |
| Confirm 3:15, not 3:50 | Three fifteen, one-five, not five-zero. | Change both times |
| A task depends on approval | We need approval before we continue. | Name the actual approver |

Add audio recognition cards when you have an authorized recording or TTS output: front is audio, back is the key facts and transcript. A text card cannot test listening by itself. Do not include employer secrets in a cloud deck.

## Review schedule and error repair

Try retrieval later the same day, then around days 1, 3, 7, 14, and 30. This is a starting schedule, not a proven best interval for everyone. An app may adapt spacing. If you fail, inspect the cause, learn again, and retry sooner. If easy, increase the interval or make the task less predictable.

Mix old and new: before Unit 14, ask about time from Unit 3, a past event from Unit 9, and a current status from Unit 11. Keep a tiny record: item, last independent attempt, next review, recurring confusion. Avoid making deck maintenance larger than actual conversation practice.

Weekly check: choose six cards in random order, answer aloud, and write two new examples. Have a partner change details in two prompts. Mark meaning correct, helper/verb correct, and support needed separately. Useful retrieval is not a speed competition.

## Practice and answers

1. Complete: We are waiting ___ approval. It depends ___ access.
2. Choose: actual/current status means the status now.
3. Repair: Could you explain me the error? Let's discuss about it.
4. Turn "blocked" into a request using Pat and a test account.
5. Does "not tested" mean "failed"? Explain.
6. Make a new sentence using one everyday phrase and one work phrase. Use two separate sentences if combining them would be unnatural.

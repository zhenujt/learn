## 2. 第一集简介里已核实的长单词流程

第一集简介写的是看长单词时：

1. 找母音
2. 从后往前按「一元一辅」切
3. 看字尾判断重音
4. 慢慢拼，再加快

简介举例 `maneuverability`，并给出老师小技巧：

- 先写出子音：`m n v r b l t`
- `eu` 字母念 `[u]`
- `i` 字母念 `[ɪ]`
- 其余母音音标都念 `[ə]`
- 整词标音：`[məˌnuvrəˈbɪlətɪ]`

从这条标音可以看出她用的约定：

| 特征 | 第一集实际写法 | 不要和英式课混用 |
| --- | --- | --- |
| 括号 | 方括号 `[ ]` | 本课跟视频用 `[]`；斜杠是另一套常见写法 |
| 长音号 | 没有 `ː` | 不要把 `[i]` 改写成 `/iː/` 再去跟她的板书 |
| 美式 r 与重音 | 有 `ˈ` `ˌ`；词里可见卷舌相关习惯 | 不要用非卷舌英音 `/ɜː/` 去套 bird |
| go / name 一类音 | KK 课里常写成 `[o]` `[e]` | 英式课常写成 `/əʊ/` `/eɪ/` |

简介还说：不论自然发音还是 KK，都要先能正确读出那个单词。自然发音是拼读线索，KK 是标音；先会读，再用来记单词。

## 3. 跟课用的完整 KK 符号表

KK（Kenyon–Knott）主要记**美式**读音。下面按常见 KK 教学表列出符号、例词和发音提示。数量会因教材而异：核心大约是 **14 个单元音 + 3 个双元音 + 24 个辅音**；有的表再加 `[ju]` 和 `[ts dz tr dr]`。这不是国际音标全表，也不是英式 20 元音表。

文字只是动作提示。跟周老师的课时，以她的口型和录音为准。

### 3.1 单元音

| KK | 例词与含义 | 初学提示 | 常见英式课写法 |
| --- | --- | --- | --- |
| [i] | see 看见；me 我 | 舌位高、偏前；KK 通常不写长音号 | /iː/ |
| [ɪ] | sit 坐；big 大的 | 比 [i] 松、略低，不能只截短 [i] | /ɪ/ |
| [e] | name 名字；day 天 | KK 常把这个滑动音写成 [e]，不是 bed 的音 | /eɪ/ |
| [ɛ] | bed 床；ten 十 | 开口中等；不要和 [e] 当成同一个符号 | /e/ 或 /ɛ/ |
| [æ] | cat 猫；apple 苹果 | 开口比 [ɛ] 大；不是字母 A 的名称 | /æ/ |
| [ɑ] | hot 热的；father 父亲 | 美式常把 hot、father 一类开后元音标成 [ɑ] | hot 英式常 /ɒ/；father 常 /ɑː/ |
| [ɔ] | law 法律；saw 锯 | 后、圆唇；有的美式口音与 [ɑ] 合流 | /ɔː/ |
| [o] | go 去；home 家 | KK 常写 [o]，不是字母 O 在所有词里的读法 | /əʊ/ 或 /oʊ/ |
| [ʊ] | book 书；good 好的 | 较松的后高元音，不能只截短 [u] | /ʊ/ |
| [u] | food 食物；blue 蓝色的 | 高、常圆唇；KK 通常不写长音号 | /uː/ |
| [ʌ] | cup 杯子；but 但是 | 重读、较开、不圆唇 | /ʌ/ |
| [ə] | about 关于；sofa 沙发 | 非重读、放松；第一集长词里大量用它 | /ə/ |
| [ɝ] | bird 鸟；work 工作 | 重读卷舌元音 | 英式非卷舌常 /ɜː/ |
| [ɚ] | teacher 老师；water 水 | 非重读卷舌元音 | 英式常是不发词尾 r 的 /ə/ |

### 3.2 双元音

KK 教学表通常另外列出这 3 个；[e] 和 [o] 已放在上表。

| KK | 例词与含义 | 初学提示 |
| --- | --- | --- |
| [aɪ] | time 时间；my 我的 | 一个音节内从较开滑向 [ɪ] |
| [aʊ] | now 现在；house 房子 | 从较开滑向圆唇的 [ʊ] |
| [ɔɪ] | boy 男孩；choice 选择 | 从 [ɔ] 一类位置滑向 [ɪ] |

有的表把 [ju]（you 你、use 使用）也单列。它常是 [j] 加 [u]，不一定算额外的基本元音。

## 4. 辅音：24 个核心项目

KK 辅音符号大体与常见 IPA 一致。清音通常不振动声带，浊音通常振动。字母名称不等于辅音：字母 B 的名称是 [bi]，不是辅音 [b]。

### 4.1 塞音

| KK | 例词与含义 | 初学提示 |
| --- | --- | --- |
| [p] | pen 笔；cap 帽子 | 双唇闭合后放开；重读音节开头常送气 |
| [b] | bag 包；job 工作 | 双唇闭合后放开，浊音 |
| [t] | ten 十；cat 猫 | 舌尖或舌端在上齿后齿龈处阻塞后放开 |
| [d] | day 天；bad 坏的 | 舌位与 [t] 相近，浊音 |
| [k] | key 钥匙；back 后面 | 舌后部接近软腭后放开 |
| [g] | go 去；bag 包 | 舌位与 [k] 相近，浊音 |

### 4.2 摩擦音

| KK | 例词与含义 | 初学提示 |
| --- | --- | --- |
| [f] | fine 好的；leaf 叶子 | 上门齿轻近下唇，清音 |
| [v] | very 很；save 保存 | 动作类似 [f]，加振动；不要换成 [w] |
| [θ] | think 想；both 两者 | 舌尖轻近上齿或齿间，气流通过，不要咬紧 |
| [ð] | this 这个；mother 母亲 | 舌位类似 [θ]，浊音 |
| [s] | see 看见；bus 公交车 | 齿龈附近留窄通道，清音 |
| [z] | zoo 动物园；busy 忙的 | 舌位类似 [s]，浊音 |
| [ʃ] | she 她；fish 鱼 | 比 [s] 靠后，唇可稍圆 |
| [ʒ] | vision 视力；measure 测量 | 舌位类似 [ʃ]，浊音；不是 [dʒ] |
| [h] | he 他；help 帮助 | 气流通过声门，口形预备后面的元音 |

### 4.3 塞擦音、鼻音、近音

| KK | 例词与含义 | 初学提示 |
| --- | --- | --- |
| [tʃ] | chair 椅子；watch 看 | 先阻塞再摩擦，紧密连成一个音 |
| [dʒ] | job 工作；page 页面 | 与 [tʃ] 类似，浊音；有的书写成 [ʤ] |
| [m] | me 我；team 团队 | 双唇闭合，声音走鼻腔 |
| [n] | no 不；ten 十 | 舌尖接触齿龈，气流走鼻腔 |
| [ŋ] | sing 唱；long 长的 | 舌后部阻塞；标准 sing 末尾没有额外 [g] |
| [l] | light 光；feel 感觉 | 气流走舌头两侧；词尾常较暗 |

| 组合 | 例词与含义 | 怎样看 |

| [ts] | cats 猫（复数）；gets 得到 | [t] 接 [s]，常被 48 表另列，一般不算额外音素 |

## 7. 用 KK 拆 apple，并用第一集的方法拆长词

**apple** 常见 KK：`[ˈæpl]` 或 `[ˈæpəl]`。

1. `ˈ`：第一音节重读，不是一个要读出来的音。
2. `[æ]`：cat 那一类音，不是字母名称 [e]。
3. `[p]`：双唇闭合后放开。
4. `[l]` 或 `[əl]`：末尾轻读。
5. 放入 `I have an apple.`（我有一个苹果）。用 an，因为开头是元音声音。

**maneuverability** 按第一集简介：

1. 子音骨架：`m n v r b l t`
2. `eu` → `[u]`
3. 字母 `i` → `[ɪ]`
4. 其余母音 → `[ə]`
5. 标音：`[məˌnuvrəˈbɪlətɪ]`
6. 先慢拼，再加快。简介说许多长词能用音节规则拆，不是把整串字母当一块死记。

这条规则是简介里的学习策略，不能保证每个英文单词都这样切。不规则词仍要听范例。

## 8. 十分钟练习

每天只选 2–4 个音，对照视频口型。建议顺序：

| 阶段 | 重点 |
| --- | --- |
| 1 | [i ɪ e ɛ æ]；分清 [e] 与 [ɛ] |
| 2 | [u ʊ ʌ ə]；重读与弱读 |
| 3 | [ɑ ɔ o ɝ ɚ]；跟美式范例，不套英式 /ɒ əʊ ɜː/ |
| 4 | [aɪ aʊ ɔɪ] |
| 5 | 清浊辅音、[θ ð v w]、[l r n ŋ] |
| 6 | 用第一集流程拆 2 个长词，再回主课短句 |

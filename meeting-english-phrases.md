## Demo Grammar and Retelling Practice

Practice reusable structures from April's workflow explanations, Carson's native preview demo, and the later publishing discussion. This is grammar practice, not an assessment of the speakers; transcripts also cannot establish actual pronunciation. These rewritten examples are not added to observed phrase counts.

| Pattern | Grammar use | English practice | Chinese translation |
| --- | --- | --- | --- |
| I am still working on + noun / -ing | Describe ongoing work; on is followed by a noun or gerund. | I'm still working on embedding the simulator in the page. | 我还在将模拟器嵌入页面。 |
| Let me + base verb | Introduce what you will explain or demonstrate next. | Let me walk you through the workflow. | 让我带大家看一下整个流程。 |
| whether + subject + verb | Use statement order inside an indirect question. | We need to check whether the software is approved. | 我们需要确认该软件是否已获批准。 |
| Once / When + present tense, ... will ... | Use present tense in a future time clause. | Once the account is approved, we will test the integration. | 账号获批后，我们会测试集成。 |
| can be + past participle | Describe a possibility in the passive voice. | The files can be published as separate packages. | 这些文件可以作为独立的包发布。 |
| noun + past participle phrase | A reduced passive relative clause describes the noun. | The simulator embedded in the page uses native rendering. | 嵌入页面的模拟器使用原生渲染。 |
| Both solutions + plural verb | Both refers to two items and takes a plural verb. | Both solutions use native rendering. | 这两个方案都使用原生渲染。 |
| If + condition, ... can ... | Make the action depend on a stated condition. | If the native output is unchanged, we can skip native publishing. | 如果原生产物未变化，我们可以跳过原生包发布。 |
| send ... to / share ... with / reply in | Learn the preposition together with its verb and purpose. | Send the notification to the submitter and reply in the original thread. | 将通知发送给提交者，并在原讨论串回复。 |

Practice in two passes: first give a roughly 30-second update covering current work, approach, and next step; then explain a workflow in roughly 90 seconds through trigger, input, processing, result, and exceptions. Substitute your own task each time. Answer: What happens if the output is unchanged? Who owns this part? Check subject-verb agreement, prepositions, and statement order after whether.

The workflow retrieves the variables, transforms the token data, and generates platform-specific outputs. We can publish the outputs as separate packages. If the generated output for a platform is unchanged, we can skip that publishing stage.

这个工作流获取变量、转换 token 数据，并生成各平台的产物。我们可以将产物作为独立的包发布。如果某个平台生成的产物未变化，就可以跳过对应的发布阶段。

## Practice Update

This is a practice script for an iOS CI discussion, not a report of verified progress.

> A quick update from my side: I'm still working on the iOS CI setup.

Reusable structure: **current work -> open question or blocker -> next step -> follow-up**.

## 只保留一条主线

英文字幕 → 意思与意图 → 符合事实的短回复 → 确认澄清 → 听与复习。

以网站当前学习计划为主安排，方法文档里的活动计入这段时间，不额外叠加。如果目标是工作沟通，可以立即进入[工作沟通资料](../04-工作沟通B1/README.zh.md)。遇到具体声音问题再查[发音资料](../01-发音入门/README.md)，不把它当作入门考试。

每周用一个新句子检查理解，并记录用了哪些帮助。目标是逐步能用，不保证固定时长后达到某个等级。

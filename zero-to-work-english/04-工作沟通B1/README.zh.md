# 软件工作沟通：字幕理解与短回复

[English version](README.md)

不必先完成通用 A1/A2 课程，才能开始有辅助的工作沟通练习。文件夹的 B1 标签表示大致课程方向，不是入门门槛，也不保证学完就达到 B1。陌生的技术讨论可能需要更多语言能力和帮助。

## 从这里开始

1. 打开[14 单元会议课程](software-meeting-demo-14-day.zh.md)，先完成字幕起步练习：读五条短问题、解释意思、回复，再展开答案。
2. 优先练 Day 2、8、9、12 的澄清、状态、阻塞和跟进，可以使用提示卡。主持和 Demo 按需要再学。
3. 字幕结构不清楚时，查[语法指南](software-workplace-grammar-guide.zh.md)的一个相关小节。里面的可选 12 周安排不是需要与网站计划同时完成的第二套课。
4. 使用[场景表达手册](software-workplace-phrases.zh.md)第 1 层的短回复，再按实际任务扩展。重要的负责人、日期、条件与承诺需要核对。

读、听、回复放在网站每日计划中一起练。14 个单元和 24 周计划都是可调整的参考，不是水平期限。使用虚构或明确获准使用的材料，不向外部工具上传保密会议记录。

## 怎样检查实际进展

用一条没有背过的短字幕，找出其中的动作、状态、时间、否定和条件。能否按事实回复，或提出具体澄清问题？记录是否用了字幕、翻译或提示卡，逐步减少帮助。误解会改变意思的句型需要回练。

## 后续可以扩展的话题

工作邮件、礼貌请求、自我介绍、站会、Bug 报告、需求、代码评审、会议发言、进度、跨时区协作、技术写作和面试都可以继续学。它们不是进入会议前必须依次完成的课程，这份话题列表也不代表已经有十二门完整独立课。
